Свёртка меню моделей по подписке

Плоский список из двенадцати строк сворачивается в четыре строки подписок. Полоски квот переезжают на строку подписки, у модели остаются имя и ярус. Клик по подписке раскрывает её модели, прежняя группа сворачивается.

Форма задачи: меню открыто

Меню открылось. Развёрнута группа текущей пары, у неё точка слева от имени. Остальные подписки свёрнуты, их квоты видны на строке группы.

Правила для согласования

  • Первый уровень это подписки. Строка группы называет подписку и несёт её полоски квот, окно 5ч и неделя.
  • Две подписки одного вида дают две строки группы, квоты у каждой свои.
  • Клик по строке подписки раскрывает её модели и сворачивает прежнюю группу. Развёрнутая группа одна.
  • Подписка с одной моделью раскрывается тем же кликом по строке группы.
  • Строка модели остаётся ступенью лестницы, имя и ярус. Полоски квот со строк моделей уехали, у подписки они одни.
  • Меню открывается с развёрнутой группой текущей пары: вердиктной при включённом переключателе, ручного выбора при выключенном. Точка у имени группы называет, где стоит текущая пара.
  • Выбор строки группу не сворачивает и меню не закрывает. Следом выбирают глубину, меню закрывает кнопка.
  • У поля ввода разговора свёртка та же, переключателя там нет.
