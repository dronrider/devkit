макет для согласования

Показ уровня

Ручной выбор глубины виден в двух местах до запуска: мини-полоска в поле подписки чата и чип глубины рядом с приоритетом на экране задачи. Уровень чипа приходит из записи этапа, а не с доски.

Мини-полоска в поле подписки чата

Выбор глубины в меню отражается мини-полоской прямо в поле модели: уровень виден без открытия меню, поле остаётся одной строкой. Без ручного выбора полоски нет.

панель чата: ручной выбор сделан
high

Мини-полоска называет уровень следующего запуска и стоит в одной строке с полем модели.

панель чата: ручного выбора нет

Следующий запуск едет вердиктом, показывать нечего, и полоски нет.

Чип глубины на экране задачи

Чип стоит вторым, сразу за приоритетом. Уровень берётся из записи этапа: текущей или последней работы строки, ручной выбор или вердикт pick. Строка без записи уровня чип не рисует.

экран задачи: строка с записью этапа
P1 high

Приоритет P1 и глубина high рядом: человек ищет в одном месте, чем сейчас живёт строка.

экран задачи: строка без записи этапа
P1

Записи уровня нет, и чипа нет: молчание честнее пустой ступени.

Правила для согласования

  • Мини-полоска в поле подписки чата показывает ручной выбор и живёт один запуск, как сам выбор.
  • Чип глубины на экране задачи приходит из записи этапа, а не с доски: у строки без записи уровня чипа нет.
  • Оба места говорят одно и то же слово уровня, латиницей флага agentctl.
