# DK-002: devkitctl: сводка по журналу запусков .devkit/log (частота команд, доля ошибок)

model: haiku

## Ход работы

Добавлена субкоманда `stats [-C dir]`, которая читает журнал .devkit/log, группирует запуски по парам (утилита, команда), и выводит таблицу с числом запусков каждой команды и долей ошибочных запусков. Отсортировано по частоте убыванием, в конце итоговая строка. Битые строки (не 4 поля табами или нечисловой код) молча пропускаются. Обновлены README.md и docstring модуля. Добавлены тесты.

## Сценарий проверки

Агентский сценарий.

Из корня devkit запустить:
```
python3 devkitctl/devkitctl.py stats
```

Ожидаемо:
- код выхода 0
- в выводе таблица со строками taskctl и shipctl с числами запусков
- в конце итоговая строка с суммой по журналу

Затем:
```
python3 devkitctl/devkitctl.py stats -C /tmp
```

Ожидаемо:
- код выхода 2
- в stderr сообщение про отсутствие журнала
