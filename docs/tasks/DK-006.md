# DK-006: agentctl: выбор модели под задачу по метаданным доски для делегирования субагенту

Модель под задачу хочется выбирать автоматически, но сменить модель своей же
сессии агент не может, этот рычаг харнес отдаёт только пользователю. Штатная
дверь другая: спавн субагента с явной моделью. Значит нужен решатель, который
по задаче говорит, какой моделью её исполнять, а сессия-диспетчер делегирует.

Анализировать задачу заново не нужно: всё уже лежит на доске. Тип, цена и
разбивка ранга (третье слагаемое это неопределённость) дают детерминированный
маппинг без ИИ внутри утилиты. `agentctl pick <ID>` читает `docs/TASKS.md` и
печатает вердикт: строку `model: ...` для машинного разбора и причину.

Правила маппинга (v1, живут в коде и в README):

- тип LLD -> opus (дизайн);
- неопределённость >= 4 -> opus, пометка «сначала грумминг, не исполнять»;
- цена XL -> opus, пометка «разбить на серию, целиком не отдавать»;
- цена S при неопределённости <= 1 -> haiku;
- остальное (M, L, S с неопределённостью 2-3, неоценённая цена) -> sonnet,
  для неоценённой цены пометка «цена не оценена».

## DoD

- `agentctl pick <ID>`: вердикт по правилам выше, флаг `-C` как у остальных
  инструментов, задача ищется во всех секциях доски, отсутствие задачи и
  нечитаемый ранг дают внятную ошибку или дефолт sonnet.
- Журнал запусков в `.devkit/log` как у taskctl/shipctl.
- Тесты: табличный юнит на маппинг, интеграционный на разбор живой доски.
- Дока: `agentctl/README.md`, упоминание в корневом README и пункт в
  `RULES.board.md` про делегирование по вердикту.

## Сценарий проверки (агентский)

Шаги выполняются с машины агента, прод не трогают (выкат devkit это
пересборка локальных бинарей).

1. Собрать: `cd ~/projects/devkit/agentctl && go build -o ~/go/bin/agentctl .`;
   код возврата 0.
2. Во временном git-репозитории с доской (`taskctl init --prefix T`) завести
   четыре задачи: `taskctl add --title a --type task --rank "0+1+1+0+0"
   --cost S`, вторую с `--rank "0+1+3+0+0" --cost M`, третью с `--type LLD
   --rank "25+5+5+0+3"`, четвёртую с `--type task --rank "25+5+5+0+3" --cost M`.
   `agentctl pick T-001` печатает `model: haiku`, `T-002` даёт
   `model: sonnet`, `T-003` даёт `model: opus` и слово «дизайн», `T-004` даёт
   `model: opus` и слово «грумминг».
3. `agentctl pick T-999` завершается ненулевым кодом с ошибкой «нет на доске».
4. `go test ./...` в `devkit/agentctl`: код возврата 0.
