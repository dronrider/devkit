# DK-013: agentctl: opus по умолчанию, sonnet без размышлений, haiku только атомарное

Указание пользователя после DK-009: sonnet моделью по умолчанию не годится.
По умолчанию задачи исполняет opus, sonnet берёт только задачи, не требующие
размышления, haiku только совсем атомарные правки.

Перевод на метаданные доски (границы выбраны при постановке):

- haiku: цена S и неопределённость 0, совсем атомарная правка с очевидным
  подходом;
- sonnet: цена S или M при неопределённости не выше 1, подход уже выбран и
  думать не над чем;
- всё остальное исполняет opus, включая L, неопределённость 2-3, неоценённую
  цену и нечитаемую разбивку ранга (неизвестность теперь трактуется в пользу
  сильной модели);
- верх маппинга не меняется: override, fable для LLD ценой L/XL, opus для
  остальных LLD, грумминг при неопределённости >= 4, разбивка XL. Правило
  «L при неопределённости 3» растворяется в новом дефолте и убирается.

Тесты на новые границы, README-таблица обновляется той же веткой.
