# DK-017: agentctl: совет отложить до сброса для любого сдвига вниз с цены M и выше

Сейчас квотный корректор (DK-012, дизайн в `docs/lld/DK-010-quota-corrector.md`)
дописывает в человеческую строку вердикта совет «если не горит, отложить до
сброса» только сдвинутым вниз LLD. По лестнице DK-015 задачи ценой M и выше
тоже считаются достойными opus, и сдвиг opus -> sonnet на них это та же потеря
качества, только в исполнении, а не в дизайне. Повышение effort до high (пол
sonnet) калибр модели не компенсирует, оно лишь дешёвая частичная страховка.

Правка: совет печатается при любом сдвиге вниз, если цена задачи M и выше
(LLD остаётся как есть, у него условие по типу, не по цене). Решение
по-прежнему за диспетчером, pick только проговаривает. S-задачи совет не
получают: на них дешёвая модель штатный исполнитель и без всякого сдвига.

## Сценарий проверки

Агентский. После слияния (выкат попутный, мелочь или поезд):

1. `cd ~/projects/devkit/agentctl && go test -count=1 ./...` завершается
   кодом 0.
2. Во временном корне с доской, где задача task ценой M, и с HOME, где снимок
   квоты держит `week_opus` в дефиците, `agentctl pick` печатает третьей
   строкой хвост про корректор и совет отложить до сброса.
3. Та же проверка для задачи ценой S: хвост про корректор есть, совета нет.

Шаги ничего не меняют, итог по коду возврата и строкам вывода.
