# DK-027: слабый ассерт гитигнора в самопроверке devkitctl: грепает голое «не гитигнорнут»

## Что происходит

Тест config_is_not_gitignored в devkitctl_test.py сверяет находку доктора
про негитигнорнутый конфиг выката с одной голой фразой «не гитигнорнут».
Соседние тесты машинных игноров сверяют полную строку находки с путём, а
здесь зелёный прогон обеспечит любая находка семейства: cmdout, ship.lock,
журнал запусков. Проверка deploy.local сломается молча, тест останется
зелёным.

## Чего хотим

Ассерт сверяет полную строку находки с путём конфига выката
(.devkit/deploy.local). Сломанная проверка конфига краснит тест, чужие
находки гитигнора его не прикрывают.

## DoD

Прогон пакета tools/devkitctl зелёный. Проба красноты: при подмене текста
находки конфига строгий ассерт падает, прежний голый оставался зелёным.

## Ранг

`0+1+0+5+1 = 9`, P3.

- Серьёзность 0: пользователь снаружи ничего не замечает, работа не встаёт.
