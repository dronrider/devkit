## Сценарий проверки (агентский)

Проверяется машинная часть постановки: строка цели заводится обычным taskctl,
доска её принимает, файл цели ложится с разделами, коммит доски идёт флагами
самой команды. Живая доска и живой `HOME` не трогаются, всё в одноразовой
директории.

Шаги:

1. `mktemp -d`, `HOME` внутрь неё, `git init` в синтетическом проекте;
2. `taskctl init --prefix GT`;
3. `taskctl add --title "Цель: ..." --type task --rank "25+8+3+0+3" --cost XL`;
4. `taskctl file GT-001`;
5. `taskctl show GT-001`;
6. дописать в файл цели разделы по заготовке скилла и погрепать их;
7. `taskctl lint`;
8. `taskctl set ... -m "docs(tasks): ..."` (коммит доски флагом команды);
9. `head -4` фронтматтера скилла и `hooks/check-symbols.py` по тронутым файлам.

Ожидаемое: строка GT-001 с заголовком от слова «Цель:», типом task, ценой XL и
ссылкой на `tasks/GT-001.md`; в файле цели пять разделов и строки бюджета с
бакетами `week_all` и `week_max`; `lint` зелёный; коммит доски создан; у скилла
разбираемый фронтматтер с полями `name` и `description`; запрещённых символов
нет.
