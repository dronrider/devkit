# DK-095: скилл goal-loop, виток: чтение состояния, нарезка, конвейер задачи, журнал, маркеры

## Ход работы

- Исполнение: субагент opus/medium по вердикту pick (квота: week_all 2%, снимок 29м назад, сдвига нет), 2026-08-03.
- Виток дописан к постановке тремя разделами скилла: «Виток» (шесть шагов от
  чтения состояния до маркера), «Маркеры выхода» (контракт с оболочкой
  goal-run) и «Где виток сворачивает». Временный абзац про отсутствие витка
  снят, шаг 8 постановки теперь называет, чем цель ведётся дальше.
- Рабочая фаза делегирована `board-batch` вторым входом, своих шагов спавна,
  ревью и слияния виток не держит. Цикл добавляет к процедуре пачки ровно два
  отличия: `pick --goal` на исполнителе и ревьювере, строка витка в «Журнале».
- Обкатка на синтетике вскрыла отличие от дизайна: `taskctl file <ID>`
  переписывает ссылку строки на файл задачи, поэтому колонка ссылки состав цели
  не держит и надёжен только список в «Задачах цели». Отличие записано в
  скилле (шаг 3) и в LLD DK-079, раздел «Форма цели».

## Сценарий проверки

Агентский. Шаги выполняются с машины агента, живая доска и прод не трогаются:
проверка идёт на синтетическом проекте во временном `HOME`, а из репозитория
читается только текст скилла. Слоя два: что в скилле есть контракт витка, и что
команды, которые он предписывает, на синтетике работают именно так, как в
тексте написано.

Скрипт целиком, звать из корня клона (`sh scenario.sh <путь к клону>`):

```sh
#!/bin/sh
# Сценарий проверки DK-095: раздел витка в скилле goal-loop и его команды.
# Живая доска не трогается: проверка идёт на синтетическом проекте во временном
# HOME, а из репозитория читается только текст скилла.
set -eu
repo=${1:-$PWD}
sand=$(mktemp -d)
export HOME="$sand/home"
export DEVKIT_HOME="$repo"
mkdir -p "$HOME/.devkit/quota" "$sand/bin"
PATH="$sand/bin:$PATH"; export PATH
(cd "$repo/agentctl" && go build -o "$sand/bin/agentctl" .)

ok() { echo "OK: $1"; }
bad() { echo "FAIL: $1"; exit 1; }

echo "== 1. разделы витка на месте, временного абзаца нет =="
for h in '^## Виток$' '^## Маркеры выхода$' '^## Где виток сворачивает$'; do
  grep -q "$h" "$repo/skills/goal-loop/SKILL.md" || bad "нет раздела $h"
done
grep -q "Пока раздела витка" "$repo/skills/goal-loop/SKILL.md" && bad "временный абзац остался"
for m in '`continue`' '`done`' '`over`' '`wait-human`' '`stuck`'; do
  grep -q -- "$m" "$repo/skills/goal-loop/SKILL.md" || bad "маркер $m не назван"
done
grep -q 'marker: continue' "$repo/skills/goal-loop/SKILL.md" || bad "формы машинной строки маркера нет"
grep -q 'board-batch' "$repo/skills/goal-loop/SKILL.md" || bad "рабочая фаза не зовёт board-batch"
ok "разделы, пять маркеров, форма marker: и вызов board-batch"

echo "== 2. символы клавиатурные =="
python3 "$repo/hooks/check-symbols.py" "$repo/skills/goal-loop/SKILL.md" \
  "$repo/docs/tasks/DK-095.md" "$repo/docs/lld/DK-079-autonomous-loop.md"
ok "запрещённых символов нет"

echo "== 3. синтетическая цель: постановка =="
now=$(date +%Y-%m-%dT%H:%M); reset=$(date -v+3d +%Y-%m-%dT%H:%M)
cat > "$HOME/.devkit/quota/claude-code.local" <<EOF
taken = $now
week_all = 22% сброс $reset
week_max = 6% сброс $reset
EOF
proj="$sand/proj"; mkdir -p "$proj"; cd "$proj"
git init -q .
taskctl init --prefix SY --name "синтетика" >/dev/null
git add -A && git -c user.email=a@b -c user.name=a commit -qm init
taskctl add --title "Цель: синтетика витка" --type task --rank "25+7+2+0+3" --cost XL
taskctl file SY-001
python3 - <<'PY'
import pathlib
p = pathlib.Path("docs/tasks/SY-001.md")
p.write_text(p.read_text() + """
## Цель

DoD: команда печатает строку.

## Бюджет

бюджет: week_all <= 25
бюджет: week_max <= 10
ярус: base

## Задачи цели

Заводит нарезка первым витком.

## Журнал

- снимок 2026-08-03T09:00: week_all 10%, week_max 2%
- 2026-08-03, нарезка: 2 задачи SY-002..SY-003, порядок по dep; continue

## Итог
""")
PY

echo "== 4. шаг 2 витка: гейт бюджета, строка витка счёт не ломает =="
out=$(agentctl spend --goal docs/tasks/SY-001.md --record)
echo "$out"
echo "$out" | head -1 | grep -qx 'gate: ok' || bad "гейт не пустил виток"
echo "$out" | grep -q 'точек расхода 2' || bad "строка витка попала в цепочку снимков"
grep -c '^- снимок ' docs/tasks/SY-001.md | grep -qx 2 || bad "--record не дописал снимок"
ok "gate: ok, посчитаны только снимки, --record дописал точку"

echo "== 5. шаг 3 витка: нарезка =="
taskctl move SY-001 in-progress
taskctl add --title "первая задача цели" --type task --rank "25+7+1+0+5" --cost M --link "tasks/SY-001.md"
taskctl add --title "вторая задача цели" --type task --rank "25+7+1+0+3" --cost M --link "tasks/SY-001.md"
taskctl dep add SY-003 SY-002
taskctl file SY-002 >/dev/null
taskctl lint
grep -q 'SY-002.*tasks/SY-002.md' docs/TASKS.md || bad "file не перебила ссылку, оговорка в скилле лишняя"
ok "строки заведены, зависимость стоит, lint зелёный"

echo "== 6. шаг 4 витка: pick с потолком цели =="
agentctl pick SY-002 --goal docs/tasks/SY-001.md --record | tee "$sand/pick.txt"
grep -qx 'tier: base' "$sand/pick.txt" || bad "потолок яруса не применён"
grep -q 'потолок цели: base' "$sand/pick.txt" || bad "причина среза не названа"
agentctl pick SY-002 --goal docs/tasks/SY-001.md --role review | grep -q 'потолок цели' || bad "ревьювер идёт мимо потолка"
grep -q 'потолок цели: base' docs/tasks/SY-002.md || bad "--record не записал причину"
ok "вердикт срезан потолком, причина в файле задачи"

echo "== 7. шаг 5 витка: строка журнала и коммит =="
printf -- '- %s, SY-002 закрыта по агентскому сценарию, выкат проверен; continue\n' "$(date +%F)" >> docs/tasks/SY-001.md
git add docs/tasks/SY-001.md docs/TASKS.md docs/tasks/SY-002.md
git -c user.email=a@b -c user.name=a commit -qm "docs(tasks): SY-001 виток нарезки"
git log --oneline -1
agentctl spend --goal docs/tasks/SY-001.md | grep -q 'точек расхода 3' || bad "цепочка снимков сбилась"
ok "строка витка легла в журнал, гейт читает цепочку дальше"

echo "== 8. маркер over: исчерпание бюджета =="
python3 - <<'PY'
import pathlib
p = pathlib.Path("docs/tasks/SY-001.md")
p.write_text(p.read_text().replace("бюджет: week_all <= 25", "бюджет: week_all <= 5"))
PY
out=$(agentctl spend --goal docs/tasks/SY-001.md)
echo "$out"
echo "$out" | head -1 | grep -qx 'gate: over' || bad "гейт не остановил цикл"
taskctl move SY-001 blocked --reason "бюджет исчерпан"
taskctl list blocked | grep -q 'блок: бюджет исчерпан' || bad "цель не встала в Blocked с причиной"
ok "gate: over, цель в Blocked с причиной"

echo "== 9. уведомитель на стопе =="
python3 "$repo/hooks/notify.py" "цель SY-001: over" "бюджет исчерпан по week_all"
ok "уведомитель зовётся формой из скилла"

rm -rf "$sand"
echo "СЦЕНАРИЙ ПРОЙДЕН"
```

Ожидаемый итог: каждый шаг печатает свой `OK:`, последняя строка «СЦЕНАРИЙ
ПРОЙДЕН», код возврата 0. Уведомитель на синтетике честно молчит и говорит,
почему: корень проекта лежит под `TMPDIR`, и живой баннер про песочницу был бы
ложным.
