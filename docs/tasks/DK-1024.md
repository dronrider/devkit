# DK-1024: Сторож выборки prose: запись долгоживущего текста без эталонов в контексте отбивается подсказкой с командой и жанром

## Что происходит

Стенд obeycheck по DK-1022, 16 сентября 2026 года, сценарий
`38-code-name-calque`, задача агенту дописать раздел README. По транскриптам
haiku скилл `prose` не позвал ни в одной из 19 сессий, ни с описанием скилла
в списке, ни с фразой ядра «перед письмом взять выборку скиллом prose» в
контексте (раскладка глубины core). Sonnet позвал в 7 из 9 сессий на
раскладках без правок и в 0 из 3, когда в RULES.md добавился пункт о кальках.
Правило мимикрии держится только на дисциплине модели. Выборка
`prose.py sample` следа в сессии не оставляет, и сторожу на записи не на что
опереться. Образец механики рядом. PreToolUse-хуки на Read
(`check-reread.py`, `check-longfile.py`) отвечают подсказкой вместо
содержимого, регистрация тройкой `PRE_READ_SCRIPTS`, `HOOK_LAYOUT`,
`PRE_READ_GAPS` в devkitctl, у хука своя находка доктора.

Ярус mini достаётся атомарной правке с очевидным подходом, и абзац README
ровно такая. Каждый README, файл задачи и черновик от haiku пишется без
корпуса, а замер DK-446 показал, что без корпуса манера идёт в карикатуру.
У sonnet то же в двух сессиях из девяти, а правка резидентного текста может
уронить вызов до нуля незаметно для автора правки.

## Чего хотим

Запись README, файла задачи, черновика или шага скилла в сессии, где выборка
не бралась, не проходит, а подсказка называет команду выборки с жанром.
Сценарий 38 на mini показывает вызовы prose в каждой сессии, и находка
доктора называет неподключённый хук.

## Границы

Запись долгоживущего файла через Bash (heredoc, sed, tee) за границей
задачи, решено развилкой «граница». Файлы доски пишет сам taskctl, и его
строки хук видеть не должен. Bash-запись едет отдельным черновиком.

### Приписка 2026-09-16: что проверил разбор

пишет (`kit/skills/prose/prose.py`, `cmd_sample`). Сторож `check-prose.py`

субагента там свой. Строки PreToolUse с матчером на запись в `HOOK_LAYOUT`
нет, категорию придётся заводить. Стенд по умолчанию несёт два хука
(`tools/obeycheck/env.go`, `hookSettings`), остальные приносит раскладка
сценария. Дубля на доске нет: DK-618, DK-619 и DK-622 про поля корпуса и текст
находки, архивная DK-523 завела сам скилл и точки вызова без сторожа.
Условий, посильных только человеку, не нашёл: секретов, доступов и внешних
шагов у задачи нет, а правило всем сессиям решено развилкой «режим».
