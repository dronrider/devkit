# DK-1052: dashboard secret не печатает токен агентской сессии

## Что происходит

2026-09-18, ревью DK-822. Доктор после DK-822 значение токена дашборда показывает только человеку за терминалом, агентской сессии он называет файл, ключ и команду `dashboard secret`. Сама команда (`cmdSecret` в tools/dashboard/main.go) печатает значение безусловно, без проверки терминала и признака агентской сессии.

Агент, которому доктор назвал команду, позовёт её следующим шагом, и токен входа уедет в вывод инструмента, в контекст и в транскрипт. Путь, закрытый в докторе, остаётся открытым шагом дальше.

## Чего хотим

Значение токена дашборда видит человек за своим терминалом, агентская сессия получает отказ с названным местом.

## Границы

Проверка терминала не годится: шаги человека в DK-481, DK-726 и DK-826 зовут команду как `$(dashboard secret)`, а подстановка команды терминалом не считается. Признак берётся тот же, что в докторе после DK-822, Go-код бинаря его уже читает (`tools/dashboard/chats.go`, foreignVars). Это второй рубеж: DK-739 уже убрала команду из разрешённых агенту по умолчанию. Рубеж `hooks/check-read-secret.py` вызов не ловит, он сверяет пути. Обобщение признака на профили харнесов отложено черновиком DK-1053. Условий, посильных только человеку, обход не нашёл: искал в CONNECT.md, README дашборда, perms.py и архиве DK-739 и DK-822.

## Развилки

Прятать значение в `dashboard secret` тем же признаком, что в докторе, либо отдавать агенту токен только в подпроцесс через secretctl?

- «признак»: чем команда узнаёт, что значение печатать нельзя?
  - решает: исполнитель
  - рекомендация: признак агентской сессии без проверки терминала: три шага человека зовут команду подстановкой
  - вариант: проверка isatty, ломает вызов человека через подстановку команды
  - источник: код tools/devkitctl/dashboard.py (agentic_session), доска DK-739

## DoD

- `dashboard secret` в агентской сессии значение не печатает, кончается ненулевым кодом и называет файл, ключ и то, что команду зовёт человек.
- Вызов человека, в том числе `$(dashboard secret)` и конвейер, работает как раньше.
- Тесты кладут обе ветки с подменой окружения, настоящих токенов в фикстурах нет.
- README дашборда и CONNECT.md говорят о поведении одной фразой, строка доктора по-прежнему называет команду.
