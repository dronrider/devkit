# DK-1054: Экран задачи получает дату движения строки, поля строки сверяет тест

## Что происходит

2026-09-18, ревью DK-650, уточнено обходом 2026-09-19. Экран задачи получает строку доски типизированной `boardRow` (tools/dashboard/tasks.go), список получает сырой ответ `taskctl list --json`. Из полей `jsonRow` (tools/taskctl/json.go) в типе нет одного, `Moved`. `Armed` и `Arm` до экрана доезжают другим каналом: `taskDeps` зовёт `taskctl dep list --json`, и `handleTask` кладёт их в ответ, это записано в README дашборда и держится тестом chain_test.go. `static/app.js` уже рисует чип даты правки из `row.moved`, а сервер поля не отдаёт, и чип молча не появляется. Тесты проверяют только, что строка `row.moved` есть в тексте app.js.

Чип даты правки на экране задачи не работает с момента появления. Класс поломки тот же, что у ранга в DK-650: новое поле ответа taskctl видно в списке и пропадает на экране задачи, и сторожа на это нет.

## Чего хотим

Экран задачи показывает дату движения строки, а поле ответа taskctl, которого нет в типе дашборда, находит тест.

## Границы

Перевод экрана задачи на сырой ответ не берётся: `boardRow` читает десяток мест сервера (chat.go, checkrun.go, lld.go, goal.go, pulse.go, runs.go, round.go, sessions.go, wake.go). Условий, посильных только человеку, обход не нашёл: искал в README и тестах дашборда.
