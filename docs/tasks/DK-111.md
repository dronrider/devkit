# DK-111: Цель: корп-контур по DK-074, конвейер поверх внешнего трекера

## Цель

Довести до конца серию корпоративного контура по принятому LLD
[DK-074](../lld/DK-074-corp-contour.md): семь задач DK-081..DK-087 закрыты в
архив вместе с доками из раздела «Затрагиваемая документация» LLD. После этого
корп-проект подключается командой `devkitctl corp`, доска живёт в боковой
директории, статусы, оценка и ворклоги уезжают в трекер через `trackctl`, а
слияние честно останавливается на границе MR.

DoD, агентский:

- `taskctl show DK-081`..`DK-087` показывают все семь задач в архиве;
- общий тест-набор из `.devkit/deploy.local` (ключ `test`) проходит с кодом 0;
- живой прогон на чистом окружении из раздела «Тесты» LLD проходит с кодом 0:
  временный «корп»-репозиторий с чужим pre-commit, подключение `devkitctl
  corp`, цикл задачи от `trackctl take` через `submit` до отказа `shipctl
  merge` с подсказкой MR на подложном адаптере; затем клон сносится,
  клонируется заново, повторный `devkitctl corp` восстанавливает обвязку
  (доска цела, второй прогон ничего не меняет).

DK-088 (LLD имитации человеческого темпа) в цель не входит: скоуп LLD выносит
её отдельным решением.
