## Что происходит

Разбор недели 14-21 сентября упёрся в данные: `taskctl spend` не нашёл данных по 231 этапу из 359 и 246 сессиям; «Ход работы» тринадцати задач несёт разработку нулевой длительности; goal-watch.log хранит три часа, notify и chat-in по 12-17 часов; журнал квоты замусорен тестовыми блоками; chat-in.log на 500 из 501 строк одинаковый отказ по DK-706 и DK-808; съёмщик квоты мёртвого харнеса glm-code отказал 37 раз; «Выкат» двух задач ссылается на несуществующие sha.

Оптимизацию расхода нельзя ни замерить, ни доказать: свод по этапам слеп на две трети, история сторожей стирается за сутки.
