# DK-1122: Стена прогона померена на -j 3, 4, 5 и 8, потолок длительности стоит по замеру

Цель: [tasks/DK-1084.md](tasks/DK-1084.md)

## Что происходит

Потолок воркеров `-j 8` стоит умолчанием в `tools/devkitctl/parallel.py:192`, а
ключ `test` из `.devkit/deploy.local` зовёт раннер без `-j`. Число это мерилось
целью DK-166 на свободной машине. Комментарий над `MAX_WORKERS` в
`tools/devkitctl/suite.py:30` говорит про плато между восемью и шестнадцатью
воркерами и откат к двадцати четырём. Соседний прогон и дашборд в том замере не
участвовали.

Замеров стенного времени одного зелёного прогона на разных `-j` в файлах
семейства нет. Есть пары «уронило или нет». DK-537 зеленеет на `-j 5`, DK-926 на
`-j 4`, DK-811 и DK-1000 на `-j 3`. Стена 322 с под `-j 8` из DK-347 мерилась при
load average 3.5-15.

Потолок длительности прогона слияния сегодня выбирается на глаз. Порог 120 с
цели DK-166 снят решением пользователя 2026-08-16 и не возвращается.

## Чего хотим

Стена одного зелёного полного прогона померена на `-j 3`, `4`, `5` и `8` на
одной машине. По замеру выбран потолок длительности прогона слияния, и число это
записано с причиной.

## DoD

- Стена полного прогона `parallel.py` померена на `-j 3`, `4`, `5` и `8`, по три
  захода на каждое значение, с load average каждого захода. Числа лежат в
  разделе «Проверка» файла задачи.
- Потолок длительности прогона слияния назван числом с причиной. Ориентир восемь
  минут, стена 322 с из DK-347 с половиной запаса.
- Замер повторяется командой, и команда эта записана.

## Ранг

`25+4+1+0+2 = 32`, P2 по своим слагаемым. С наследованием от цели DK-1084 ранг
строки 65.

- Серьёзность 25. Потолок выбирается на глаз, обход дешёвый. Взять число из
  старого замера.
- Ценность 4. Прогон слияния идёт перед каждым слиянием, и его длительность
  видит каждая задача.
- Неопределённость 1. Приём назван человеком развилкой «длительность» цели,
  открыт объём замеров.
- Поправка на баг 0. Строка заводит замер.
- Рычаг 2. Ускоряет свой поток по теме бюджета машины.

Цена S. Вид приёмки агентский, барьеров из шести не названо. Стена и load average
читаются с машины агента.
