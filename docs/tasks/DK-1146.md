# DK-1146: Хук спавна ставит этап организации по полю agent шаблона

## Что происходит

Этап «Хода работы» хук спавна `agent-watch.py` выбирает по карте имён
определений субагентов, зашитой в сам хук. Своё определение организации в эту
карту не попадает, и работа под ним следа в записи задачи не оставляет.
LLD DK-972 (`docs/lld/DK-972-plan-templates.md`), решение 10, говорит, что свой
этап организации это скилл или определение субагента, а находит его хук по полю
`agent` шаблона.

## Чего хотим

`agent-watch.py` читает шаблон задачи (парсер подмножества на python уже есть у
профилей), находит этап по маске `agent` и пишет его `title`. `internal/stage`
принимает заголовок из шаблона. Сегодняшняя карта по именам определений
остаётся запасной для случая, когда шаблона нет.

Тесты: спавн субагента по определению организации даёт строку этапа в «Ходе
работы», незнакомое определение идёт по старой карте.

## Границы

Состав встроенных этапов здесь не меняется, ворота не трогаются. Работа идёт в
хуке и в приёме заголовка, файлы с agentctl и internal/trace не пересекаются.
Строка может идти параллельно с DK-1143.

## DoD

Этап организации со своим определением субагента получает след без правки хука.

## Ранг

`50+5+1+0+2 = 58`, P1.

- Серьёзность 50: работа под своим определением в запись задачи не попадает, и
  ход работы снаружи неполон.
- Ценность 5: выигрывает организация со своими этапами, у devkit карта и так
  совпадает.
- Неопределённость 1: маска и запасная карта названы LLD.
- Поправка на баг 0: новая работа.
- Рычаг 2: снимает правку хука с каждого нового определения субагента.
