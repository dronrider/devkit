# DK-1245: развилка ревью из worktree доезжает до ответа с main

## Что происходит

2026-09-30, DK-1233. Ревьювер писал развилку через `taskctl -C /Users/rider/projects/devkit-dk-1233 decide --ask`, парковка закоммитила на main только строку доски и запись «Ждёт человека» (коммит 569842514). На main `taskctl decide DK-1233` отвечает «открытых развилок нет», развилка лежит в копии файла задачи в worktree ветки.

Панель показывает блок вопроса по строке доски, а ответ человека уходит на main, где развилки нет: `decide --answer` её не найдёт. Разговор с человеком по итогам ревью не сходится без ручного `-C`.

Обход назвал причину. Стражи несимметричны. boardGuard (tools/taskctl/worktree.go:100) гонит правку доски в основной чекаут. Правку файла задачи из worktree он не трогает, поэтому развилка легла в дерево ветки штатно. У решётки decide стража нет вовсе. decideRecord (tools/taskctl/decide.go:48) молча берёт копию файла от того корня, где стоит вызов. История DK-1233 подтвердила окно в десять часов. Парковка 569842514 закоммитила на main только записи «Ход работы». Голова развилки с решением доехала коммитом f10119e57 к 11:05.

## Чего хотим

Решётка decide получает стража по образцу reviewTreeGuard (tools/taskctl/worktree.go:82, DK-536). Вызов из основного чекаута на задачу с несбитой веткой отказывает с подсказкой писать из дерева. Строка-инструкция в блоке вопроса (tools/taskctl/decidechat.go:70) зовёт команду с адресом дерева через `-C`. Перевоз файла задачи парковкой на main обход отверг. Доску правит диспетчер и только в основном чекауте, дерево задачи сносится слиянием. Перевезённая копия повторила бы отказ DK-536.

## Развилки

Парковка везёт файл задачи из worktree на main, или развилки ревью пишутся сразу на main, или ответ панели ходит в дерево ветки?

- «страж»: как развилка ревью из дерева ветки доезжает до ответа с main?
  - решает: исполнитель
  - рекомендация: страж решётки по образцу reviewTreeGuard и инструкция блока с адресом дерева: правка одного условия, звонков вызова трогать не надо
  - вариант: парковка перевозит файл задачи на main при живой развилке дерева
  - источник: код, tools/taskctl/worktree.go:82 и :100 (reviewTreeGuard, boardGuard), tools/taskctl/decidechat.go:70, возражение против перевозки: правила доски п. 9, архив DK-536

## DoD

Вызов decide из основного чекаута на задачу с несбитой веткой отказывает с подсказкой адреса дерева. Блок `--chat` несёт инструкцию с этим адресом. Сценарий DK-1233 на стенде даёт отказ. Развилка лежит в дереве, ответ приходит с main, расхождение копий видно сразу.
