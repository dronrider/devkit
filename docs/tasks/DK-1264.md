# DK-1264: У тестов дашборда одна конвенция, и она записана в стиль

## Что происходит

Обзор tools/dashboard показал расхождение записи с жизнью. В docs/STYLEGUIDE.md
записано правило. Тест лежит рядом с модулем, зовётся `<модуль>_test.go`,
общего файла тестов на несколько модулей нет. В каталоге из 86 тестовых
файлов у 43 нет парного исходника. Имя теста называет сцену (chatbusy,
designlogin, humansend), парного модуля у сцены нет.

Стенд пакета собран в чужих для него файлах. writeScript из server_test.go
зовут 41 файл, newTestEnv 35. TestMain всего пакета лежит в tasks_test.go
рядом с tasksEnv и sandboxRealNotifier. У крупнейшего файла каталога
chats.go (4422 строки) парного теста нет вовсе. Его тесты размазаны по
восьми сиротам chat*_test.go.

## Чего хотим

Одна конвенция, по которой новый тест кладётся без раздумий. По ней же
находится место теста правки. Направление выбирает развилка «стандарт тестов
дашборда». После выбора расхождение устраняется в одну сторону: либо
оговорка в стиле, либо перетасовка файлов.
