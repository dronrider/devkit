# DK-1265: chats.go дашборда разбит на тематические файлы

## Что происходит

chats.go это крупнейший файл каталога. В нём 4422 строки, около ста функций
и больше десяти тем. Жизненный цикл разговоров (запуск, стоп, сказать,
вопрос-ответ), бланк-чаты, память chatStore, скриншоты (handleChatShot),
заголовки (titleFill), модель и harness, разбор пейна (paneState),
самолечение (healClaim), архив.

Семья вокруг разделена осознанно. chat.go держит реплики, chatwatch.go
сторож смерти, chatpast.go заходы окна, chatsweep.go уборку. Слипся сам
бог-файл. Парного chats_test.go нет, тесты размазаны по восьми файлам.
Любая правка чата читается в двух гигантах сразу. Это исходник и
chat_test.go на 3345 строк.

## Чего хотим

Домен чатов уезжает в пакет chats по разрезу из обзора: хендлеры жизненного
цикла, бланк-черновики, скриншоты с заголовками, разбор пейна. Семья chat*
едет в тот же пакет, наружу смотрят явные точки входа, внутренности с
маленькой буквы. Поведение наружу не меняется, маршруты и ответы те же.
