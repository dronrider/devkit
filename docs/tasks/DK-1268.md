# DK-1268: Структурный долг дашборда собран местами и разбирается приписками

## Что происходит

Накопленный некритичный объём из обзора каталога. Ни один пункт не блокирует
работу, вместе это заметное трение. Поэтому долг собран одной строкой и
разбирается приписками.

Места из обзора 2026-10-01:

- static/app.js это 18010 строк одним файлом. Тестируется только из Go
  через node-скрипты testdata. Правка фронта не локализована ни в коде,
  ни в тестах.
- Приём memo-кэша написан руками в четырёх местах. Память процесса под
  своим замком, ключённая отпечатком файла или TTL, плюс forget* для
  стендов. Места: txs и chunks в feed.go, pulseSteps в pulse.go, peerKinds
  в sessions.go. Пятая память повторит рецепт и забудет forget*. Кандидат
  на общий тип в internal.
- git зовётся напрямую runProc("git") в projects.go:119 и board.go:149.
  Готовый internal/gitrun при этом простаивает. Знание о запуске git живёт
  в двух местах.
- README дашборда это 534KB и 43 раздела одним файлом. Поиск по нему
  медленный, ревью правки читает мегабайт. При следующей большой правке
  рассмотреть раскладку по темам с оглавлением.

## Чего хотим

Каждое место разбирается припиской к этой строке, когда до него доходит
очередь. Прямо здесь оно помечается «сделано» с коммитом либо уезжает
отдельной строкой, если выросло. Строка долга одна.

## DoD

  строкой доски.
