# DK-1272: Третья подписка routerai со своей лестницей ярусов и съёмщиком трат

## Что происходит

Разговор 2026-10-01, нужен провайдер верхних ярусов лестницы моделей. Каталог routerai.ru разобран через публичный /api/v1/models, в нём 538 моделей. Поддержка Anthropic-совместимого /v1/messages подтверждена документацией. API отвечает с машины без VPN.

Цены за 1M вход/выход/кеш в рублях. У claude-sonnet-5.5 это 217/1086/21.7, у claude-opus-5.5 будет 434/2173/21.7.

Бесплатного текстового яруса нет. Нулевая цена стоит у 40 моделей, и почти все они медиа-генерация или реранкеры. Единственная текстовая stealth/space-bunny-alpha анонимна и нестабильна. Доступность моделей от баланса не зависит. При пустом балансе платный вызов падает с ошибкой 402.

Смок 2026-10-01 прошёл, ключ лежит в secretctl под именем routerai-token. Все четыре ступени лестницы ответили в формате Anthropic Messages с заголовком Authorization Bearer. Base URL для харнеса это https://routerai.ru/api, клиент докладывает /v1/messages сам. Развилка про base URL из «Вопроса» снята этим смоком. Размышляющие модели отдают блоки thinking и text, бюджет max_tokens в 16 токенов размышление съедает целиком.

Лестница glm-code уже гетерогенная, это поправил обход груминга. В машинном слое стоит pro = "claude-code:opus", но действующей подписки claude-code нет, и появится ли она, неизвестно. Опираться на это назначение нельзя. Вырожден ярус max, в glm-code.toml он сложен в glm-5.3. Ревью дизайна и приёмка LLD сидят на base-модели. У подписки z.ai моделей выше нет.

Факты обхода 2026-10-01, чтобы исполнитель не проверял их второй раз. Секция [quota] в профиле обязательна по наличию, но может стоять пустой, это штатно выключенный корректор (validateProfile, harness.go 305). Для платного баланса есть готовая механика budget_based с бюджетом в машинной секции (DK-033), но скрипт съёмщика в профиль кладётся только после живой проверки эндпоинта, прецедент DK-181. У доктора болванка второй подписки прибита к имени glm-code (ALT_SUB_HARNESS, devkitctl.py 519), без складывания алиасов DK-751 субагент в сессии routerai уйдёт на алиас первой лестницы. Токен харнеса лежит в settings.json его каталога по образцу z.ai, механики секрета в профиле нет. Соседние строки: контроль трат это территория DK-365 и её ребёнка DK-182, предупреждение раньше отказа это DK-501, задача ссылается на них и не дублирует.

Детект профиля routerai обязан стоять пустым. Клиент тот же claude, детект дал бы пересечение с claude-code, и харнес выбирает только явный DEVKIT_HARNESS от run и exec. Сам routerai встаёт в enabled машинного слоя, это калитка раскладки правил, хуков и скиллов. Дока DK-090 и README devkitctl пишут про вторую подписку в единственном числе, третьему харнесу нужна правка на множественное, она в скоупе задачи.

## Чего хотим

Routerai встаёт третьей самостоятельной подпиской со своей полной лестницей ярусов, предмет закрыт человеком 2026-10-01. Профиль собирается из каталога сервиса: mini это deepseek-v4-flash за 5.2 руб, base это glm-5.3 из того же каталога, не из подписки z.ai, pro это claude-sonnet-5.5, max это claude-opus-5.5. Кандидатов верха подтверждает стенд prompt-test. Сессия на routerai живёт целиком на токенах сервиса, пересечений с лестницами glm-code и claude-code нет, они остаются как есть. По умолчанию машина остаётся на glm-code, routerai выбирается явно. Входное условие одно, ключ routerai в secretctl под именем routerai-token.

## Границы

Лестница glm-code и её машинный слой не трогаются, подписка claude-code остаётся вне задачи. Предупреждение раньше 402 это территория DK-501, корректор ярусов по подпискам это DK-365 и её ребёнок DK-182, задача ссылается на них и не дублирует.

## Сценарий проверки

Съёмщик и доктор проверяются во временных каталогах на фейковом эндпоинте, живая машина не участвует. Шаги агентские и гоняются после слияния в main.

1. Профиль третьей подписки несёт бюджетный съёмщик.

   ```sh
   grep -q 'budget_based = true' kit/harness/routerai.toml && grep -q 'snap/routerai.sh' kit/harness/routerai.toml && test -x kit/harness/snap/routerai.sh && echo "шаг 1: профиль с budget_based и исполнимым съёмщиком на месте"
   ```

   Ожидаемый итог. Профиль объявляет съёмщика script и флаг budget_based, скрипт исполним.

2. Съёмщик снимает баланс с фейкового эндпоинта и кладёт первый сэмпл истории.

   ```sh
   D=$(mktemp -d) && echo "$D" > /tmp/dk1272-stand && mkdir -p "$D/srv/v1" "$D/home" "$D/.devkit" && printf 'enabled = ["routerai"]\n' > "$D/.devkit/harness.local" && printf '{"data":{"credits":4508.74}}' > "$D/srv/v1/credits" && (python3 -m http.server --directory "$D/srv" 39713 >/dev/null 2>&1 &) && sleep 1 && printf '{"env":{"ANTHROPIC_BASE_URL":"http://127.0.0.1:39713","ANTHROPIC_AUTH_TOKEN":"stub"}}' > "$D/home/settings.json" && DEVKIT_HARNESS=routerai DEVKIT_HARNESS_HOME="$D/home" DEVKIT_QUOTA_BUDGET=5000 HOME="$D" sh kit/harness/snap/routerai.sh > "$D/snap.txt" && pkill -f '3971[3]' && grep -q 'balance_all = 10%' "$D/snap.txt" && grep -q 'window5h_rub = 0 руб' "$D/snap.txt" && grep -q 'balance_rub = 4509 руб' "$D/snap.txt" && grep -q 4508.74 "$D/.devkit/quota/routerai.history.local" && echo "шаг 2: снимок несёт долю бюджета, нулевое окно и остаток, история приняла сэмпл"
   ```

   Ожидаемый итог. Снимок из четырёх строк, остаток 4509 руб, в истории первый сэмпл.

3. Окно трат считается по истории сэмплов.

   ```sh
   D=$(cat /tmp/dk1272-stand) && printf '{"data":{"credits":4318.5}}' > "$D/srv/v1/credits" && python3 -c "import datetime;print((datetime.datetime.now()-datetime.timedelta(hours=2)).strftime('%Y-%m-%dT%H:%M')+' 4700')" > "$D/.devkit/quota/routerai.history.local" && (python3 -m http.server --directory "$D/srv" 39713 >/dev/null 2>&1 &) && sleep 1 && DEVKIT_HARNESS=routerai DEVKIT_HARNESS_HOME="$D/home" DEVKIT_QUOTA_BUDGET=5000 HOME="$D" sh kit/harness/snap/routerai.sh > "$D/snap2.txt" && pkill -f '3971[3]' && grep -q 'window5h_rub = 382 руб' "$D/snap2.txt" && grep -q 'balance_rub = 4319 руб' "$D/snap2.txt" && test "$(grep -c '' "$D/.devkit/quota/routerai.history.local")" = 2 && echo "шаг 3: окно трат посчитано от сэмпла двухчасовой давности"
   ```

   Ожидаемый итог. Окно 382 руб, остаток 4319 руб, в истории два сэмпла.

4. agentctl quota печатает рублёвые строки снимка.

   ```sh
   D=$(cat /tmp/dk1272-stand) && printf 'taken = %s\nbalance_all = 12%%\nwindow5h_rub = 119 руб\nbalance_rub = 4312 руб\n' "$(date +%Y-%m-%dT%H:%M)" > "$D/.devkit/quota/routerai.local" && HOME="$D" agentctl quota --harness routerai > "$D/quota.txt" && grep -q 'window5h_rub: 119 руб' "$D/quota.txt" && grep -q 'balance_rub: 4312 руб' "$D/quota.txt" && ! grep -q 'потрачено' "$D/quota.txt" && ! grep -q 'предупреждение' "$D/quota.txt" && echo "шаг 4: quota печатает траты окна и остаток, проценты и предупреждения скрыты"
   ```

   Ожидаемый итог. Строки window5h_rub и balance_rub с суммами. Строк процентов и предупреждений нет. Доля бюджета из снимка достаётся корректору, показ балансового провайдера остаётся рублёвым.

5. Доктор раскладывает болванку каждой подписке из машинного слоя.

   ```sh
   D=$(cat /tmp/dk1272-stand) && H="$D/doc-home" && mkdir -p "$H/.devkit" && printf 'enabled = ["glm-code"]\n\n[glm-code]\nhome = "~/.devkit/claude-glm"\n\n[routerai]\nhome = "~/.devkit/routerai-home"\n' > "$H/.devkit/harness.local" && (HOME="$H" devkitctl doctor --fix > "$D/doctor.txt" 2>&1 || true) && test -f "$H/.devkit/claude-glm/settings.json" && test -f "$H/.devkit/routerai-home/settings.json" && grep -q 'ANTHROPIC_BASE_URL' "$H/.devkit/routerai-home/settings.json" && echo "шаг 5: болванка разложена обеим подпискам с ключом home"
   ```

   Ожидаемый итог. Файл settings.json появился в каталогах обеих подписок, включая routerai.

6. Дока говорит о подписках во множественном числе и о типе провайдера.

   ```sh
   grep -q 'по одному на каждый' tools/devkitctl/README.md && grep -q window5h_rub docs/lld/DK-090-heterogeneous-ladder.md && grep -q 'с пополняемого' tools/dashboard/README.md && echo "шаг 6: дока обновлена"
   ```

   Ожидаемый итог. Все три якоря находятся.

Живой шаг с настоящим токеном в обкатку не входит. После выката на машине с ключом routerai-token прогоняются снятие и показ. Команда agentctl quota refresh --harness routerai снимает настоящий баланс, agentctl quota --harness routerai и панель печатают траты за окно и остаток рублями.
