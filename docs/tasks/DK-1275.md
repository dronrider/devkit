# DK-1275: devkitctl test не протаскивает фильтр -k в python-прогоны

## Что происходит

Обёртка `devkitctl test` принимает хвост ключей после пути и передаёт его
дальше, но python-прогон его отвергает: suite.py отказал с ошибкой
«unrecognized arguments: -k alt_sub» при живом прогоне в ревью DK-1272.
Точечный запуск python-тестов недоступен, каждая проверка едет полным
пакетом, у devkitctl это 331 секунда.

## Чего хотим

Хвост ключей после пути доезжает до python-прогонов целиком, фильтр `-k`
отбирает тесты по имени.

## DoD

`devkitctl test <путь> -k <имя>` гоняет только отобранные тесты, проверено
прогоном на живом пакете devkitctl.

## Ранг

`0+4+0+0+2 = 6`, P3.

- Серьёзность 0: обход полный прогоном дешёвый и очевидный, конвейер не
  встаёт.
- Ценность 4: заметное ускорение каждой правки с python-тестами, полный
  пакет идёт пять с половиной минут против секунд у фильтра.
- Неопределённость 0: симптом и место названы, обёртка и suite.py известны.
- Поправка на баг 0: новая работа, ничего работавшего не ломается.
- Рычаг 2: python-прогоны касаются каждой задачи, трогающей devkitctl.
