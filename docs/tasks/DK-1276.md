# DK-1276: Сторож прозы меряет окно правки, а не файл

## Что происходит

Сторож прозы DK-446 при правке через Edit меряет окно правки, а не файл
целиком. Конвенционная метка «Ожидание:» из сценариев DK-646 и DK-624 кладёт
окно за порог двоеточий: замер дал 29,6 при пороге 19, а файл целиком даёт
5,5 на 1000. Нашёл ревьювер DK-1272, обходом стала перестройка метки на
«Ожидаемый итог.» без двоеточия, что расходится с конвенцией сценариев.

## Чего хотим

Сторож меряет файл целиком, конвенционная метка сценария проходит при правке
соседнего абзаца.

## DoD

Правка абзаца в файле сценария с меткой «Ожидание:» проходит сторож,
проверено прогоном на живом тексте задачи.

## Ранг

`25+4+0+0+2 = 31`, P2.

- Серьёзность 25: штатная конвенционная метка сценария отвергается сторожем,
  обход ломает конвенцию перестройкой фразы.
- Ценность 4: сценарий проверки пишется в каждой задаче доски.
- Неопределённость 0: симптом и оба замера названы.
- Поправка на баг 0: новая работа, ничего работавшего не ломается.
- Рычаг 2: сторож стоит на каждом коммите текста.
