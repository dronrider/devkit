# DK-1278: Отпечаток обкатки ловит правки выше сценария

## Что происходит

Ворота слияния сверяют отпечаток сценария проверки с отметкой обкатки и
отказывают словами «сценарий менялся после обкатки». Отпечаток при этом
считается шире раздела сценария: в DK-1272 вердикт второго круга ревью лёг
строкой в раздел «Ревью» выше сценария, сам сценарий не изменился ни на
символ, а слияние всё равно отказало. Лечится перегоном обкатки, что съедает
цикл слияния целиком, обкатка обязана становиться последней правкой файла
задачи перед слиянием.

## Чего хотим

Отпечаток считается по тексту раздела «Сценарий проверки», правки соседних
разделов файла задачи его не ломают.

## DoD

Правка раздела вне сценария после обкатки не отказывает слиянию, проверено
прогоном ворот на живом файле задачи.

## Ранг

`0+4+0+0+2 = 6`, P3.

- Серьёзность 0: обход перегоном обкатки дешёвый и очевидный, конвейер не
  встаёт.
- Ценность 4: каждая запись в файл задачи после обкатки сейчас требует
  перегона, это лишний цикл на слияние.
- Неопределённость 0: механизм локализован по живому отказу в DK-1272.
- Поправка на баг 0: новая работа, ничего работавшего не ломается.
- Рычаг 2: ворота слияния стоят у каждой задачи доски.
