# DK-1286: Подъём без хуков паркуется находкой, заготовка уходит по мёртвому tmux

## Что происходит

Профиль routerai в каталоге машинного хозяйства создан без единого хука
devkit, у профиля glm-code их шесть групп, от SessionStart до Stop. Хук
старта пишет журнал сессий, по нему дашборд связывает tmux-сессию с
разговором. Чат на deepseek 02.10 не оставил в журнале записи. Заготовка
«Новый чат» после подъёма не пришилась к разговору, осталась в списке
второй мёртвой строкой и живёт вечно, запись с поднятым tmux сторож не
стирает.

Молчат не только записи журнала. Без хуков у подписки нет сторожа плана,
проверки прозы и рубежа ревью, разговор идёт мимо всей обвязки devkit.
Добавление подписки сегодня это env-пары руками и онбординг руками, состав
хуков не готовит никто.

## DoD

Подъём сессии подписки, в конфиге которой нет хуков, не идёт молча. Дашборд
паркует чат находкой «обвязки нет: devkitctl doctor --fix», agentctl exec
отказывает той же находкой. Заготовка чата с поднятым tmux стирается сама,
когда tmux-сессия умерла, а привязки в журнале сессий так и не появилось.
Обе половины закрыты тестами. Приёмка доказана живым прогоном на routerai
этой машины. Doctor --fix от main кладёт хуки без находок, свежая заготовка
пришивается к сессии, журнал получает записи.

## Находки разбора

- Болванку env и хуки доктор раскладывает по двум разным обходам. Болванка
  идёт по каталогам машинного слоя (`alt_sub_harnesses`), хуки по списку
  `enabled` (`enabled_harnesses`). Подписка с ключом home до включения в
  enabled получает болванку без хуков, половинчатая раскладка routerai легла
  с этого стыка.
- Хуки кладёт `devkitctl doctor --fix` из HOOK_LAYOUT
  (tools/devkitctl/devkitctl.py), каждому включённому харнесу по `[hooks]
  config` его профиля. На 02.10 доктор печатает по routerai два десятка
  находок, отдельной команды добавления подписки нет.
- Пришивание заготовки идёт по журналу (tools/dashboard/chats.go).
  `chatBlankList` ищет владельца tmux по записям журнала, `chatBlankSweep`
  хранит запись с поднятым tmux до ручного закрытия. Мёртвая строка из
  ситуации это blank-9ed9b7e2 (tmux-chat-2, deepseek), убрана рукой.
- Журнал сессий пишет hooks/session-task.py на SessionStart в
  ~/.devkit/sessions.log, записей routerai там до 02.10 нет ни одной.
- 02.10 во время разбора doctor --fix уже прогнан, хуки routerai легли.
  Живой прогон приёмки обязан это пережить, барьер проверяется на конфиге
  без хуков.
