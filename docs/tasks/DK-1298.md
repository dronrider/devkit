Выбор модели в панели чата разворачивается из лестниц включённых подписок.
Источник списка это agentctl harness --json по машинному слою
(~/.devkit/harness.local). У подписки ярусы mini, base, pro и max, пунктов
сверх лестницы у панели нет.

Каталог routerai закрывает сотни моделей, для разговоров человеку нужны
избранные вне лестницы. Пример набора: anthropic/claude-fable-5.1,
moonshotai/kimi-k3, z-ai/glm-5.3-prime, google/gemini-3.7-flash. Это
топ-ступень свежего семейства, второе мнение чужой школы, усиленная ступень
glm и дешёвая модель с длинным контекстом. Править ради чата саму лестницу
нельзя. По ярусам назначает задачи agentctl pick, правка лестницы
перенастроила бы конвейер задач.

Ожидание. Машинный слой принимает у подписки список моделей чата сверх
лестницы. Панель выбора показывает эти строки с подпиской-владельцем, подъём
чата идёт обвязкой владельца. Вердикт pick список не читает, назначение задач
остаётся на лестнице.

## Сценарий проверки

Вид агентский. Правка машинная и кодовая, ни один из барьеров (глаза, доступ,
необратимость, секрет, согласие, событие) не задет. Шаги идут после выката из
корня основного чекаута, где живой машинный слой и выкаченный дашборд. Токен
входа в дашборд шаги не печатают.

1. Машинный слой отдаёт список чата владельцу. `agentctl harness --json` по
   копии машинного слоя во временном HOME показывает у подписки ключ chat со
   списком, а лестница остаётся четырьмя ярусами.

```sh
tmp=$(mktemp -d) && mkdir -p "$tmp/.devkit" && printf 'default = "claude-code"\nenabled = ["claude-code"]\n\n[claude-code]\nmini = "h"\nbase = "s"\npro = "o"\nmax = "f"\nchat = ["модель-чата"]\n' > "$tmp/.devkit/harness.local" && HOME="$tmp" agentctl harness --json | python3 -I -c 'import json,sys; v=json.load(sys.stdin); h=[x for x in v["harnesses"] if x["name"]=="claude-code"][0]; assert h["chat"] == ["модель-чата"], h; assert len(h["models"]) == 4, h'
```

2. Ручка живого дашборда несёт список с владельцем. После входа токеном из
   ~/.devkit/dashboard.local ручка /api/harnesses отдаёт у routerai его chat,
   лестница подписки цела.

```
tmp=$(mktemp -d) && tok=$(sed -n 's/^token = "\(.*\)"$/\1/p' "$HOME/.devkit/dashboard.local") && test -n "$tok" && curl -s --max-time 5 -c "$tmp/jar" -H 'Content-Type: application/json' -d "{\"token\": \"$tok\"}" http://127.0.0.1:7112/api/login >/dev/null && curl -s --max-time 5 -b "$tmp/jar" http://127.0.0.1:7112/api/harnesses | python3 -I -c 'import json,sys; v=json.load(sys.stdin); h=[x for x in v["harnesses"] if x["name"]=="routerai"][0]; assert h["chat"] == ["anthropic/claude-fable-5.1"], h; assert len(h["models"]) == 4, h'
```

3. Фронт выкаченного дашборда свежий. В /assets/app.js живого дашборда стоит
   подпись строки сверх лестницы.

```
tmp=$(mktemp -d) && tok=$(sed -n 's/^token = "\(.*\)"$/\1/p' "$HOME/.devkit/dashboard.local") && test -n "$tok" && curl -s --max-time 5 -c "$tmp/jar" -H 'Content-Type: application/json' -d "{\"token\": \"$tok\"}" http://127.0.0.1:7112/api/login >/dev/null && curl -s --max-time 5 -b "$tmp/jar" http://127.0.0.1:7112/assets/app.js | grep -q "сверх лестницы"
```
