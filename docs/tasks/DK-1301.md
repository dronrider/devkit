# DK-1301: Подключение подписки mimo четвёртым харнесом

## Что происходит

Подписка Xiaomi MiMo оплачена отдельно от агрегатора routerai, и подключить
её некуда. Платформа даёт Anthropic-совместимый эндпоинт `/v1/messages`.
Варианта два. Pay-as-you-go работает с ключом `sk-`, Token Plan с ключом
`tp-`, у каждого режима свой адрес из доки платформы. Оба адреса отвечают
с рабочей машины примерно за секунду. В примерах из доки авторизация идёт
заголовком `api-key`, а официальный python-SDK шлёт `x-api-key`. Рабочую схему
для клиента выбирает смок. Серия моделей V2.6 анонсирована из трёх имён,
точный список даёт `GET /v1/models` с ключом.

Подписка в devkit держится на трёх слоях. Коммитимый профиль
`kit/harness/<имя>.toml`, машинный `~/.devkit/harness.local` и каталог
`~/.devkit/claude-<имя>` с `settings.json`, раскладку которого делает
`devkitctl doctor --fix`. Сегодня так подключены glm-code и routerai. Список
подписок дашборд читает у `agentctl harness --json`, панель строится из него же.

## Чего хотим

- Профиль `kit/harness/mimo.toml`, близнец `routerai.toml`. Раздел квоты не
  заводится, публичного эндпоинта остатка у платформы в доке не нашлось.
  Найдётся, снимок заведём отдельной строкой.
- В машинном слое секция `[mimo]` с адресом каталога и собственной полной
лестницей ярусов из моделей платформы, имя `mimo` в `enabled`. Адрес эндпоинта,
токен и подстановки алиасов живут в `settings.json` машинного каталога, как у
соседних подписок.
- Каталог `~/.devkit/claude-mimo` раскладывает `devkitctl doctor --fix`. Токен
  вписывает человек сам, значения не появляется ни в чатах, ни в коммитах.
- Подписка видна в панели дашборда и отвечает в чате, консольный чат поднимается
  командой `agentctl exec --harness mimo -- claude`.
- Задачи идут на подписке диспетчерской сессией на харнесе mimo.

## Сценарий проверки

Адрес эндпоинта и токен читаются из `~/.devkit/claude-mimo/settings.json`,
литеральных адресов и ключей в шагах нет. Живые шаги прогоняются после того,
как человек впишет токен.

- Исключение: обкатка (живой ключ и машинный слой вне дерева прогона)

1. В свежем дереве devkit: `cd tools/agentctl && go test ./...`. Ожидание:
   тесты зелёные.
2. В том же дереве: `agentctl harness --json`. Ожидание: в выводе есть
   `"name": "mimo"` с четырьмя ступенями, у ступеней нет поля `via`.
3. Запрос `POST` на адрес из `ANTHROPIC_BASE_URL` с путём `/v1/messages`, ключ
   из `ANTHROPIC_AUTH_TOKEN` файла настроек уходит в заголовок, в выводе только
   код ответа. Ожидание: 200.
4. `agentctl exec --harness mimo -- claude -p "ответь одним словом: связь"`.
   Ожидание: в выводе есть реплика модели.
5. `grep -c 'routerai' ~/.devkit/harness.local`. Ожидание: вхождения только
   внутри секции `[routerai]`, у `[glm-code]` ссылок нет.
