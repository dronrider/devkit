# DK-1304: Использование Token Plan в блоке квоты дашборда

## Что происходит

Пульт дашборда показывает остатки подписок по снимкам квоты. У профиля mimo
секция квоты пустая с постановки DK-1301. Публичного эндпоинта остатка тогда
в доке платформы не нашлось. Снимок решили завести отдельной строкой, когда
эндпоинт найдётся. Пользователь смотрит использование Token Plan в кабинете
платформы и переносит цифры на глаз.

2026-10-06 эндпоинт нашёлся, ответ пришёл с куками сессии кабинета. Он отдаёт
использование подписки списком строк с именем, израсходованным числом, лимитом
и процентом. Месячный срез приходит отдельным блоком. Проценты в ответе
округлены грубо. Три знака после запятой даёт пересчёт из израсходованного и
лимита. Этот эндпоинт не открывает ключ модели. Съёмщику нужны куки сессии
учётной записи.

## Чего хотим

Блок квоты пульта показывает использование Token Plan двумя строками по
утверждённому макету. Первая строка несёт потраченное за последние пять часов
и остаток из лимита. Буквы B и M показывают порядок чисел. Вторая строка несёт
процент подписки тремя знаками после запятой и индикатор темпа трат. Темп
сравнивает скорость последних часов со скоростью ровного расхода до сброса. Он
стоит словом «медленно», «в темпе» или «быстро» с цветной точкой. По нему
видно, усиливать работу или притормозить.

Данные идут снимком. Съёмщик-скрипт запрашивает эндпоинт использования с куками
сессии из хранилища секретов и печатает снимок в каталог квоты. Дальше его
читает существующий обработчик квоты пульта. Протухший снимок и отсутствие
данных показываются словами. Тишина в блоке недопустима.

## Границы

- Кредиты и токены задача не различает. Эндпоинт называет единицу токеном,
  платформа считает квоты кредитами, блок показывает числа как есть.
- Графики истории трат и отдельного экрана нет. Окно последних пяти часов
  считается прямо в блоке.

## DoD

- Съёмщик печатает снимок из ответа эндпоинта использования в каталог
  съёмщиков профиля. Куки сессии он читает из хранилища секретов. В коммит и в
  файлы задач они не попадают.
- Блок квоты показывает обе строки на живых данных. B/M в первой, три знака у
  процента, темп словом с цветной точкой.
- Потраченное за пять часов считается разностью снимков внутри окна. При
  короткой истории окно сокращается и подписывается своим размером.
- Нет данных и протухший снимок показываются словами. Пустой блок на штатную
  работу не похож.
- Тесты зелёные, сценарий проверки прогнан не автором правки.

  хранилище.
- Поправка на баг 0: новая работа, сломанного нет.
- Рычаг 2: съёмщик по образцу соседних поднимет следующие снимки внешних API,
  наружу ничего не отдаёт.

## Сценарий проверки

Агентский. Шаги гоняются из корня дерева после слияния в main. Живой кабинет
в шагах не участвует. Съём и куки остаются за машиной с доступом, а съёмщик
проверяется синтаксисом и честным отказом, формат снимка и показ проходят
разбором и тестами.

```sh
sh -n kit/harness/snap/mimo.sh
```

Ожидание: код 0, синтаксис съёмщика цел.

```sh
env -u DEVKIT_HARNESS sh kit/harness/snap/mimo.sh 2>&1 | grep -q 'DEVKIT_HARNESS'
```

Ожидание: отказ с причиной про пустое имя харнеса, до хранилища секретов и
сети дело не доходит. Переменную шаг снимает явно, у проверяющего она бывает
выставлена его же сессией.

```sh
H=$(mktemp -d) && mkdir -p "$H/.devkit/quota" && printf 'taken = %s\nmonth_plan = 43%% сброс 2026-10-31T23:59\nwindow5h_cred = 123456789 кред 5ч\nbalance_cred = 876543211 кред\nspent_cred = 653456789 кред\n' "$(date +%Y-%m-%dT%H:%M)" > "$H/.devkit/quota/mimo.local" && printf 'default = "claude-code"\nenabled = ["claude-code", "mimo"]\n\n[mimo]\nhome = "%s"\n' "$H" > "$H/.devkit/harness.local" && env -u DEVKIT_HARNESS -u DEVKIT_HOME GOWORK=off HOME="$H" go -C tools/agentctl run . quota --harness mimo | grep -q 'window5h_cred: 123456789 кред 5ч' && rm -rf "$H"
```

Ожидание: код 0, печатается разобранный снимок с хвостом окна «5ч» на месте,
предупреждений о неизвестных ключах нет. Код дерева шаг зовёт через go run,
установленный agentctl бывает старее свежего слияния. Переменные сессии
снимаются явно, GOWORK=off прячет чужой go.work домашнего каталога.


Ожидание: пакет зелёный, тесты плана закрывают процент с тремя знаками, темп,
короткую историю и показ без данных.


Ожидание: пакет зелёный, кредовые строки читаются и пишутся, профиль mimo
