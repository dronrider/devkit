# DK-1307: Съёмщик панели берёт не тот claude из профиля логин-оболочки

## Что происходит

Тест TestSnapUsagePanelRetriesRateLimit поднимает настоящую сессию tmux с
подложным клиентом на PATH и гоняет через неё съёмщик панели /usage. Сессия
tmux стартует логин-оболочкой, её профиль дописывает пользовательские префиксы
PATH впереди всего остального. Настоящий claude из каталога этих префиксов
выходит вперёд подложного, клиент поднимается настоящий и показывает в
служебном каталоге вопрос доверия. Распознаватель блокеров панели узнаёт этот
экран, съёмщик уходит с отказом, и тест падает.

Тот же путь запуска читается как дефект съёмщика: snapUsagePanel зовёт claude
по имени, и оболочка сессии берёт свой. Два клиента на машине дают съём
неизвестно каким из них, а тест со стендом не может удержать своего клиента.

На main тест красный. Ворота слияния гоняют тесты в свежем дереве и отбивают
каждую правку, чей дифф трогает tools/agentctl: конвейер доски не доезжает до
main.

## Чего хотим

Съёмщик берёт claude разрешением пути в своём процессе и передаёт tmux абсолют
пути. Профиль оболочки сессии тогда не участвует в выборе клиента, тест
удерживает подложного клиента на любом PATH машины, и TestSnapUsagePanelRetriesRateLimit
зелёный.

## Границы

- Ход панели не меняется: подъём сессии, набор команды, блокеры, пережатие
  отказа по частоте остаются как есть. Правка заканчивается выбором пути
  клиента.
- Обособление tmux-сервера в тесте сюда не входит. С абсолютом пути сервер и
  профиль на выбор клиента не влияют.

## DoD

- TestSnapUsagePanelRetriesRateLimit красный на старом коде и зелёный на
  исправленном, это видно прогоном regcheck.
- Пакет tools/agentctl зелёный целиком.
- Сценарий проверки прогнан не автором правки.
