# DK-1317: швы конвейера: хвосты долга и двойной заход

Цель: [tasks/DK-1326.md](tasks/DK-1326.md)

## Что происходит

Окна task-DK-796 и task-DK-839 2026-10-07 снял штатный стоп конвейера
task-run: проход кончился, задача в архиве, конвейер встал с записью
«задача закрыта» и снял живую голову (журнал .devkit/log, 09:23:05 и
11:43:40). Долг DK-1176 отдала та же сессия DK-796 через board-debt, а с
10:35 DK-1176 дополнительно вёл конвейер taskctl run. Наблюдение собрано
по журналу конвейера, реестру чатов и отметкам ходов.

Стоп конвейера смотрит только на статус задачи и для закрытой молчалив
(loud=False), а хвосты сессии он не видит. Фоновая команда старта ветки и
отложенная реплика «продолжай работу» умерли вместе с окном, о потере ни
строки, ни уведомления.

На DK-1176 вышло два захода в одном рабочем дереве: ручной старт с
субагентами и конвейер taskctl run DK-1176. Правило уступления живым
субагентам («заказ не подаётся, ход поднимет их конец») столкновение
развело, порядка нет, исход свела случайность.

## Чего хотим

Остановка конвейера больше не роняет работу молча. Хвосты либо доезжают,
либо гаснут вслух с записью в задаче и уведомлением. Строку с чужим
заходом конвейер не поднимает. На задаче один заход.

## Границы

Видимость turn_failed и механика resume_failed за DK-1321, решено
развилкой «шов» файла цели. Доведение исходов очереди за DK-1322.

## Развилки

- «хвосты»: куда девать хвосты долга при стопе конвейера?
  - решает: исполнитель
  - рекомендация: каждый хвост получает запись в задаче и уведомление;
    хвосты либо доезжают, либо гаснут вслух
  - вариант: доезжать все хвосты принудительно
  - решено агентом 2026-10-09: каждый хвост получает запись в задаче и
    уведомление. Хвосты либо доезжают, либо гаснут вслух; принудительное
    доезжание всех отвергнуто: фоновая команда старта ветки может быть
    уже не нужна после стопа
- «один заход»: как оставить на задаче один заход?
  - решает: исполнитель
  - рекомендация: строку с чужим заходом конвейер не поднимает; замок на
    задаче или проверка живого субагента
  - вариант: правило уступления живым субагентам как есть
  - решено агентом 2026-10-09: строку с чужим заходом конвейер не
    поднимает, проверка по живому субагенту или замку; правило уступления
    как есть отвергнуто: порядка нет, исход сводит случайность
