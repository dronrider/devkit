# DK-1324: рядовой пуш проходит без спроса у человека

Цель: [tasks/DK-1326.md](tasks/DK-1326.md)

## Что происходит

Восемь октября чат «DK-1309 груминг» (сессия 1eb920ea) с 10:01 четырежды
ответил «ждёт ввода». Исполнитель довёл правку, спросил разрешения на
пуш origin main и ждёт человека. Правила разрешают пушить коммиты доски
сразу и без просьбы, автономность в проекте включена. Pre-push пропускает
диапазон доски и код со следом ревью через shipctl push --check-only
(rangeVerdict и reviewTraceGate). Рядовой пуш паркует задачу на часы и
останавливает цепочку следующих строк. Пока человек не вернулся, правка
лежит локально, и соседние слияния её не подхватывают.

Автономность лежит в .devkit/deploy.local, из worktree задачи её не видно,
и в промптах exec-* о ней ни слова (DK-792). Связь «закрывается той же
правкой» с DK-792 снята, решено развилкой «792» файла цели.

## Чего хотим

В автономном проекте рядовой пуш отработанных коммитов веток задач
проходит без человека. Main остаётся вопросом человеку. Голый git push
без спроса не расширяется. Правило правится через автономный режим
shipctl вторым исключением RULES.core.md. Pre-push ведёт пуш кода тем же
shipctl. Чат на пуше не стоит.

## Границы

Main остаётся вопросом человеку, решено развилкой «main» файла цели.
Голый git push не расширяется. Связь с DK-792 снята: DK-792 живёт ролью
и промптами exec-*, DK-1324 закрывает калитку пуша. shipctl autonomy
нет, есть совет mergeFork в shipctl status.
