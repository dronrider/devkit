# DK-1324: рядовой пуш проходит без спроса у человека

записан 2026-10-08
приоритет: высокий

## Черновик

### Ситуация

Восемь октября чат «DK-1309 груминг» (сессия 1eb920ea) с 10:01 четырежды ответил «ждёт ввода». Исполнитель довёл правку, спросил разрешения на пуш origin main и ждёт человека. Правила разрешают пушить коммиты доски сразу и без просьбы, автономность в проекте включена. Pre-push пропускает диапазон доски и требует отметки DEVKIT_PUSH_OK на код. Автономность лежит в .devkit/deploy.local, из worktree задачи её не видно, и в промптах exec-* о ней ни слова (DK-792).

### Осложнение

Рядовой пуш паркует задачу на часы и останавливает цепочку следующих строк. Пока человек не вернулся, правка лежит локально, и соседние слияния её не подхватывают.

### Вопрос

Какие пуши идут без спроса в автономном проекте. Ветка задачи и коммиты доски всегда, main в рамках конвейера уже пушит shipctl? Как pre-push узнаёт автономность, раз deploy.local из worktree не видно.

### Гипотеза

В автономном проекте рядовой пуш отработанных коммитов проходит без человека. Вопрос остаётся для аномалий. Это force, main вне конвейера и корп-контур. Исполнитель спрашивает утилиту shipctl autonomy.
