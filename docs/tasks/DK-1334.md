# DK-1334: Тик зовёт очередь слияний пустой, когда в ней стоит снятая строка

## Что происходит

Утром 2026-10-09 очередь слияния держала одну снятую строку DK-1312. Тик
сторожка при этом печатал «очередь слияний пуста: ни одной строки In progress
с веткой» и повторял строку в журнале каждые пять минут. Очередь не пуста,
в ней стоит снятая работа с причиной снятия. Разглядеть это по журналу
невозможно, помогает только отдельный вызов `shipctl queue`. Причина в
queueDrain (tools/shipctl/queue.go): снятые строки обходятся молча, а хвост
отчёта один и тот же для пустой очереди и для очереди из одних снятых.

## Чего хотим

Отчёт тика называет снятые строки и причины, молчание не маскирует стоящую
работу. Пустая очередь печатается по-прежнему.

## DoD

- при единственной снятой строке отчёт тика и журнал сторожка называют её
  и причину снятия
- пустая очередь печатается прежней строкой
