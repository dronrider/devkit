# DK-1337: В списке задач не отображается дата

## Что происходит
В списке задач не отображается дата. Если нажать на колонку и отсортировать по ней то на какое-то время дата появляется и потом пропадает. 

## Чего хотим
Сделать чтобы дата отображалась. 

## DoD
Дата стабильно отображается в соответствующей колонке в списке задач.
## Ранг

## Ход работы
- Разобрал путь даты: taskctl `list --json` (boardTimes/lineDate) -> дашборд
  без изменений -> колонка «Дата». Клиент рисует дату честно, гаснет она
  на сервере. Любые незакоммиченные правки docs/TASKS.md закрывали ворота
  boardClean, и поле moved пустело у всех строк доски разом. Правки без
  коммита на живой машине случаются постоянно (set/close/arm/dep из дашборда
  ходят без -m, у move -m есть окно между записью и коммитом), отсюда мигание
  и пустая колонка.
- Проверил на стенде. `git blame --incremental` annotate рабочую копию, правленая
  строка получает нулевой sha с временем «сейчас», нетронутые хранят даты своих
  коммитов. Ворота clean сняты целиком, blame точен и на грязном дереве.
  boardClean удалён, ageLabel/lineDate/rowNoteParts/rowIdleHours потеряли
  параметр clean.
- Тест бага TestListJSONDirtyBoardKeepsMoved (json_test.go): на грязной доске
  нетронутые строки несут дату коммита, правленая сегодняшнюю. Regcheck
  подтвердил, красный на HEAD, зелёный на правке. Полный прогон tools/taskctl
  зелёный. README taskctl поправлен там же, где обещал молчание на грязном
  дереве.
- До пользователя доезжает пересборкой бинарей devkitctl update, дашборд
  зовёт установленный taskctl.
