# DK-1372: Подъём чата висит на вопросе клиента сутки и оживает чужим заголовком

## Что происходит

Подъём чата передаёт первый промпт аргументом команды запуска. В новом дереве
Claude Code встаёт на вопрос доверия папки «Yes, I trust this folder». Пока
вопрос стоит, промпт из аргумента не отправляется. Сессии нет, транскрипта
нет, и в списке чат остаётся пустой строкой. Карточка «вопрос клиента» в
панели показывает сам вопрос. Состояние ожидающего запуска панель нигде не
показывает.

Снятие вопроса приходит через панель в любое время после подъёма. Ответ
«пункт 2 (Yes, I trust this folder)» закрывает диалог, и отложенный промпт
уходит в работу в эту же секунду. Сессия появляется в момент ответа. Чат
получает автозаголовок из первого промпта, такого текста человек не вводил, и
чат выглядит созданным сам собой.

Наблюдение 2026-10-13. 12.10 16:02:44 из панели поднят чат в дереве xr-proxy
(tmux-сессия chat-4) с промптом про использование подписки GLM. Диалог
доверия простоял сутки, в памяти пользователя подъёма не осталось. 13.10
15:54:20 тот же диалог снят карточкой вопроса клиента chat-4, в 15:54:21
появилась сессия 0dc127bf. В списке всплыл чат «Использование подписки GLM за
5 часов» с вопросом из запуска.

## Чего хотим

Подъём, который ждёт ответа на вопрос клиента, виден в панели как ждущий.
Возраст ожидания стоит рядом с чатом, и человек читает его без журнала.
Отложенный промпт либо дожидается открыто, либо отменяется по сроку, который
панель показывает тем же местом. Снятие вопроса не приходит сюрпризом через
сутки после запуска.

## Границы

Заголовок из первого промпта остаётся как есть. Автоответов на вопросы клиента
задача не заводит. Диалог доверия новых деревьев и его обход остаются за
клиентом.

## DoD

1. Стенд поднимает чат в дереве без доверенной папки с промптом в аргументе.
   Панель показывает этот чат ждущим ответа на вопрос клиента, с возрастом
   ожидания.
2. На том же стенде ответ на карточку вопроса отправляет промпт, и тот же чат
   показывает сессию, которая появилась из промпта.
3. Ожидание без ответа не длится сутки молча. Либо панель держит его видимым
   всё время, либо по сроку отменяет промпт и показывает причину.
4. Поломка воспроизводится на старом коде и закрыта на исправленном, проверено
   regcheck.

## Ранг

`50+6+3+5+2 = 66`, P1.

- Серьёзность 50. Основной сценарий подъёма прерывается молча на сутки. Ответ
  на соседнюю карточку стреляет старым промптом, и человек видит чат, которого
  не заводил. Обход есть, ручной и догоняющий через сутки.
- Ценность 6. Подъём чата всплывает каждый день. Видимость состояния запуска
  теперь единственная его невидимая часть.
- Неопределённость 3. Цепочка восстановлена по журналу панели и команде запуска
  процесса. Открыты детали: форма видимого ожидания и место, где панель
  показывает возраст.
- Поправка на баг +5. Дефект подъёма.
- Рычаг 2. Правка касается одного пути запуска, соседние сценарии панели она
  не разблокирует.
