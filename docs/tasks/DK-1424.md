# DK-1424: close не требует smoke при слиянии документации без выката

## Что происходит

2026-10-23 при закрытии DK-1413 на main d1f92423b команда taskctl close
завершилась с отказом:
«в «Выкате» есть слияние, а отметки smoke на последний выкат нет».
Следующая штатная команда shipctl smoke DK-1413 тоже завершилась с отказом:
«нет непроверенного выката: очередь она не держит, и отметка ей не нужна».
Оба результата переданы диспетчером, подтверждён один случай.

DK-1413 содержит только docs/, слита trainmerge без deploy и опубликована.
Свежая независимая проверка завершилась успешно. Выполнены пять шагов,
обкатка 2/2 и проверки подмен 8/8. Строка остаётся в Check. Результат
доставлен, но штатно закрыть проверенную агентскую документацию не
получается даже вручную.

В tools/taskctl/gate.go closeSmokeGate требует SmokeCovers при любой
записи MergedShas. В tools/shipctl/record.go cmdSmoke проверяет checkQueue
и не ставит отметку задаче, у которой нет непроверенного выката. Запись
слияния документации ошибочно приравнена к выкату при закрытии. Ложный
smoke и удаление записи слияния не являются допустимым обходом.

## Чего хотим

Проверенная агентская задача только с документацией закрывается после
слияния и публикации без deploy и без отметки smoke. Запись слияния
сохраняется. Проверки close и smoke одинаково различают слияние и
непроверенный выкат. Закрытие настоящего выката без действующей отметки smoke
по-прежнему запрещено.

## Границы

- Исправляется условие необходимости smoke при закрытии. Остальные
  требования приёмки и проверки результата сохраняются.
- Отметки задним числом, удаление свидетельств слияния и принудительный
  обход проверок не входят в решение. Поведение тестируется на временных
  репозиториях и файлах задач.
- DK-1363 и черновик DK-1133 касаются противоположного дефекта, при
  котором настоящий выкат закрывается без smoke. Их защитное поведение
  надо сохранить.
  Дубля открытой задачи или черновика для слияния документации не найдено.
- Регресс и распространённость по другим задачам не установлены.
  DK-1413 остаётся в Check до будущего исправления инструмента.

## DoD
