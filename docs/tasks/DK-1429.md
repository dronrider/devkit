# DK-1429: Свободное обсуждение становится основным чатом черновика

Цель: [tasks/DK-1253.md](tasks/DK-1253.md)

## Что происходит

Черновик, оформленный из разговора, не связывает этот разговор с записью.
Контекст постановки остаётся в свободном чате, кнопка черновика заводит
новый разговор, и постановка начинается без накопленного обсуждения. Когда
из одного разговора выходит несколько черновиков, источник не виден ни у
одного.

## Чего хотим

При оформлении черновика из свободного разговора текущий чат становится его
основным, в журнал назначений пишется строка с источником «оформление»
(решение 1 LLD DK-1422). Назначение сохраняется при оформлении черновика
в задачу и начале работы, создание черновика разработку не запускает.

Если из общего разговора получается несколько самостоятельных черновиков,
каждый получает свой основной чат с итогом постановки и ссылкой на источник.
Один чат назначается основным только одной записи, при выделении второй
записи первое назначение сохраняется. Находка другой проблемы в работе над
задачей оформляется отдельным черновиком со своим чатом. Исходное обсуждение
доступно из всех записей, созданных по его итогам.

## Границы

Реализуется источник «оформление» и правило одного назначения из решений 1
и 6 LLD DK-1422. Журнал назначений и ручку адреса заводит DK-1427. Способ
подписи роли «груминг» на отрезке относится к DK-871, разбор старых черновиков
без строки оформления остаётся миграции DK-1432 (подтверждение П3 по входу
черновика).

## DoD

- Свободный чат становится основным для одного черновика и сохраняется
  при оформлении в задачу и начале работы.
- Несколько записей из одного обсуждения получают отдельные основные чаты
  с постановкой и ссылкой на общее обсуждение.
- Первый черновик сохраняет назначение при выделении второго из того же
  разговора, у второго собственный основной чат.
- Создание черновика не запускает разработку.
- Тесты закрывают запись источника «оформление», единственность назначения
  и сохранение при смене вида записи.
