# DK-143: остаток sh по правилу выбора языка

Задача цели [DK-135](DK-135.md). Правило языка принято в
[DK-139](archive/2026/DK-139.md): граница sh это сотая строка или первая своя
функция, всё, что за ней, переезжает на python.

## Задача

Привести к правилу остаток sh, который не берут DK-141 и DK-142. По счёту
DK-139 это `kit/skills/test.sh` (111 строк, две своих функции),
`kit/skills/goal-loop/test.sh` (279) и `kit/skills/goal-loop/goal-run.sh`
(230). Правило их относит к сложному, значит они переезжают на python;
`hooks/quota-refresh.sh`, три точки входа git (`pre-commit`, `commit-msg`,
`pre-push`) и фикстура `tools/obeycheck/testdata/fake-agent.sh` остаются, и на
каждый оставшийся файл в доке лежит причина.

Счёт DK-139 снят до переезда, поэтому перед работой пересчитать корпус самому
и сказать в файле задачи, сошлось ли: правило машинное, и проверять его надо
машиной.

`goal-run.sh` это оболочка цикла цели, её зовут путём из чекаута
(`kit/skills/goal-loop/goal-run.sh`), и путь этот назван в самом скилле
`goal-loop`. Переезд на python меняет имя файла, значит правится и текст
скилла, и его тест. Оболочка при этом рабочая: цикл цели поднимается ею прямо
сейчас, так что поведение (замок с pid, журнал, коды возврата 0/1/2/3, разбор
маркера последней строкой) обязано сохраниться один в один, и тест это
показывает.

Прогоны, которые звали переехавшие файлы, правятся тем же коммитом: `.github/
workflows/ci.yml`, перечень локальных прогонов в конце `README.md`, команды
внутри скиллов. Гитигнорнутый `.devkit/deploy.local` правит диспетчер, туда не
лезть.

## Сценарий проверки

Агентский.

1. Пересчёт корпуса sh: каждый оставшийся файл проходит границу правила
   (меньше сотни строк и без своих функций) либо стоит в исключениях правила с
   причиной в доке.
2. Поведение оболочки цели сохранено: тест гоняет замок с чужим pid, воронку
   из трёх витков без записи, коды возврата 0/1/2/3 и разбор маркера последней
   строкой.
3. Прогоны CI зелёные, включая новые python-тесты скиллов и оболочки.
4. Текст скилла `goal-loop` и перечень локальных прогонов `README.md` называют
   новые пути, мёртвых команд не осталось.
