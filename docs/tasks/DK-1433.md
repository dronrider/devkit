# DK-1433: Сквозная проверка основного чата на живом дашборде

Цель: [tasks/DK-1253.md](tasks/DK-1253.md)

## Что происходит

Состав цели DK-1253 закрывается порознь, у каждой строки своя приёмка.
Стыки строк вместе на живом дашборде не проверялись, а риск живёт на стыках.
Кнопка после миграции, список после передачи диспетчера, чат цели после
смены носителя.

## Чего хотим

Агентский заход в живой дашборд проходит пользовательские пути из раздела
«Сценарий проверки» цели DK-1253 целиком. Открытие задачи из списка и формы
при работающем и остановленном диспетчере со сверкой адреса, истории
и адресата контрольной реплики. Передача новому диспетчеру и смена стадий
без новых строк основного чата. Превращение свободного обсуждения
в черновик, оформление задачи, два черновика из одного обсуждения и цель
с задачами. Параллельное обсуждение с названиями, фильтрами и
переименованием. Изменение требования в цели с доставкой и подтверждением
в задаче, прямой вопрос в задаче с ответом там же. Миграция на наборах
из DoD со спорным случаем, ручным выбором, повтором и откатом связей.

## Границы

Нового кода строка не пишет. Находки стыков уходят в строки своих частей
состава, правка мелкой боли ездит этим же коммитом. Сценарий берётся из цели
без пересмотра, наборы миграции из её DoD.

## DoD

- Пройдены все шесть шагов сценария проверки цели на живом дашборде,
  итог каждого шага вложен в файл задачи.
- Контрольная реплика доезжает назначенному диспетчеру на каждом шаге,
  где человек пишет в чат.
- Находки стыков разобраны: исправлены строкой-виновником либо названы
  с судьбой в отчёте.
- Наличие непустого адреса без истории и адресата приёмкой не признано.

## Ранг

Собственная сумма `25+6+1+0+2 = 34`, с бонусом S+2 ранг 36. Ранг 65 и P1
унаследованы от DK-1253.

- Серьёзность 25. Без сквозного прохода цель закрывается на разрозненных
  приёмках, дыры стыков остаются незамеченными.
- Ценность 6. Один проход доказывает цель целиком, дешевле закрытия
  находок после приёмки.
- Неопределённость 1. Шаги сценария готовы, код всех строк слит.
- Поправка на баг 0. Проверка, поломки нет.
- Рычаг 2. Проход подтверждает модель для следующих целей.

## Приёмка

Вид агентский. Барьеров из закрытого списка нет: заход в дашборд выполняет
агент, миграция прогоняется на изолированных данных, шаги имеют объективный
итог.

## Сценарий проверки

Вид приёмки агентский. Прогон идёт на живом дашборде из свежего дерева.

1. Пройти шаги 1-5 раздела «Сценарий проверки» цели DK-1253, вкладывая вывод
   каждого шага в файл задачи.
2. Прогнать шаг 6 (миграция) на наборах из DoD цели: спорный случай,
   ручной выбор, повторный запуск, откат связей, сохранность переписки
   после миграции.
3. Сверить, что контрольная реплика каждого шага доехала назначенному
   диспетчеру и в истории стоит адресат.
