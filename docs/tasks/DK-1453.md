# DK-1453: Автоматические задачи используют только разрешённые подписки

## Что происходит

При поиске независимого проверяющего все включённые подписки стали кандидатами. Так вторичная routerai получила проверку без разрешения пользователя. Включение подписки нужно отделить от допуска к автоматическим задачам.

## Чего хотим

Явное разрешение автоматических назначений в машинной конфигурации. Без настройки разрешена только подписка по умолчанию. Вторичные подписки участвуют после явного разрешения. Ручные чаты и явный выбор подписки сохраняются.

## DoD

- Независимый автоматический выбор в agentctl, shipctl и dashboard учитывает одну политику допуска, включая владельца ступени via. Предпочтение текущей подписки не отменяет запрета.
- При отсутствии разрешённой независимой модели возвращается понятный отказ. Запрещённая подписка не поднимается ради обхода отказа.
- На этой машине разрешены glm-code и glm-code-2, routerai остаётся включённой для ручного использования.
- Есть регрессия: вторичная включена, но не разрешена; после явного разрешения она участвует; при запрете всех независимых моделей запуск отсутствует. Ручной доступ не затронут.
