# DK-1457: Задача попадает на доску только с заполненной постановкой

## Что происходит

2026-10-25 пользователь показал случай создания задачи без описания. На временной доске бинарь из текущих исходников принимает add с заголовком, типом, рангом, ценой и видом приёмки. В файле остаются пустыми «Что происходит», «Чего хотим», «DoD» и «Ранг», а lint сообщает, что доска и архив в порядке.

Следующий исполнитель получает заголовок вместо постановки и вынужден восстанавливать контекст. Ядро доски не требует прочитать форму до записи. В board-task очевидные находки освобождены от проверок готовности; при оформлении черновика проверяется только заголовок DoD.

## Чего хотим

Новая task или bug попадает на доску только с заполненными обязательными разделами. Готовое описание принимается непосредственно в add через --body-file, черновик оформляется прежним add --id после проверки собранного файла. Ядро становится короче и требует чтения формы перед записью.

## Развилки

Открытых вопросов нет. Пользователь утвердил сокращение ядра, обязательную форму задачи и проверку заполнения в taskctl. Условий, посильных только человеку, не найдено.

## DoD

- Прямой add без описания и оформление пустого черновика завершаются ошибкой до изменения доски и переноса файла; сообщение перечисляет недостающие разделы.
- Готовая постановка через --body-file и содержательный черновик через --id создают полноценную задачу; заголовки в примерах, комментарии, пустые пункты и заглушки не подменяют заполнение.
- Lint находит неполные живые карточки, переход в работу требует заполнения; формы LLD и целей сохранены, архив не переписывается.
- Резидентное ядро не растёт; TASKFORM.md, полные правила, процедуры и README утилиты согласованы с новым порядком.
- Регрессионные тесты падают на прежнем коде и проходят после правки; сценарий obeycheck проверяет создание задачи либо черновика с резидентным ядром.

Структура уже определена в TASKFORM.md. Пользователь отверг расширение резидентного ядра перечнем разделов. Переписываются вводная и первый пункт без увеличения размера ядра.
