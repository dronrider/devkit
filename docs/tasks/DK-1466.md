# DK-1466: Часовое условие взвода с аргументом времени и уведомлениями браузера

Цель: [tasks/DK-1198.md](tasks/DK-1198.md)

## Что происходит

У взвода рёбер порядка нет аргумента времени, решение DK-933.6 отложило его. Напоминаний по времени у дашборда нет, отложенный черновик возвращается без даты, браузер молчит о сроках.

## Чего хотим

Взвод принимает часовое условие аргументом `--at`. Сторожок срабатывает в срок, напоминание ложится в журнал уведомителя. Отложенный черновик возвращается к названной дате, браузерное уведомление приходит с настройкой часа и числа дней до срока.

## DoD

Часовой взвод с аргументом `--at` срабатывает в срок, напоминание ложится в журнал уведомителя, отложенный черновик возвращается к дате, браузерное уведомление приходит.

## Ранг

- Ценность 8: напоминания по времени одна из причин макета Дозор.
- Неопределённость 2: решение DK-933.6 называет аргумент, открыты детали браузерных уведомлений.
- Поправка на баг 0: новое поведение.
- Рычаг 2: на часовой аргумент опирается возврат отложенного и контроль к сроку.

## Сценарий проверки

Проверка идёт на синтетических данных самих тестов, без участия человека.
Шаги несут ограждённые блоки команд, обкатка гоняет их в свежем дереве
ветки. Итог шага это нулевой выход команды и ok в выводе обёртки.

1. Часовой взвод держит строку до срока. Тест заводит доску со взводом на
   минуту вперёд и проверяет обход ждущих до часа и после него.

```sh
devkitctl test tools/taskctl -run 'TestArmHourHoldsRowUntilTime' -count=1
```

2. Отложенный черновик возвращается к названной дате. Тест ставит
   `defer --until`, читает пометку до дня возврата и в сам день.

```sh
devkitctl test tools/taskctl -run 'TestDraftDeferUntilReturnsDraft' -count=1
```

3. Круг напоминаний кладёт строки окна в журнал уведомителя поводом
   `task_due`, лента видит событие о строке доски. Час из конфига, окно
   днями и один круг в сутки проверяются на синтетической доске.

```sh
devkitctl test tools/dashboard -run 'TestDueRemind|TestNotificationsDueIsTaskEvent' -count=1
```

4. Часовая форма взвода разбирается сторожем доски и иглой тика, маркер
   «после» перед ней читается.

```sh
devkitctl test tools/devkitctl watch_test board_test
```

5. Регрессия закрыта на базе. Новые тесты краснеют на main и зелёнеют на
   ветке, база названа явно. Regcheck обязан напечатать, что тест краснеет
   на main и проходит на текущем коде.

```sh
regcheck --base 9322a55 --tests tools/devkitctl/watch_test.py,tools/devkitctl/board_test.py -- devkitctl test tools/devkitctl watch_test board_test
```
