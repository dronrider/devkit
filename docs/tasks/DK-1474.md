# DK-1474: Тик гасит молчащий проход головы сам

## Что происходит

26.10.2026, голова DK-489. Проход 5 длился 4835 секунд. Полтора часа из них
не дали ни одной отметки хода. В 12:36 сесс разом закрыл больше двадцати
фоновых `sleep 600` с пустой сдачей. Тик записал молчание в журнал и
продолжил наблюдать. За три часа голова сняла около двух часов модельного
времени, строка не сдвинулась.

Замок по признаку жизни (DK-1454) замерзший процесс не держит. Конвейер
поднимает нового исполнителя, а старая сессия продолжает тратить квоту.
Дашбордная «Стопа» агенту недоступна, вход в панель закрыт. Своего стопа у
тика нет.

## Чего хотим

Порог молчания тик уже считает для журнала. Тот же замер ставит заказ
стопа, проход паркуется с причиной «молчание». Потолок проходов держит
повтор от закольчивания.

## Развилки

отметок хода?

## DoD

Тик, увидев проход головы молчащим дольше порога, заказывает стоп сессии и паркует проход причиной «молчание». Потолок проходов не пускает закольчивание. Условий, посильных только человеку, при разборе не нашёл: стоп идёт готовым механизмом, доступов и согласий задача не требует.

## Ранг

`25+8+1+0+2 = 36`, P2.

25+8+1+0+2 = 36, P2

- Серьёзность 25: молчащая голова жгёт квоту и держала конвейер, затор 25.10 стоил ночи.
- Ценность 8: автостоп убирает класс заторов, которые иначе разбирает человек по факту.
- Неопределённость 1: подход решён человеком 2026-10-26, порог и причина парковки названы.
- Поправка на баг 0: новое поведение тика.
- Рычаг 2: порог молчания уже считается для журнала, стоп встаёт на готовый замер.
