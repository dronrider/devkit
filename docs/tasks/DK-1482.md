# DK-1482: Сценарии остановок и конфликтов конвейера разобраны в документации

## Что происходит

При параллельной работе нескольких сессий и компьютеров задачи останавливаются
на разных этапах. Процедуры восстановления описаны по отдельным инструментам.
Общей таблицы сценариев, способов восстановления и границ автоматики нет.

## Чего хотим

Разобрать путь от постановки до закрытия и положить в docs справочник для
разбора остановок. Отдельно проверить защиту между процессами, чекаутами,
машинами и пользователями.

## DoD

- Для каждого сценария указаны признаки, область влияния, действующий механизм,
  порядок восстановления и оставшийся пробел.
- Выводы сверены с исходниками и существующими тестами. Предполагаемые риски
  отделены от подтверждённых ограничений.
- Из README и карты переходов есть ссылка на справочник.
- Приведены порядок актуализации и приоритеты незакрытых сценариев.

## Ранг

25 за затруднения в основном процессе с ручным обходом, 7 за общий справочник,
2 за сверку нескольких механизмов, 0 за исследовательскую задачу,
4 за ускорение последующих исправлений.

## Ход работы

Разбор проведён по исходникам текущего чекаута. Чужие незакоммиченные файлы
задач в работу не входят. Справочник лежит в docs/concurrency.md.

- Вычитка: 4 файла, 10 правок, 1 пометка, 2026-10-26.
