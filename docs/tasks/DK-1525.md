# DK-1525: Запись черновика требует однозначности и отказывает при малой фактуре

## Что происходит

При записи создаётся черновик, который оформлен не по шаблону. Я бы хотел, чтобы черновик заполнялся как нужно. То есть к черновику сейчас нет требований, а зря. Без нужной детализации превратить его в понятную задачу будет невозможно. Хочется чтобы скилл board-draft требовал однозначности от входящей информации и раскладывал всё сам по шаблону, а если информации мало отказывался создавать запись и задавал вопросы. Такая же история и с board-task. Нельзя создавать задачи которые непонятны для исполнителей.

По словам автора, без нужной детализации превратить черновик в понятную задачу невозможно. Поле быстрой записи на главной странице дашборда кладёт весь текст в «Ситуацию», подразделы «Осложнение», «Вопрос» и «Гипотеза» остаются пустыми, сам DK-1525 записан так (коммит 3a9088fe5). Путь человека идёт мимо скилла board-draft. Обязанность агента раскладывать фактуру по четырём подразделам уже записана (board-draft, п. 7 процедуры), а сырая запись с дашборда опирается на решения DK-1465 и DK-447.

## Чего хотим

Слова автора: черновик заполняется как нужно. Скилл board-draft требует однозначности от входящей информации и раскладывает всё сам по шаблону, а если информации мало, отказывается создавать запись и задаёт вопросы. Такая же история и с board-task: нельзя создавать задачи, которые непонятны для исполнителей.
