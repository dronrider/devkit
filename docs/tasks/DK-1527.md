# DK-1527: Быстрая запись дашборда раскладывает мысль и спрашивает недостающее

## Что происходит

Поле быстрой записи на главной странице дашборда кладёт весь текст в «Ситуацию», подразделы «Осложнение», «Вопрос» и «Гипотеза» остаются пустыми. Путь человека идёт мимо скилла board-draft и сегодня сознательно сырой (DK-1465, DK-447). Слово человека в разборе DK-1525 включило сценарий СЦ-4, черновики с дашборда обязаны приезжать в накопитель разобранными.

## Чего хотим

Отправленная мысль раскладывается по четырём подразделам на сервере после отправки, форма остаётся одним полем и человек в момент записи над формой не работает (развилка «охват подсказки» разбора DK-1525). Запись с малой фактурой черновика не создаёт, недостающее уходит вопросами в чат без записи (слово человека в развилке «отказ записи»).

## DoD

Запись из одной фразы с дашборда не создаёт черновик, вопрос виден в чате. Запись с фактурой приезжает в накопитель с раскладкой по четырём подразделам, как записи через скилл board-draft. Тест быстрой записи (tools/dashboard/newtask_test.go) проверяет раскладку и отказ.

## Ранг

`25+6+3+0+2 = 36`, P2.

- Серьёзность 25: сырые записи разбирает груминг восстановительными вопросами, трение заметное, обход дешёвый.
- Ценность 6: улучшение, которого ждут и просят, сценарий выбран словом человека.
- Неопределённость 3: раскладка выбрана на сервере, в деталях развилки и пересечение сервера с клиентом.
- Поправка на баг 0: новое поведение пути записи.
- Рычаг 2: небольшая своя польза, следующие записи приезжают разобранными.
