# DK-1528: Ворота add меряют понятность задачи до записи строки

## Что происходит

Ворота add меряют заполненность разделов постановки, понятность текста проверяют вычитка и ревью, машинного рубежа нет (СЦ-3 разбора DK-1525). Непонятное описание становится строкой, исполнитель возвращает его на переформулировку.

## Чего хотим

Ворота add расширяются дискретными признаками понятности из развилки «рубеж понятности» разбора DK-1525. «Что происходит» называет наблюдение с местом или командой, «Чего хотим» и DoD наблюдаемы снаружи, субъективной шкалы нет.

## DoD

taskctl add с описанием, где «Что происходит» не называет наблюдение с местом или командой, отказывает и называет признак. Описание с наблюдаемыми «Чего хотим» и DoD проходит. Тесты ворот проверяют оба исхода.

## Ранг

`25+5+2+0+2 = 34`, P2.

- Серьёзность 25: непонятные задачи возвращаются на переформулировку, трение заметное, обход дешёвый.
- Ценность 5: улучшение, которого ждут и просят, сценарий выбран словом человека.
- Неопределённость 2: признаки рекомендованы развилкой, открыты детали их проверки.
- Поправка на баг 0: новое поведение ворот.
- Рычаг 2: небольшая своя польза, понятные постановки дешевле в работе.
