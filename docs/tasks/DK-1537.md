# DK-1537: Выбор ответа в чате виден и отправляется без закрепа

## Что происходит

В чате дашборда варианты ответа выглядят выделенными строками без галочек.
askPickWire создаёт пустую кнопку caskpick, хотя стили рисуют отметку на
вложенном caskbox. Рекомендованные варианты сценариев доступны только после
кнопки прикрепления. Предпросмотр выбора стоит в строке с кнопками поля ввода
и на телефоне растягивает панель. После отправки отметки пропадают.

## Чего хотим

Человек видит рекомендуемый выбор сразу и отправляет его обычной кнопкой
чата. Для нескольких вариантов стоят галочки, для одного радиокнопки.
Выбор автоматически уезжает вложением вместе с необязательным сообщением.
Подтверждённые отметки остаются в исходном вопросе.

## Развилки

Решено пользователем 2026-10-31 по интерактивным макетам. Все три кнопки
жёлтые, с рамкой 3 px и светлым движущимся бегунком. У «По рекомендации»
рамка красная. У «Мой вариант» и «Выбрать и обсудить» рамка умеренно
насыщенная синяя. Левый край поля ввода совпадает с блоками сообщений.

## DoD

- Рекомендованные варианты отмечены при первом открытии вопроса.
- Галочки позволяют выбрать несколько вариантов и снять все отметки.
- Радиокнопки допускают один вариант, новый выбор заменяет прежний.
- Выбор прикрепляется автоматически и обновляется после каждого изменения.
- Кнопки прикрепления и предпросмотра выбора удалены из поля и ленты.
- При неизменённой рекомендации кнопка называется «По рекомендации».
- Изменённый выбор без текста отправляется кнопкой «Мой вариант».
- Выбор с текстом отправляется кнопкой «Выбрать и обсудить».
- Подтверждённые отметки видны после отправки и обновления страницы.
- Набранный текст, изображения и другие вложения отправляются прежним путём.
- Поле ввода и сообщения выровнены, на ширине 320 px нет переполнения.
- Регрессионный тест падает на исходном коде и проходит после исправления.

## Проектирование UI

Согласовано пользователем 2026-10-31 в этой сессии. Реализация разрешена.
Все три кнопки жёлтые с рамкой 3 px и светлым движущимся бегунком.
У рекомендации рамка oklch(0.53 0.17 25), бегунок oklch(0.86 0.075 25).
У двух остальных состояний рамка oklch(0.505 0.145 258), бегунок
oklch(0.83 0.085 245). Оборот 2.8 s linear infinite, при reduced-motion
рамка статична. В макете conic-gradient от угла анимации с основой до
240 deg, переходом к светлому на 275 deg, светлым до 315 deg и возвратом
к основе на 350 deg.

Для нескольких вариантов native checkbox, для одного native radio с общим
name в пределах вопроса. Рекомендация отмечена сразу. Повторное нажатие
радиокнопки не снимает её. После отправки отметки остаются в исходном
сообщении доступными для просмотра. Выбор сохраняется после перезагрузки.

Текст для «По рекомендации» и «Мой вариант» необязателен. С текстом кнопка
называется «Выбрать и обсудить». Обычная отправка без открытого вопроса
сохраняет прежний вид. Предпросмотра или закрепа выбора нет ни в поле, ни
в ленте, служебное вложение с выбором сервер получает автоматически.
Граница поля ввода совпадает с внешней левой границей сообщений. На узком
экране отправка стоит отдельной строкой на всю ширину под выбором модели.

При опросе должны появляться новые вопросы, даже если выбор прикреплён
автоматически. Для нового снимка появляется новый выбор, подтверждённые
отметки остаются у своего вопроса. При ошибке отправки выбранные варианты
можно отправить повторно. Набранный текст и другие вложения сохраняют прежний путь.
