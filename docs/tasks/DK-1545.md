# DK-1545: Подтверждение груминга показывает подготовленную задачу

## Что происходит

Механика DK-1469 работает. Карточка add несёт готовое тело задачи, лежит в записи черновика и применяется после решения человека. Витрина называет её «предложением разбора». Слово читается иначе, как мысль человека по черновику. Назначение подтверждения из витрины не видно. Пользователь отказался работать с витриной в этом виде 2026-11-01.

Подтверждение на деле нужно для другого. Описание задачи проверяют заранее. Тогда к исполнению вопросов к человеку не останется, и агенты сделают работу автономно. Эта цель в LLD DK-1469 не записана. Там обоснованием стоит сохранность доски.

## Чего хотим

Словарь и витрина говорят «подготовленная задача». Вопрос `proposals ask` и экран записи панели показывают карточку add задачей со статусом «подготовлена». После решения человека статус становится «подтверждена». Внутренняя механика не меняется. Снимки, редакции, план применения и четыре исхода остаются как есть. Существующие записи с карточками открываются новой витриной без миграции схемы.

Назначение подтверждения записано в LLD DK-1469 и скилле board-groom. Описание проверяется заранее ради автономного исполнения.

Вне границы правки два направления из обсуждения. Первое, перенос карточек в отдельное хранение. Запись черновика остаётся их местом. Второе, вклады людей по черновику до груминга. Это отдельная фича, участник доски сегодня один. Условий, посильных только человеку, не нашлось. Правка текстов и витрины доступов и секретов не требует. Взгляд пользователя на новой витрине остаётся приёмкой.
