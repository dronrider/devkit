# DK-1547: [dashboard] Незачатый чат с черновиком тонет в списке

## Что происходит

У незачатого разговора Mtime ставится по времени создания записи (chatBlankList, chats.go), и набор черновика стартового сообщения порядок не двигает. Чат, в котором человек сейчас пишет, уходит вниз под сегодняшние разговоры, хотя список держит свежие сверху.

## Чего хотим

Набор черновика двигает позицию незачатого чата: время последней записи черновика становится временем сортировки записи. Группы списка (открытый чат, активные, дни) и их порядок DK-656 не меняются.

## DoD

Пишу стартовое сообщение в новом чате, открываю список: чат стоит среди сегодняшних по времени последней буквы черновика.

## Ранг

`25+4+1+0+0 = 30`, P2.

- Серьёзность 25: заметное трение, обход открытым чатом в панели есть.
- Ценность 4: позиция по активности прямо названа в гипотезе черновика.
- Неопределённость 1: место правки найдено, остаётся сделать.
- Поправка на баг 0: случай появился вместе с незачатыми чатами.
- Рычаг 0: на другую работу не влияет.
