# DK-1564: Согласование груминга: идеи на форме, задачи ссылками без портянок

## Что происходит

Перестройка витрины DK-1545 не сняла боль. Тела подготовленных задач лежат в записи черновика блоком JSON. Вопрос согласования несёт те же тела портянкой в чат. Поля для мысли человека на форме черновика нет. Пользователь 2026-11-02 отверг витринную правку и задал желаемое тремя пунктами.

## Чего хотим

Первое, слово «предложение» в старом виде не фигурирует нигде. Ни в чатах, ни в черновиках. Блоки тел задач уходят из записи черновика, подготовленные задачи живут отдельно. Адрес хранения и миграцию старых записей выбирает правка LLD DK-1469, она едет этой же задачей.

Второе, у черновика появляется раздел идей. Кнопка на форме записи, человек пишет текстом мысль, идеи видны в записи. Грумер поднимает их на разборе, человек подтверждает приём.

Третье, согласование короткое. Агент готовит задачи и пишет в чате «Подготовил задачи, согласуй их описание». Дальше вопрос обычными галками. У каждой задачи в чате стоит ссылка, пользователь открывает её и читает задачу. Потом подтверждает или просит поправить. Портянок тел задач в чате нет.

DK-1545 принята пользователем 2026-11-02 подэтапом. Словарь статусов «подготовлена» и «подтверждена» остаётся. Условий, посильных только человеку, не нашлось. Взгляд на новой форме остаётся приёмкой.

## DoD

Слово «предложение» и блоки тел задач не фигурируют ни в чатах, ни в черновиках. Старые записи читаются. На форме черновика есть кнопка оставить мысль. Идеи лежат разделом записи, грумер их поднимает, человек подтверждает приём. Согласование идёт репликой «Подготовил задачи, согласуй их описание» и вопросом галками. У задач ссылки, описание читается по ссылке. Дальше подтверждение или просьба поправить. Договор DK-1469 переписан, подтверждение работает на автономное исполнение.
