# DK-1564: Согласование груминга: идеи на форме, задачи ссылками без портянок

## Что происходит

Перестройка витрины DK-1545 не сняла боль. Тела подготовленных задач лежат в записи черновика блоком JSON. Вопрос согласования несёт те же тела портянкой в чат. Поля для мысли человека на форме черновика нет. Пользователь 2026-11-02 отверг витринную правку и задал желаемое тремя пунктами.

## Чего хотим

Первое, слово «предложение» в старом виде не фигурирует нигде. Ни в чатах, ни в черновиках. Блоки тел задач уходят из записи черновика, подготовленные задачи живут отдельно. Адрес хранения и миграцию старых записей выбирает правка LLD DK-1469, она едет этой же задачей.

Второе, у черновика появляется раздел идей. Кнопка на форме записи, человек пишет текстом мысль, идеи видны в записи. Грумер поднимает их на разборе, человек подтверждает приём.

Третье, согласование короткое. Агент готовит задачи и пишет в чате «Подготовил задачи, согласуй их описание». Дальше вопрос обычными галками. У каждой задачи в чате стоит ссылка, пользователь открывает её и читает задачу. Потом подтверждает или просит поправить. Портянок тел задач в чате нет.

DK-1545 принята пользователем 2026-11-02 подэтапом. Словарь статусов «подготовлена» и «подтверждена» остаётся. Условий, посильных только человеку, не нашлось. Взгляд на новой форме остаётся приёмкой.

## DoD

Слово «предложение» и блоки тел задач не фигурируют ни в чатах, ни в черновиках. Старые записи читаются. На форме черновика есть кнопка оставить мысль. Идеи лежат разделом записи, грумер их поднимает, человек подтверждает приём. Согласование идёт репликой «Подготовил задачи, согласуй их описание» и вопросом галками. У задач ссылки, описание читается по ссылке. Дальше подтверждение или просьба поправить. Договор DK-1469 переписан, подтверждение работает на автономное исполнение.

## Сценарий проверки

Агентская часть гоняется из корня дерева после слияния, у шагов с синтетической
доской своё временное дерево. Человеческая половина глазами на живой панели
после выката: кнопка «Оставить мысль» на экране записи и согласование галками
со строками-ссылками вместо портянок тел.

```sh
sh -c 'grep -r -l -E "draft proposals|Предложения разбора" kit/skills tools/taskctl/README.md tools/dashboard/README.md tools/obeycheck/scenarios; test $? -eq 1'
T=$(mktemp -d) && taskctl -C "$T" init --prefix SC >/dev/null && printf 'мысль на разбор' | taskctl -C "$T" draft --prio mid >/dev/null && ID=$(taskctl -C "$T" draft list --json | jq -r '.drafts[0].id') && SNAP=$(taskctl -C "$T" draft prepared "$ID" | jq -r .snapshot) && printf '%s' '{"proposals":[{"id":"p1","revision":1,"outcome":"drop","text":"лишнее","reason":"сценарий"}]}' | taskctl -C "$T" draft prepared save "$ID" --base "$SNAP" >/dev/null && test -f "$T/docs/tasks/prepared/$ID.md" && ! grep -q 'Предложения разбора' "$T/docs/tasks/drafts/$ID.md" && printf '%s\n%s\n' "$T" "$ID" > /tmp/dk1564-scen.state && echo 'носитель: prepared-файл заведён, блок из записи срезан'
T=$(sed -n 1p /tmp/dk1564-scen.state) && ID=$(sed -n 2p /tmp/dk1564-scen.state) && Q=$(taskctl -C "$T" draft prepared ask "$ID") && test "$(printf '%s' "$Q" | jq -r '.prepared.sources[0].proposals[0].text')" = '' && printf '%s' "$Q" | jq -r .text | grep -q "#$(basename "$T")/draft/$ID/prepared/p1" && test -f "$T/.devkit/chat/task-$ID.ask" && echo 'вопрос: тел нет, строка-ссылка и ожидание на месте'
test -f docs/tasks/prepared/DK-1531.md && test -f docs/tasks/prepared/DK-1555.md && ! grep -q 'Предложения разбора' docs/tasks/drafts/DK-1531.md docs/tasks/drafts/DK-1555.md && echo 'миграция: живые записи на prepared-носителе'
```

Ожидание. Первый шаг не печатает файлов и кончается кодом ноль: прежних имён
группы и блока в скиллах, README и сценариях нет. Второй печатает «носитель:
prepared-файл заведён, блок из записи срезан», третий «вопрос: тел нет,
строка-ссылка и ожидание на месте», четвёртый «миграция: живые записи на
prepared-носителе». Любой другой вывод или ненулевой код это провал шага.
