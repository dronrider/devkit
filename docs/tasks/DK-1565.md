# DK-1565: Ответ «По рекомендации» без текста кладёт в ленту пустое сообщение

## Что происходит

В чате дашборда открыт вопрос с вариантами, поле ввода пустое. Нажать «По
рекомендации». То же выходит с «Мой вариант» без отметок.

В ленте ждался читаемый след ответа. По замыслу DK-1537 следом ответа служат
подтверждённые отметки в вопросе, отдельного блока выбора в ленте нет. В
ленту встал пустой пузырь «вы» с одной подписью доставки.

Причина найдена в исходниках 2026-11-02. Клиент по дизайну DK-1537 шлёт
пустой text вместе с выбором. Браузерный тест chat_choice_browser.mjs
утверждает пустой текст как ожидаемый. Сервер кладёт в транскрипт
SelectionMessage с пустым text. Лента рисует запись в двух местах.
Локальное эхо makeEcho.draw в static/app.js строит пузырь сразу после
нажатия. Пузырь записи транскрипта идёт через chatBubble там же. Защита
fire() пустую строку пропускает. При selection текст необязателен, так
задумано в DK-1537.

## Чего хотим

Ответ с выбором и без слов не оставляет в ленте пустого пузыря. След ответа
читается выбранным в развилке способом. Дорога агента не меняется. Провод с
пустым text и вложением уходит как прежде, выбор доезжает до taskctl тем же
порядком.

## Границы

Предложение и комментарий сценария не трогаем, у них своя дорога. Механику
доставки, дожима и повтора не трогаем. Правка затрагивает только рисование
ленты.
