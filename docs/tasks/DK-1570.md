# DK-1570: Ручной выбор глубины размышления при запуске

## Что происходит

Глубину размышления (effort) для запуска задачи выбирает вердикт `agentctl pick`, ручки у человека в панели нет. Маппинг идёт по неопределённости строки. Ноль едет low, единица и двойка medium, тройка high; LLD и грумминговый вердикт едут xhigh, max маппингом не выдаётся вовсе. Обход один, строка «Эффорт:» в файле задачи, и на каждый разовый запуск она требует правки файла. Харнес glm-code-2 умеет выставлять уровень, delegate-команда несёт `--effort`. Панель его не выставляет. Дизайн снят макетом `.devkit/mockup-effort-select.html`, пользователь согласовал его 2026-11-03.

## Чего хотим

Одно меню на два места: стрелка у кнопки «Выполнить» и клик по выбору модели в строке ввода чата. В меню секция моделей и ползунок глубины со ступенями выбранной семьи моделей. Строка меню это подписка, модель и ярус целиком, как в лестнице `agentctl harness`, рядом две полоски её квот, окно 5ч и неделя. Подписок одного вида может быть несколько: на каждую подписку своя строка с той же моделью, полоски показывают квоты именно её. Позиция по умолчанию это вердикт pick, на шкале её показывает кольцо, вердикт вне набора ступеней поднимается до ближайшей сверху. Выбор действует на один запуск, в чате на следующий запуск из разговора. Настройкой на экране или на задаче он не становится. Приоритет на запуске такой. Слова в команде и ручной выбор в меню сильнее строки «Эффорт:», строка сильнее вердикта. Пока выбор не потрачен, его показывают мини-полоска в поле подписки чата и чип глубины рядом с приоритетом на экране задачи. В ленте чата плашек и кнопок нет, уровень поехавшей работы агент называет текстом. Контрол один и тот же у кнопки груминга черновика. Условий, посильных только человеку, не нашлось.

## DoD

У кнопки запуска и у выбора модели в строке ввода чата открывается одно меню с ползунком глубины. Выбор действует на один запуск. Следующий запуск задачи едет выбранным уровнем, и это видно в записи `~/.devkit/runs` (определение `exec-<уровень>` либо `--effort` в команде спавна). Кольцо на шкале показывает вердикт pick, вердикт вне набора ступеней поднимается до ближайшей сверху. При двух подписках одного вида меню показывает по строке на подписку с квотами каждой. Шкала несёт ступени выбранной семьи моделей. Пока выбор не потрачен, его показывают мини-полоска в поле подписки чата и чип глубины рядом с приоритетом на экране задачи, уровень чипа приходит из записи этапа. В ленте чата лишних элементов нет. Тесты покрывают проезд выбора в команду запуска и состав меню. Для новичка в доке панели появляется вход, первый запуск с ручной глубиной по шагам.
