# DK-1581: Подписка OpenCode Go доступна через Claude Code

## Что происходит

Дашборд запускает Claude Code с GLM и RouterAI. Подписка OpenCode Go приобретена, ключ хранится отдельно. Профиля этой подписки в devkit нет. Нужен DeepSeek V4.1 Flash для основной работы и DeepSeek V4 Pro для сложных задач.

## Чего хотим

Добавить профиль opencode-go с отдельным каталогом настроек, существующими хуками, навыками и запуском через agentctl exec. Подключить подписку на машине дашборда. Секрет подставлять через secretctl без вывода значения. Модели появляются в существующем переключателе. Разговор продолжается после переключения подписки.

## Границы

Используем клиент Claude Code и Anthropic-совместимый API OpenCode Go. Нового клиента, прокси и изменений формата транскрипта нет. Подписка по умолчанию и разрешение автоматических запусков сохраняются. Учёт остатка квоты отдельным съёмщиком в эту работу не входит; неизвестный остаток нельзя показывать как полный.

## Развилки

Открытых человеческих развилок нет. Пользователь подтвердил подключение Go с DeepSeek Flash и Pro. Основная модель Flash, верхние ярусы Pro.

## DoD

Профиль проходит валидацию обоими читателями. doctor раскладывает хуки и навыки. На рабочей машине Flash выполняет команду и правку файла в отдельном стенде, Pro отвечает через тот же endpoint. В API дашборда видны обе модели. Проверено продолжение истории после переключения подписки. Инструкция первого подключения записана рядом с профилями.

## Ранг

`25+5+3+0+4 = 37`, P2.

- Серьёзность 25: дополнительный исполнитель при работающих текущих.
- Ценность 5: подписка приобретена для ежедневных задач.
- Неопределённость 3: сторонний API и удалённая машина требуют живой проверки.
- Поправка на баг 0: новая возможность.
- Рычаг 4: дополнительная ёмкость исполнителей.

- вид: agent
- Секрет подставляется secretctl в подпроцесс, удалённая машина доступна по SSH. Проверки API и истории автоматизируются. Условий, посильных только человеку, не найдено.
