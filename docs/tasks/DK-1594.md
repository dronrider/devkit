# DK-1594: Строка активности чата липнет к полю ввода, блеск слова медленный

## Что происходит

Проверил 2026-11-04 живую панель чата после закрытия DK-1586. В строке активности остались две недоработки.

Снизу у строки нет отступа. Её нижняя рамка стоит вплотную к полю ввода, и два блока читаются как один слипшийся. В макете `.devkit/mockup-DK-919/index.html` у строки в узкой раскладке снизу 12 точек.

Блеск слова идёт слишком медленно. Один проход полосы занимает 3,2 секунды, и слово кажется почти неподвижным. Пользователь просит сделать анимацию живее.

## Чего хотим

Между строкой активности и полем ввода появляется видимый зазор. Блеск слова идёт заметно быстрее, но полоса не мелькает и слово остаётся читаемым.

## DoD

Замер в браузере даёт зазор между нижней рамкой строки и верхом поля ввода не меньше 10 точек. Тест держит и зазор, и новый период блеска. Замер гоняет четыре фазы анимации и видит полосу в новом темпе. README панели называет новый период.

## Ранг

`0+2+0+5+0 = 7`, P3.

- Серьёзность 0: строка работает, это вид и удобство чтения.
- Ценность 2: строку видно в каждом ходе, но правка мелкая.
- Неопределённость 0: место и величина отступа известны, темп задаётся одной строкой.
- Поправка на баг 5: это недоработка уже сданной DK-919.
- Рычаг 0: на другую работу правка не влияет.

## Ход работы

- 2026-11-04: строке активности дан нижний отступ 12 точек при верхних 6 и левых 17, период блеска сокращён до 2 секунд. Тест держит новые числа, probe читает длительность из computed style и мерит зазор снизу. README называет новый период и зазор.
- Вычитка: 1 файл, 0 правок, 1 пометка, 2026-11-04.

## Сценарий проверки

Вид агентский, шаги гоняются из корня свежего дерева. Стенд поднимает
страницу в headless Chrome, живые доски не трогаются. Первый шаг воспроизводит
старую поломку на main. Probe получает style.css из коммита до правки.

1. Старая поломка. Probe мерит зазор между нижней рамкой строки и верхом поля
   ввода по style.css из main.

```sh
git show d8dc6e1b7:tools/dashboard/static/style.css > /tmp/dk-1594-old.css && node tools/dashboard/testdata/busyrow_probe.mjs "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" 440 /tmp/dk-1594-old.css
```

Ожидание это код 1 и в `problems` строка про зазор снизу. Поле `gap` равно 0
точек при нужных 10.

2. Тест пакета держит новый период блеска и отступы строки.

```sh
devkitctl test tools/dashboard
```

Ожидание это код 0 и «ok» у пакета go:dashboard.

3. Замер текущим файлом стиля. Probe читает период из computed style и видит
   новый темп.

```sh
node tools/dashboard/testdata/busyrow_probe.mjs "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" 440
```

Ожидание это код 0, поле `gap` равно 12, `duration` равно `2s`, положения
фона по фазам 100, 75, 50, 25 процентов.
