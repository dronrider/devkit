# DK-1599: Диалоги дашборда соответствуют стандарту форм

## Что происходит

В цепочке задач собранный состав хранится локально и теряется при закрытии без вопроса. У «Записать» цепочки и «Копировать» разворота фрагмента нет иконок. Решения 3, 6 и 7 DK-1438 задают поведение и оформление этих диалогов.

## Чего хотим

Цепочка с собранным составом запрашивает подтверждение ухода карточкой потери. Пустой состав закрывается сразу. Крестик, Escape и клик мимо проходят один путь. Кнопки «Записать», «Копировать», «Не записывать» и «Остаться» получают иконки по стандарту. Отступы цепочки берутся из существующей лестницы.

## Границы

Выполняется после задачи каркаса из нарезки DK-1438. Просмотр снимка и фрагмента закрывается без карточки потери, как предусмотрено решением 3. Механика сборки цепочки, вопросы разговора и вход не меняются.

## DoD

- Закрытие заполненной цепочки каждым из трёх способов показывает карточку потери. «Остаться» сохраняет состав; «Не записывать» закрывает диалог. Пустой состав закрывается сразу.
- У четырёх названных кнопок есть иконки, отступы цепочки соответствуют лестнице решения 7. Диалоги читаются на широком и узком экране.
- Снимок и фрагмент закрываются крестиком, Escape и кликом мимо без карточки потери; копирование фрагмента сохраняет прежний результат.
- Браузерный сценарий подтверждает поведение. Независимая приёмка проверяет установленный дашборд после выката на синтетическом проекте.

## Ранг

`25+5+1+0+0 = 31`, P2.

- Серьёзность 25: собранный состав можно потерять; обходом служит отказ от закрытия до записи.
- Ценность 5: подтверждение ухода сохраняет работу человека, диалоги соответствуют общему стандарту.
- Неопределённость 1: состав правки задан решениями 3, 6-8 DK-1438.
- Поправка на баг 0: добавляется принятое стандартом поведение.
- Рычаг 0: другие задачи этой правки не ждут.
