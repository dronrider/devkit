# DK-1606: Общий список чатов теряет основную строку при передаче в одну секунду

Цель: связано с DK-1433 и DK-1601, держит приёмку DK-1253

## Что происходит

При сквозной проверке DK-1433 на установленном b110be669 передача роли в одну
секунду даёт в общем списке чатов колеблющуюся основную строку. У задачи XR-903
полные строки запуска A dd834458-28d1-4387-b674-b00ae8fabd55 и
B 42bc6b8e-ae27-4c89-b71b-23b8980da483 несут одну временную метку
2026-11-05T05:35:44 UTC. Чтение task/chat вернуло носителя B во всех 64
случаях, контрольную реплику получил B.

64 пары read-only чтений GET task/chat и GET chats?all=1&days=3 дали строку
id=XR-903, main=true только 28 раз. В остальных 36 чтениях строки в списке
нет, вместо неё стоит физическая A с past=[B]. Между чтениями состояние не
менялось. Браузерный снимок сети показал ту же смену main XR-903 на сырую A
между одинаковыми запросами. Геттер после DK-1601 отдаёт B устойчиво, путь
сборки общего списка выбирает запись по-другому и на одинаковых секундах даёт
то A, то B.

Каждое чтение с полными строками и точными SID сохранено в
/private/tmp/dk1433-final-run/proof/list-flap-FAIL.json.

Ожидалась основная строка B в каждом чтении списка.

## Чего хотим

Сборка общего списка выбирает основную строку тем же правилом, что и геттер
task/chat после DK-1601. Повторные чтения без мутаций возвращают одну и ту же
основную строку. Передача с зазором во времени читается списком по-прежнему.

## Границы

Геттер task/chat после DK-1601 не переделывается. Порядок физических строк в
past не меняется. Разделение ленты после нового подъёма окна это DK-1138,
здесь речь о выборе основной строки в общем списке.

## DoD

- Повторные read-only чтения общего списка возвращают main=B без пропусков
  на 64 проходах.
- Поведенческий тест воспроизводит две полные строки одной секунды, падает
  на версии до правки и проходит после.
- Передача с зазором во времени читается списком как раньше.
- README описывает правило выбора основной строки списком.

## Ранг

`50+5+2+5+3 = 65`, P1.

- Серьёзность 50: живой основной чат пропадает из общего списка, читатель
  открывает мёртвое окно.
- Ценность 5: общий список это вход в разговоры дашборда.
- Неопределённость 2: правило геттера известно, место сборки списка ищется
  по доказательству.
- Поправка на баг 5: колебание подтверждено 64 чтениями установленного
  бинаря.
- Рычаг 3: снимает красные шаги 2 и 5 приёмки цели DK-1253.
