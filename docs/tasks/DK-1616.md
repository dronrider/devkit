# DK-1616: [dashboard] Дашборд убирает зеркало вопроса клиента

## Что происходит

У вопроса человеку два канала. Рабочий идёт командой taskctl decide: блок в реплике, галочки панели при строках вариантов, ответ обычной репликой (DK-864, DK-1374). Второй канал соскребает родной диалог клиента из tmux-панели. Ручка GET /chats/{sid}/ask (chats.go:3851) зовёт tmuxAskOf (tmux.go:417), панель рисует карточку «Клиент ждёт ответа» (paintClientAsk, app.js:15089) с кнопками вариантов, ответ уезжает клавишами (handleChatAskAnswer, chats.go:4129, tmuxAnswer tmux.go:445). Пользователь назвал механику ущербной и отказался от неё 2026-11-02. В карточку попадали служебные опции клиента («Type something.», «Chat about this»), строка вопроса ломалась глифами терминала, выбор подтверждался вслепую. Решение человека записано в DK-1563: склейку убрать, вопросы на дашборде только текстом с галочками, плашка «Клиент ждёт разрешения» умирает вместе со склейкой.

## Чего хотим

Зеркало исчезает. У вопроса человеку остаётся один дашбордный канал decide и родный диалог у консоли.

- Дороги зеркала сняты: ветка tmuxAskOf в handleChatAsk, ветка tmuxAnswer в handleChatAskAnswer, карточка paintClientAsk с кнопками askOptLine, плашка paintAskStuck. Ручка GET /ask оставляет askpass и вопрос агента (kind agent).
- При своих дорогах остаются: очередь askHold и признак запертости chatStuck из журнала уведомителя (метка «ждёт ответа в терминале» в списке чатов, превращение реплики в нажатие варианта в /say, дренаж очереди), логин клиента (parseTmuxAsk и tmuxAnswerText в clientlogin.go), метка доверия каталогу (chats.go:1339), чип widgetWaits строки доски (waiting.go:515).
- Тесты: tmux_test.go чистится от тестов зеркала, разбор для логина и доверия остаётся. agentask_test.go требует отсутствия paintClientAsk вместо наличия. askroad_test.go снимает строки плашки. poc_clientask.mjs и poc_caskopt.mjs уходят.
- Дока: README переписан под оставшиеся дороги (разделы «Вопрос клиента кнопками», «Две дороги вопроса и строка журнала»). ARCHITECTURE.md описывает канал реплик и не правится.
