# DK-1629: Экран черновика запрашивает несуществующую строку задачи

## Что происходит

В HAR два ответа 404 на GET tasks/DK-1563 и tasks/DK-1604. Сервер отвечает, что ID принадлежит записи накопителя и строки доски пока нет. В static/app.js paint предварительная загрузка quick включается при rt.id, включая rt.draft и подготовленную задачу. Она обращается к API обычной строки и может показывать её оболочку загрузки. Лишние запросы заняли 143-203 мс.

## Чего хотим

Маршруты черновика и подготовленной задачи читают свой API и получают соответствующую оболочку загрузки.

## Развилки

Открытых человеческих развилок нет. Пользователь 2026-11-06 поручил оформить все находки исследования тяжёлых ручек. Доступы и необратимые шаги от человека для реализации и проверки не требуются. Реализацию выбирает исполнитель в пределах описанного поведения.

## DoD

- Открытие и обновление draft и draft/prepared не запрашивает tasks/<ID> для исходной записи.
- Обычная задача сохраняет предварительную загрузку и правильную обработку отсутствующей строки.
- Проверка маршрутов и запросов падает на старом коде и проходит через regcheck после правки.

## Ранг

`0+3+1+5+1 = 10`, P3.

0+3+1+5+1 = 10, цена S.

- Серьёзность 0. Это лишний запрос, основной экран продолжает открываться.
- Ценность 3. Убираются ложные 404 и чужая оболочка загрузки.
- Неопределённость 1. Неверное условие маршрута найдено.
- Поправка на баг 5. Оба 404 воспроизведены из HAR.
- Рычаг 1. Разделяется загрузка разных видов записи.

## Сценарий проверки
