# DK-1632: Колокольчик скачивает полную ленту ради одной отметки

## Что происходит

static/app.js refreshBellDot на каждом refresh получает полный GET notifications и использует время последнего события. Размер ответа в HAR около 83 КБ. Локальная обработка занимает 53-96 мс, включая подписи и связь событий с разговорами. Для одной точки состояния эти данные не нужны.

## Чего хотим

Колокольчик получает лёгкий признак новых событий. Полная лента загружается для просмотра ленты.

## Развилки

Открытых человеческих развилок нет. Пользователь 2026-11-06 поручил оформить все находки исследования тяжёлых ручек. Доступы и необратимые шаги от человека для реализации и проверки не требуются. Реализацию выбирает исполнитель в пределах описанного поведения.

## DoD

- Для точки не передаются тела полной ленты и не собираются подписи всех событий.
- Сохранён первый заход без подсветки старой истории, отметка просмотра и фильтрация служебных событий.
- Клиент и сервер согласованы, полная лента работает прежним способом.
- Автоматические проверки покрывают первый вход, новое событие и просмотр; документация описывает путь маркера.
