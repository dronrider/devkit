1. `git ls-files` по замку молчит: пути в индексе нет.

```sh

```

2. `git check-ignore -v` называет правило в .gitignore: путь прикрыт.

```sh
git check-ignore -v .devkit/merge-queue.json.lock
```

3. Новый клон файл не получает.

```sh
t=$(mktemp -d) && git clone -q --local . "$t/k" && test ! -e "$t/k/.devkit/merge-queue.json.lock" && rm -rf "$t"
```
