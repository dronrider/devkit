# DK-1651: Замок merge-queue.json.lock закоммичен в репозиторий

## Что происходит

Файл .devkit/merge-queue.json.lock закоммичен в репозиторий (коммит
ee1ebb1d1 с закрытием DK-1295), check-ignore его не прячет. Комментарий
queue.go:36-38 называет файл состоянием конвейера одной машины, которому
в git места нет. Файл пустой и безвредный по устройству (lock.go:119),
замок работает и под свободным состоянием.

## Чего хотим

Убрать файл из индекса (git rm --cached) и закрыть путь гитигнором. Замок
на диске остаётся работать как раньше.

## Границы

- Механика lock.go и содержимое замка не трогаются.

## DoD

git ls-files не показывает .devkit/merge-queue.json.lock, путь закрыт
гитигнором, замок создаётся и снимается как раньше. Новые клоны файл не
получают.

## Ранг

`0+1+0+0+0 = 1`, P3.

- Серьёзность 0: клоны работают, пропажи никто не замечает.
- Ценность 1: чистые клоны и честный гитигнор.
- Неопределённость 0: одна команда и строка гитигнора.
- Поправка на баг 0: ничего не перестало работать, лишний файл в индексе
  ничего не ломает.
- Рычаг 0: дальше ни на что не влияет.
