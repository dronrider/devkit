# DK-1695: В дашборде работает профиль Codex

## Что происходит

В дашборде нет рабочего профиля Codex для обычного чата. Пользователь хочет подключить его через подписку ChatGPT. В DK-1624 уже проверены основные возможности протокола, но дальнейшая доводка прототипа не нужна для подключения профиля.

Пользователь 2026-11-11 уточнил приоритет: «Прототип задрачивать не стоит. Нужно завершить подключение профиля, а всё остальное потом».

## Чего хотим

Выбрать профиль Codex в дашборде, открыть его чат и работать с ним через действующую подписку. Довести этот путь до рабочей машины пользователя.

## Границы

Первый рабочий профиль использует app-server и штатный вход Codex. Текущие профили и рабочие чаты сохраняются. Смена клиента с переносом старой истории отложена; при неподдерживаемом переходе исходный разговор сохраняется, а ограничение видно до продолжения.

Закрытие, повторная обкатка и слияние DK-1624 не являются предпосылкой. Не запускать её taskhead и не расходовать подписку на повторное исследование. Из прототипа можно использовать уже известные результаты по мере надобности.

## DoD

1. Профиль Codex доступен в штатном выборе профилей и моделей дашборда. Для нового чата используется app-server и действующий вход через подписку ChatGPT.
2. Пользователь отправляет запрос, получает поток ответа, видит вызовы инструментов, их результаты и завершение. Codex может выполнить команду и изменить файл в отдельном тестовом проекте согласно действующей политике доступа.
3. Отмена, завершение и ошибка процесса не оставляют чат в вечном ожидании. При отсутствии клиента или входа видна конкретная причина.
4. Текущие профили и существующие чаты продолжают работать. Неподдерживаемый перенос истории не приводит к её потере или скрытому началу пустого разговора.
5. Есть необходимые автономные проверки адаптера и один ограниченный живой прогон рабочего профиля на синтетическом проекте. README описывает первый запуск. Подключение раскладывается штатной автоматикой, профиль проверен после выката на рабочей машине.

## Ранг

25+7+2+0+3 = 37, P2.

- Серьёзность 25: нужная пользователю подписка недоступна из чата дашборда.
- Ценность 7: пользователь получает рабочий профиль Codex для повседневных задач.
- Неопределённость 2: протокол опробован, остаётся встроить ограниченный путь в существующий чат.
- Поправка на баг 0: добавляется новая возможность.
- Рычаг 3: рабочий адаптер послужит основой следующих шагов интеграции.

## Приёмка

- вид: agent
- Профиль проверяется автоматизированно и на отдельном синтетическом проекте с действующим входом. Перенос между клиентами в этот прогон не входит.

## Сценарий проверки

1. После выката выбрать Codex, открыть новый тестовый чат и получить ответ на запрос.
2. Выполнить команду и правку файла в синтетическом проекте. Проверить отображение инструментов и завершение запроса.
3. Отменить запрос, проверить видимую ошибку недоступного клиента и обычную работу текущего профиля Claude. До обкатки исполнитель добавляет конкретные команды и ожидаемые исходы.

## Отложено

Позднее выполнить перенос Claude -> Codex -> Claude, общий журнал между клиентами, восстановление импортированной истории и защиту повторного импорта от дублей. Подробная прежняя постановка сохранена в коммите e6354b9a1. Продолжение исследования и закрытие DK-1624 также отложены.

## Вход исполнителю

Продолжать на glm-code-2 через текущий taskhead. Этот заказ заменяет прежнее требование сначала довести DK-1624 и реализовать весь перенос истории. Сразу подключать рабочий профиль Codex, провести нужные проверки, ревью и выкат. Не запускать параллельное исследование прототипа и не менять глобальную подписку по умолчанию.

Проверить текущие harnesses.go, chatlift.go и профиль kit/harness/codex.toml, выбрать минимальный путь до работающего чата. Использовать штатный вход клиента, секреты и чужие чаты не читать. Обновлённую постановку вычитать отдельным свежим контекстом и сохранить перед началом ветки. Прежний заказ следующих проходов со ссылкой на обязательную доводку прототипа считать отменённым.
