# DK-171: Цель: подписка z.ai в конвейере: гетерогенная лестница, запускатор vscode, скилл командной работы

## Цель

Подписка claude-code упирается в недельные бакеты, и дефицит двигает вердикты
вниз по лестнице, то есть платит качеством. Вторая подписка (GLM Coding Plan у
z.ai, Anthropic-совместимый endpoint) должна расширять пропускную способность
конвейера: дешёвые ярусы уезжают на неё, дорогая подписка тратится на то, что
требует сильной модели. Рядом два усилителя параллельности: запускатор
отдельного инстанса vscode с конфигом glm и скилл командной работы, чтобы
несколько людей или агентов вели один проект без конфликтов.

DoD (агентский):

1. Тестовая задача доски с ярусом base проходит конвейер исполнителем на
   подписке z.ai, и в файле задачи остаётся запись, чьей подпиской она сделана.
2. Команда-запускатор открывает инстанс vscode, где claude ходит в endpoint
   z.ai; dry-run печатает окружение (CLAUDE_CONFIG_DIR и base URL) без запуска
   редактора.
3. Скилл командной работы лежит в kit/skills и проходит
   `python3 kit/skills/check-skills.py`.

## Бюджет

бюджет: week_all <= 25
бюджет: week_max <= 10

## Задачи цели

Ядро цепочки уже стоит на доске, остальное заводит нарезка первым витком:

- DK-090: LLD гетерогенной лестницы, ярус разворачивается в чужой харнес.
- DK-040: agentctl run, делегирование native/cli/none с ограничителем
  вложенности; без него cli-режим не едет.
- Профиль kit/harness/glm-code.toml и машинный слой (CLAUDE_CONFIG_DIR, base
  URL, токен): задачи даст разбивка DK-090.
- Запускатор vscode с конфигом glm: заводит нарезка.
- Скилл командной работы над одним проектом: заводит нарезка.
