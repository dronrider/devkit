# DK-1710: Чат Codex остаётся с техническим идентификатором вместо названия

## Что происходит

14 ноября пользователь прислал снимок чата Codex в дашборде. После первой реплики «Тест» в шапке остаётся «чат asfa9829». Ожидается название, по которому можно узнать разговор. Сейчас вместо него показан технический идентификатор.

## Чего хотим

Название разговора Codex в шапке и списке чатов отображается по тем же правилам, что у остальных профилей. После первой реплики техническая заглушка заменяется названием разговора.

## Границы

Чиним название чата. Перенос истории и расширение прототипа сюда не входят. В ленте снимка также видно userMessage. Это диагностическая подсказка, отдельную доработку ленты в эту задачу не включаем. Чужие неотслеживаемые файлы сохраняем, в коммиты включаем только явные пути задачи.

## DoD

- Чат Codex после первой пользовательской реплики получает осмысленное название в шапке и списке.
- Название сохраняется после обновления страницы и повторного открытия разговора.
- Тест воспроизводит техническое название на прежнем коде и проходит после исправления.
- Исправление проверено на обновлённом дашборде.
