# DK-1710: Чат Codex остаётся с техническим идентификатором вместо названия

## Что происходит

14 ноября пользователь прислал снимок чата Codex в дашборде. После первой реплики «Тест» в шапке остаётся «чат asfa9829». Ожидается название, по которому можно узнать разговор. Сейчас вместо него показан технический идентификатор.

## Чего хотим

Название разговора Codex в шапке и списке чатов отображается по тем же правилам, что у остальных профилей. После первой реплики техническая заглушка заменяется названием разговора.

## Границы

Чиним название чата. Перенос истории и расширение прототипа сюда не входят. В ленте снимка также видно userMessage. Это диагностическая подсказка, отдельную доработку ленты в эту задачу не включаем. Чужие неотслеживаемые файлы сохраняем, в коммиты включаем только явные пути задачи.

## DoD

- Чат Codex после первой пользовательской реплики получает осмысленное название в шапке и списке.
- Название сохраняется после обновления страницы и повторного открытия разговора.
- Тест воспроизводит техническое название на прежнем коде и проходит после исправления.
- Исправление проверено на обновлённом дашборде.

## Ранг

`25+4+1+5+1 = 36`, P2.

- Серьёзность 25: по техническому идентификатору неудобно находить нужный разговор, содержимое можно проверить открытием чата.
- Ценность 4: разговоры Codex становятся различимыми в общем списке.
- Неопределённость 1: симптом подтверждён снимком, источник заголовка проверит исполнитель.
- Поправка на баг 5: отображается техническая заглушка после отправки сообщения.
- Рычаг 1: исправление действует для следующих разговоров того же профиля.

## Приёмка

- вид: agent
- Проверены доступ, секрет, необратимость, согласие, событие и глаза. Условий, посильных только человеку, не найдено. Заголовок и его сохранение проверяются по состоянию дашборда и отрисованному тексту.

## Ход работы

- Вычитка: 1 файл, 1 правка, 0 пометок, 2026-11-14.
- Исправлена передача первой реплики в общую лестницу названия. Regcheck подтвердил красноту на main; адресные тесты прошли. Проверка обновлённого дашборда остаётся после выката.

## Сценарий проверки

Изолированный стенд создаёт разговор Codex, проверяет название в списке и
первую реплику при повторном чтении. Соседний тест проверяет архивирование.

```sh
devkitctl test tools/dashboard -run 'TestAppChatTitleFromFirstMessage|TestAppChatListAndArchive|TestTitle'
```

После выката войти в дашборд, открыть отдельный разговор Codex и отправить
короткую реплику. Проверить название в шапке и списке, обновить страницу и
повторно открыть разговор. Название должно сохраниться. Проверить название
обычного разговора другого профиля. При проверке через API нужен вход в
дашборд; токен в вывод не печатать.
