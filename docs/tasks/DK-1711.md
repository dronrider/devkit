# DK-1711: Груминг на Sol завершается до первого хода

## Что происходит

14 ноября пользователь выбрал Sol кнопкой груминга черновика и запустил разбор. Работы в чате не видно. Журнал дашборда подтверждает запуск груминга DK-1536 через профиль codex в 16:24:43. Через секунду клиент завершился, не начав хода и не зарегистрировавшись. Подготовленных результатов нет. Временный каталог опекуна уже удалён, точная причина завершения пока неизвестна.

## Чего хотим

Груминг черновика запускается на выбранной модели Sol через профиль Codex. Начало работы и её состояние видны в дашборде. При отказе запуска пользователь получает конкретную причину.

## Границы

Восстановить запрошенный пользователем груминг DK-1536 после исправления причины. Сохранить выбор Sol, исходный черновик и порядок согласования результатов. Подготовленные задачи не применять без подтверждения пользователя. Перенос истории между клиентами сюда не входит. Чужие неотслеживаемые файлы не трогать.

## DoD

- Повторный запуск груминга на Sol начинает ход, который виден в чате черновика.
- Выбор модели и профиля сохраняется, скрытого переключения на другую подписку нет.
- Отказ клиента до первого хода диагностируется и доступен пользователю.
- Исправление покрыто тестом с проверкой красноты на прежнем коде и проверено на обновлённом дашборде.

## Ранг

`25+5+2+5+2 = 39`, P2.

- Серьёзность 25: выбранный запуск не работает, пользователь может выбрать другой профиль.
- Ценность 5: выбранная модель начинает разбор черновика из дашборда.
- Неопределённость 2: завершение клиента подтверждено, точная причина ещё не установлена.
- Поправка на баг 5: действие запуска завершается без хода и результата.
- Рычаг 2: тот же вход используется для следующих запусков груминга.
