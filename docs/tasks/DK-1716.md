# DK-1716: Задача на Sol не запускается из-за отсутствия секции head

## Что происходит

15 ноября 2026 года пользователь выбрал Sol в меню на форме задачи и нажал «Выполнить». Вместо начала работы получил ошибку: «в профиле kit/harness/codex.toml нет секции [head]: чем поднимать голову задачи, не сказано». В профиле есть делегирование через Codex CLI и протокол codex для чатов, но секции [head] нет. Груминг на Sol уже работает через app-server. Причину выбора неподходящего пути запуска задачи нужно подтвердить.

## Чего хотим

Кнопка «Выполнить» запускает работу по задаче с выбранной моделью Sol и профилем Codex. Начало работы и причина возможного отказа видны в чате задачи. Выбор модели и глубины сохраняется.

## Границы

Исправляется запуск задачи на Codex, без переноса истории между клиентами и развития остального прототипа. Не запускать заново пользовательскую задачу до проверки отсутствия живого исполнителя. Незавершённую работу другого клиента не дублировать.

## DoD

- Запуск с формы на Sol проходит штатные ворота задачи и начинает ход в профиле codex без ошибки про [head].
- Повторный запуск не создаёт второго исполнителя; выбранные модель и глубина доходят до клиента, разговор связан с задачей.
- Ошибка раннего запуска видна пользователю, прежний запуск через Claude сохраняется.
- Регрессионный тест воспроизводит отказ на старом коде. Отдельная свежая сессия проверяет запуск на выкате с безопасной задачей, не выполняя исходную UI-задачу вместо пользователя.

## Ранг

`50+7+3+5+2 = 67`, P1.

- Серьёзность 50: основной сценарий выполнения задачи на выбранной подписке недоступен; обход требует другого клиента.
- Ценность 7: пользователь сможет выполнять задачи на уже подключённой подписке Codex.
- Неопределённость 3: известен отказ загрузки профиля, нужно проверить стык дашборда, оболочки задачи и app-server.
- Поправка на баг 5: модель доступна для выбора, но заказ выполнения завершается ошибкой.
