# DK-1730: Новые Sol и Astra доступны в выборе моделей дашборда

## Что происходит

18 ноября 2026 пользователь попросил обновить список моделей дашборда после
выхода новых Sol и Astra. В официальном журнале OpenAI за 17 ноября указаны
`gpt-6.2-sol` и `gpt-6.2-astra`:
https://developers.openai.com/api/docs/changelog.
Через дашборд нужны выбор этих версий и запуск с выбранным идентификатором.

## Чего хотим

В списке моделей дашборда доступны GPT-6.2 Sol и GPT-6.2 Astra.
Выбранная версия сохраняется и передаётся при запуске чата.
Доступность в установленном клиенте проверяется отдельно от наличия в API.
Условий, посильных только человеку, при сверке документации и настроек выката
не нашёл.

## DoD

- В выборе моделей есть `gpt-6.2-sol` и `gpt-6.2-astra` с верными названиями.
- При выборе каждой версии запуск получает её точный идентификатор.
- Существующие сохранённые варианты продолжают открываться.
- После выката наличие новых вариантов подтверждено на живом дашборде.

## Ранг

`25+6+3+0+2 = 36`, P2.

- Серьёзность 25: новые версии недоступны из привычного выбора дашборда.
- Ценность 6: обновление нужно пользователю для текущей работы.
- Неопределённость 3: проверить стык списка, сохранения и запуска клиента.
- Поправка на баг 0: добавляются выпущенные версии моделей.
- Рычаг 2: новые модели можно будет выбирать в следующих запусках.

## Приёмка

- вид: agent
- Наличие вариантов и передачу идентификатора можно проверить с машины агента.

## Сценарий проверки

Обкатка проверяет поставляемый профиль через собранный `agentctl` в свежем
дереве с временным HOME. Новые модели должны появиться без ручной настройки
`chat`. Машинный список и прежние ярусы должны сохраниться.

```sh
mkdir -p "$HOME/.devkit" && printf 'enabled = ["codex"]\ndefault = "codex"\n' > "$HOME/.devkit/harness.local" && agentctl harness --json | python3 -c 'import json,sys; v=json.load(sys.stdin); h=next(h for h in v["harnesses"] if h["name"]=="codex"); assert h["enabled"]; assert h["chat"]==["gpt-6.2-sol","gpt-6.2-astra"],h; assert not v.get("warns"),v; print("Обе новые версии доступны из профиля")'
printf 'enabled = ["codex"]\ndefault = "codex"\n[codex]\nmini = "gpt-6-luna"\nbase = "gpt-6.1-terra"\npro = "gpt-6.1-sol"\nmax = "gpt-6-astra"\nchat = ["saved-model", "gpt-6.2-sol"]\n' > "$HOME/.devkit/harness.local" && agentctl harness --json | python3 -c 'import json,sys; v=json.load(sys.stdin); h=next(h for h in v["harnesses"] if h["name"]=="codex"); assert h["chat"]==["saved-model","gpt-6.2-sol","gpt-6.2-astra"],h; m={x["tier"]:x["model"] for x in h["models"]}; assert m=={"mini":"gpt-6-luna","base":"gpt-6.1-terra","pro":"gpt-6.1-sol","max":"gpt-6-astra"},m; print("Прежние варианты и ярусы сохранены, повторов нет")'
```

После выката независимый агент проверяет живой дашборд. В ответе списка
чатов проекта должны быть обе новые модели с подпиской Codex. При выборе
каждой модели её точный ID должен сохраняться в записи и передаваться
app-server при запуске. Проверка не требует менять ярусы назначения задач.
