# DK-1744: Запуск задач предлагает прежний Sol и блокирует реплики в чате

## Что происходит

20 ноября пользователь запустил DK-1741 кнопкой «Выполнить». В выборе была
Sol 6.1 и не было Sol 6.2. Работающий чат выполнял задачу, но следующая
реплика получила отказ с требованием выбрать gpt-6.2-sol. Сообщение не ушло.
Ожидался доступный актуальный выбор при запуске и возможность продолжить
тот же разговор без потери переписки и контекста.

DK-1736 обновила только выбор обычного чата. Назначения pro/max для запуска
задач остались прежними, а проверка устаревшей модели применяется и к таким
чатам. Пользователь обновил Codex и просит актуальные Sol/Astra 6.2 во всех
местах выбора. Доступность моделей нужно проверить заново.

## Чего хотим

Новый запуск чата, задачи и агента предлагает и использует Sol/Astra 6.2.
Старые машинные назначения не возвращают прежние версии в доступный выбор.
Прежний ID в существующем разговоре остаётся честной записью истории.
Явный переход чата задачи на 6.2 сохраняет переписку, привязку к задаче и
контекст Codex. Действующий ответ не обрывается выбором модели.

## Границы

DK-1741 ведёт девять изменений поведения панели, включая меню живого Codex.
Здесь исправляется согласованность каталога и запуска и проверяется переход
со старой модели. Пересечение с пунктом 8 DK-1741 нужно сверить перед правкой.
Пользовательский чат DK-1741 диагностируется без отправки служебных реплик,
остановки работы и ручной перезаписи его файлов.

## DoD

- Все места выбора Sol/Astra для нового чата и кнопки «Выполнить» показывают
  только 6.2. Сервер передаёт выбранный точный ID клиенту.
- Стандартный профиль Codex и совместимость с прежними машинными
  назначениями дают актуальные модели при новом запуске задачи и агента.
- Уровни мышления и подписка сохраняются. Terra и Luna не меняются.
- Переход существующего чата задачи на 6.2 проверен с прежней историей,
  контекстом Codex и привязкой к задаче. Если текущая реализация теряет
  внутреннюю нить, она исправлена; видимая история не выдаётся за полный
  контекст модели.
- Для DK-1741 дан ответ о безопасном переходе по фактическому состоянию.
- Проверены регрессия, установленный дашборд и актуальный клиент Codex.

## Ранг

`50+8+3+5+2 = 68`, P1.

- Серьёзность 50: сообщение в действующий чат задачи не отправляется.
- Ценность 8: сломан ежедневный запуск и продолжение задач.
- Неопределённость 3: нужно согласовать каталог, запуск и нить Codex.
- Поправка на баг 5: отказ воспроизведён пользователем.
- Рычаг 2: последующие запуски используют единый актуальный выбор.

## Приёмка

- вид: agent
- Проверка проводится в тестовых чатах на временном HOME. Пользовательская
  задача не используется для пробных сообщений и смены модели.
