# DK-1749: Аудит учитывает присваивания внутри synctest

## Что происходит

Аудит DK-1748 отклоняет доказательство присваивания внутри
`synctest.Test`. В `TestAppTaskSilenceProbe` присваивание выполняется
в теле теста, однако проверка ищет выражение только в теле именованной
функции и пропускает литералы функций. Из-за этого слияние правки
таймера остановилось после успешных тестов.

## Чего хотим

`taskctl review audit-record` принимает проверяемую ссылку на присваивание
в callback стандартного `testing/synctest.Test`. Присваивание и чтение
должны относиться к тому же тестовому сценарию. Случайное совпадение
имени, вложенная функция без вызова и одноимённый внешний пакет
по-прежнему не дают доказательства.

## DoD

- Корректное свидетельство для `synctest.Test`, в том числе внутри
  `t.Run`, проходит машинную проверку. Неверная строка, присваивание
  в соседнем замыкании и неподтверждённое чтение отклоняются.
- Регрессия воспроизводится на старом валидаторе. Тест проходит после
  правки. Команда аудита принимает фактическое присваивание DK-1748.
- Руководство по аудиту показывает, как указать строку присваивания
  и его потребителя для `synctest`.

## Ранг

`25+7+1+5+4 = 42`, P2.

- Серьёзность 25: подтверждённая тестами правка застряла на проверке доказательства.
- Ценность 7: ревьювер может проверить тест с виртуальным временем.
- Неопределённость 1: отказ локализован в обходе Go AST.
- Поправка на баг 5: отказ воспроизведён командой аудита для DK-1748.
- Рычаг 4: та же проверка применяется к следующим задачам с тестами на synctest.

## Ход работы

- На исходном коде TestNameAssignmentSynctestScenario завершался отказом
  поиска присваивания. После исправления целевой набор прошёл.
- На копии аудита DK-1748 исходный taskctl отказал всем шести записям.
  Бинарь, собранный с DK-1749, принял те же шесть записей.

## Сценарий проверки

Запустить проверку свидетельства для теста с виртуальным временем.
Присваивание и чтение в одном сценарии проходят проверку, включая
случай с `t.Run` и чтением из запущенной горутины. Присваивание
в незапущенном замыкании и чтение другой переменной отклоняются.

```sh
devkitctl test internal -run '^TestNameAssignmentSynctest' -count=1 -v
```
