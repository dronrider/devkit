# DK-1753: Отчёт аудита сбрасывает обкатку задачи

## Что происходит

22 ноября `shipctl merge DK-1746` отклонил обкатку `cd4efa04f29a` на коммите `7ab8c8419`. Между ними изменились карточка и отчёт аудита DK-1746. Обкатка заново пишет карточку, а машинная проверка подписей требует, чтобы проверенное дерево совпадало с выпускаемым за пределами файла аудита. Задача застряла между двумя проверками.

## Чего хотим

Отчёт аудита текущей задачи можно зафиксировать после обкатки. Шлюз слияния сохраняет отметку свежести и отдельно проверяет сам отчёт. Изменение кода, настроек и фикстур требует новой обкатки. Изменённый сценарий проверяется по своему отпечатку.

## DoD

- Шлюз принимает отметку, когда после прогона появился отчёт `docs/tasks/<ID>.review-audit.json` этой задачи и записи доски. Он отклоняет изменение отчёта другой задачи, кода, сценария или его фикстуры.
- Регрессионный тест воспроизводит отказ на прежнем коде. После выката штатный `shipctl` содержит исправленный шлюз.
