# DK-1754: Аудит имён отклоняет результаты функций JavaScript

## Что происходит

При проверке DK-1741 taskctl отклонил доказательства результата пяти
функций JavaScript. Среди них есть возвращённый Promise, число и объекты
без отдельного имени. Независимый прогон может проследить эти значения
до потребителя. Утилита сейчас принимает подписанные наблюдения о записях,
а доказательство результата требует разбора выражения другого языка.

## Чего хотим

Проверяющий может подписать наблюдение о результате функции JavaScript.
В отчёте указаны возвращённое значение, его потребитель и контрольный
прогон с другим значением. Taskctl сверяет подпись, исходник и коммит.

## DoD

- Taskctl принимает подписанный возврат свойства, числа и объекта,
  включая объект на нескольких строках. Потребитель получает тот же
  результат, в контроле результат меняется.
- Чужой коммит, неверная подпись, подмена потребителя и совпадающий
  контроль отклоняются. Прежние доказательства записи проходят.
- Установленный taskctl принимает поддерживаемый результат в отдельном
  тестовом репозитории. Аудит исходной задачи выполняет пользователь.

## Ранг

`50+8+3+5+4 = 70`, P1.

- Серьёзность 50. Проверка останавливает выпуск исправлений дашборда.
- Ценность 8. Можно подтвердить результаты из реального прогона.
- Неопределённость 3. Форму доказательства читают taskctl и shipctl.
- Поправка на баг 5. Отказ воспроизведён для пяти функций.
- Рычаг 4. Один формат годится для следующих задач с JavaScript.

## Сценарий проверки

Прогнать проверку подписанного результата и прежних наблюдений записи.

```sh
devkitctl test internal -run '^TestNameRuntime(Result|Write)Integration$' -count=1 -v
```

В чистом репозитории стенда записать результат через штатный taskctl.
Проверить, что подписанный результат принят, а изменённый возвращённый
объект отклонён.

```sh
DEVKIT_TASKCTL_ARTIFACT="$(command -v taskctl)" devkitctl test tools/taskctl -run '^TestCLIRuntimeResultInstalled$' -count=1 -v
```
