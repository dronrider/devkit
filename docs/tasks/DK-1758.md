# DK-1758: Меню нового чата теряет отметку модели

## Что происходит

Новый чат может показывать gpt-6.2-sol (codex) в поле модели, а в открытом меню ни одна модель не отмечена. Если в записи чата есть имя модели без подписки, поле выбирает первую строку с этим именем. Меню ищет исходную пару с пустой подпиской и не находит строку.

## Чего хотим

При открытии меню отмечена та же доступная модель с той же подпиской, которую показывает поле.

## DoD

Браузерная проверка открывает меню нового чата с сохранённым именем без подписки и проверяет отметку у пары, показанной в поле. При одинаковых именах на разных подписках отмечена ровно одна строка.

## Ранг

`0+6+2+5+2 = 15`, P3.

- Серьёзность 0. Чат работает, отметка расходится с полем.
- Ценность 6. Пользователь попросил устранить расхождение.
- Неопределённость 2. Найдено условие расхождения в коде.
- Поправка на баг 5. Есть шаги воспроизведения.
- Рычаг 2. Меню используется при выборе модели в чатах.
