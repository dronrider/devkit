# DK-203: Окно второй подписки без задачи: shipctl code без аргумента

записан 2026-08-09

## Что происходит

`shipctl code` требует ID задачи: без аргумента отказ «жду: code <ID>
[--dry-run] [--probe]» (воспроизведено на синтетическом клоне 2026-08-09).
Привязка открытия окна к задаче это остаток механики «дерево на задачу»: до
DK-192 без ID было никак, дерево заводилось под ветку. После DK-192 копия окна
вечная и окружение лежит в самой директории, окну задача не нужна, оно нужно
просто как «vscode на второй подписке», а работа в нём начинается словами
«выполни DK-XXX» в чате.

Сегодняшний путь заставляет назвать задачу дважды (аргументом команды и потом
в чате) и двигает доску раньше времени: задача уезжает в In progress при
открытии окна, до того как работа реально началась. Обход дешёвый, когда копия
уже заведена: открыть её из дока или «Open Recent», окружение после DK-192 в
директории и так. Заведение первой копии без задачи обходом не покрывается.

## Чего хотим

`shipctl code` без аргумента заводит либо фокусирует окно на копии, стоящей
detached на main, освежает окружение из машинного слоя и доску не трогает.
Вариант с ID остаётся как есть: переключение копии на ветку задачи и перевод в
In progress, его сессия в окне зовёт сама, когда получает задачу. `--dry-run`
и `--probe` работают в обоих вариантах.

## DoD

`shipctl code` без аргумента открывает окно второй подписки: копия заведена
при нужде, стоит detached на main со свежим окружением, доска не двинулась ни
на строку. С ID поведение прежнее. Дока запускатора описывает оба входа.

## Ранг

`0+5+1+0+2 = 8`, P3.

- Серьёзность 0 (Minor). Ничего не сломано: окно с задачей открывается как
  задумано, заведённая копия открывается из дока, без задачи живут.
- Ценность 5. Ощутимое улучшение, которого просят: уходит двойное называние
  задачи и преждевременный In progress при открытии окна.
- Неопределённость 1. Подход выбран (безадресная ветка поведения в той же
  команде), правка в одной утилите и одном языке, осталось сделать.
- Поправка на баг 0. Новое поведение, не дефект.
- Рычаг 2. Небольшая своя польза: старт окна дешевле, доска не двигается зря.
