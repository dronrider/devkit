# DK-213: Хук check-commit: ID задачи в коммите на main проекта с доской

записан 2026-08-09

## Что происходит

Тот же случай IRC-103, что в DK-212: коммит f519c70 лёг в main it-road-course
мимо ветки задачи, с subject без ID, и теперь конфликтует с настоящей веткой
irc-103 по AGENTS.md. Ядро правил доски требует ID в subject (по нему находятся
коммиты задачи, revert и состав поезда, и связь эта чинится дорого), но
check-commit.py проверяет только следы ассистента, одну строку и префикс из
истории. Коммит в main без ID проходит молча.

## Чего хотим

check-commit.py в репозитории с доской (docs/TASKS.md у корня) на ветке main
даёт находку коммиту, который трогает файлы вне доски (docs/TASKS.md,
docs/tasks/, docs/TASKS-archive.md) и не несёт ID вида ABC-123 в subject.
Внезадачной мелочи остаётся штатный обход `--no-verify`. Фичеветки не
проверяются: рубеж про main, куда код задачи доезжает слиянием.

## DoD

Тесты хука: коммит кода на main без ID даёт находку, с ID проходит, коммит
одних файлов доски проходит, фичеветка и репозиторий без доски не трогаются.
hooks/README.md описывает рубеж.
