# DK-223: Заход извне и проверка дашборда с телефона [после DK-219, DK-222]

записан 2026-08-09

Задача цели DK-112 ([DK-112.md](DK-112.md)), замыкающая строка серии.

## Чего хотим

Последний шаг цели: дашборд открывается с телефона извне домашней сети, и
пользователь проходит экраны доски, живого статуса, переписки и уведомлений.
Канал это решение выката, а не архитектуры: заход извне даёт браузерный вход
xr-proxy (XR-252 на доске XR), дома хватает адреса машины в своей сети. В
задаче само подключение дашборда за канал (конфигом выката, без правок
архитектуры) и пользовательская проверка по DoD.

Внешняя предпосылка: XR-252 живёт на чужой доске, и это единственное место
цели, зависящее от неё. Пока XR-252 не закрыта, задачу не брать; взятая и
упёршаяся в канал строка уходит в Blocked по правилам доски. Сам дашборд
каналонезависим и ведётся параллельно, этой строки он не ждёт.

## Ранг

`25+6+3+0+0 = 34`, P2.

- Серьёзность 25 (Major). Обещание цели «с любого устройства» без захода
  извне выполняется только дома; обход есть (домашняя сеть, машина), полоса
  Major.
- Ценность 6. Ощутимое: дашборд начинает работать из любой точки, а не
  только из своей сети.
- Неопределённость 3. Стык с чужим каналом: xr-proxy, VPS, браузерный вход.
  Развилки сидят на границе и видны живым прогоном.
- Поправка на баг 0. Новая работа.
- Рычаг 0. Замыкающий шаг, дальше ничего не разблокирует.

## Сценарий проверки

Пользовательский, ровно DoD цели: с телефона вне домашней сети (мобильная
сеть, VPN выключен) открыть адрес дашборда через браузерный вход xr-proxy,
войти по аутентификации дашборда, пройти экраны доски, живого статуса,
переписки и уведомлений; каждый экран живой и показывает данные машины. На
этой проверке цикл штатно останавливается и зовёт человека.
