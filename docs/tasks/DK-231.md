# DK-231: Транскрипты ~/.claude/projects очищены от утёкших тел токенов

Задача цели DK-207. Тела утёкших токенов нашли дорогу в сессионные транскрипты:
36 файлов `~/.claude/projects/*.jsonl` содержат хотя бы один из пяти префиксов
(Jira PAT, Confluence PAT, GitLab PAT, Telegram bot id, GitHub PAT). Любой, кто
откроет эти транскрипты или погрепает каталог, найдёт значения.

## Что делается

Одноразовый скрипт проходит по `~/.claude/projects/*.jsonl` и заменяет тела
токенов на маску, не ломая структуру JSONL. Скрипт живёт в `local-docs`, в
коммит не едет. Для поиска берутся надёжные префиксы тел из пяти токенов, а не
шумные generic вроде `sk-` или `Bearer` с сотнями ложных срабатываний. Замена
идёт по телу токена (достаточно длинному префиксу), значение заменяется на
`<redacted>`, остальная строка JSONL сохраняется.

## DoD

Греп по префиксам утёкших токенов в `~/.claude/projects/` не находит ни одного
файла. Транскрипты остаются валидным JSONL, сессии по ним читаются.

## Сценарий проверки

Агентский.

    grep -rlE '<префиксы пяти токенов>' ~/.claude/projects/
    => пусто

Префиксы берутся из текущих значений (они же после чистки ротируются
пользователем, это за рамками цели), в файл задачи и в коммит не пишутся.

Прогон 2026-08-10, префиксы по 24 символа тела каждого из пяти токенов,
собраны из env через `secretctl exec` (значения в текст не выводятся):

    SCENARIO exit=1 matches=0

`grep -rlE` по `~/.claude/projects/` вернул код 1 (совпадений нет),
список файлов пуст.

## Развилки

Замена в JSONL требует аккуратности: значение может быть частью поля в JSON, и
наивный `sed` по строке ломает структуру, если в значении есть кавычка или
слэш. Берётся поточная обработка с JSON-парсингом на строку, замена значения в
поле и обратная сериализация, либо проверенный регекс по телу токена с
ограничением на символы, допустимые в нём. Состав префиксов уточняется по
хранилищу на момент исполнения.

## Ход работы

- Исполнение: подпроцесс glm-5.2/medium по вердикту pick (квота: объявления нет, корректор выключен), 2026-08-10.
- Замер «до» (по 24-символьным префиксам тел, значения из env через `secretctl exec`): попадания в 34 файлах, всего 774 замены. Из них 31 файл `.jsonl` (672 замены) и 3 файла `tool-results/*.txt` (102 замены). По токенам: Jira 335, Confluence 107, GitLab 292, Telegram 35, GitHub 5.
- Чистка: одноразовый скрипт `/tmp/redact-tokens.py` (вне репо, в коммит не едет) поточно прошёл по всем текстовым файлам `~/.claude/projects/`, заменил тела на `<redacted>` регексом `re.escape(prefix24) + [A-Za-z0-9_-]*` (префикс плюс допустимые символы тела), так что кавычки и слэши за пределами тела не затрагиваются и структура JSON не ломается.
- Замер «после»: 0 файлов с попаданиями, 0 замен.
- JSONL-валидность: проверены все 1273 файла `.jsonl` (254002 строки), `json.loads` по каждой строке проходит без ошибок.
- Сценарий проверки пройден: см. выше.
