# DK-243: Доска дашборда: действия со строки, ранг тултипом, дата статуса вместо возраста, кнопка на главную

записана 2026-08-11, замечания 3, 9, 10 и 11 пользовательской проверки цели DK-112

## Чего хотим

Четыре замечания одного экрана доски:

- строка задачи получает действия без захода внутрь: взять в работу, стоп;
  перетаскивания строк между статусами не заводим, статусы двигает конвейер,
  а прямое действие со строки закрывает ту же потребность честно;
- расшифровка ранга уходит из строки в тултип или разворот по наведению:
  сейчас она ест место, а нужна изредка;
- вместо «строка не двигалась N дней» показывать дату последней смены
  статуса, это легковеснее;
- кнопка перехода на главную (список проектов) с любого экрана: сейчас
  привычного «домой» нет.

## Ранг

`25+6+2+0+1 = 34`, P2.

- Серьёзность 25 (Major). За каждым действием приходится лезть внутрь
  задачи, доска остаётся смотрелкой; обход есть, потому Major.
- Ценность 6. Ощутимое удобство основного экрана, четыре замечания
  пользователя.
- Неопределённость 2. Подходы ясны, развилки в деталях UX по макету.
- Поправка на баг 0. Новая работа.
- Рычаг 1. Действия со строки пригодятся и ленте (поднять виток), и
  будущим экранам.

## Сценарий проверки

Агентский по API и статике: действия строки зовут те же ручки запуска и
стопа (греп разметки и тест хендлеров), расшифровка ранга не рендерится в
строку, дата статуса приходит в ответе доски и рендерится вместо возраста,
кнопка на главную есть на каждом экране (греп по вшитой статике). Взгляд
глазами остаётся пользователю обычным порядком.

## Ход работы

- Исполнение: субагент opus/medium по вердикту pick (квота: week_all 8%, week_max 9%, снимок 0м назад, сдвига нет), 2026-08-11.
- Дату последней правки строки считает taskctl и отдаёт полем `moved` в
  `list --json`: своей даты у перевода в статус на доске нет, а перевод двигает
  ту же строку, и `git blame` по ней уже считает возраст для печати. Клиент
  дату не выводит сам, вне git и на грязном дереве поля просто нет.
- Действие со строки зовёт те же ручки `POST` и `DELETE /runs`, что кнопки
  экрана задачи: своей команды у строки нет, иначе рубежи ручки держались бы
  в двух местах. Нажатие гасит переход внутрь задачи.
- Слагаемые ранга ушли из строки в подсказку при наведении и в разворот по
  нажатию: наведения на телефоне нет, поэтому оба форм-фактора закрыты одним
  элементом, а не двумя.
- Главная это новый экран пустого хэша со списком проектов; кнопка «На
  главную» стоит в шапке над всеми экранами, на телефоне её место занимает
  первая нижняя вкладка.
- Прогоны: `regcheck --base main` на новых тестах taskctl и dashboard (краснеют
  на main, проходят на ветке), `GOWORK=off go test -count=1 ./...` в
  `tools/taskctl` и `tools/dashboard`.
- Ревью: субагент sonnet/high по вердикту pick (квота: week_all 8%, week_max 9%, снимок 0м назад, сдвига нет), 2026-08-11.
