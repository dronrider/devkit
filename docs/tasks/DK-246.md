# DK-246: Лента уведомлений входом с колокольчика, а не пунктом меню

записана 2026-08-11, замечание 1 пользовательской проверки цели DK-112

## Чего хотим

Лента живёт пунктом основного меню, а привычное место входа в уведомления
это значок-колокольчик вверху со счётчиком непрочитанного. Переосмыслить
вход: колокольчик в шапке на обоих форм-факторах, по нему панель или экран
ленты; счётчик решить вместе с вопросом отметок прочитанного, который LLD
сознательно отложил (у сервера нет места для пометок, состояние клиента
дашборду не разрешено; если счётчик без пометок невозможен, честно показать
точку-индикатор новых с последнего захода по локальному времени клиента и
записать выбор в LLD).

## Ранг

`0+4+2+0+0 = 6`, P3.

- Серьёзность 0 (Minor). Удобство: лента доступна и сейчас, дело в привычке
  входа.
- Ценность 4. Заметное удобство, названо пользователем.
- Неопределённость 2. Развилка счётчика упирается в отложенное решение об
  отметках прочитанного.
- Поправка на баг 0. Новая работа.
- Рычаг 0. Локальная правка навигации.

## Сценарий проверки

Агентский по статике: колокольчик в шапке обоих форм-факторов, ведёт на
ленту, пункт меню убран или переименован по решению задачи (греп разметки).
Взгляд глазами за пользователем.
