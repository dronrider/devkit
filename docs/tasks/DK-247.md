# DK-247: Запуск конвейера из-под launchd не находит claude: ~/.local/bin мимо PATH агента

записана 2026-08-11, замечание 4 второй пользовательской проверки цели DK-112

## Чего хотим

Кнопка «В работу» на проде отвечает «claude не нашёлся в PATH: headless-сессию
конвейера поднять нечем». Третье звено корня DK-217: agent_path в
tools/devkitctl/dashboard.py собирает каталог бинаря devkit, системные пути и
brew, а claude стоит символьной ссылкой в ~/.local/bin и в этот список не
попадает. Дописать ~/.local/bin в расчёт тем же правилом (наличием каталога
на машине), doctor --fix перевзводит существующего агента, диагностика
дашборда остаётся честной для машин, где claude не стоит вовсе.

## Ранг

`25+5+1+5+1 = 37`, P2.

- Серьёзность 25 (Major). Управление с дашборда мертво на проде, обход это
  сидеть за машиной.
- Ценность 5. Возвращает обещанную кнопку к жизни.
- Неопределённость 1. Корень найден, правка одной функции с тестом.
- Поправка на баг 5. Дефект доводки, найден пользователем на проде.
- Рычаг 1. Тот же PATH понадобится любому будущему подпроцессу.

## Сценарий проверки

Агентский. Тест dashboard.py: agent_path с существующим ~/.local/bin включает
его и не включает несуществующие; тест перевзвода старого plist без этого
пути. На проде после doctor --fix: launchctl print показывает PATH с
~/.local/bin, POST runs на фикстурной задаче поднимает сессию (или, без
живого прогона, дашборд перестаёт отвечать «claude не нашёлся» на /healthz
руками диспетчера).
