# DK-248: Редизайн экранов дашборда в Claude Design: форма задачи, шапка с логотипом, лента, индикаторы, состав цели, заведение

записана 2026-08-11, замечания 1, 3, 5, 6, 9, 11, 12, 13, 14, 16 второй пользовательской проверки цели DK-112

## Чего хотим

Дорезка DK-243..DK-246 делалась без захода в Claude Design, и пользовательская
проверка это увидела. Обновить дизайн-проект «Дашборд devkit» (оба
форм-фактора) по замечаниям, до кода:

- форма задачи: без надписи «Правки нет...», кнопки сохранения и действий
  одним блоком, «Отменить правку» только при живой правке; блок зависимостей
  словами «Заблокировано задачами» и «Блокирует выполнение задач»;
- шапка: вместо кнопки «На главную» логотип-иконка в левом верхнем углу с
  подсветкой и переходом на главную по нажатию; на главной самой кнопки нет;
- лента и колокольчик: перерисовать вход и экран, иконку колокольчика
  заменить приличной; место для флеш-уведомлений (всплывашка в углу при
  новом событии, как в macOS);
- список проектов: вместо подписи «тихо» кружок-индикатор (серый неактивно,
  зелёный идёт работа, красный требуется внимание);
- экран цели: состав цели как сабтаски в трекерах (список задач с судьбой и
  статусом), а не пустой блок зависимостей;
- заведение: единая форма с переключателем задача-черновик (форма как у
  правки задачи; несохранённую нельзя взять в работу, черновику доступен
  только груминг), человеческий плейсхолдер вместо «Мысль с телефона»,
  слово «строка» из кнопок убрать;
- дата изменения без приписки «правка».

Решения UX принимает исполнитель и называет причины, заказ на один вариант.
Реализация уезжает задачами DK-249, DK-250, DK-251, они ждут макетов.

## Ранг

`25+7+2+0+3 = 37`, P2.

- Серьёзность 25 (Major). Кривой UX дорезки на каждом экране, обход есть.
- Ценность 7. Десять замечаний пользователя одним заходом.
- Неопределённость 2. Развилки в деталях макетов.
- Поправка на баг 0. Новая работа.
- Рычаг 3. Держит три задачи реализации.

## Сценарий проверки

Пользовательский: открыть проект в Claude Design, пройти обновлённые экраны
в обоих форм-факторах, замечания комментариями там же. Плановый стоп.
