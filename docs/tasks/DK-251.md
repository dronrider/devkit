# DK-251: Состав цели сабтасками, единая форма задача-черновик и раздел черновиков с оформлением

записана 2026-08-11, замечания 11, 14, 15 второй пользовательской проверки цели DK-112

## Чего хотим

- Экран цели показывает состав как сабтаски в трекерах: список задач цели со
  статусами и судьбой (источник это раздел «Задачи цели» файла цели плюс
  строки доски и архива), а не пустой блок зависимостей;
- заведение единой формой с переключателем задача-черновик: поля как у
  правки задачи (черновику текст и заголовок), несохранённое нельзя взять в
  работу, черновику доступен только груминг;
- раздел «Черновики» в проекте рядом с бэклогом: список из
  docs/tasks/drafts/ (taskctl draft list), просмотр текста, действие
  «Оформить» поднимает сессию груминга конвейером (промпт по механике
  DK-250), после которого строка оказывается в Backlog.

## Ранг

`25+6+2+0+1 = 34`, P2.

- Серьёзность 25 (Major). Состав цели невидим, черновики недостижимы с
  телефона: половина мобильного цикла работы с доской отсутствует.
- Ценность 6. Прямые просьбы пользователя.
- Неопределённость 2. Источники данных известны, развилки в форме.
- Поправка на баг 0. Новая работа.
- Рычаг 1. Груминг с телефона кормит всю доску.

## Сценарий проверки

Агентский: на синтетической цели с задачами состав отдаётся API и рендерится
списком со статусами; черновики видны разделом, текст читается; «Оформить»
поднимает сессию с грумминговым промптом (фикстурный tmux); форма заведения
переключается задача-черновик и не даёт взять несохранённое в работу.
