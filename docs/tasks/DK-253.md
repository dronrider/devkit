# DK-253: Остаток подписок на главной: снимки квоты подключаемыми модулями без хардкода харнесов

записана 2026-08-11, замечание 1 третьей пачки пользовательской проверки цели DK-112

## Чего хотим

Блок процентов подписки с макетов (боковая колонка главной) так и не доехал
до кода. Показать остатки всех подключенных подписок: снимки уже лежат в
~/.devkit/quota/<харнес>.local (их пишет agentctl quota refresh, сегодня там
claude-code и glm), формат один. Дашборд читает каталог и показывает блок на
каждую подписку: имя харнеса, бакеты с процентами, возраст снимка; протухший
снимок подписан честно. Ничего специфичного для конкретного харнеса в код не
шить: список это содержимое каталога, разбор один на всех; выбор способа
(чтение файлов напрямую или подпроцесс agentctl) по границе LLD, решение
записать.

## Ранг

`25+6+2+0+1 = 34`, P2.

- Серьёзность 25 (Major). Квота это то, чем дышит агентская разработка, и на
  макете блок обещан; обход это agentctl budget за машиной.
- Ценность 6. Прямая просьба, видно с телефона, когда пора притормозить.
- Неопределённость 2. Формат снимков известен, развилка в способе чтения.
- Поправка на баг 0. Новая работа.
- Рычаг 1. Модульная читалка пригодится будущим харнесам.

## Сценарий проверки

Агентский: фикстурный каталог снимков с двумя харнесами отдаётся API и
рендерится блоками на главной, протухший снимок подписан, пустой каталог это
различимая пустота, ничего именного в коде (греп по именам харнесов в
tools/dashboard возвращает пусто).
