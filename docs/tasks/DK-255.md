# DK-255: Экран агента: журнал цели из файла при чате-цикле, заголовок вместо имени сессии, формулировки

записана 2026-08-11, замечания 2, 5 (журнал), 6 третьей пачки пользовательской проверки цели DK-112

## Чего хотим

- Журнал цикла для цели, которую ведёт живой чат: файла .devkit/goal-<ID>.log
  у такой цели нет и не будет, а раздел «Журнал» в файле цели есть и пишется
  каждым витком. Показывать его строки вместо «журнала нет: цель не гонялась
  оболочкой», с подписью источника; пустота остаётся различимой;
- активная работа подписывается заголовком задачи с доски («Цель: дашборд
  управления...»), а не именем сессии goal-DK-112; имя сессии остаётся
  мелкой подписью;
- формулировка «ведётся снаружи» заменяется понятной («ведёт другая сессия,
  стоп отсюда недоступен» или короче, решить по месту), там же где она
  встречается в ответах API и статике.

## Ранг

`25+5+2+0+0 = 32`, P2.

- Серьёзность 25 (Major). Пустой журнал у живой цели выглядит поломкой, имя
  сессии вместо заголовка сбивает.
- Ценность 5. Экран агента начинает говорить на языке доски.
- Поправка на баг 0. Собрано как задумано.
- Неопределённость 2. Источники известны, развилки в разборе раздела.
- Рычаг 0. Локальная правка экрана.

## Сценарий проверки

Агентский: фикстурная цель с разделом «Журнал» и без goal-лога отдаёт строки
раздела с подписью источника; работа с фикстурной доски подписана заголовком;
греп «ведётся снаружи» по коду и статике пуст. Взгляд глазами за
пользователем в проверке цели.

## Ход работы

- Исполнение: субагент opus/medium по вердикту pick (квота: week_all 18%, week_max 20%, снимок 0м назад, сдвига нет), 2026-08-11.
- Код: журнал цели читается из двух источников. Без `.devkit/goal-<ID>.log`
  ручка берёт строки списка из раздела «Журнал» файла цели (путь со ссылки
  строки доски, иначе `docs/tasks/<ID>.md`) и называет источник полем `source`
  со словами в `source_note`, в SSE это событие `source`. Дострение файла цели
  идёт не смещением, а по изменению файла и числу отданных строк: файл
  переписывается целиком. Заведись журнал оболочки при открытом экране, поток
  скажет `source` заново и повезёт строки оттуда. Пустота различима тремя
  причинами: файла цели нет, раздела нет, раздел пуст. Живая работа получила
  поле `title` со строки доски, им подписаны карточки работ и шапка экрана
  агента, имя сессии ушло мелкой подписью. Формулировка «ведётся снаружи»
  заменена на «ведёт другая сессия» с приписком про недоступный отсюда стоп;
  греп по коду, статике и README держит тест. 2026-08-11.
