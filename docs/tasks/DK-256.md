# DK-256: Экран «Агенты»: живые агенты всех проектов списком, переходы в статус и чат

записана 2026-08-11, решение пользователя при проверке макетов DK-248

## Чего хотим

Раздел «Агенты» стоял мёртвой заглушкой с каркаса DK-217. Пользователь решил
наполнить: экран-список живых агентов по всем проектам, у каждого заголовок
задачи с доски, проект, вид работы (агент цели, конвейер задачи, ведёт
другая сессия), длительность, переходы в живой статус и чат, кнопка
остановки; пустота словами. Данные это works из ответов проектов, своей
ручки, вероятно, не нужно (реши по месту). Макет рисует DK-248 («08
Агенты»), реализация по нему.

## Ранг

`25+5+1+0+1 = 32`, P2.

- Серьёзность 25 (Major). Мёртвый пункт меню на каждом экране.
- Ценность 5. Сводный взгляд «кто чем занят» без обхода проектов.
- Неопределённость 1. Данные и переходы готовы, макет будет.
- Поправка на баг 0. Новая работа.
- Рычаг 1. Список пригодится ленте и главной.

## Сценарий проверки

Агентский: на синтетике с двумя проектами и живыми работами экран отдаёт
всех агентов с заголовками задач и переходами; пустота словами; пункт меню
и вкладка ведут на экран (греп статики).
