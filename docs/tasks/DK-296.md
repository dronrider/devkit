# DK-296: dashboard: чат открывается у обычной задачи и зовёт её целью

## Что происходит

У задачи DK-208 работа не идёт, и на её экране агента стоит кнопка «Чат с
агентом»: условие в `renderAgent` (`tools/dashboard/static/app.js`) пускает в
чат при `!work || work.kind === "goal"`, то есть всякий раз, когда живой
работы нет. Комментарий рядом говорит ровно обратное: «у обычной задачи
отправка получила бы «не цель», и кнопка вела бы в тупик». Тупик и выходит.

Дальше экран чата зовёт задачу целью: заголовок собирается склейкой
`"goal-" + id` для кого угодно, и над обычной задачей стоит `goal-DK-208`.
А внизу страницы, в блоке «Входящие», лежит отказ ручки: «DK-208 не цель:
заголовок не начинается с «Цель:», а сообщение кладётся только в файл цели».
Чтобы его увидеть, страницу надо пролистать.

Поймано пользователем 2026-08-13.

## Чего хотим

В чат обычной задачи попасть нельзя: кнопка стоит там же, где на строке доски
и на экране «Агенты», то есть у цели. Заголовок чата зовёт работу тем именем,
какое у неё есть, а не приставкой `goal-`. Заход по прямой ссылке
`#проект/chat/<ID>` на не-цель отвечает словами вместо экрана переписки, а не
прячет отказ в подвале.

## DoD

На экране задачи, чья строка не начинается с «Цель:», кнопки чата нет ни при
живой работе, ни без неё. Заход по прямой ссылке на чат такой задачи говорит,
что переписка бывает только у цели, и ведёт обратно на задачу. Заголовок чата
цели прежний, у прочих без приставки `goal-`. Держат это тесты статики по
образцу соседних (`TestStaticChat*`).
