# DK-337: dashboard: кнопки действий не сверены с макетами экранов 11 и 12 целиком

## Что происходит

Приёмка пользователя 2026-08-14 по цели DK-327, второй заход: DK-336 привела
к макету только составную кнопку со списком подписок, а тот же дизайн кнопок
правился макетами целиком, и остальные кнопки остались прежнего вида. Пример
пользователя: «Выполнить» без стрелки. Смотреть экраны «11 Подписка при
запуске» и «12 Груминг черновика» проекта «Дашборд devkit» в Claude Design
(2a4ed62c-f591-492a-b488-a331d9974ea5): там дизайн кнопок и правился.

## Чего хотим

Полная сверка всех кнопок действий с обоими макетами по всем фреймам, а не
одной кнопки с одного фрейма: обычная кнопка запуска без стрелки (Backlog,
In progress, Check обеих приёмок), кнопки экрана черновика («Провести
груминг», «Остановить груминг», «Повторить груминг», «Удалить» с
подтверждением), кнопки полосы действий задачи, вид на ноутбуке и телефоне.
Каждое расхождение либо закрывается правкой, либо в файле задачи названо,
почему остаётся (элемент макета, которого в дашборде нет).

## DoD

- Список всех кнопок обоих макетов со сверкой записан в файл задачи, у
  каждой исход: совпала, поправлена, расхождение с причиной.
- Кнопки на экранах совпадают с макетами; поведение не регрессирует.
- Замеры и стенд держат новый вид, screen_keep.mjs зелёный; агентская
  приёмка структурно против утверждённых макетов (особый случай ACCEPTANCE).
