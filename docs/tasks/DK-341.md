# DK-341: hooks/inbox.py: почтальон доставляет реплики идущему витку на событии инструмента

## Ход работы

- Исполнение: субагент opus/high по вердикту pick (квота: week_all 73%, week_max 61%, снимок 26м назад, сдвига нет), 2026-08-15.

## Постановка

Вторая строка разбивки LLD DK-136 (docs/lld/DK-136-live-chat.md, пункт 2
«Почтальон»): hooks/inbox.py читает почту сессии по адресу из оси DK-340,
вносит лежащие реплики в контекст идущего витка каналом добавки, отмечает
доставку, раскладывается хуком автоматикой подключения, замер цены события
на месте. Состав, устройство почты, тесты и границы в LLD (разделы
«Устройство почты» и «Тесты»), он решение и есть. Ось DK-340 уже в main
(hookio.tool_event, hookio.context, событие tool-done в профилях).
