### Правки

1. `serve_forever(poll_interval=0.02)` у локального сервера релизов в
   `update_test` (`UpdateCase.setUp`). Замер: shutdown при интервале по
   умолчанию 0,502 с, при 0,02 с уже 0,011 с. Сервер тестовой нагрузкой не
   загружен, частый опрос ему ничего не стоит.
2. Кеш git-чтений в `update.git` (`git_cache(True)` на прогон doctor в
   `main`). Ответы читающих команд (`tag --list`, `rev-parse`, `log`,
   `status`, `merge-base`, `symbolic-ref --quiet`) запоминаются до конца
   прогона, любая меняющая команда (fetch, checkout, `tag <имя>`) кеш чистит.
   Чтения из `devkitctl.py` (devkit_checkout, code_commit, version_gap,
   unsaved_go) переведены с собственного `run` на `update.git`, иначе кеш их
   не видел. По умолчанию кеш выключен: прямые вызовы из тестов ходят в git
   между собственными мутациями.
3. Диспетчер заглушек в `testenv` (`Sandbox.bin`): заглушки бинарей devkit и
   tmux лежат симлинками на один скрипт с разбором `case "$0"`, каждое имя
   отвечает своей строкой `--version`. Диспетчер прогревается холостым
   запуском при создании стенда. Замер: 12 отдельных файлов 2,65 с против
   0,10 с на 12 симлинков. Разбор по `$0`, а не по basename: подставной PATH
   стенда короткий и basename в нём нет.
