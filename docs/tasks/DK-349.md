# DK-349: dashboard: одиночная кнопка запуска без стрелки теряет скругление справа

## Что происходит

Приёмка пользователя 2026-08-15 по цели DK-327: у одиночной кнопки запуска
без стрелки (вырожденные случаи составной кнопки: строка-цель, одна подписка
на машине, непрочитанный список) правые углы без скругления, как будто рядом
стоит узкая часть, которой нет. По макету 11 одиночная кнопка скруглена со
всех сторон; обрезанные углы это вид половины split-кнопки.

## Чего хотим

Вырожденная кнопка выглядит обычной кнопкой темы: скругление со всех сторон,
без шва под отсутствующую узкую часть. Составная кнопка со стрелкой не
меняется. Замер кнопок (buttons.js или split_run.js) держит оба вида.

## DoD

- У кнопки без стрелки радиус со всех четырёх углов, у составной прежний вид.
- Тест замера падает на старом коде; стенд screen_keep.mjs зелёный.

## Ход работы

- Исполнение: субагент haiku/low по вердикту pick (квота: week_all 74%, снимок 35м назад, сдвига нет), 2026-08-15.
- Проблема: класс split вешался на обёртку всегда, даже для одиночной кнопки (вырожденные случаи: строка-цель, одна подписка, непрочитанный список). CSS правило .split .btn:not(.more2) обрезал правые углы (border-top-right-radius:0, border-bottom-right-radius:0).
- Решение: в runControl() не вешать класс split для вырожденных случаев (isGoal || list.length < 2). Вернуть просто широкую кнопку без обёртки span.split.
- Регрессия в testdata/screen_keep.mjs: добавлена проверка в раздел подписок, что при одной подписке или пустом списке узел кнопки НЕ обёрнут в span.split.

## Итог

Кнопка запуска без узкой части теперь отображается как обычная кнопка с одинаковым скруглением со всех сторон. Составная кнопка со стрелкой выбора подписки остаётся без изменений.

## Сценарий проверки

1. Открыть дашборд devkit в браузере.
2. На строке задачи без подписок (строка-цель или одна подписка): одиночная кнопка запуска должна быть скруглена со всех сторон, без видимого шва для отсутствующей узкой части.
3. На строке задачи с несколькими подписками: составная кнопка (широкая с узкой стрелкой) должна выглядеть как раньше, с обрезанными правыми углами на широкой части.
4. На полосе действий задачи: одиночная кнопка запуска скруглена со всех сторон, составная кнопка не изменилась.
