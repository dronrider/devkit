# DK-350: Когда на дашборже я нажимаю "Новая задача" находясь при этом в черновиках открывается форма создания задачи с типом задача, а должно было быть черновик.

записан 2026-08-15

## Черновик

Когда на дашборже я нажимаю "Новая задача" находясь при этом в черновиках открывается форма создания задачи с типом задача, а должно было быть черновик.
Состояние переключателя задача-черновик должно быть контекстозависимым

## Из черновика DK-351 (записан 2026-08-15)

### Черновик

На дашборде на форме создания задачи при выборе типа "Черновик" отображается блок с дополнительными полями задачи впустую отвлекая внимание пользователя, его для черновиков надо просто скрывать.
