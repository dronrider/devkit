# DK-355: dashboard: кружок статуса и колонка хода в строке доски

заведена грумингом черновика DK-338 2026-08-15: механика осталась за DK-338,
эта строка про доску, карта экрана задачи за DK-356

## Что происходит

Строка доски знает про идущую работу с DK-317, но говорит о ней одним словом:
идёт или оборвана. Чем задача занята, по списку не сказать, и главный экран
дашборда отвечает на «что сейчас происходит» одинаково для разработки, ревью и
ожидания человека. Различает их сегодня только заход на экран агента, по одной
задаче за раз.

## Чего хотим

Строка доски показывает состояние работы и вид деятельности сразу, как в макете
«01 Доска» проекта «Дашборд devkit»: единственный кружок стоит до ID и говорит о
состоянии (работает, снаружи, очередь), отдельная колонка хода несёт вид
деятельности цветным словом (разработка зелёным, ревью жёлтым, снаружи серым), а
уточнение идёт вторым рядом той же колонки. На телефоне ход занимает третий ряд
строки, своего кружка колонка не заводит.

Данные приезжают готовыми от DK-338: вид деятельности и время начала лежат в
поле строки, клиент их рисует и сам ничего не выводит из двух списков.

## DoD

- Строка доски на ноутбуке несёт кружок состояния до ID и колонку хода цветным
  словом, уточнение вторым рядом; телефонная строка несёт то же третьим рядом.
- Вид деятельности берётся полем данных строки, сборки на клиенте из строки и
  списка работ нет.
- Строка без живой работы кружка не красит, и пустая колонка хода не занимает
  места впустую.
- Расхождений с макетом нет: значения, разметка и стили сверены против фреймов
  ноутбука и телефона.
- Поведение описано в README дашборда, правка едет со своими тестами по
  test-standard.
