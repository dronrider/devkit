# DK-361: Рубеж безопасности в хуках

вырезан из черновика DK-162 на груминге 2026-08-15

## Что происходит

Секрет, попавший в код, не ловится ничем: check-sensitive.py проверяет только
доску и доки, диффа кода он не видит. Аудита зависимостей нет вовсе. В
автономном режиме слияние идёт без человека, и дифф с ключом или уязвимой
зависимостью уезжает в main молча.

## Чего хотим

Детерминированный слой рядом с hooks/check-symbols.py, ноль контекста, работает
без памяти сессии:

- скан секретов и ключей в диффе кода; до автономного слияния это единственный
  рубеж, поэтому стоять он обязан раньше, чем скилл DK-162;
- аудит зависимостей инструментами экосистем: govulncheck для go, pip-audit
  для python (других языков в devkit нет, cargo audit понадобится только
  вместе с rust).

## DoD

Хук на синтетическом репозитории рубит коммит со вставленным в дифф ключом и
пропускает чистый; аудит зависимостей гоняется на своём рубеже и красен на
заведомо уязвимой версии; оба с тестами по стандарту devkit.
