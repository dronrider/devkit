# DK-362: dashboard: headless-запуск с доски не наблюдаем, чата нет в сессиях

## Что происходит

Реплика пользователя во «Входящие» цели DK-327, 2026-08-15 (доставлена
витку почтальоном DK-341): случайный запуск с дашборда перевёл DK-194 в In
progress, исполнитель ушёл в headless (tmux task-DK-194 через agentctl
exec), но работа не видна: чата нет в списке сессий, экрана агента с доски
тоже нет, найти можно только раскопками по транскриптам. Сценарий 2 цели
(«видеть, чем агент занят») на headless-запусках не закрыт: строка In
progress не подкреплена ничем наблюдаемым.

## Чего хотим

Headless-сессия, поднятая с доски через agentctl exec, видна как обычная:
разговор стоит в списке сессий задачи, экран агента открывается с доски
(чип «работает» ведёт на живой статус), и это держит тест. Разобрать, чем
headless-запуск через exec отличается для sessions.go от прежнего прямого
подъёма (каталог, cwd, session_id), и закрыть щель.

## DoD

- Запуск с доски через agentctl exec даёт разговор в списке сессий задачи и
  рабочий экран агента; тест воспроизводит headless-сессию (транскрипт в
  каталоге дерева задачи с cwd от exec) и падает на старом коде.
- Смок или стенд держит стык, regcheck зелёный.
