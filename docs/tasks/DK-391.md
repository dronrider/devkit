# DK-391: board-task: что идёт строкой сразу и что в черновик, файл задачи при заведении, а не при взятии в работу

## DoD

- В board-task раздел «Новая задача» ссылается на ворота готовности из
  board-groom и делит вход на «строкой сразу» и «в черновик» с примерами из
  решения 2 LLD DK-133.
- Шаг взятия в работу говорит про добивание строк, заведённых до рубежа,
  фразы «однострочному бэклогу файл не нужен» нет.
- LLD-задача заводится файлом при заведении строки, тень этого шага в
  board-team снята.
- Вес скилла под порогом тела 16 000 символов.

## Ход работы

- Разработка: подпроцесс glm-5.3/medium по вердикту pick (потолок цели: pro, вердикт и так не выше; квота: объявления нет, корректор выключен), 2026-08-17 10:23-10:24.
- kit/skills/board-task/SKILL.md приведён под контракт решения 2 LLD DK-133
  (docs/lld/DK-133-entry-gates.md): пункт 1 «Новой задачи» получил ссылку на
  ворота board-groom и изъятие для очевидных находок, добавлены подразделы
  «Что идёт строкой сразу» и «Что уходит в черновик» с примерами решения 2 и
  общим признаком границы, шаг 3 взятия в работу переписан под добивание
  дорубежных строк (изменяющие команды отказывают без файла и называют
  `taskctl file <ID>`), фраза «однострочному бэклогу файл не нужен» снята,
  абзац про LLD-задачу выровнен под файл при заведении.
- kit/skills/board-team/SKILL.md, шаг 3 захвата задачи: из последовательности
  взятия в работу убрана команда `taskctl file <ID>`, тень board-task из
  замечания 8 ревью DK-394.
- Скилл после правки 15 411 символов целиком, порог тела 16 000 выдержан,
  ужимать соседнюю прозу не пришлось.
- Ревью: подпроцесс glm-5.3/high по вердикту pick (потолок цели: pro, вердикт и так не выше; квота: объявления нет, корректор выключен), 2026-08-17 10:28-10:39.

## Сценарий проверки

Агентский, по свежему main после слияния, из корня репозитория.

1. `grep -rn "однострочному бэклогу" kit/skills/` ничего не находит: отменённая
   доктрина из скиллов ушла.
2. `grep -n "Что идёт строкой сразу\|Что уходит в черновик"
   kit/skills/board-task/SKILL.md` даёт оба подраздела раздела «Новая задача».
3. `grep -n "Ворота готовности" kit/skills/board-task/SKILL.md` даёт ссылку на
   раздел «Ворота готовности» board-groom в пункте 1 «Новой задачи».
4. `grep -rn "taskctl file" kit/skills/` подаёт только добивание строк,
   заведённых до рубежа: board-task, шаг 3 взятия в работу, и board-batch,
   подготовка пачки; шага «файл при взятии в работу» больше нет ни в одном
   скилле.
5. `python3 hooks/check-symbols.py kit/skills/board-task/SKILL.md
   kit/skills/board-team/SKILL.md` молчит (код возврата 0).
6. `cd tools/devkitctl && python3 -m unittest
   weigh_test.MeasureTest.test_14_live_skills_are_under_the_limit` заканчивается
   OK: тело board-task под порогом 16 000 символов.

## Исключения

- Исключение: тесты (правка бескодовая: скиллы и файл задачи, вес и чистота
  символов проверяются шагами 5 и 6 сценария).
