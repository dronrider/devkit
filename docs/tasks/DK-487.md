живёт в ветке poc-chat цели DK-397. Ветка несёт раздел LLD со списком и

taskctl-часть в эту строку не входит. show разыменовывает ссылку строки и
печатает строки «дизайн:» по ссылкам из файла задачи. Код лежит в своей
ветке dk-470-lld-link и не сближался с main весь месяц. У него свой дифф и
свой инструмент. Груминг увёл его отдельной строкой DK-1176.

По решению 5 DK-459 доводка режется по диффу до слияния. Доводки пока нет.
Код уже месяц живёт на проде без тестов, ревью и доки. Форма LLD в коде до
сих пор подписана комментарием «круг 2 POC DK-470»
(tools/dashboard/static/app.js).

Хвосты из перечня дыр POC остались нетронутыми. У раздела LLD нет вкладки на
узком экране. С дашборда нет заведения нового LLD. Ссылка на конкретное
«Решение N» не адресуется якорем и живёт прозой. Линт ссылок на lld/ не
расширен.

Регулярка lldRefs пока лежит только в dashboard. Она станет дублем в taskctl
позже, когда DK-1176 привезёт туда свою версию для «дизайн:». Тогда обеим
строкам стоит свести регулярку в общее место, а пока это не мешает ни одной
из них.
