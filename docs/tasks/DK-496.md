# DK-496: Нарезка доводки по диффу ветки POC в goal-cut

Цель: [tasks/DK-490.md](tasks/DK-490.md)

## Что происходит

Доводка утверждённого POC режется до слияния, и вход у этой нарезки, по
решению 5 LLD [lld/DK-459-poc-mode.md](../lld/DK-459-poc-mode.md), это дифф
ветки и перечень дыр из решения 4, а не замысел. Скилл `goal-cut` сегодня
умеет резать только от постановки: доводка, нарезанная так, повторяет план
вместо сделанного, а дыры перечня остаются без строк, и после слияния память
о недостающем испаряется вместе с веткой.

## Чего хотим

В `goal-cut` вход «режу по сделанному»: материалом идут дифф ветки против
`main` и перечень дыр из показа, вместе с замечаниями, отложенными самим
пользователем при утверждении. Каждая дыра либо становится строкой доводки,
либо явно признаётся несущественной, третьего исхода у неё нет.

## DoD

- В теле `goal-cut` есть вход нарезки по диффу ветки: материалом названы дифф
  против `main` и перечень дыр, а не постановка.
- Порядок требует исхода по каждой дыре и по каждому отложенному замечанию:
  строка доводки или явное «несущественно».
- Стык с порядком слияния назван: нарезка идёт до слияния, пока ветка жива.

## Ранг

`25+5+1+0+2 = 33`, P2.

- Серьёзность 25: без входа по диффу доводка режется по замыслу, а не по
  сделанному, и долг дыр не гаснет, а забывается.
- Ценность 5: нарезка доводки это первое условие слияния каждого утверждённого
  POC.
- Неопределённость 1: вход и материал названы решением 5.
- Поправка на баг 0: поломки нет.
- Рычаг 2: нарезанная по факту доводка и позволяет сливать POC как есть, не
  переписывая набело.
