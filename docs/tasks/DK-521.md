# DK-521: Сторож прозы check-prose.py: метрики замера, пороги конфигом, хук записи

Цель: [tasks/DK-446.md](tasks/DK-446.md)

## Что происходит

Замер по 38,5 тыс. слов агентской прозы репозитория лежит в разделе «Что
показал замер» файла цели. Он нашёл пять примет, которых нет у людей: довод в
той же фразе (49% против 22%), двоеточие-довод в середине фразы (19,9 против
7,5 на 1000 слов), хвост «..., а не Y» (4,4 против 1,1), вывод-афоризм в конце
абзаца (4,2% абзацев против нуля), метафорный глагол при абстрактном подлежащем
(8-10 против 0-0,7). Прототип счётчиков написан в разборе и вложен в файл цели
разделом «Скрипт замера». Скрипт живёт текстом в задаче. Кода в репозитории
для него нет, и посчитать эти числа сейчас нечем.

## Чего хотим

Хук `hooks/check-prose.py` по образцу `check-symbols.py`: разбор фрагмента при
записи, режимы `--hook` и файловый, ответ через `hookio.py`. Модели он не
зовёт, считает регулярками. Пороги на предупреждение и отдельные пороги на
блокировку читаются из конфига, конфигурация задаёт поведение. Первый прогон
калибрует пороги по человеческому корпусу из архива DK-173 (девять issue с URL,
раздел «Калибровка по живым текстам») и по первому коммиту RULES.md.

## DoD

1. `hooks/check-prose.py` считает шесть метрик замера: средняя длина
   предложения, доля предложений длиннее 25 слов, довод в той же фразе,
   двоеточие в середине фразы, хвост «..., а не Y», афоризм в конце абзаца.
2. Пороги и режим (предупреждение или блокировка) лежат в конфиге, код их не
   содержит. `devkitctl doctor` показывает отсутствие конфига находкой.
3. Хук подключён на запись файла и в pre-commit.
4. Тесты хука зелёные: метрика на записанном фрагменте, порог предупреждения,
   порог блокировки, чистый текст без находок.
5. Числа калибровки записаны в раздел «Проверка» с указанием корпуса.

## Ранг

`25+6+2+0+3 = 36`, P2.

- Серьёзность 25: трение с дешёвым обходом, вычитка `proofread` ловит слоп.
- Ценность 6: работает на каждой записи долгоживущего текста.
- Неопределённость 2: подход выбран, открыты пороги и раскладка конфига.
- Рычаг 3: даёт общий чек-лист перекалибровке `proofread` (DK-524) и числа
  замеру (DK-526).
