# DK-523: Скилл prose подмешивает эталоны в момент письма, зовут четыре точки

Цель: [tasks/DK-446.md](tasks/DK-446.md)

## Что происходит

К моменту письма модель хуже держит стилевую инструкцию из начала контекста, и
разбор цели собрал на это ссылки («Style Amnesia», «Lost in Multi-Turn
Conversation»). Проба DK-173 показала то же самое. Три задачи переписывались с
полным списком замечаний в контексте, но шаблоны воспроизводились всё равно.
Примеры держат форму сильнее правил, а после 2-10 образцов улучшение почти
прекращается. Сейчас в devkit нет скилла, который приезжает в контекст в
момент написания текста.

## Чего хотим

Скилл `prose` в `kit/skills/`. В контекст письма попадает случайный набор
эталонных фрагментов из корпуса DK-522 и короткий горячий список из пяти
примет замера. Ядро правил при этом не растёт, решение DK-173.2 остаётся в
силе. Зовут скилл четыре точки, где пишется долгоживущий текст: оформление
черновика в `board-groom`, файл задачи в `board-task`, LLD в `exec-xhigh`,
правка README.
Набор фрагментов случайный, чтобы тексты не выходили однородными.

## DoD

1. `kit/skills/prose/SKILL.md` есть, в нём горячий список из пяти примет и
   правило брать эталоны того же жанра.
2. `grep -l prose kit/skills/board-groom/SKILL.md kit/skills/board-task/SKILL.md
   kit/agents/exec-xhigh.md` печатает три пути.
3. Два запуска скилла дают разные наборы фрагментов, это показывает тест.
4. Правка README как точка вызова названа в самом скилле.
5. Прогон `prompt-test` по скиллу записан в «Ход работы».

## Ранг

`25+8+2+0+2 = 37`, P2.

- Серьёзность 25: трение с дешёвым обходом.
- Ценность 8: ради этого цель и затевается, первый черновик пишется живой
  прозой.
- Неопределённость 2: форма скилла ясна, открыты объём выборки и место
  горячего списка.
- Рычаг 2: ускоряет свой поток по одной теме.

## Ход работы

- Вычитка: 1 файл, 5 правок, 1 пометка, 2026-08-25.
- Разработка: субагент opus/medium по вердикту pick (квота: week_all 20%, week_max 2%, снимок 1м назад, сдвига нет), 2026-08-25 17:01-17:01.

1. `grep -l prose` по трём путям из DoD печатает три пути.
2. Тест скилла на двух запусках печатает разные наборы фрагментов.
3. Черновик, написанный с подключённым скиллом, проходит пороги
