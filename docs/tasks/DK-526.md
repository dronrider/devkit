# DK-526: Мера прозы: десять новых текстов проходят пороги check-prose.py

Цель: [tasks/DK-446.md](tasks/DK-446.md)

## Что происходит

Цель в том, чтобы изменить то, как пишется текст. Проверить это можно только
числами на текстах, написанных после внедрения скилла. Замер до внедрения лежит
в файле цели, замер после делать нечем, пока нет сторожа DK-521 и скилла
DK-523.

## Чего хотим

Прогон `check-prose.py` по десяти долгоживущим текстам, написанным с
подключённым скиллом `prose`. Числа записаны рядом с числами замера до
внедрения, чтобы разницу было видно в одном месте.

## DoD

1. Собраны десять долгоживущих текстов, написанных после внедрения скилла
   (черновики, файлы задач, LLD, разделы README).
2. `check-prose.py` по ним даёт: двоеточие в середине фразы не больше 10 на
   1000 слов, хвост «..., а не Y» не больше 2 на 1000, предложений с доводом в
   той же фразе не больше 30%, средняя длина предложения не больше 19 слов.
3. Таблица «до и после» записана в файл цели рядом с разделом «Что показал
   замер».
4. Пороги, не сошедшиеся с замером, названы в файле задачи с причиной.
   Направление порогов при этом не меняется.

## Ранг

`25+4+1+0+1 = 31`, P2.

- Серьёзность 25: трение с дешёвым обходом.
- Ценность 4: числа нужны один раз, на приёмке цели.
- Неопределённость 1: считает готовый сторож, открыт только отбор текстов.
- Рычаг 1: другую работу не разблокирует.

- Разработка: субагент sonnet/high по вердикту pick (квота: week_all 25%, снимок 1м назад, сдвига нет), 2026-08-25 20:35-20:35.

2. Сводка укладывается в пороги из DoD.
3. Таблица «до и после» лежит в `docs/tasks/DK-446.md`.
