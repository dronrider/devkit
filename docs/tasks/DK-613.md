# DK-613: Скилл work-plan: план работ сессии ведёт одно правило и утилита

## Что происходит

Правило «веди план работ файлом ~/.devkit/plans/<ID сессии>.json» живёт в пяти копиях. Оно стоит в четырёх kit/agents/exec-*.md и в инструкции задания дашборда (planRule в POC-дереве, tools/dashboard/chats.go). Читает файлы только кольцо прогресса дашборда, в самом devkit читателей нет. Разбор дашборда терпит три формата (массив, объекты с полями stages/steps/items, состояние done наравне с completed). Агенты пишут файл кто как. Замена на TodoWrite проверена 30.08 и не подходит. У сессий на Fable инструмента в наборе нет вовсе (1 транскрипт из 588 за неделю), а у GLM есть. Файлов планов за ту же неделю 153.

Правило есть, а текста, который его задаёт, в правилах devkit нет. Человек, читающий RULES, о плане не узнаёт. Агент получает его приписками, которые панель вырезает из ленты (cutOrderRules) и корпус прозы отсеивает (TAIL_MARKS в prose.py). Пять копий расходятся, формат плывёт, запасной адрес chat-N.json при пустом CLAUDE_CODE_SESSION_ID подпирает GLM-контур.

## Чего хотим

Есть скилл work-plan: один формат файла, адрес по ID сессии из окружения или события хука, у субагента <ID>-sub.json, чужой не перезаписывать, ритм ведения. Утилита пишет и показывает план (show печатает план живой сессии в терминале), формат держат её тесты. Вход в скилл одной строкой в RULES.core.md, exec-* и board-chat отсылают к нему, копий текста нет. Дашборд остаётся одним из читателей, а разбор трёх форматов у него уходит.

## Развилки

Утилита это подкоманда taskctl plan или своя по правилу раскладки README «Раскладка»? Чистка планов кончившихся сессий идёт по возрасту доктором или при снятии сессии?

## DoD

- В kit/skills есть скилл work-plan: формат файла плана, адрес по ID сессии, файл субагента, ритм ведения; вход в него одной строкой в RULES.core.md.
- Утилита пишет и читает план: команда show печатает план живой сессии в терминале, формат держат её тесты.
- Из kit/agents/exec-*.md текст правила снят, стоит отсылка к скиллу; копий правила в devkit нет (греп по «Веди план работ»).
- Стенд prompt-test: сессия на обеих раскладках ведёт план по скиллу без инструкции к реплике.
