# DK-617: prose: приёмы страницы по режиму чтения, раздел про правку готового текста и перенос из другого формата

## Что происходит

Решения 1, 2 и 4 LLD DK-606 (`docs/lld/DK-606-prose-structure.md`). Приёмы
страницы раскладываются по режиму чтения, словарь типов открытый. Раздел
«Правка готового текста» несёт инвариант «структура исходника это данные» и
случай переноса из другого формата (HTML, вики). Последним шагом захода зовётся
proofread. Перечень блоков открытый. Под него попадает любой не-абзацный блок
markdown, fenced-блок вместе с языком (код, mermaid), цитата, инлайн-код и
ссылки.

Стенд obeycheck 2026-08-30, след в файле DK-606. Перенос HTML в md по промпту

3 и 0 из 6. Два абзаца оговорки в конце SKILL.md удержали структуру 3 из 3.
Сценарии, образцы и раскладки лежат в скретчпаде сессии b7cc7ae5, каталог

него уже есть.

## Чего хотим

В `kit/skills/prose/SKILL.md` встают два раздела. Первый раскладывает приёмы
страницы по четырём режимам чтения: подряд, по диагонали, по столбцу, по шагам.
Режим отвечает на вопрос, что читатель делает с текстом, и держит свой набор
приёмов. Рядом стоит таблица «тип документа, режим абзацев», словарь типов
открытый, новый тип это одна строка. Ключ ставится на блок. Тип задаёт режим
абзацев по умолчанию, а разметка блока переопределяет его.

Второй раздел про правку готового текста. Инвариант из решения 2 стоит дословно.
Структура исходника это данные, стилю принадлежат только слова внутри фразы.
Слово типа тут не нужно, режим читается с разметки правимого блока. Перечень
неприкосновенных блоков открытый, под него попадает любой не-абзацный блок
markdown, а число блоков после правки равно числу до. Тем же разделом закрыт
перенос из другого формата: HTML-страница, вики, чужой markdown. Последним шагом
того же захода зовётся `proofread`, до отчёта, а не перед коммитом.
