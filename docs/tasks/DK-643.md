# DK-643: Сценарий без выката обкатывается в чистом окружении до перевода в Check

Цель: [tasks/DK-161.md](tasks/DK-161.md)

## Что происходит

Сценарий, выполнимый без выката, сегодня обкатывается там же, где шла работа,
в прогретом чекауте с живыми HOME и PATH. Дефекты окружения из-за этого
всплывают после слияния. Стенд самопроверки DK-138 падал в свежем worktree,
а в прогретом был зелёным, и находилось это уже прогоном DoD.

## Чего хотим

Сценарий без выката обкатывается в чистом окружении до перевода в Check.
Команда обкатки гоняет шаги сценария в дереве и окружении DK-641, кладёт вывод
в раздел «Проверка» и ставит отметку, а `taskctl move check` без отметки
отказывает и называет команду. Гасится пометкой-исключением по образцу трёх
нынешних ворот слияния (`advice.go`).

Пункт DoD 3 цели DK-161, вторая половина. После DK-641, кирпич дерева и
окружения общий.

## DoD

1. Команда обкатки гоняет шаги сценария в свежем дереве и собранном окружении,
   вывод ложится в раздел «Проверка» файла задачи, отметка ставится машинно.
2. `taskctl move check` без отметки отказывает и называет команду, гасится
   пометкой-исключением по образцу нынешних ворот.
3. `regcheck` и `obeycheck` зелёные, у правки своя пирамида тестов, стенд по
   prompt-test для правленых текстов.

## Ранг

- Серьёзность 25: дефекты окружения всплывают после слияния, цена видна по
  дорезке DK-155, обходной путь есть.
- Ценность 7: закрывает вторую половину пункта DoD 3, дефекты встают до Check.
- Неопределённость 2: подход выбран нарезкой, ворота по готовому образцу,
  открыты детали.
- Баг 0: новая работа.
- Рычаг 4: отметка обкатки это вход для ворот move и будущих ворот merge.
