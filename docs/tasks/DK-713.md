# DK-713: Цель: любой чат панели, даже архивный, принимает реплику и доносит ответ агента

## Цель

Пользователь ставит задачу просто. В любом чате панели можно написать агенту
и получить ответ. Чат может быть архивным или старым. Ввод не гасится,
реплики не пропадают молча, предупреждающих состояний нет.

DoD: стенд держит по одному чату в каждом барьерном состоянии.

- живой
- мёртвый, имя tmux умерло
- архивный
- старше окна трёх суток
- разговор без задачи
- gone, имя tmux отдано чужому разговору

Сценарий гоняют по живому серверу ручками панели. В каждый чат он отправляет
реплику-маркер «ответь одним словом» и ждёт ответа агента в ленте. Цель
достигнута, когда прогон печатает «6/6 доставлено, 6/6 отвечено». Ни одна
реплика не висит «в очереди». Финальный виток повторяет прогон после
последнего выката.

порт из ~/.devkit/dashboard.local, токен даёт `dashboard secret`, вход идёт
ручкой логина. Шаг один и он живой, барьер тут само событие: разговоры в
барьерных состояниях подделать нечем, их надо иметь.

1. - Исключение: обкатка (нужна живая служба и настоящие разговоры в шести
   состояниях; в свежем дереве с временным домом их нет и взяться им неоткуда).
   Собрать по одному чату в каждом состоянии: живой; мёртвый, чьё имя tmux
   умерло; архивный; старше окна трёх суток; разговор без задачи; gone, чьё имя
   отдано другому разговору. Часть найдётся среди живых на машине, часть
   готовится руками: поднять чат и снять его сессию, взять чат из архива,
   поднять чат без задачи. Чужих живых разговоров не трогать.

   В каждый отправить репликой слова «ответь одним словом: готово» и дождаться
   ответа агента в ленте. Считать два числа: сколько реплик приняла ручка и
   сколько ответов пришло. Реплика, повисшая в очереди, считается
   недоставленной.

   Ожидание: шесть доставленных из шести и шесть отвеченных из шести, ни одной
   висящей в очереди. Следы переживают прогон: ответ ручки с дорогой доставки,
   строки лент с ответами агента и журнал службы без строк про очередь.
