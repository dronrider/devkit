# DK-713: Цель: любой чат панели, даже архивный, принимает реплику и доносит ответ агента

## Цель

Пользователь ставит задачу просто. В любом чате панели можно написать агенту
и получить ответ. Чат может быть архивным или старым. Ввод не гасится,
реплики не пропадают молча, предупреждающих состояний нет.

DoD: стенд держит по одному чату в каждом барьерном состоянии.

- живой
- мёртвый, имя tmux умерло
- архивный
- старше окна трёх суток
- разговор без задачи
- gone, имя tmux отдано чужому разговору

Сценарий гоняют по живому серверу ручками панели. В каждый чат он отправляет
реплику-маркер «ответь одним словом» и ждёт ответа агента в ленте. Цель
достигнута, когда прогон печатает «6/6 доставлено, 6/6 отвечено». Ни одна
реплика не висит «в очереди». Финальный виток повторяет прогон после
последнего выката.
