# DK-725: Цель стоит первой в полосе равных, подтянутые задачи под ней

## Что происходит

Задача цели наследует её ранг (приписка «от DK-713» в хвосте скобки), и при
равном итоге `taskctl list` ставит предпосылку раньше зависимой. Для рёбер
цели это значит, что сама цель замыкает свою полосу. На 2026-09-02 верх
бэклога devkit это восемь задач DK-713 с рангом 71, и только девятой идёт
строка цели. `taskctl batch` берёт цену S и M, XL-строку цели он не увидит
никогда. Единственный вход в цикл цели это явное «выполни цель».
Диспетчер видит задачи цели наверху бэклога и разбирает цель по ним, минуя
гейт бюджета, журнал и файл цели.

Отдельный ранг целям это не лечит. Любое число у цели подтянет её задачи
до того же уровня, и при равенстве они снова встанут над ней.

## Чего хотим

Внутри полосы равного итога цель идёт первой, а её задачи, подтянутые до её
ранга, стоят сразу под ней. Инвариант ранга по числу не меняется. Задача цели
по-прежнему не ниже цели. Меняется только порядок среди равных, и только для
рёбер цели. Для суффикса «[после X]» порядок прежний, предпосылка раньше
зависимой. Задача с собственным рангом выше цели остаётся над ней. Она
срочнее сама по себе.

Брать задачи цели поодиночке никто не запрещает: человек может осознанно
взять одну задачу, когда квоты на цикл цели нет. Речь только о том, что
показывает список.

## Границы

Сторож в `taskctl batch` против взятия задач незапущенной цели не заводится.
Взятие одной задачи цели по решению человека это нормальный ход.

## Развилки

Цель с собственным суффиксом «[после N]», где N держится задачей той же цели,
даёт цикл в порядке полосы. Цикл не ломает `orderTier` (порядок сохраняется
по номеру), находку даёт lint; специально этот случай не чинится.

## DoD

- В `taskctl list` и в самом `docs/TASKS.md` после `taskctl sort` строка цели
  стоит выше своих задач с припиской «от <ID цели>» при равном итоге.
- Тест в `tools/taskctl` на полосу равных: цель, две её задачи (одна с
  «[после другой]»), задача с собственным рангом выше цели; ожидаемый порядок
  выписан явно.
- Абзац про порядок Backlog в `tools/taskctl/README.md` (пункт «Backlog
  отсортирован по итоговому R» и раздел «Поправки к рангу») называет
  исключение для рёбер цели.
