# DK-733: Тесты группировки чатов падают от времени суток, а не от кода

Цель: [tasks/DK-713.md](tasks/DK-713.md)

## Что происходит

TestDashboardSmokeChatGroupOrder в tools/dashboard/chat_smoke_test.go кладёт фикстуру со временем now-2h и now-1h и ждёт, что обе записи встанут в группу «сегодня». Прогон после полуночи роняет тест. now-2h уезжает во «вчера».

Всплыло дважды за ночь, на ревью DK-726 и на прогоне DK-660, оба раза около часа ночи. Оба раза время разбора уходило на выяснение, что падение чужое и к правке отношения не имеет.

Детерминизм тут чинится фиксацией отсчёта. Фикстура должна брать не now, а привязанный к границе суток момент.

## Чего хотим

Обе фикстуры семьи (стенд `testdata/poc_chatgroup.mjs` за TestStaticChatListGroups
и подготовка сессий в TestDashboardSmokeChatGroupOrder) кладут время записей не
сдвигом от момента запуска, а сдвигом от местного полудня текущего дня. Час, в
который гоняется прогон, на группировку фикстуры больше не влияет. `chatDayHead`
в `static/app.js` и сама проверка остаются как были. Меняется только то, откуда
фикстура берёт точку отсчёта.

## Развилки

Рассмотрены два пути.

Первый путь: передать тестам «сейчас» явным параметром. `chatDayHead` в
`static/app.js` пришлось бы научить принимать его вместо внутреннего `new
Date()`. Путь отвергнут. Это правка группировки чатов ради теста, а постановка
отдельно просит её не трогать. Настоящий баг живёт не в коде, а в двух
фикстурах.

Выбран второй путь. Фикстура берёт точку отсчёта не от `Date.now()` (JS-стенд)
и не от `time.Now()` (Go-смоук), а от местного полудня сегодняшнего дня. Все
сдвиги фикстуры (2, 3, 26 и 72 часа) укладываются в сутки от полудня. Соседний
день они не задевают ни при каком часе запуска. Полдень стоит от границы суток
дальше всех остальных точек отсчёта. Правка целиком в тестовых файлах, код
группировки не тронут.

## DoD

Прогон `GOWORK=off go test -count=1 ./...` в tools/dashboard зелёный в любой
час суток. Проверяется прогоном с подменённым временем машины либо стендом,
который кладёт фикстуру относительно границы суток. Оба теста семьи (TestStaticChatListGroups и
TestDashboardSmokeChatGroupOrder) перестают зависеть от часа.

## Сценарий проверки

Агентский. Оба члена семьи (TestStaticChatListGroups и
TestDashboardSmokeChatGroupOrder) читают одну и ту же группировку
`chatDayHead` из `static/app.js`. Шаг ниже гоняет эту логику настоящим
`app.js` через JS-стенд `testdata/poc_chatgroup.mjs`. «Сейчас» подменяется на
час ночи без внешних инструментов, нужен только `node`, который сценариям и
так нужен.

Второй член семьи (Go-смоук) шагом не покрыт. При обычном `go test` подмена
часа до него не доезжает. Цепочка вызовов cmd/go на этой машине глушит
`DYLD_INSERT_LIBRARIES` у тестового бинаря. Подмену видит только бинарь,
собранный `go test -c` и запущенный напрямую под `faketime`. Разбор и
краснота этого пути лежат в отчёте исполнителя. Шаг сценария libfaketime не
требует.

1. Час ночи, в который валился TestStaticChatListGroups (DK-726, DK-660),
   воспроизводится подменой `Date` внутри одного процесса `node`, без правки
   рабочего дерева и без внешних утилит:

   ```sh
   root="$(git rev-parse --show-toplevel)"
   wrap="$(mktemp -t dk733-night).mjs"
   cat > "$wrap" <<'JS'
   const RealDate = Date;
   const now = new RealDate();
   const target = new RealDate(now.getFullYear(), now.getMonth(), now.getDate(), 1, 30, 0, 0);
   const OFFSET = target.getTime() - RealDate.now();
   class FakeDate extends RealDate {
     constructor(...a) { if (a.length === 0) super(RealDate.now() + OFFSET); else super(...a); }
     static now() { return RealDate.now() + OFFSET; }
   }
   globalThis.Date = FakeDate;
   console.error("час подменён на " + new Date().toString());
   await import(new URL("./testdata/poc_chatgroup.mjs", "file://" + process.cwd() + "/").href);
   JS
   cd "$root/tools/dashboard" && node "$wrap" static/app.js
   ```

   Ожидается строка `poc_chatgroup: ok` и код возврата 0 независимо от
   настоящего часа машины: час 01:30 воспроизводит именно то время суток, в
   которое старая фикстура (сдвиг от `Date.now()`) уводила «сегодняшний
   разговор» в группу «вчера».
