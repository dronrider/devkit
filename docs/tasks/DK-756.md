# DK-756: LLD: ревью чужой задачи в корп-контуре

## Что происходит

В корп-контуре просьба «проведи ревью задачи AB-123» сегодня ничем не
поддержана. Тикет чужой, и `trackctl take` назначит его на меня. Строки на
боковой доске нет. Замечания уходят в MR как сложится разговор, а ответы
автора в тредах никто не смотрит, пока не попросят. Скилл `review` и след
ревью заметкой git уже есть, входа для чужой задачи нет.

## Чего хотим

Дизайн сценария ревью чужой задачи: строка на боковой доске без касания
тикета, промежуточный файл замечаний, режимы `confirm` и `auto` из конфига,
вопрос человеку без ожидания внутри команды, опрос тредов тиком и второй круг
без приказа, судьба строки по MR. Документ в `docs/lld/DK-756-foreign-review.md`,
восемь решений, нарезка на три строки.

## DoD

- Восемь развилок из разговора 2026-09-03 закрыты решениями с отвергнутыми
  вариантами.
- Живой материал назван с путями, новых утилит не заводится.
- Зависимости от DK-715, DK-695, DK-724 и DK-474 названы, дубля нет.
- Три строки с ценой и порядком заведены на доске после утверждения.

## Ранг

`25+8+3+0+4 = 40`, P2.

- Серьёзность 25. Ревью чужих MR идёт руками и по памяти, обход есть, но
  каждый раз разный.
- Ценность 8. Ради этого сценария и затевался скилл ревью. Коллеги получают
  ревью по одним правилам.
- Неопределённость 3. Подход ясен, развилки разобраны с пользователем, детали
  публикации и опроса тредов открыты.
- Поправка на баг 0.
- Рычаг 4. Каждое следующее ревью коллеги идёт без ручного захода.

## Приёмка

- вид: user
- барьер «согласие»: дизайн утверждает пользователь, обхода у согласия нет.

## Сценарий проверки

1. Прочитать `docs/lld/DK-756-foreign-review.md`: у каждого из восьми решений
   назван отвергнутый вариант и причина.
2. Сверить решения с ответами пользователя в разговоре 2026-09-03: цена и ранг
   по тикету, файл рядом с файлом задачи, один ключ `publish`, вопрос последней
   репликой, опрос ключом `poll`, порог `silence` сутки, одно возражение и
   стоп, закрытие по MR молча, ворклог ключом.
3. На доске стоят три строки из раздела «Что меняется в строках» с маркером
   `[после DK-756]`, третья ещё и `[после DK-724]`.
