# DK-784: Шапка вопроса со сроком слепляет заголовок и остаток времени

## Что происходит

2026-09-04, приёмка DK-772. Панель спросила пароль, и в шапке вопроса
заголовок «Пароль просит sudo» сросся с остатком времени в одно слово
«sudoосталось 1 мин». Между ними нет ни пробела, ни отступа.

Шапка собирается в двух местах `tools/dashboard/static/app.js`, в
`paintAskpassAsk` и в шапке вопроса агента (строки 11352 и 11600). Заголовок
кладётся элементом `b`, остаток времени соседним `span` класса `n`. Пробела
между инлайновыми элементами браузер не рисует. Правило отступа для этого
класса написано у трёх других шапок, `.sitem .n`, `.shead .n`, `.btier .n`.
У `.caskh` такого правила нет (`static/style.css`, строка 283). Слипаются обе
шапки, и вопрос про пароль, и вопрос агента.

## Чего хотим

Заголовок и остаток времени в шапке вопроса разделены зазором. Правило живёт
в стиле шапки и накрывает оба места сразу. Пробел в разметку каждой из них
дописывать не нужно.

## Сценарий проверки

Первый шаг воспроизводит поломку на выкаченном стиле. Панель отдаёт
`style.css` без входа. Правило зазора видно в отданном файле.

- Исключение: обкатка. Шаги судят выкаченный стиль и стенд из слитой ветки.
  На HEAD до слияния нет ни того, ни другого.

```sh
curl -s http://127.0.0.1:7112/assets/style.css | grep -o '\.caskh \.n{[^}]*}'
node tools/dashboard/testdata/poc_caskhgap.mjs tools/dashboard/static/app.js
```

Ждём такого. Первая команда печатает правило `.caskh .n` с ненулевым
`margin-left`. До правки выдача была пустой, слипание шло отсюда. Вторая
печатает `poc_caskhgap: ok`.
