# DK-785: У скилла review есть вход для новичка: первый запуск и все ключи конфига

## Что происходит

Конфиг скилла review описан в трёх местах для агента и утилиты: раздел «Конфиг» скилла, README taskctl, образец `.devkit/review.conf`. Входа для человека, который ставит скилл впервые, нет, а образец конфига отстал от ключей `poll`, `silence` и `worklog`. Вопрос пользователя 2026-09-04: где посмотреть, как его конфигурировать.

## Чего хотим

Раздел «Ревью: первый запуск» в корневом README: разложить, настроить, позвать, и таблица всех ключей конфига с умолчаниями. Образец конфига несёт все ключи.

## DoD

- В README.md раздел «Ревью: первый запуск» с тремя шагами и таблицей ключей, каждый ключ из `loadReviewConf` и из раздела «Конфиг» скилла в таблице есть.
- `.devkit/review.conf` devkit несёт `poll`, `silence`, `worklog` с комментариями.
- Сторожа прозы и символов без блокировок.
