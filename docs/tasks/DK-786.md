# DK-786: Замыкающая задача фичи несёт в DoD вход для новичка, ревью его спрашивает

## Что происходит

Сценарий чужого ревью собрался тремя строками DK-757, DK-758, DK-759, у каждой дока своей правки в README утилиты, а входа для человека не появилось: страницу первого запуска никому не отдали, и ревьюверы её не спросили. Пришлось дописывать отдельной DK-785. Разбор с пользователем 2026-09-04.

## Чего хотим

В `board-task` условие: задача, замыкающая фичу из нескольких строк, несёт в DoD вход для новичка, отдельной строки под доку нет, задаче без фичи пункт не нужен. В скилле `review` вопрос второго уровня про доку спрашивает у замыкающей задачи одну страницу первого запуска.

## DoD

- `board-task`, раздел «Новая задача», пункт 5 с условием и признаком замыкающей задачи.
- `review`, вопрос второго уровня про доку дополнен фразой про страницу первого запуска у замыкающей задачи; тело скилла в пороге 16000.
- Сторожа скиллов, веса, символов и прозы без блокировок.

## Ранг

`25+5+0+0+3 = 33`, P2.

- Серьёзность 25. Без правила вход для новичка теряется на каждой фиче из нескольких строк.
- Ценность 5. Правило ядра «у доки фичи есть вход» получает место в DoD.
- Неопределённость 0. Две фразы.
- Поправка на баг 0.
- Рычаг 3. Каждая нарезка на несколько строк.
