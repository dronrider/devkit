# DK-870: Конвейер гасит воронкой сессию, ждущую субагентов или приёмки человеком

## Что происходит

Чат задачи обрывается хвостом терминала со словами «сессия task-<ID> прожила
3 мин и кончилась», а следующая реплика в него ложится недоставленной. Так
кончились task-DK-696 (7 сентября, 22:38) и task-DK-864 (8 сентября, 10:51).
Снимает сессию не дашборд, а оболочка конвейера `task-run.py`: три прохода
подряд короче полутора минут без движения строки она считает воронкой и
снимает клиента. Воронку она ловит в двух штатных случаях.

Первый: задача с видом приёмки mixed или user стоит в Check, агентская часть
сценария прогнана, остаток за человеком. Оболочка должна встать со словами
«задача ждёт приёмки человеком», но узнаёт этот случай по слову
«пользовательск» в выводе `taskctl show`, а с DK-298 show печатает «вид mixed»
и «вид user». Стенд оболочки до сих пор играет старый формат, поэтому зелёный.
Голова трижды за десять секунд отвечает «моя часть закрыта, ждём вас», и
оболочка снимает её.

Второй: голова раздала работу фоновым субагентам и ждёт их. Каждый заказ
«Продолжай» она закрывает за 15-40 секунд словами «исполнитель работает», и
на третьем такое ожидание снимается вместе с субагентами, а их работа
пропадает. У DK-864 так погиб исполнитель exec-high на седьмой минуте задачи.

## Чего хотим

Оболочка узнаёт ждущую приёмки задачу по нынешнему выводу show и встаёт на ней
штатно. Проход, кончившийся при живых субагентах сессии (реестр
`~/.devkit/agents/<сессия>.json`, который пишет хук agent-watch), воронкой не
считается, и следующий заказ на него не подаётся: голову будит конец
субагента, как будит её реплика человека.

## DoD

- `waits_user` в `task-run.py` читает «вид mixed» и «вид user» из строки
  show, стенд `task_run_test.py` играет нынешний формат.
- Проход с живыми субагентами не идёт в счёт воронки и не получает заказа
  «Продолжай»; реестр субагентов оболочка читает тем же путём и с той же
  подменой каталога (`DEVKIT_AGENT_WATCH_DIR`), что и хук.
- Тесты обоих случаев красные на старой оболочке, зелёные на новой, краснота
  сверена `regcheck`.
- Раздел про воронку в `tools/dashboard/README.md` и скилл `board-task`
  называют оба исключения.

## Ранг

- Серьёзность 50: конвейер задачи с субагентами кончается потерей работы
  исполнителя, обход есть (вести задачу руками из терминала), но болезненный.
- Ценность 7: конвейер с экрана снова доводит задачу до конца без присмотра.
- Неопределённость 1: оба места найдены по журналам, править есть что.
- Поправка на баг 5.
- Рычаг 4: чинит цикл разработки агентом, каждая следующая задача с экрана
  дешевле.

## Сценарий проверки

Шаги гоняются по порядку и держат общий стенд в `/tmp/dk870-stand`. Там лежит
оболочка конвейера из родителя коммита правки, а рядом с нею стенд тестов из
ветки. Живых сессий тут не поднимается ни одной, клиента, доску и tmux играют
стабы самопроверки, и конвейер машины шаги не трогают. Репозиторий каждый шаг
берёт от своего рабочего дерева. Каждый шаг это одна строка.

```sh
d=/tmp/dk870-stand; r=$(git rev-parse --show-toplevel); rm -rf "$d"; mkdir -p "$d/old" && fix=$(git -C "$r" log --format=%H -S 'def busy' -- kit/skills/board-task/task-run.py | tail -1) && git -C "$r" archive "$fix^" kit/skills/board-task | tar -x -C "$d/old" && cp "$r/kit/skills/board-task/task_run_test.py" "$d/old/kit/skills/board-task/task_run_test.py" && echo "стенд $d готов: оболочка из $fix^, стенд тестов из ветки"
```

Ждём строку «стенд /tmp/dk870-stand готов» с коммитом старой оболочки.

Второй шаг воспроизводит оба дефекта на коде до правки. Первый тест играет три
коротких прохода при живых субагентах сессии, второй строку в check с видом
приёмки mixed.

```sh
d=/tmp/dk870-stand; python3 -c 'import sys,unittest;p=sys.argv[1];sys.path.insert(0,p);import task_run_test as t;names=["TestLiveHead.test_live_agents_do_not_feed_the_funnel","TestPasses.test_mixed_acceptance_stops_the_pipeline"];r=unittest.TextTestRunner(verbosity=2).run(unittest.TestLoader().loadTestsFromNames(names,t));print("старая оболочка: провалов %d из %d"%(len(r.failures)+len(r.errors),r.testsRun));sys.exit(None if r.failures or r.errors else "баг не воспроизвёлся: старая оболочка прошла оба теста")' "$d/old/kit/skills/board-task"
```

Ожидание: оба теста красные, «старая оболочка: провалов 2 из 2». В выводе видно
причину, стоп «3 прохода подряд вхолостую» у первого и незамеченный вид приёмки
у второго.

Третий шаг гоняет те же тесты и оба соседних по правленой оболочке. Она берётся
из рабочего дерева шага. На обкатке это ветка, после выката клон правил.

```sh
r=$(git rev-parse --show-toplevel); python3 -c 'import sys,unittest;p=sys.argv[1];sys.path.insert(0,p);import task_run_test as t;names=["TestLiveHead.test_live_agents_hold_the_order","TestLiveHead.test_live_agents_do_not_feed_the_funnel","TestPasses.test_mixed_acceptance_stops_the_pipeline","TestPasses.test_user_acceptance_stops_the_pipeline"];r=unittest.TextTestRunner(verbosity=2).run(unittest.TestLoader().loadTestsFromNames(names,t));bad=len(r.failures)+len(r.errors);print("правленая оболочка: провалов %d из %d"%(bad,r.testsRun));sys.exit("оболочка не держит воронку либо не узнаёт вид приёмки" if bad else None)' "$r/kit/skills/board-task"
```

Ожидание: «правленая оболочка: провалов 0 из 4».

Четвёртый шаг сверяет разбор с живым форматом `taskctl show`.
Строка доски берётся первая, у которой show называет вид приёмки, и вид в её
выводе подменяется по очереди на все три.

```sh
r=$(git rev-parse --show-toplevel); python3 -c 'import importlib.util,json,re,subprocess,sys;s=importlib.util.spec_from_file_location("taskrun",sys.argv[1]);m=importlib.util.module_from_spec(s);s.loader.exec_module(m);d=json.loads(subprocess.run(["taskctl","list","--json"],capture_output=True,text=True).stdout);ids=[r["id"] for sec in d["sections"] for r in sec["rows"] if any(str(n).startswith("вид ") for n in r.get("notes") or [])];sys.exit("на доске нет строки с видом приёмки: живой формат show показать нечем") if not ids else None;said=subprocess.run(["taskctl","show",ids[0]],capture_output=True,text=True).stdout;print(said.strip());w=lambda k:m.Pipeline.waits_user(None,re.sub(r"вид \w+","вид "+k,said),"check");got=dict((k,w(k)) for k in ("agent","mixed","user"));print("вердикты оболочки: agent %s, mixed %s, user %s"%(got["agent"],got["mixed"],got["user"]));bad=[x for x,c in (("агентский вид остановил конвейер",got["agent"]),("вид mixed не узнан",not got["mixed"]),("вид user не узнан",not got["user"])) if c];sys.exit(bad[0] if bad else None)' "$r/kit/skills/board-task/task-run.py"
```

Ожидание: печатается вывод show живой строки и «вердикты оболочки: agent False,
mixed True, user True».
