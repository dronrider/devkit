# DK-879: заголовок чата берётся из транскрипта харнеса, а не заказом у haiku

записан 2026-09-09
приоритет: средний

## Черновик

### Ситуация

Дашборд называет чаты лестницей titleFor в tools/dashboard/chats.go. Сначала берётся запись summary транскрипта, потом сохранённый заголовок в ~/.devkit/chats, потом эвристика titleTrim. Фоном идёт заказ у haiku отдельным процессом `claude -p --model haiku` из каталога ~/.devkit/titles.

Замер сделан 2026-09-09 по этой машине. Транскриптов с записью summary ноль из 3373, с записью ai-title 1743. Заказов haiku по dashboard.log с 1 сентября 308. Ещё 17 транскриптов заказа лежат в ~/.claude/projects под именами тестовых каталогов. Тесты дашборда ходят в живого клиента.

Claude Code сам пишет запись `{"type":"ai-title","aiTitle":"..."}` сразу после первой реплики человека, до первого ответа модели. У интерактивных сессий она есть почти всегда. На подписке glm-code она тоже есть, и генерирует её endpoint подписки. У сессий печатного режима `-p` записи нет. Команда `/rename` и флаг `claude --name` пишут запись `custom-title`. Флаг проверен и в печатном режиме. Шапку читает readSessionHead в sessions.go, и чтение обрывается после Branch и First. До ai-title оно не доходит.

У других агентов та же развилка. OpenCode и Goose называют сессию своей дешёвой моделью на первой реплике. Codex CLI и Gemini CLI показывают первую реплику. Второй процесс поверх харнеса ради заголовка не поднимает никто.

### Осложнение

Заголовок появляется с задержкой на подъём отдельного клиента, а заказов на заход списка по два. Каждый заказ жжёт токены подписки по умолчанию на украшение списка. Механика привязана к одному поставщику, и чат на glm-code называется haiku с claude-code. Заказы из тестов тратят квоту на каждом прогоне.

### Вопрос

Порядок лестницы предлагается такой: custom-title, ai-title, summary, сохранённый заголовок, эвристика. Какие точки запуска в chatCmd получают флаг `--name`, среди кандидатов запуск задачи, груминг, цель и прогон Check. Убирать ли заказ haiku целиком вместе с titleDir, меткой [devkit-title] и фильтрами служебных сессий, или оставить за ключом конфига.

### Гипотеза

Чат в списке дашборда получает заголовок через секунды после первой реплики без отдельного процесса и без токенов дашборда. Сессии, поднятые дашбордом с известным предметом, названы до первого токена. Тем же именем они видны в окне терминала и в списке `claude --resume`. Заголовок чата второй подписки пишет её же модель. Тесты дашборда в живого клиента не ходят.
