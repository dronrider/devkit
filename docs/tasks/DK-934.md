# DK-934: Взведённая строка стартует сама по слиянию предпосылки

Цель: [tasks/DK-902.md](tasks/DK-902.md)

## Что происходит

2026-09-11, нарезка цели DK-902. Ребро «после» снимается только закрытием
предпосылки, и освобождённая строка ждёт в Backlog руки человека. LLD DK-933
решила устройство взвода и сузила эту строку до него. Смысл ребра ушёл строкой
DK-943, команда цепочки ушла строкой DK-940 вне цели.

## Чего хотим

`taskctl` взводит строку на её предпосылки, и взведённая строка стартует сама.
Ребро снимается так, как задала строка DK-943. Строку поднимает `taskctl run`
из DK-931. Состав берётся из решений LLD DK-933.

- Суффикс `[взвод]`, команды `arm` и `arm --off`. `arm` отказывает строке с
  человеческой развилкой, с неопределённостью 4-5 или ценой XL и строке
  незакрытой цели (решение 1).
- Вид ждущих «взвод» в хвосте обхода DK-932 с воротами ёмкости и подъёмом
  через `taskctl run` (решение 5).
- Файл отказа `.devkit/arm/<ID>`, зов один раз на смену причины, строка
  попытки в `.devkit/log`, каталог в .gitignore.
- Три состояния в `list` и `show`, поле взвода в `dep list --json`.
- `move` из Backlog снимает `[взвод]`. Lint находит `[взвод]` вне Backlog и на
  строке незакрытой цели, хвост обхода такую строку пропускает.

Отказ подъёма из-за квоты или потолка деревьев приходит уведомлением.

## Границы

Команда `chain` идёт строкой DK-940 вне цели. Скилл цепочки и диалог
дашборда идут после неё строками DK-941 и DK-942. Часовое условие остаётся
строкой DK-538 и встаёт на механизм после этой.

## DoD

- Взведённая строка стартует сама после слияния кода всех предпосылок. Строка
  уровня N стартует после всех строк уровня N-1.
- Откат и провал предпосылки держат взведённую строку до нового слияния.
  Возврат предпосылки из Check с замечаниями её не держит (решение 3).
- Взведённая строка отличается от заглохшей в `taskctl list`, сторожок её
  брошенной не считает.
- Тест на временном репозитории. Цепочка из трёх строк на двух уровнях
  стартует по слияниям, уровни ставятся рёбрами `dep add` и взводом `arm`.
