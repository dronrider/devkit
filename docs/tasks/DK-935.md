# DK-935: Кнопка и подъёмы дашборда запускают голову через taskctl run

Цель: [tasks/DK-902.md](tasks/DK-902.md)

## Что происходит

2026-09-11, нарезка цели DK-902 чтением кода. Дашборд поднимает голову своей
функцией `startTaskSession` (tools/dashboard/runs.go:406). К ней ведут кнопка
экрана, `dashboard wake`, `dashboard check` и `dashboard round`. DK-931
заводит команду `taskctl run` с замком и лестницей. Путей запуска станет два,
и кнопка сможет поднять вторую голову рядом с той, что поднял тик.

## Чего хотим

Кнопка экрана и три подъёма дашборда запускают голову через общий код
запуска из DK-931. Замок один на все пути. Дашборд показывает отказ на
занятом замке теми же словами, что сейчас отказ 409.

## Границы

Вид экрана не меняется. Здесь только путь запуска.

## DoD

- Кнопка «Выполнить», `dashboard wake`, `check` и `round` поднимают голову
  через общий код запуска. Своей логики tmux у `startTaskSession` не остаётся.
- Голова, поднятая `taskctl run`, даёт кнопке отказ с тем же текстом, что
  живая сессия сейчас.
- Тесты дашборда на запуск проходят на новом пути.
