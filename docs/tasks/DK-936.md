# DK-936: Стенд трёх ожиданий на временном репозитории

Цель: [tasks/DK-902.md](tasks/DK-902.md)

## Что происходит

2026-09-11, нарезка цели DK-902. Первый пункт DoD цели требует стенда на
временном репозитории, который показывает три ожидания. Голова с живым
ожиданием переживает воронку оболочки. `taskctl close` и `shipctl merge`
поднимают припаркованных с машинным разрядом и взведённые рёбра «после». Тик
сторожка добирает пропущенное событие. Каждая строка цели везёт свои тесты,
а сквозного прогона через все утилиты сразу нет.

## Чего хотим

Один скрипт заводит временный репозиторий с доской и тремя строками,
подменяет клиента харнеса и tmux и гоняет три ожидания подряд. На каждое
ожидание скрипт печатает строку исхода и кончается кодом возврата. Прогон DoD
цели зовёт его одной командой.

## Границы

Живой замер цели ночью стендом не проверяется, его подтверждает прогон DoD
по `.devkit/log`. Стенд не трогает живую доску, `~/.devkit` и службы машины.

## DoD

- Скрипт проходит три ожидания на временном репозитории и кончается кодом 0.
  Каждое ожидание печатает строку исхода.
- Скрипт кончается ненулевым кодом, когда любое ожидание не снялось.
  Проверяется откатом одного звена.
- Стенд подменяет HOME и не трогает службы launchd машины.
- Команда стенда названа в README утилиты, рядом с которой он лежит, и в
  разделе «DoD» цели.

## Сценарий проверки

1. Стенд гоняется одной командой и проходит три ожидания подряд. В выводе три
   строки исхода («ожидание «живое ожидание против воронки»: ок» и соседние),
   последняя строка «три ожидания прошли», код возврата 0. Прогон занимает
   около сорока секунд. Стенд убирает за собой временный проект и дом.
2. Откат любого звена красит стенд. Тесты откатывают три звена. Голова
   кончает ход без отметки `agentctl wait`, строку не взводят, а тик молчит.
   Каждый прогон обязан выйти кодом 1 и назвать сломанное ожидание. Четыре
   теста класса идут около двух минут, часть времени уходит на сборку
   бинарей копии devkit.

```sh
python3 tools/devkitctl/devkitctl.py waitcheck
```

```sh
cd tools/devkitctl && GOWORK=off python3 -m unittest waitcheck_test
```

Ожидаемый итог: обе команды кончаются нулём, стенд печатает три снятых
ожидания, а тесты откатов проходят все четыре.
