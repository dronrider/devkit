# DK-942: Диалог цепочки на дашборде, список задач и номера уровней

## Что происходит

2026-09-11, нарезка LLD DK-933, третий заезд черновика DK-721 вне цели DK-902.
Карточка зависимостей на дашборде принимает один ID в поле ввода. Взвода она
не показывает, и цепочку с уровнями на ней не собрать.

## Чего хотим

В карточке вместо поля ввода список задач с поиском и переключатель
автозапуска, который зовёт `arm` и `arm --off`. Из списка доски открывается
диалог цепочки. Строки раскладываются по номерам уровней, предпросмотр идёт
через `chain --dry-run`, запись через `chain`. Три состояния взвода видны на
строке списка и в карточке, приходят они из `dep list --json`.

## DoD

- Цепочка из трёх строк на двух уровнях собирается диалогом и ложится на
  доску теми же рёбрами, что даёт `chain`.
- Переключатель ставит и снимает `[взвод]`, отказ `arm` виден в карточке с
  причиной.
- Проверка идёт тестом сервера дашборда на синтетической доске.

## Ранг

`25+5+3+0+2 = 35`, P2.

- Серьёзность 25: обход через чат или терминал дешёвый.
- Ценность 5: цепочку видно на доске и собирают глазами.
- Неопределённость 3: сервер на go, экран и стык с taskctl через JSON, три
  процесса.
- Поправка на баг 0: новая работа.
- Рычаг 2: небольшая своя польза.
