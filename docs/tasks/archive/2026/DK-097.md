синтетическом окружении: временный HOME, временный клон devkit, пустой проект.

нарочно возвращает настоящий HOME и работает в чекауте (уведомитель молчит из
временной директории, и в клоне тесты хуков упали бы не по делу).

```bash
sh docs/tasks/DK-097-check.sh
```

## Ревью

- Уточнение про taskctl -C неверно диагностирует поломку: проверено сборкой бинаря и прогоном 'taskctl draft -C <dir> "текст"' (и в синтетическом окружении, и повторно) - директория резолвится верно (черновик уходит на доску devkit, не проекта), а вот текстовый аргумент после -C молча теряется при разборе флагов подкоманды и черновик уходит читать stdin (зависание в интерактиве, ошибка 'нет текста черновика' на закрытом stdin). Формулировка 'форма из LLD увела бы черновик на доску проекта' в skills/live-core/SKILL.md (шаг 7) и в docs/tasks/DK-097.md ('Ход работы') фактически неверна и вводит в заблуждение будущих читателей; рекомендуемая форма taskctl -C <dir> draft "..." сама по себе рабочая, поменять нужно только объяснение причины.: исправлено
- Мелкая правка форматирования: в docs/lld/DK-079-autonomous-loop.md строка 272 ('ним в stdin) и обходится по месту. Цель не сворачивает в ремонт ядра: бюджет платился за') вышла на 90 символов - единственная строка прозы во всём документе длиннее 80 (остальные держат перенос на ~78), видимо не перенеслась при правке абзаца про taskctl -C. Перенести по общему шаблону документа.: исправлено
