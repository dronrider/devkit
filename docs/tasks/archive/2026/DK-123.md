# DK-123: shipctl start в корп-контуре зовёт merge, которого там нет

Найдено прогоном сценария DK-087 на живом корп-стенде. `shipctl start` в
корп-контуре заканчивает строкой «по готовности: shipctl merge <ID>», а `merge`
там отказывает: слияние ведёт MR-флоу компании. Первый же шаг пользователя в
подключённом проекте зовёт команду, которая ему откажет.

Подсказка в корп-контуре должна называть настоящий следующий шаг: `trackctl
submit`, пуш ветки, MR. Текст этого шага уже есть в отказе `merge`
([shipctl/corp.go](../../../../shipctl/corp.go)), сочинять его заново не надо.
