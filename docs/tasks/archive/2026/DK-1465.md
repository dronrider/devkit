# DK-1465: Главная дашборда собирает межпроектный обзор с формой быстрой записи

Цель: [tasks/DK-1198.md](tasks/DK-1198.md)

## Что происходит

«Главная» дашборда это список проектов с карточкой квоты. Межпроектного обзора нет, просроченное и полка ожидания не собираются на одном экране, запись с телефона требует сначала выбрать проект в списке.

## Чего хотим

Главная становится обзором поверх досок. Виджеты держат сегодня и просроченное по сроку и верх по рангу. Полка ожидания показывает, от кого ждут. Ближайшие вехи идут лентой по датам, цели в работе несут прогресс состава. Новое без разбора и сделанное за неделю по дате закрытия закрывают список. Форма быстрой записи живёт на самой странице с выбором проекта, у формы две кнопки, записать в накопитель и записать с разбором сразу. Первый абзац записи становится заголовком без отказа.

## Развилки

- «заголовок-записи»: где живёт заголовок, чтобы запись одним абзацем проходила?
  - решает: исполнитель
  - рекомендация: первый абзац записи становится заголовком без отказа, порог первой строки не бьёт запись с телефона, находка DK-447
- «полка-срок»: срок у ожидания на полке, где граница с двадцатиминутным рубежом живости сессии?
  - решает: исполнитель
  - рекомендация: срок заводится только ожиданиям от человека и не смешивается с рубежом живости сессии, тот рубит по живости агента, просрочка ответа живёт своим сроком

## DoD

Smoke дашборда открывает главную с виджетами сегодня и просроченного, верха по рангу, полки ожидания, вех, целей с прогрессом, нового и сделанного за неделю; форма записи с выбором проекта кладёт черновик.
