# DK-187: Замена «ярус» на «уровень» в доке, выводе agentctl и промптах

Постановка: [lld/DK-173-agent-prose.md](../../../lld/DK-173-agent-prose.md)

## Что происходит

Слово «ярус» вшито в README agentctl, в русские строки вывода утилит и в
определения агентов kit/agents. Пользователь пометил слово неудачным при
разборе DK-173, вопрос 2 закрыт решением заменить слово на «уровень», ключи
профиля вроде spend_pro при этом не трогаются.

## Чего хотим

README agentctl, русские строки вывода agentctl и определения агентов
kit/agents говорят «уровень» там, где стоял «ярус». Замена механическая,
машинные поля не меняются: латинский ключ tier, ключи профиля и имена полей
остаются как есть. Вывод devkitctl и shipctl, правила и скиллы в правку не
входят, предмет назван заголовком.

## DoD

- В tools/agentctl/README.md и kit/agents/*.md слова «ярус» нет ни в одном
  падеже.
- Русские строки вывода agentctl печатают «уровень», латинский ключ tier и
  ключи профиля не изменились.
- Тесты, проверяющие строки вывода, правятся вместе с ним и зелёные, прогон
  идёт через devkitctl test.
- Слова «ярус» вне предмета задачи остаются на местах.

## Ранг

`0+2+0+0+0 = 2`, P2.

- Серьёзность 0: работа не ломается, слово лишь спотыкается при чтении.
- Ценность 2: вывод и дока читаются без запинки.
- Неопределённость 0: замена механическая по принятому решению DK-173.
- Поправка на баг 0: правка текста.
- Рычаг 0: других мест слово не касается.
