# DK-254: Чат с агентом: открытие хвостом, якорь при обновлении, markdown и ссылки, время клиента, честные имена

записана 2026-08-11, замечания 3, 4, 7, 8, 9, 10, 11 третьей пачки пользовательской проверки цели DK-112

## Чего хотим

Семь правок чата и транскрипта:

- кнопка называется «Чат с агентом», не «Переписка»;
- чат открывается хвостом (последние реплики и поле ввода сразу видны), а
  не началом с листанием вниз;
- обновление по событию не перебрасывает наверх: позиция держится якорем,
  новые реплики дописываются вниз, при взгляде в историю прокрутка не
  дёргается;
- markdown реплик рендерится (заголовки, списки, код, жирный), своим
  минимальным рендером без внешних зависимостей, с экранированием HTML;
- ссылки кликабельны;
- время реплик в часовом поясе клиента;
- плейсхолдер «Написать агенту...» (честность про виток остаётся подписью
  под полем), формулировка «хвост живой» заменяется человеческой.

исполняется), время через локаль клиента, переименования грепом. Взгляд
