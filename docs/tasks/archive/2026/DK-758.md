# DK-758: Замечания чужого ревью копятся файлом и публикуются в MR по ключу publish

Цель: [lld/DK-756-foreign-review.md](../../lld/DK-756-foreign-review.md)

## Что происходит

Замечания к чужому MR уходят в треды как сложится разговор, человек не видит их до публикации, а режима «сначала покажи» нет. Решения 2, 3 и 4 LLD DK-756.

## Чего хотим

Файл `docs/tasks/<ID>.review.md` с блоками замечаний и четырьмя состояниями. `taskctl review draft <ID>` добавляет блок, `taskctl review publish <ID>` гонит одобренные в MR по командам `threads.md` с паузами и вписывает id тредов. Ключ `publish = confirm | auto` в `review.conf`, умолчание `confirm`. Раздел скилла `review` «Ревью чужой задачи» с порядком шагов, вопросом человеку последней репликой хода и парковкой «ждёт подтверждения». Чужая ветка не правится.

## DoD

- `draft` кладёт блок с файлом, строкой, меткой, текстом и состоянием «черновик», ручная правка файла разбирается.
- `publish` на заглушке API публикует только одобренные блоки, вписывает id тредов, держит паузу, при `auto` одобряет всё сам, при `confirm` отказывает без одобренных.
- Нечитаемый файл даёт отказ с именем блока.
- Раздел скилла написан, сторож скиллов знает про новый раздел, прогон `prompt-test` на стенде с заглушкой показывает вопрос человеку последней репликой и парковку.
- README taskctl и раздел «Конфиг» скилла знают ключ `publish`.
