# DK-091: devkitctl doctor: находка «autonomous = true при пустом deploy=» ложно срабатывает в проекте, которому нечего катить (репозиторий доков, локальная библиотека). Автономия там осмысленна: агент сам сливает и пушит, а выката нет вовсе. Сейчас такой проект не может поднять флаг чисто, а с DK-079 это ещё и запрет на автономный цикл в нём. Разобрать, отличать ли «выката нет» от «выкат забыли вписать»: отдельным ключом (deploy = none), либо признанием пустого deploy законным при явной пометке.
