# DK-099: taskctl draft теряет текст черновика, когда флаг -C стоит после подкоманды: в case "draft" текст берётся только из args[1] и только если тот не начинается с дефиса, а оставшийся позиционный аргумент из fs.Args() не читается вовсе. Команда молча уходит за текстом в stdin: в интерактиве это зависание, на закрытом stdin ошибка «нет текста черновика». Директория при этом резолвится верно, у подкоманды свой флаг C. Найдено при обкатке DK-097. Починка: после fs.Parse брать текст из fs.Args(), если он не взят раньше; тест на обе формы вызова.
