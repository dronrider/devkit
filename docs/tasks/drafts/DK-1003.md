# DK-1003: Отбитый taskctl move пишет «снята» в реестр сессий

записан 2026-09-15
приоритет: высокий

## Черновик

### Ситуация

2026-09-15, сессия с заказом «Выполни DK-852» взяла по ходу DK-998. Перевод `taskctl move DK-998 check` был отбит трижды: в 03:05 дважды из основного чекаута, где ветки ещё не было, и в 03:37 внутри `shipctl merge` из-за протухшей отметки обкатки. Каждый отказ лёг в `~/.devkit/sessions.log` записью «снята DK-998»: `touchWork` в `tools/taskctl/main.go:448` зовётся до исполнения команды, а `touchDone` смотрит только на аргументы.

### Осложнение

Строка осталась в In progress, а по реестру сессия с ней закончила. Строка потеряла признак работы и «Стоп», кнопка чата у DK-998 завела новый разговор вместо живого, поиск чатов по «DK-998» ничего не нашёл. Человек искал разговор задачи руками.

### Вопрос

Пусто.

### Гипотеза

Отказанный перевод реестр не трогает: запись «снята» ложится только после удачного исхода команды. Тест: отбитый move в Check оставляет реестр как был, удачный пишет «снята».
