# DK-1010: Коммиты доски из сессий задач подписаны автором stand, а не человеком

записан 2026-09-15
приоритет: средний

## Черновик

### Ситуация

С 2026-09-13 18:27 коммиты доски, которые кладут сессии задач в tmux и тики сторожка, идут с автором `stand <stand@local>`. В истории devkit таких 273 из последних 400, а коммиты из окна редактора подписаны именем пользователя. Первый такой коммит это след сценария проверки DK-942: стенд заводил временный HOME и репозиторий с `git config user.name stand`. Глобальный gitconfig пользователя правильный, локального user у клона devkit нет, у демона дашборда HOME штатный, tmux-сервера в момент проверки не было. Зацепка: окружение, в котором taskctl run и тик поднимают голову задачи (task-run.py, обвязка tmux), либо конфиг из чужого HOME. В истории и на гитхабе это выглядит так, будто отвечал и решал стенд, а не человек; строки «решено человеком» в файлах задач писал тот же автор. Проверить: `git -C ~/projects/devkit log --format='%an|%ae' -n 400 | sort | uniq -c`, поднять голову любой задачи через taskctl run и посмотреть `git var GIT_AUTHOR_IDENT` из её окна.
