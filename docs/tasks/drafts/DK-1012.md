# DK-1012: Субагент вычитки с меткой задачи перезаписал план исполнителя

записан 2026-09-15
приоритет: средний

## Черновик

### Ситуация

Исполнитель DK-974 вёл план с меткой DK-974. Субагент вычитки по скиллу proofread поднялся из его хода с той же меткой и положил свой план поверх. План исполнителя пропал, и он восстановил его повторным plan set после возврата вычитки. Метка одна на пачку субагентов, а вложенный субагент внутри исполнителя ей не отличим. Нужен свой хвост метки у вложенного захода либо отказ plan set, когда файл с меткой уже ведёт другой заход.
