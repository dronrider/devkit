# DK-1013: Скилл proofread велит звать agentctl pick без ID, а команда его требует

записан 2026-09-15
приоритет: низкий

## Черновик

### Ситуация

Скилл proofread просит выбрать модель вычитки вызовом agentctl pick «без привязки к задаче». Команда без ID не работает. Исполнитель DK-974 взял модель sonnet и определение exec-medium из текста скилла руками. Скиллу нужна рабочая форма вызова либо готовый вердикт для вычитки в самом тексте.
