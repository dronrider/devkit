# DK-1014: Стенд obeycheck не находит claude в оболочке Bash субагента

записан 2026-09-15
приоритет: средний

## Черновик

### Ситуация

Исполнитель DK-974 гонял стенд из оболочки Bash субагента. Пробная сессия упала с «claude: executable file not found in $PATH». В той оболочке нет ~/.local/bin. Исполнитель обошёл экспортом PATH перед прогоном. Обход ручной, и у следующего исполнителя он повторится. Вход в стенд может сам подставлять каталог с бинарём харнеса либо честно называть, какой каталог добавить в PATH.
