# DK-1015: Две сессии получили один ID: черновик и задача разошлись на DK-1011

записан 2026-09-15
приоритет: средний

## Черновик

### Ситуация

Сессия доски завела черновик DK-1011 командой taskctl draft. В те же минуты другая сессия оформила задачу DK-1011 командой taskctl add и запушила её в origin. Счётчик taskctl id считает по локальному чекауту и в origin не смотрит. Rebase прошёл без конфликта, файлы лежали в разных каталогах, и на доске оказались задача и черновик с одним номером. Черновик перенумерован руками в DK-1014. Выдача ID перед коммитом может сверяться с origin/main либо брать номер после подтягивания ветки.
