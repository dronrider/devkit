# DK-1016: Тесты devkitctl падают на гонке fingerprint песочницы с git maintenance

записан 2026-09-16
приоритет: высокий

## Черновик

### Ситуация

С git 2.54 команда git commit в Sandbox.__init__ (testenv.py:471) поднимает отсоединённый git maintenance run --auto. Он пакует свежие объекты и снимает опустевшие каталоги .git/objects/XX. В это время Sandbox.fingerprint() (testenv.py:659) обходит rglob по всему дереву вместе с .git и падает FileNotFoundError. На main describe_test.DoctorTest красный три раза из четырёх. С GIT_CONFIG_KEY_0=maintenance.auto GIT_CONFIG_VALUE_0=false зелёный пять из пяти, gc.auto=0 не помогает. Слияние DK-974 прошло только с этим обходом в --test. Лечить в песочнице: maintenance.auto=false в git_init либо обход fingerprint без захода в .git.
