# DK-1019: Стенд poc_panel.mjs красен на main, гоняет его никто

записан 2026-09-16
приоритет: средний

## Черновик

### Ситуация

Исполнитель DK-1011 нашёл в tools/dashboard/testdata/poc_panel.mjs падение, не связанное с задачей: блок про смешанную ленту субагента говорит «помечено чужих записей 9, ожидал семь». Go-раннера у стенда нет, поэтому краснота на main никем не видна. Куски про кнопки пузыря DK-1011 переписала, само расхождение по ленте не чинила. Разобрать, откуда девять записей вместо семи, и завести стенду раннер, как у poc_chatgone и poc_chatnobtn.
