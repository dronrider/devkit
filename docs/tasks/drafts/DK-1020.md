# DK-1020: agentctl plan на неверный флаг печатает go-usage без формы команды

записан 2026-09-16
приоритет: средний

## Черновик

### Ситуация

Прогон obeycheck по сценарию 41 на ярусе mini, 2026-09-16. Сессия зовёт `agentctl plan set --title "..." --step "..."` и `agentctl plan set --step "..."`. Утилита отвечает `flag provided but not defined: -title`, дальше идёт сырой usage пакета flag с `-label` и `-sid`, код выхода 2. Форму команды (пункты строками через пробел) утилита не показывает.

### Осложнение

Модель после отказа не пробует верную форму и бросает план. Две клетки из трёх красные по «плана работ сессия не положила», хотя намерение положить план было. Дашборд при этом рисует пустое кольцо. Форма команды лежит в скилле work-plan, который модель яруса mini не открывает, и отказ утилиты остаётся единственным местом, где её можно подсказать.

### Вопрос

Подсказка в отказе только у plan или у всех подкоманд agentctl с позиционными аргументами?

### Гипотеза

На неизвестный флаг `agentctl plan` отвечает словами, формой команды с примером `agentctl plan set "первый пункт" "второй пункт"`. Модель со второй попытки кладёт план.
