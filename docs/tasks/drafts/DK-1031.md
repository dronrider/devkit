# DK-1031: Ошибки review level и пуша при коде у черновика называют taskctl add

записан 2026-09-17
приоритет: низкий

## Черновик

### Ситуация

Соседняя сессия 16 сентября 2026 года правила код по черновику. `taskctl
review level <ID>` завершился ошибкой, файл задачи ищется в
`docs/tasks/<ID>.md` (`tools/taskctl/review.go:183`), а черновик лежит в
`docs/tasks/drafts/`. Пуш отбит: pre-push через `shipctl push --check-only`
требует у код-коммита ID задачи не из Backlog (DK-602). Оба поведения
штатные, код при черновике по правилам доски не пишется, сначала
`taskctl add --id`.

### Осложнение

Ни одна из двух ошибок не говорит, что делать. Агент ищет обход вроде
DEVKIT_PUSH_OK или бросает след ревью, а правка уезжает без него.

### Гипотеза

Обе ошибки по ID, у которого есть файл в drafts, печатают «это черновик,
оформи задачу: taskctl add --id <ID>». Та же подсказка у `taskctl status`.
