# DK-1033: Рубежи коммита путают двоеточие в пути с разделителем строки диффа

записан 2026-09-17
приоритет: низкий

## Черновик

### Ситуация

Находка ревью DK-509. Режим --diff у check-symbols.py, check-sensitive.py и check-prose.py разбирает строку диффа через split(":", 2) и решает пропуск testdata по первому куску. Путь с двоеточием сразу после сегмента testdata (hooks/testdata:x/foo.py) обманывает разбор, и обычный файл уходит без проверки символов. Риск теоретический, но разбор у трёх сторожей один и тот же, и чинить его стоит одним общим куском, а не по одному в каждом.
