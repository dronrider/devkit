# DK-1034: Тест worktree shipctl красен при .devkit в глобальном gitignore

записан 2026-09-17
приоритет: низкий

## Черновик

### Ситуация

Находка исполнителей DK-123 и DK-122. Тест TestStartWorktreeCarriesCommittedLink в tools/shipctl/worktree_test.go зовёт git add .devkit/devkit без -f, а глобальный ~/.gitignore_global этой машины содержит .devkit, и git отвечает «ignored by one of your .gitignore files». Падает и на чистом main, к правкам задач отношения не имеет. В стенде слияния с временным HOME проходит. Стоит либо подставлять тесту пустой глобальный gitignore, либо звать add с -f.
