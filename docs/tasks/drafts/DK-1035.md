# DK-1035: Стенды дашборда молча пропускаются без node, и merge их не проверяет

записан 2026-09-17
приоритет: средний

## Черновик

### Ситуация

Находка исполнителя DK-970. Обёртки клиентских стендов poc_*.mjs в go test дашборда уходят в t.Skip, когда node не найден в PATH. На этой машине node не установлен ни в PATH, ни через homebrew, поэтому go test ./... зеленеет, не прогнав ни одного стенда, и стенд слияния shipctl merge с временным HOME тоже их не видит. Исполнитель обошёл это, распаковав node 22 в каталог сессии и добавив его в PATH на прогонах. Стоит решить, чем видно пропуск: доктор ловит отсутствие node, а regcheck и merge падают на пропуске стенда вместо тихого скипа.
