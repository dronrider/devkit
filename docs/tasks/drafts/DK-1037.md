# DK-1037: Ворот тестов у merge не считает стенды poc_*.mjs тестовыми файлами

записан 2026-09-17
приоритет: средний

## Черновик

### Ситуация

Находка на слиянии DK-970. Правка панели чата шла с тестом в виде стенда tools/dashboard/testdata/poc_chatnext.mjs, обёртка которого в chat_test.go стояла и раньше. Ворот «в диффе ветки против main нет тестовых файлов» стенд тестом не признал и отбил слияние, хотя regcheck по тому же стенду краснел на main. Пришлось гасить ворот пометкой исключения. Стоит научить ворот считать тестами файлы testdata/poc_*.mjs и сценарии стендов, которые зовёт какой-то *_test.go.
