# DK-1039: Ворота обкатки гасят отметку поезда чужими файлами задач

записан 2026-09-17
приоритет: высокий

## Черновик

### Ситуация

На пачке из двенадцати задач 2026-09-17 ворота перевода в Check у shipctl ship отбили состав целиком. Сверка в tools/taskctl/gate.go принимает отметку обкатки, только если HEAD равен её коммиту или все коммиты после него трогают один файл этой задачи (onlyTaskDocSince). В поезде отметки других задач ложатся коммитами в соседние файлы docs/tasks/, и любая из них гасит отметку всех остальных. Незакоммиченными их оставить тоже нельзя, ship требует чистых файлов задач. Выход был один, пометка «Исключение: обкатка» на каждой задаче со ссылкой на зелёную отметку. Стоит либо считать докой все docs/tasks/*.md и docs/TASKS.md, либо сверять отметку с последним кодовым коммитом, а не с HEAD.
