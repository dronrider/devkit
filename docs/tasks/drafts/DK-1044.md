# DK-1044: Подготовка сценария стенда пишет синтетику в чекаут devkit по cwd

записан 2026-09-18
приоритет: средний

## Черновик

### Ситуация

Находка на прогоне стенда по DK-1025, 2026-09-17. Подготовка сценария 25-stand-trace (mkdir kit/skills/demo, файл OB-024-demo-skill.md, demo-skill-wait.md) и запись следа obeycheck --task идут по каталогу, найденному от cwd, а не по --devkit и не по временному проекту стенда. При cwd в основном чекауте синтетика легла в /Users/elenavnukova/projects/devkit неотслеживаемыми файлами, а след стенда попал в файл задачи чужого чекаута. Обход: запуск из дерева задачи обёрткой sh со своим cd. Стоит привязать и подготовку, и след к --devkit либо к временному проекту.
