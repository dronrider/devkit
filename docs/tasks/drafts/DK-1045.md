записан 2026-09-18
приоритет: средний

## Черновик

### Ситуация

На слиянии DK-620 2026-09-18 пятый ворот shipctl merge отказал: «на kit/skills/check-skills.py (шапка файла) нет сценария стенда: правка текста для агентов меряется прогоном». Файл это сторож скиллов на python с тестами в check_skills_test.py, агенты его не читают. Ворота берут предмет по каталогу kit/skills, а не по типу файла. Пришлось гасить пометкой исключения в DK-620 и DK-618. Стоит исключить из предмета ворот файлы *.py и *_test.py под kit/skills либо смотреть на расширение.
