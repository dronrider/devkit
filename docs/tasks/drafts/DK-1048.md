# DK-1048: файл задачи DK-796 несёт разделы постановки дважды, lint красен

записан 2026-09-18
приоритет: средний

## Черновик

### Ситуация

2026-09-18, `taskctl lint` на main печатает одну находку: docs/tasks/DK-796.md:91, раздел «Границы» стоит после «Ранг». В файле разделы «Границы», «Развилки», «DoD» и «Ранг» записаны дважды (строки 27-73 и 91-137), файл заведён грумингом 2026-09-09, коммит 1cdfc237.

### Осложнение

Процедура пачки просит зелёный lint до старта, и каждая пачка теперь начинает с разбора чужой находки. DK-796 это P1 в Backlog, исполнитель получит постановку в двух версиях и не узнает, какая действует.

### Вопрос

Которая из двух версий разделов действующая, решает автор груминга: перестановкой находка не лечится, версии надо свести.

### Гипотеза

В файле DK-796 каждый раздел один, lint доски зелёный.
