# DK-1051: rehearse гоняет блок sh построчно, а TASKFORM об этом молчит

записан 2026-09-18
приоритет: низкий

## Черновик

### Ситуация

2026-09-18, DK-986 и DK-631. `taskctl rehearse` исполняет каждую строку блока `sh` раздела «Сценарий проверки» отдельным `sh -c`. Продолжение строки обратным слешем и переменная, заведённая строкой выше, ломают шаг. Оба исполнителя написали многострочные шаги, получили красную обкатку и переписали шаги в одну строку через `&&`.

### Осложнение

Каждый новый исполнитель тратит на это лишний заход обкатки. В TASKFORM.md про одну команду на строку не сказано, отказ обкатки причину тоже не называет.

### Вопрос

### Гипотеза

TASKFORM.md называет правило одной команды на строку, а красная обкатка на строке с обратным слешем подсказывает причину.
