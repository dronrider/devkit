# DK-1053: признак агентской сессии зашит переменной одного харнеса

записан 2026-09-18
приоритет: низкий

## Черновик

### Ситуация

2026-09-18, ревью DK-822. `agentic_session` в tools/devkitctl/dashboard.py узнаёт агентскую сессию константой `CLAUDECODE=1`. Харнесы описаны профилями kit/harness/*.toml с секцией detect, готового разбора «какой харнес активен сейчас» в python-части нет: harness.py проверяет только форму профиля. Сегодня константа накрывает оба профиля, у второго detect пуст нарочно.

### Осложнение

Сессия харнеса с другим признаком увидит значение токена в выводе доктора. Пока такого харнеса нет, поломка спит.

### Вопрос

### Гипотеза

Признак агентской сессии берётся из профилей харнесов одним общим разбором, новый профиль накрывается без правки кода.
