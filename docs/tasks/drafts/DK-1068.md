# DK-1068: Ход чужой задачи виден с другой машины до смены статуса

записан 2026-09-19
приоритет: высокий

## Черновик

### Ситуация

Этапы работы пишет `agentctl pick --record` в `~/.devkit/runs`, реестр сессий лежит в `~/.devkit/sessions.log`, дашборд читает оба локально. В файл задачи пакет этапов уезжает только при смене статуса. Пока чужая машина держит строку, здесь виден лишь коммит «в работу» и подпись «строка не двигалась 0 дней», та же, что у брошенной задачи.

### Осложнение

Пользователь второй машины не видит, идёт ли по задаче работа, на каком она этапе и не встала ли на вопросе. Живая чужая работа неотличима от заброшенной.

### Вопрос

Каналов доставки видно три. Пакет этапов уезжает в файл задачи на каждом этапе коммитом доски, реестр записей отдаётся по relay между дашбордами, либо сводка кладётся в origin отдельной веткой без истории. Цена лишних коммитов доски против цены сетевого канала.

### Гипотеза

На экране задачи с любой машины видны этапы, время последнего движения и признак ожидания человека у чужой работы.
