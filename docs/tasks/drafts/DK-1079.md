# DK-1079: taskctl run берёт прочерк из вердикта pick за имя модели

записан 2026-09-20
приоритет: низкий

## Черновик

### Ситуация

На пустом стенде без профилей харнеса agentctl pick печатает model: -, а askPick в tools/taskctl/run.go берёт этот прочерк за модель и taskctl run передал бы клиенту --model -. Нашлось 2026-09-20 на доработке DK-911 при тесте pickargs_test.go с живым agentctl. Хочется, чтобы прочерк читался как «модели нет» и run поднимал голову без --model либо отказывал с причиной.
