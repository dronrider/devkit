записан 2026-09-20
приоритет: низкий

## Черновик

### Ситуация

Сценарий проверки DK-911 разворачивает стенд в /tmp/dk911-rehearse, и два прогона рядом (обкатка и проверяющий) топчут друг друга: первая попытка проверяющего 2026-09-20 упала на шаге 16 «a branch named xr-001-fix already exists», повтор через минуту прошёл. Хочется, чтобы путь стенда был уникальным на заход (mktemp -d), и то же правило для сценариев соседних задач.
