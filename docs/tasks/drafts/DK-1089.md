# DK-1089: board-ship ждёт слияние пустым ходом, а agentctl wait в нём не назван

записан 2026-09-21
приоритет: высокий

## Черновик

### Ситуация

Разбор транскрипта диспетчера DK-881 (сессия e45bfe00, 17-20 сентября 2026). Из 954 ходов 115 это Bash `true` с описанием «ожидание уведомления монитора» и ещё 90 ходов голого текста «Жду». Вместе 228 ходов, 24% сессии, каждый с перечитыванием окна около полумиллиона токенов. Команда `agentctl wait <ID> слита <ID>` лежит в репозитории с 11 сентября (DK-930). Сессия DK-1032 звала её 13 раз и пустых ходов не имеет. Раздел «Как ждать долгий шаг» скилла board-ship велит ждать через Monitor, про wait говорит только board-task.

### Осложнение

74% вывода DK-881 (281k токенов) ушло после чистого вердикта ревью на доставку правки в четыре строки до main. По сводке `taskctl spend` за неделю статья «оркестрация» съела 62% вывода, этапы субагентов 3%.

### Гипотеза

Скилл board-ship велит ждать слияние командой `agentctl wait` с условием и сроком, ход после этого кончается. Рубеж хука отбивает Bash `true` и ход без инструмента с текстом «Жду» подсказкой про wait.
