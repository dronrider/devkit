# DK-1091: Чужую красноту ворот merge диспетчер чинит задачами с полной церемонией

записан 2026-09-21
приоритет: средний

## Черновик

### Ситуация

Внутри сессии DK-881 родились DK-1059, DK-1062, DK-1063, DK-1064 и DK-1069, около 176 ходов. Каждая прошла `taskctl add`, выборку прозы, файл задачи, ревью субагентом, обкатку, заметку ревью, пуш и закрытие. Ни одна не была предметом DK-881, все всплыли препятствием воротам. Разбор группы закрытых задач: те же строки найдены реактивно после многочасовых провалов конвейера.

### Осложнение

Побочные строки стоят дороже самой правки. Исполнитель отвлечён от предмета, а виновник красноты, чужой пакет, чинится с полным циклом ревью посреди чужого захода.

### Гипотеза

Ворота merge различают красноту вне диффа ветки, печатают «чужая краснота: пакет X, тест Y» и кладут черновик сами, а ветку пропускают по тронутым компонентам. Чужая краснота едет в очередь отдельной строкой, не внутри чужой сессии.
