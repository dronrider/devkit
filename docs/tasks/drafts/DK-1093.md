# DK-1093: Заметка уровня ревью ставится руками и протухает после каждого коммита

записан 2026-09-21
приоритет: средний

## Черновик

### Ситуация

DK-881: 18 связок `head=$(git rev-parse --short=12 HEAD); git notes --ref=review add -f -m "Уровень 2 до $head: ..."`. Сессия звала `taskctl review level` и `review clean`, заметку на свежий sha они не ставят, а после любого коммита (вычитка, след обкатки) ворота merge просят её заново.

### Осложнение

По ходу на каждый коммит плюс риск расхождения sha в заметке и в файле задачи; ворота merge отказывают на верном по сути ревью.

### Гипотеза

`taskctl review level` ставит заметку на HEAD сама. Ворота merge принимают заметку на предке, если дифф после неё пуст или лежит в файле самой задачи.
