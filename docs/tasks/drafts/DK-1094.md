# DK-1094: Фоновый цикл повторов merge живёт часами без потолка

записан 2026-09-21
приоритет: средний

## Черновик

### Ситуация

agents.log за 19 сентября: работы bx68ctzz9 (8ч55м) и bls5e4gpl (10ч19м) по DK-881, обе `for i in $(seq 1 3); do out=$(shipctl merge DK-881 --train 2>&1) ...`. Сессия закрылась с окном 863580 при потолке 200000. Сторож фоновых работ считал работу идущей все девятнадцать часов.

### Осложнение

Задача ценой S висит сутки, квота горит на перечитывании окна при каждом пробуждении, человек видит «идёт».

### Гипотеза

Повтор слияния это ключ команды с потолком попыток и времени (`shipctl merge --retry N --for 30m`), а не for-цикл в Bash. Сторож фоновых работ помечает работу старше потолка и будит сессию.
