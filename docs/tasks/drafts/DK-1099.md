# DK-1099: Этап разработки в «Ход работы» пишется нулевой длительностью

записан 2026-09-21
приоритет: средний

## Черновик

### Ситуация

Файлы закрытых за неделю задач: DK-631, DK-650, DK-822, DK-894, DK-986, DK-1054, DK-1055, DK-1060, DK-449, DK-464, DK-1024, DK-467, DK-630 несут «Разработка: ... 00:27-00:27» при правке 5-12 файлов. Свод `taskctl spend` за неделю: этапов 359, без данных 231, работ без этапа 137.

### Осложнение

`taskctl spend` и `elapsed` считают мимо, разбор недели по этапам слеп на две трети, а метку времени приходится сверять с коммитами.

### Гипотеза

Этап закрывается фактом сдачи субагента (хук SubagentStop), а не записью диспетчера, и несёт номер работы. Строка «Ход работы» пишется из записи этапа.
