# DK-1100: Раздел «Выкат» ссылается на sha, которых нет в истории main

записан 2026-09-21
приоритет: низкий

## Черновик

### Ситуация

DK-449: 11 sha в «Выкат» недостижимы из main, DK-464: 28 sha. Похоже на squash или переписывание истории после слияния.

### Осложнение

Раздел «Выкат» и ссылки строки архива не годятся для git-археологии, `taskctl spend` и regcheck по ним ничего не найдут.

### Гипотеза

Слияние пишет в «Выкат» sha, которые лежат в main после него, и ворота close сверяют их достижимость.
