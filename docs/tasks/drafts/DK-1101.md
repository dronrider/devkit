# DK-1101: Сторожевые журналы не держат неделю

записан 2026-09-21
приоритет: средний

## Черновик

### Ситуация

Разбор недели 14-21 сентября: goal-watch.log хранит последние три часа, notify.log и chat-in.log по 12-17 часов, agents.log и quota-refresh.log только с 18 сентября. Неделю целиком удалось свести лишь по dashboard.log грепом.

### Осложнение

Анализ процесса за окно длиннее суток невозможен, а сторож и цикл цели теряют собственную историю при каждой ротации.

### Гипотеза

Журналы ротируются по дням и хранятся 14 суток, единой командой свода читаются за окно дат.
