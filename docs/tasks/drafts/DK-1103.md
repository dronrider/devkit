# DK-1103: chat-in опрашивает безадресные разговоры DK-706 и DK-808 впустую

записан 2026-09-21
приоритет: средний

## Черновик

### Ситуация

chat-in.log за 12,6 часа: 500 из 501 строк это тождественный отказ «адрес task-DK-706 отказ: разговор принадлежит не этой сессии, безадресная строка ждёт хозяина», то же по DK-808, подряд от шести разных сессий.

### Осложнение

Сотни бесполезных обращений в сутки, журнал забит одной строкой, живая реплика в нём не видна.

### Гипотеза

Безадресный разговор опрашивается один раз и помечается, повторный отказ по тому же адресу не пишется, а разговор без хозяина старше суток архивируется с уведомлением.
