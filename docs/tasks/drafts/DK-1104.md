# DK-1104: Съёмщик квоты glm-code отказывает всю неделю, а сторож снимает дальше

записан 2026-09-21
приоритет: средний

## Черновик

### Ситуация

quota-refresh.log 14-21 сентября: 37 отказов «харнес glm-code: съёмщик отказал: ответ не похож на квоту z.ai: code 500», снимок харнеса датирован 9 сентября, 12 суток без рабочей квоты. Подписка GLM закончилась в сентябре.

### Осложнение

Каждый тик сторожа платит за мёртвый харнес, а гейт квоты цели читает протухший снимок.

### Гипотеза

Харнес без живой квоты выключается в конфиге одной командой, сторож после трёх одинаковых отказов уведомляет человека и снимать перестаёт.
