# DK-1106: Субагент поднимает вложенных субагентов и сдаёт ход, не дождавшись их

записан 2026-09-21
приоритет: высокий

## Черновик

### Ситуация

21 сентября сессия разбора недели подняла четырёх исполнителей general-purpose на чтение файлов задач, каждый поднял по четыре форка и сдал ход текстом «жду уведомлений», результат пришёл только после того, как сторож фоновых работ разбудил родителей. DK-909: вычитчик поднял второго вычитчика. Память сессий держит ловушку «фоновая работа в субагенте».

### Осложнение

Шестнадцать форков вместо четырёх, пустая сдача, диспетчер собирает итог из транскриптов руками, сторож кричит на разобранную работу.

### Гипотеза

Определения субагентов devkit и промпты диспетчера запрещают вложенный спавн исполнителю, хук спавна отбивает Agent из субагента с подсказкой сделать работу самому или вернуть её диспетчеру.
