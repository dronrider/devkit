# DK-1107: Вычитка идёт по кругу на каждом круге ревью

записан 2026-09-21
приоритет: средний

## Черновик

### Ситуация

DK-911 вычитана трижды (строки 5.1, 6.1 и 6.2 разбора транскрипта DK-909), раздел README про `taskctl spend` дважды, второго вычитчика поднял первый. За два дня по цели DK-909 вычитка ходила 21 раз с медианой четыре минуты.

### Осложнение

Каждый круг ревью переписывает те же абзацы и зовёт вычитку заново, а сама вычитка стирает лексику devkit («ворота», «зовёт») и рвёт причинность в примерах.

### Гипотеза

Вычитка встаёт один раз перед слиянием по диффу задачи, и вложенный спавн ей запрещён.
