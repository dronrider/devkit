# DK-1109: Утилиты доски отбивают форму по одной претензии за ход

записан 2026-09-21
приоритет: низкий

## Черновик

### Ситуация

DK-881: `taskctl add` отказал пять раз подряд, по одной претензии за ход («нужен --accept», «в разбивке ранга 5 слагаемых», «серьёзность из {0, 25, 50, 75}»). DK-909: ранг из шести слагаемых, ёлочки в имени развилки, первая строка черновика длиннее 72 символов, ручной `agentctl stage ревью`. DK-881 гоняла `check-symbols.py` руками 45 раз, потому что хук на Write и Edit не видит sed и heredoc.

### Осложнение

Шесть-семь холостых ходов на задачу с полумиллионным окном каждый.

### Гипотеза

Отказ утилиты печатает все претензии к форме разом с примером верного вызова, сторож символов и прозы висит pre-commit хуком, а не только на Write и Edit.
