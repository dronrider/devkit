# DK-1111: Зелёная отметка проверки стоит без настоящего прогона

записан 2026-09-21
приоритет: высокий

## Черновик

### Ситуация

DK-996: команда стенда в файле задачи не передавала `--end субагент`, сценарии 27, 30 и 39 объявляют «конец: субагент», при умолчании все три молча пропущены, итог «сценариев 3, все зачтены» получен без единого прогона, поймало только ревью. DK-971: шаг обкатки помечен «зелёный» при дословном `FAILED (errors=1)` в том же блоке вывода. DK-900: параллельная сессия закрыла строку до конца прогона проверки, вывод дописан задним числом.

### Осложнение

Ворота обкатки и стенда пропускают то, что не проверялось, и вся тяжесть повторных прогонов не даёт даже гарантии.

### Гипотеза

Стенд печатает «пропущено N сценариев по условию конца» и отказывает в «зачтён» при нуле прогонов, обкатка ищет маркеры провала тестового фреймворка в выводе шага, закрытие ждёт конца собственного прогона проверки.
