# DK-1112: Цель: доставка правки до main дешевле самой правки

записан 2026-09-21
приоритет: высокий

## Черновик

### Ситуация

Разбор недели 14-21 сентября 2026: 1368 коммитов, из них 1027 коммиты доски. Свод `taskctl spend`: статья «оркестрация» 62% вывода, этапы субагентов 3%. У DK-881 правка в четыре строки заняла три минуты, а 80% ходов диспетчера (770 из 954) и 281k токенов вывода ушли после ревью на слияние: пустые ходы ожидания, ворота merge на чужих тестах, ручные обходы стэшем, конфликты доски, заметки ревью руками, побочные задачи из чужой красноты.

### Осложнение

Квота недели горит на доставке, а не на работе; правка ценой S живёт двое суток; задачи с готовым вердиктом ревью ждут слияния 2-9 часов.

### Вопрос

Ждать ли слияние командой в той же сессии или отдавать поезду целиком, а сессию отпускать после вердикта ревью?

### Гипотеза

Доля вывода диспетчера после чистого вердикта ревью ниже 30% по `taskctl spend`, пустых ходов ожидания ноль, merge гоняет только тронутые компоненты, конфликт доски и чужие файлы разбирает утилита. Задачи цели: DK-1089 ожидание командой wait, DK-1090 тесты по тронутым компонентам, DK-1091 чужая краснота черновиком, DK-1092 слияние доски утилитой, DK-1093 заметка ревью утилитой, DK-1094 потолок фоновых повторов, DK-1109 холостые отказы формы. Из накопителя сюда же: DK-985, DK-980, DK-1070, DK-1035, DK-1037, DK-821, DK-332, DK-981, DK-987, DK-831, DK-788, тесты под нагрузкой DK-764, DK-746, DK-944, DK-983, DK-1000, DK-1038.
