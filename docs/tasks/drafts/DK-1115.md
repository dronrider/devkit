# DK-1115: Цель: сторожа и субагенты без холостых кругов

записан 2026-09-21
приоритет: высокий

## Черновик

### Ситуация

Разбор недели 14-21 сентября: разлив 33 раза подряд упал об одну чужую незакоммиченную правку; plan-watch дал 36 сигналов «сдача» из 314 тиков, пункт «слияние с выкатом» висел 33 часа; DK-1032 перезапускалась пять раз за час; цель DK-909 простояла ночь в blocked ради развилки с одним живым вариантом, из 33 её субагентов 17 ушли в обвязку (повторные прогоны, вычитка трижды, вычитчик поднял вычитчика); в сессии разбора четыре исполнителя подняли шестнадцать форков и сдали пустые ходы.

### Осложнение

Сторожа шумят и не эскалируют, субагенты множатся и дублируют работу, ночные вопросы останавливают автономный цикл.

### Гипотеза

Одинаковый отказ сторожа не повторяется больше двух раз без уведомления, вложенный спавн исполнителю отбит, вычитка одна на задачу, развилка без альтернатив не ждёт человека. Задачи цели: DK-1105 эскалация разлива, DK-1106 запрет вложенного спавна, DK-1107 одна вычитка перед слиянием, DK-1108 развилка с одним вариантом. Из накопителя: DK-775, DK-1067, DK-955, DK-1077, DK-898, DK-1042.
