# DK-113: Автономный цикл цели не работает headless: витки, которые поднимает goal-run.sh и сама сессия-диспетчер, зовутся голым claude -p, и на машине пользователя такая сессия упирается в разрешения харнеса. Не отрабатывает ничего: ни taskctl, ни shipctl, ни agentctl (включая гейт бюджета agentctl spend), ни правка файлов, ни notify.py. Виток не может даже записать строку в Журнал цели, поэтому со стороны стоп неотличим от молчания. Поймано на цели DK-109 2026-08-04. Развилки: класть в оболочку флаги разрешений при вызове claude -p; либо devkitctl doctor кладёт в settings.json пользователя allowlist на утилиты devkit и правку docs (машинный контур, как определения agents/ и скиллы); либо оболочка проверяет права первым же прогоном и отказывается стартовать с внятной находкой, а не после первого пустого витка. Заодно у goal-run.sh нет проверки, что поднятый виток вообще способен работать: пустой виток без записи в Журнал он считает продвижением до третьего подряд.
