# DK-1134: Ворота готовности shipctl ready решением есть, командой нет

записан 2026-09-23
приоритет: средний

## Черновик

### Ситуация

Решение DK-460.1 ставит ворота готовности командой `shipctl ready`, и её же
называют ворота слияния и пуша. Команды в утилите нет. `shipctl ready DK-764`
отвечает «неизвестная команда "ready"», а `shipctl ready DK-908` вместо ворот
печатает справку по флагам. Ловилось дважды за одну сессию цикла цели DK-1084,
2026-09-23.

Пока команды нет, готовность сверяется глазом по форме пометки из
`tools/shipctl/advice.go:229`, а решение LLD висит неисполненным. Снаружи ворот
виден только отказом merge, и третьего канала из DK-460.4, находки при пуше,
этим способом не проверить.

Разобрать надо, что из решения DK-460 доехало до кода, и дальше либо дописать
команду, либо переписать решение под то, чем ворота держатся сейчас.
