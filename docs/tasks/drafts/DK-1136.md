# DK-1136: go:dashboard: TempDir cleanup гонка валит прогон под GOMAXPROCS=1

записан 2026-09-23
приоритет: средний

## Черновик

### Ситуация

Три подряд живых прогона `python3 tools/devkitctl/parallel.py` упали на
`go:dashboard`. Код новый, из DK-1123 (доля по числу живых воркеров). Оба раза
тесты одни и те же: TestChatListGluesWindowPasses и
TestChatListShowsQuotaWait, testing.go:1464, TempDir RemoveAll cleanup:
unlinkat ...: directory not empty. Стена до провала 508-514 с. Потолок из
DK-1122 - 1560 с, раздутия стены нет. Провал при этом повторился 3 из 3 раз.

Замеры 2026-09-23, круг 3 ревью DK-1123, ответили на причинность числами.
Пакет dashboard в одиночку под GOMAXPROCS=1 зелёный и на свободной машине
(494 с), и под двенадцатью счётчиками нагрузки (658 с при load average 32).
Без переменной под той же нагрузкой он берёт 653 с.

Под полным прогоном картина обратная. С GOMAXPROCS=1 провалились пять
прогонов из пяти, с GOMAXPROCS=2 шестой, а без переменной прошли зелёными и
старый код (1178 с), и новая раздача долей DK-1123 (1320 с). Тесты в провалах
разные (TestChatListGluesWindowPasses, TestChatListShowsQuotaWait,
TestChatKeepOpensHiddenGoalTurn), путь один: `.../<имя теста>/001/.devkit:
directory not empty`. Историческая база без переменной это один красный
прогон из шести (DK-1122, раунд 2, -j5).

Механика видна в коде. Список чатов заказывает заголовок фоном
(`titleOrder`, `tools/dashboard/chats.go`), горутина ждёт подпроцесса клиента
и уже после конца тела теста пишет файл в дом стенда
(`chatStoreWrite` -> `<home>/.devkit/...`). Уборка `t.TempDir` идёт в ту же
секунду, и запись попадает в её окно. GOMAXPROCS с одним-двумя полюсами
задерживает горутину до ближайшей точки планировщика, и под нагрузкой полного
прогона этой точкой оказывается сама уборка.

DK-1123 переменную с раздачи сняла (доля едет только флагом `-p`), и её
прогон зелёный. Гонка от этого не исчезла, а вернулась к прежней редкости.
Чинить её тесту: дождаться заказанного заголовка перед уборкой (взять и
отдать слот `titleJobs` в `t.Cleanup` стенда `newTestEnv`) либо не пускать
стенд к настоящему клиенту вовсе. Вторым выходом чинится и другое: стенд
сейчас зовёт живой `claude` и жжёт квоту на заголовки фикстур. С починкой
DK-1123 сможет вернуть GOMAXPROCS в раздачу. Годится строкой под цель
DK-1084, в семейство тестов, которые красят чужие слияния.
