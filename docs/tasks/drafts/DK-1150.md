# DK-1150: Резолв github.com сломан в кэше системы, пуш идёт обходом

записан 2026-09-23
приоритет: средний

## Черновик

### Ситуация

2026-09-23 виток 10 цели DK-1084 упёрся в пуш. Git говорит «Could not
resolve host: github.com», тогда как dig это же имя резолвит без запинки, а
соседние имена того же хостинга getaddrinfo отдаёт исправно. Сломан кэш
системного резолвера на одном имени, /etc/hosts чист.

Починка это sudo dscacheutil -flushcache и sudo killall -HUP mDNSResponder,
пароль у человека. Обход без прав нашёлся: в конфиг репозитория прописан
ключ http.curloptResolve с адресом из dig, пуш с ним проходит, и наследуют
его все worktree.

Обход снять после починки резолва. Адрес хостинга не вечный, и когда он
сменится, пуш встанет уже по вине обхода. Барьер стоил циклу стопа витка 9.
