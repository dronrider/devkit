# DK-1185: Отказ decide --ask на рваном имени развилки называет лишним вопрос

записан 2026-09-26
приоритет: средний

## Черновик

### Ситуация
Исполнитель DK-1179 звал `taskctl decide DK-1179 --ask «оплата ядра» --hint ... "вопрос"`. Имя из двух слов без кавычек оболочки разошлось на два аргумента.
### Осложнение
Отказ команды назвал лишним аргументом сам вопрос, а не рваное имя, и исполнитель искал ошибку в вопросе.
### Вопрос
Как отказу назвать настоящую причину, когда позиционных аргументов больше одного?
### Гипотеза
Разбор аргументов сверяет счёт позиционных и при лишнем подсказывает про кавычки вокруг имени с пробелом, как это уже делает подсказка про stdin у draft.
