# DK-1189: Сторож прозы считает прозой строки замечаний taskctl review add

записан 2026-09-26
приоритет: средний

## Черновик

### Ситуация
Ревьювер DK-1179 писал замечания через `taskctl review add`. Строка замечания это машинная выжимка с адресами кода и числами, хук check-prose на коммите файла задачи дал по ней пять находок (средняя длина 21,1 при пороге 19, двоеточие 29,6 при 19, довод в фразе 62,5 при 48).
### Осложнение
Переписать замечание под порог без потери адресов и чисел нельзя, а пометка «оставлено» в «Ход работы» на каждое замечание это шум. Соседний случай уже решён для строки «источник» под развилкой (черновик DK-1170).
### Вопрос
Считать ли строки раздела «Ревью» машинными целиком или только строки с адресами кода?
### Гипотеза
Строки раздела «Ревью» вносятся в перечень машинных строк kit/skills/proofread/machine-lines.md, сторож прозы их не меряет, как и строки «Выкат» и «Проверка».
