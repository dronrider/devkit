# DK-1190: Тест носителя цикла agentctl падает под оболочкой goal-run

записан 2026-09-26
приоритет: средний

## Черновик

### Ситуация

Слияние DK-1181 из витка оболочки goal-run упало на TestWatchRegisterNamesSessionAndCarrier (tools/agentctl/watch_test.go): тест ждёт carrier = chat, а watchRegister читает DEVKIT_GOAL_SHELL из окружения процесса, и под оболочкой там стоит shell. Правка ветки agentctl не трогала, без переменной тест зелёный, с ней красный. Тест должен сам ставить переменную пустой (t.Setenv), как ставит HOME и сессию, иначе всякое слияние из витка оболочки красное, и обходить его приходится unset руками. Проверить остальные тесты, читающие окружение оболочки, тем же взглядом.
