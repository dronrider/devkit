# DK-1194: Реплика в чат задачи без живой сессии лежит без подъёма и без зова

записан 2026-09-26
приоритет: высокий

## Черновик

### Ситуация

2026-09-26 21:41 из дашборда ушла реплика задаче DK-892, стоявшей в Check с отметкой smoke. Голова задачи (окно tmux task-DK-892) к тому времени была снята: слияние и перевод в Check сделала соседняя сессия в 19:53. Строка легла во вход `.devkit/chat/task-DK-892.in` с ответом «её возьмёт первый же ход сессии задачи», журнал дашборда написал «реплика задаче DK-892 легла в чат task-DK-892» без приписки «без ведущей сессии». Повторы в 21:45 и 21:48 отбиты как дубли. Живые чаты по соседству каждый ход отказывали в подхвате записью chat-in «разговор принадлежит не этой сессии, безадресная строка ждёт хозяина» (DK-430.2). Тик сторожка по строке писал «подъём не нужен, отметка smoke прогнан стоит». В ручке отправки дашборда (tools/dashboard/chat.go, handleTaskMessage) подъём зовётся только в ветке parkedByAsk (DK-922). Оживил руками `taskctl run DK-892`, лестница подняла новое окно с первого раза.

### Осложнение

Реплика человека лежит в очереди без адресата и без срока, пока кто-то не поднимет голову руками. Ни дашборд, ни тик, ни соседние сессии её не двигают, зова человеку с готовой командой тоже нет, и тишина в панели неотличима от штатного ожидания. Это ровно тот случай, который цель DK-902 закрывала лестницей подъёма («кнопка дашборда, close, merge и тик запускают одну команду»), но к входу чата задачи лестница не подключена. Человек ждал ответа в чате 20 минут и не получил ни ответа, ни отказа.

### Вопрос

Кто зовёт подъём: ручка отправки дашборда сразу (как для ответа по вопросу) или тик сторожка по признаку «во входе задачи лежит безадресная строка, а живой сессии по задаче нет»? Возможно оба: ручка сразу, тик добирает пропущенное, как у остальных ожиданий DK-902. Отдельно проверить, почему дашборд счёл ведущую сессию живой и не пометил реплику недоставленной: taskLead нашёл кого-то в состоянии live с задачей DK-892, хотя окно задачи было мертво.

### Гипотеза

Реплика в чат задачи, у которой нет живой сессии, в любом статусе строки поднимает голову той же лестницей, что и ответ на вопрос, а при отказе лестницы человек видит в панели громкий зов с готовой командой. Стенд: строка в Check без окна, реплика из дашборда, через тик окно поднято и строка из входа забрана.
