# DK-1196: Бинарь go build в каталоге dashboard красит тест имён харнесов

записан 2026-09-27
приоритет: низкий

## Черновик

### Ситуация

Находка исполнителя DK-1119 (второй круг, 2026-09-27). go build ./... в tools/dashboard оставляет в каталоге пакета собранный бинарь dashboard, и TestQuotaNoHarnessNamesInCode читает каталог целиком, находит в машинном коде имя харнеса и краснеет. На main то же самое, стоит бинарю там остаться. В сценарии DK-1119 обойдено сборкой с -o /dev/null. Разобрать: сторож должен читать только исходники (расширения .go, .js, .css, .md), либо стандарт тестов говорит собирать с -o /dev/null, либо каталог бинаря уходит в .gitignore и сторож его пропускает.
