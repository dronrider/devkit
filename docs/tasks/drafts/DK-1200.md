# DK-1200: Голова по ответу человека получает тот же ответ заказом каждого прохода

записан 2026-09-27
приоритет: средний

## Черновик

### Ситуация

2026-09-27 23:07 голову DK-1194 подняла команда taskctl run. В поле --order лёг ответ человека на развилку «порядок прогона шага 1». Оболочка kit/skills/board-task/task-run.py при пустом --again берёт заказ следующих проходов равным первому. Работа по ответу кончилась первым проходом: замечание закрыто, ветка слита, строка в Check с видом agent без отметки smoke. Следующие три прохода принесли тот же текст ответа слово в слово. Стопа на Check с агентской приёмкой у оболочки нет. Она ждёт от головы прогона сценария, и заказ об этом молчит.

### Осложнение

Каждый проход голова тратит на сверку уже сделанного и на поиск источника повтора. Через три коротких прохода оболочка снимет её как воронку. Прогон сценария в Check тогда остаётся за тиком. Ответ человека на развилку исполнен, и заказом второго прохода он уже ничего не просит.

### Вопрос

Брать заказ следующих проходов по состоянию строки? На In progress это «Продолжай выполнение <ID>», на Check с агентской приёмкой «прогони сценарий проверки чужими руками». Второй путь: taskctl run при ответе человека ставит --again сам.

### Гипотеза

Голова, поднятая ответом человека, после исполнения ответа получает заказ по состоянию строки. Повторов одного текста в панели нет.
