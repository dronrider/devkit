# DK-1200: Голова по ответу человека получает тот же ответ заказом каждого прохода

записан 2026-09-27
приоритет: средний

## Черновик

### Ситуация

2026-09-27 23:07 голову DK-1194 подняла команда taskctl run с ответом человека на развилку «порядок прогона шага 1» в поле --order. Оболочка kit/skills/board-task/task-run.py при пустом --again берёт заказ следующих проходов равным первому. Работа по ответу кончилась первым проходом (замечание закрыто, ветка слита, строка в Check с видом agent без отметки smoke), а следующие три прохода принесли тот же текст ответа слово в слово. Стопа на Check с агентской приёмкой у оболочки нет, она ждёт от головы прогона сценария, но заказом об этом не говорит.

### Осложнение

Каждый проход голова тратит на сверку уже сделанного и разбор, откуда пришёл повтор, а через три коротких прохода оболочка снимет её как воронку, и прогон сценария в Check останется за тиком. Ответ человека на развилку в качестве заказа второго прохода уже не имеет смысла: он про решение, которое исполнено.

### Вопрос

Заказ следующих проходов брать по состоянию строки («Продолжай выполнение <ID>», а на Check с агентской приёмкой «прогони сценарий проверки чужими руками»), или taskctl run при ответе человека должен ставить --again сам?

### Гипотеза

Голова, поднятая ответом человека, после исполнения ответа получает заказ по состоянию строки, а не повтор ответа, и повторов одного текста в панели нет.
