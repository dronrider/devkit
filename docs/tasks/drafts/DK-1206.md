# DK-1206: agentctl plan не находит пункт по тексту, работает только номер

записан 2026-09-28
приоритет: низкий

## Черновик

### Ситуация

`plan done` без номера сразу после `plan set` первый пункт не закрыл, `plan step "<текст>"` отказал словами «идущего пункта в плане нет», а справка обещает адресацию пункта куском текста. Наблюдение ревьювера DK-1169 2026-09-28. Сверить с work-plan и либо починить адресацию текстом, либо убрать обещание из справки.
