# DK-1215: Гейт бюджета цели стоит на входе в работу, а не посреди доводки

записан 2026-09-28

Гейт `agentctl spend` остановил цикл DK-1084 вердиктом «over» при week_max 44 из 30. У цели в тот момент оставалось слить готовую DK-1168 и взять одну строку цены S. Цель простояла два дня. Простой обошёлся дороже перерасхода. Ветка DK-1169 за это время потерялась, восемь веток разошлись с main и сегодня собирали конфликты.

Человек сказал прямо. Бюджет нужен для решения, брать ли задачу. Тормозить по нему почти сделанную работу смысла нет.

Чего хотим. Гейт проверяется перед взятием нового: перед slot, перед нарезкой, перед стартом строки. Виток с фазой слияния, проверки или закрытия на руках доводит её без гейта. Перерасход на доводке пишется предупреждением в журнал цикла. Стопом он не становится, и запрещает он только подъём новых исполнителей. Вопрос человеку звучит «брать ли следующую строку».

Отдельно про меру. Бакет общий на машину, и соседние сессии съедают потолок цели. Число это верхняя граница трат машины, и стопом цели оно служить не может.
