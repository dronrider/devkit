# DK-1234: Слова экрана входа клиента живут двумя списками

записан 2026-09-29
приоритет: низкий

## Черновик

### Ситуация

Один экран входа читают два списка слов порознь: paneLoginMarks в
tools/dashboard/chats.go:2281 и loginScreenWords в
tools/dashboard/clientlogin.go:309, три слова из четырёх совпадают.
Расхождение старше DK-920, и диалог входа в Claude Design ни одному из них не
известен, поэтому узнаватель окна разговора его не видит.

Рядом лежит мёртвая константа loginGoneFix в chats.go:342: порядок действий
переехал в панель строкой LOGIN_AGAIN, а константа осталась.

Найдено разбором единства входа на приёмке DK-920.
