# DK-1239: Обкатка зачитывает пустой прогон go test за зелёный

записан 2026-09-29
приоритет: средний

## Черновик

### Ситуация

2026-09-29, доводка DK-1191. Сценарий проверки гоняет `go test -C tools/dashboard -run '...'` по основному дереву, а тесты жили только в ветке. До слияния обкатка получала «testing: warning: no tests to run», exit 0, и шаг считался зелёным.

### Осложнение

Ворота обкатки пропускают сценарий, который ничего не проверил: имя теста с опечаткой или тест, не доехавший до main, дают тот же зелёный. Провал виден только глазами в выводе.

### Гипотеза

Шаг обкатки с go test и «no tests to run» в выводе считается красным с причиной «тестов под маской нет».
