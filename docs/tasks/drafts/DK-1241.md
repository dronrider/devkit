# DK-1241: Тест потока сессий дашборда ждёт события стенным сроком и валит слияния

записан 2026-09-29
приоритет: средний

## Черновик

### Ситуация

2026-09-29 ~16:50, первый заход `shipctl merge DK-1204 --train` отбит красным go:dashboard: `TestSessionStreamPicksUpNewSubLog`, `sessions_test.go:1643: поток оборвался: context deadline exceeded`. Тест ждёт события из потока со стенным сроком 10 с, под тремя соседними прогонами не поспевает. shipctl назвал падение нагрузочным вне диффа задачи, но проход остановил. Повтор слияния на разгруженной машине прошёл. Тем же днём `devkitctl test tools/dashboard` на ветке упёрся в срок go test 1200 с при трёх соседних прогонах, в одиночку 195 с.

### Осложнение

Красный полный прогон это 10-20 минут машины впустую и лишний круг очереди; за день go:dashboard отбил девять слияний, больше любого другого компонента. Признание стенного времени из DK-1230 до этого теста не доехало.

### Гипотеза

Тест ждёт событие без потолка в секундах, по образцу стандарта тестов DK-1126, и под нагрузкой не краснеет; компонент go:dashboard уходит из счётчика foreign-fails.
