# DK-1246: Печать блока decide --chat перевешивает ожидание на вызвавшую сессию

записан 2026-09-30
приоритет: высокий

## Черновик

### Ситуация

2026-09-30 10:04, консультационная сессия по DK-1233 (заголовок чата «DK-1233 один вариант ответа») прогнала `taskctl decide DK-1233 --chat` через Bash ради диагностики. Команда переписала признак `.devkit/chat/task-DK-1233.ask` на ID этой сессии (tools/taskctl/ask.go, WriteAsk с askSession), позвала уведомитель и поставила этап «ждёт человека» второй раз. В run-файле задачи две строки «ждёт человека»: 00:42 от захода ветки и 10:04 от консультации.

### Осложнение

Блок вопроса появился в ленте чужого чата, человек принял его за новый вопрос. Команда, которую зовут посмотреть блок, имеет побочное действие парковки, и любой диагностический вызов утаскивает ожидание задачи с сессии-исполнителя.

### Вопрос

Разделить печать и парковку флагом, или парковать только сессию, у которой задача взята в работу, или признак с чужой сессии не перезаписывать?

### Гипотеза

Просмотр блока вопроса из любой сессии ожидание задачи не двигает: признак и этап «ждёт человека» принадлежат заходу, который задал вопрос.
