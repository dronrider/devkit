# DK-1249: Парсер развилок теряет решение при переносе вопроса на вторую строку

записан 2026-09-30
приоритет: средний

## Черновик

### Ситуация

Развилку «часы пункта» в DK-1243 исполнитель записал руками с переносом вопроса по 80 колонкам. Парсер ParseForks обрывает подстроки на первой строке не по форме, и строки «решает» и «решено» под перенесённым вопросом не читались. taskctl decide показывал развилку открытой за человеком, а taskctl close отказывал закрывать решённую задачу. Починено правкой файла в одну строку. Парсеру стоит склеивать продолжение с отступом в два пробела к голове, либо сторож формы обязан называть такой перенос находкой.
