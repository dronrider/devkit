# DK-1251: Тег deployed в чекауте потребителя отстаёт от origin

записан 2026-09-30
приоритет: средний

## Черновик

### Ситуация

Слияние DK-1243 шло в другом клоне, там тег deployed уехал на 644b5a2f2 и запушен. Этот чекаут подтянул main через git pull, а перемещённый тег pull не обновляет, и локальный deployed остался на ca18b3c61 от 29 сентября. Итог у shipctl status аномалия «код в окне выката, а задача не в In progress», shipctl smoke отказывает «нет непроверенного выката», а taskctl closable требует отметку smoke. Починено вручную командой git fetch origin +refs/tags/deployed:refs/tags/deployed. Тег стоит подтягивать в devkitctl catchup или перед сверкой окна выката в shipctl.
