# DK-1260: Побудка строки без текста ответа оставляет развилку открытой

записан 2026-09-30
приоритет: низкий

## Черновик

### Ситуация

Ситуация: DK-1072 разбужена 2026-09-30 в 09:59 коммитом «разбуждена ответом», в котором поменялась одна строка docs/TASKS.md, а в файле задачи ответа нет и развилка «вход в дерево» осталась со значением «решает: человек».
Осложнение: конвейер подал заказ «Продолжай выполнение» на строку, чей вопрос по существу не отвечен, и сессия начала работу по устаревшему решению.
Вопрос: откуда приходит побудка без ответа (кнопка панели, пустая строка в decide --answer, тик) и должна ли она вообще снимать парковку?
Гипотеза: побудку с пустым ответом надо отбивать, а строку держать в blocked, пока в развилку не легла хотя бы одна строка ответа.
