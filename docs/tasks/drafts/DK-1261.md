# DK-1261: Индекс решений обещает shipctl ready, а команды нет

записан 2026-09-30
приоритет: средний

## Черновик

### Ситуация

Решение DK-460.1 в docs/map.md говорит, что ворота готовности стоят командой shipctl ready, а не абзацем скилла. В коде такой подкоманды нет: shipctl отвечает «неизвестная команда ready» и печатает справку, где готовность видна только через status с вердиктом «сливать и выкатывать можно». Найдено 2026-09-30 при сверке ворот перед слиянием DK-624.

Расхождение доки и кода: либо команда не доехала и её надо дописать, либо решение пересмотрели, и индекс решений с ним разошёлся. Разобрать, какая из двух половин верна, и свести.
