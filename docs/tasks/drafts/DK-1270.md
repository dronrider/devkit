# DK-1270: devkitctl test не видит test_tool.py: ищет go.mod, suite.py, *_test.py

записан 2026-10-01
приоритет: средний

## Черновик

### Ситуация

Ситуация: в проекте obeycheck тесты по сценарию задач гоняются как python3 test_tool.py, файл под маску *_test.py не подпадает, обёртка отказывает «нет ни go.mod, ни suite.py, ни файлов *_test.py: прогонять нечего» (поймано на OB-001).
Осложнение: исполнитель гоняет команду сценария напрямую, мимо журнала обёртки.
Вопрос: читать ли devkitctl test команду тестов из сценария задачи или ключа проекта.
