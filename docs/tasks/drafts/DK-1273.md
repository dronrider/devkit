# DK-1273: devkitctl test не знает тестовых файлов test_*.py

записан 2026-10-01
приоритет: средний

## Черновик

### Ситуация

2026-10-01, задача OB-001 в проекте без go: корень содержит test_tool.py
(штатное имя из README проекта), прогон devkitctl test (и regcheck через
него) отказал: «нет ни go.mod, ни suite.py, ни файлов *_test.py».
Исполнитель проверял красноту руками по скиллу test-standard: временный
возврат бага и python3 test_tool.py.

### Осложнение

Python-проекты с pytest-именованием test_*.py не попадают в штатный прогон:
калитка слияния (shipctl merge требует зелёный прогон) не видит их тестов,
и краснота остаётся на совести ручной проверки каждого исполнителя.
Переименование в *_test.py ломает сценарий проверки задачи, то есть
проекты подстраиваются под обёртку, а не наоборот.

### Вопрос

Распознавать test_*.py рядом с *_test.py или вынести список имён в ключ
конфига проекта?

### Гипотеза

Штатный прогон тестов подхватывает test_*.py, и калитка слияния видит их
красноту без ручной проверки.
