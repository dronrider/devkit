# DK-1283: остаток подписок показывает историю сэмплов routerai как подписку

записан 2026-10-02
приоритет: средний

## Черновик

### Ситуация

Каталог ~/.devkit/quota задуман держать только снимки, подписка это файл
<харнес>.local, и дашборд читает каждый такой файл, беря имя подписки из
имени файла (readQuota, tools/dashboard/quota.go). Съёмщик routerai
(kit/harness/snap/routerai.sh) ведёт историю сэмплов баланса для окна трат
в файле routerai.history.local рядом со снимком. Дашборд принял его за
подписку «routerai.history», и в блоке остатка человек видит мусор. Четыре
строки «не разобрана» и приписка «момента снятия в снимке нет, возраст
неизвестен» вместо остатка.

### Осложнение

Чужой файл в каталоге снимков не покрыт тестом дашборда, а контракт съёмщика
разрешает держать своё состояние рядом со снимком. Следующий агрегатор с
балансом положит такой же сайдкар, и мусор повторится на новой подписке.

### Вопрос

Чинить на стороне съёмщика или дашборда. Съёмщик может писать сайдкар без
суффикса .local, тогда дашборд перестанет его видеть без своей правки. Либо
дашборд отличает снимки от посторонних файлов сам. Рекомендую первое,
суффикс .local уже занят снимком, и старый файл уезжает переименованием при
первом же съёме.
