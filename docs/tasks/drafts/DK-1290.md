# DK-1290: Панель видит файл истории съёмщика отдельным харнесом

записан 2026-10-02
приоритет: средний

## Черновик

### Ситуация

Проверка DK-1272 после выката 2026-10-02 нашла косметическую поломку показа. Панель дашборда перечисляет routerai.history.local из каталога снимков отдельным харнесом «routerai.history» и ругается на разбор строк. Файл истории держит сэмплы съёмщика в формате «дата баланс», это не формат снимка. Замечание записано в разделе «Проверка» архива DK-1272.

### Осложнение

Список харнесов панели шумит посторонней строкой с руганью на каждом круге обновления. Корзины рубля у routerai при этом верны, данные не страдают. Читающему панель приходится отделять сигнал от шума руками.

### Вопрос

Отфильтровать файлы истории по маске имени или разобрать историю отдельным типом записи?

### Гипотеза

Панель перечисляет только снимки харнесов, файл истории в списке не виден и ругани нет.
