## постановка (task)
источник: заказ человека, чат 05.10
роль: человек

Выбор модели в панели чата разворачивается из лестниц включённых подписок.
Источник списка это agentctl harness --json по машинному слою
(~/.devkit/harness.local). У подписки ярусы mini, base, pro и max, пунктов
сверх лестницы у панели нет.

Каталог routerai закрывает сотни моделей, для разговоров человеку нужны
избранные вне лестницы. Пример набора: anthropic/claude-fable-5.1,
moonshotai/kimi-k3, z-ai/glm-5.3-prime, google/gemini-3.7-flash. Это
топ-ступень свежего семейства, второе мнение чужой школы, усиленная ступень
glm и дешёвая модель с длинным контекстом. Править ради чата саму лестницу
нельзя. По ярусам назначает задачи agentctl pick, правка лестницы
перенастроила бы конвейер задач.

Ожидание. Машинный слой принимает у подписки список моделей чата сверх
лестницы. Панель выбора показывает эти строки с подпиской-владельцем, подъём
чата идёт обвязкой владельца. Вердикт pick список не читает, назначение задач
остаётся на лестнице.

связи: DK-328 (выбор подписки в кнопке запуска), DK-1177 (владелец модели
между подписками)
