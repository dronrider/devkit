# DK-1310: devkitctl stats не умеет окно, у команды нет --from и --to

записан 2026-10-06
приоритет: средний

## Черновик

### Ситуация

Цифра: за окно 26.09-06.10 журнал запусков дал 46830 вызовов и 5591 ненулевой код, а статистика печатает только итог за всё время (352379 вызовов, 46% ошибок).
Пример: доли ошибок за окно (shipctl smoke 585 из 624, agentctl wait 743 из 816) считались фильтром строки .devkit/log по времени, такого среза у утилиты нет.
Мера: флаги --from и --to у devkitctl stats с тем же форматом вывода.
