# DK-1312: Перезапись префикса длинных потоков: 361M токенов на проценте запросов

записан 2026-10-06
приоритет: высокий

## Черновик

### Ситуация

Цифра: 1615 запросов из 125559 переписали префикс, суммарно записано 361M токенов кусками по ~900k.
Пример: поток 8257b5e0 на запросе 2103 из 2772 записал 943821 токен, чтение кэша упало с 940279 до нуля; десятки таких перезаписей приходятся на один поток.
Мера: порог ротации по числу ходов и объёму префикса с отметкой ротации в журнале сессий.
