# DK-1313: Журнал запусков не различает отказ ворот и падение утилиты

записан 2026-10-06
приоритет: средний

## Черновик

### Ситуация

Цифра: за окно 26.09-06.10 shipctl ready дал 38 вызовов с ненулевым кодом из 38, shipctl merge 262 из 292, а доля ненулевых кодов у smoke доходит до 94%.
Пример: отказ ворот готовности и падение бинаря в журнале оба выглядят строкой «инструмент, команда, код», и доля ошибок для разбора DK-1227 грозит ложной тревогой на штатных отказах.
Мера: отдельный код выхода у отказа ворот либо поле «отказ или падение» в строке журнала запусков.
