# DK-1315: хуки прозы и символов бьют по чужому тексту ревью в файле задачи

записан 2026-10-07
приоритет: низкий

## Черновик

### Ситуация

Замечания ревью кладутся в файл задачи командой taskctl review add.

### Осложнение

Хук прозы (DK-446) на правке файла считает весь файл, включая чужой текст
замечаний, и отбивает запись секции сценария. Хук символов отбивает коммит на
длинном тире в тексте ревью, которого автор правки не писал. На DK-1227
обошли записью через Bash мимо хука Edit и git commit --no-verify.

### Вопрос

Чинить рубежи так, чтобы тексты замечаний ревью не попадали в подсчёт
сторожа прозы и проверку символов.

### Гипотеза

Хуки пропускают раздел «Ревью» файла задачи либо проверяют только
добавленные строки правки.
