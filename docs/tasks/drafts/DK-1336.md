# DK-1336: agentctl plan set: этапы строки с переводом строки легли одним пунктом

записан 2026-10-09
приоритет: средний

## Черновик

### Ситуация

2026-10-09, находка из работы над DK-1322: план передавался команде
`agentctl plan set` одним аргументом, где этапы разделены переводом
строки. Все этапы легли одним пунктом, `plan step` отказал
«идущего пункта нет», закрыть удалось одним `plan done` на весь
список. Ожидаемое поведение: каждый перевод строки разбивает
аргумент на отдельный пункт, либо команда отбивает аргумент с
внятной формой входа (этапы отдельными аргументами). Обходной путь
есть (передавать этапы отдельными аргументами), поэтому уровень
разбора mid: мелочь с тихой порчей структуры плана.

Проверка: тест на tools/agentctl, где plan set одним аргументом с
переводом строки даёт два пункта, а plan step 1 открывает первый.
