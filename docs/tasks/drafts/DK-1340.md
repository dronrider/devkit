# DK-1340: rules.py --layout не собирает слой home/ на харнесе mimo

записан 2026-10-09
приоритет: высокий

## Черновик

### Ситуация

Ситуация. layout() в tools/devkitctl/rules.py строки 1275-1276 резолвит
global_file через os.path.expanduser, а не через harness_path. Точка
«не найдена», слой home/ пропускается молча. Вдобавок
rule_sources(depth=core) не кладёт RULES.core.md в корень (CORE_RULES
исключён), и файл достижим только home-импортом. Из-за этого obeycheck
--task отказал бы staleLayout, а сценарии с предметом RULES.core.md
приходится собирать home-слой руками.

Чего хотим. layout() резолвит global_file тем же путём, что и остальные
точки харнеса; слой home/ собирается сам; rule_sources на depth=core
отдаёт RULES.core.md, и obeycheck --task проходит без ручной сборки.
