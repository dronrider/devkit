# DK-1341: devkitctl test -run уходит в unittest discover и роняет python-каталог

записан 2026-10-09
приоритет: средний

## Черновик

### Ситуация

Ситуация. Обёртка devkitctl test с ключом -run на python-каталоге
прогоняет unittest discover с этим же ключом, каталог падает. Встречалось
на DK-1321 и DK-1324: приходилось гонять каталог целиком либо звать
python-модуль напрямую. Ключ -v ведёт себя так же.

Чего хотим. Либо -run/-v разбираются до зова сьютов и уходят им
построчно, либо обёртка честно отказывает на неподдерживаемом ключе
вместо падения discover.
