# DK-1342: taskctl review clean отказывает повторять ревью на том же коде

записан 2026-10-09
приоритет: средний

## Черновик

### Ситуация

Ситуация. Повторный прогон review clean на неизменённом диффе отбивает
отказом, --new-round спасает только несравнимый случай. Ревьюверу на
DK-1321 пришлось обходить это руками. Рядом всплывает ложное срабатывание
check-machine-lines.py на правке длинного тире в хвосте вердикта.

Чего хотим. review clean повторяем на том же коде с честным «без
замечаний» либо явным именем нового круга; check-machine-lines не
срабатывает на типографике внутри уже машинных строк.
