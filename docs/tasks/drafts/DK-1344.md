# DK-1344: течь фикстуры obeycheck: lint на фикстуре видит чужой git

записан 2026-10-10
приоритет: средний

## Черновик

### Ситуация

2026-10-10, обкатка слияний по цели DK-1326. Пока на main стояла незапушенная мелочь loadfail, TestFixtureProjectPassesLint падал находкой про main впереди origin: фикстура testdata/project лежит без своего репозитория, taskctl lint на месте поднимается к гиту девкита и берёт чужое опережение за свою находку. На находке сгорели повторы чужих слияний DK-499 и DK-1312, DK-1321 сняли с очереди.

Осложнение: любая мелочь между выкатами красит go:obeycheck всем слияниям машины, пока её не увезёт попутный пуш; незапушенный код в main красит и ту правку, которая течь чинит, потому что тест судит по внешнему гиту.

Гипотеза: тесту нужна копия фикстуры со своим гитом по образцу makeEnv (seedRepo, hooksPath, свой origin), и дальше lint судит содержимое фикстуры. Решить на месте: хватит ли seedRepo без origin, ведь без origin находка про опережение молчит, но и проверки с remote теряют смысл.
