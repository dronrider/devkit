# DK-1347: Грязь чужого файла задач блокирует всю очередь слияний

записан 2026-10-10
приоритет: средний

## Черновик

### Ситуация

2026-10-10, `shipctl queue --drain` на devkit: все пять строк очереди (DK-1317,
DK-1335, DK-499, DK-1300, DK-828) получили один отказ «в рабочем дереве
незакоммиченное по файлам задачи». Грязь была одна: незакоммиченный чужой
docs/tasks/DK-1335.md в основном чекауте на main. requireCleanScoped в
tools/shipctl/ops.go считает файлы через mergeRangePaths по двухточечному
`main..branch`, а туда попадают и файлы, изменённые на main после точки
ветвления ветки.

### Осложнение

Одна незакоммиченная строка чужой задачи на main останавливает слияние всех
независимых строк очереди до приезда чужой правки. Держатель одной задачи
блокирует чужой конвейер, а отказ не называет причину по существу: каждая строка
пишет про своё дерево.

### Вопрос

Считать грязью только файлы, которые ветка реально трогает (трёхточечный
`merge-base...branch`), или оставлять чужие задачные файлы конфликтом назначения
с явным перечнем.

### Гипотеза

Очередь пропускает строки, чьи файлы чисты, и держит только те, чьей работы грязь
касается: одна грязная задача не замирает конвейер остальных.
