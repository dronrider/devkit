## Ситуация

Ревьювер DK-1349 заводил план захода меткой DK-1349-review.

## Осложнение

Метка оказалась занята чужим закрытым планом, plan set отказал. Заход ушёл под другой меткой. Метка закрытого плана не освобождается, повторно её взять нельзя, и занятость всплывает только на попытке записи.

## Вопрос

Когда метка плана освобождается, и снимается ли она с закрытого плана?

## Гипотеза

plan set отбирает метку закрытого плана себе или переиспользует его запись, а не отказывает.
