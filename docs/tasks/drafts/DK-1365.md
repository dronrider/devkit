# DK-1365: check-machine-lines.py не принимает путь файла, рубеж сверить нечем

записан 2026-10-12
приоритет: средний

## Черновик

### Ситуация

2026-10-12, вычитка DK-1361: прямой вызов python3 hooks/check-machine-lines.py с путём файла падает в usage с кодом 2. Рубеж машинных строк работает только в роли --hook на событии записи.

### Осложнение

Правку машинных строк вне хука нечем сверить чтением файла, как это умеет check-symbols.py. Автор правки узнаёт о сломанной строке только отбивкой хука в момент записи, а вычитчик не может проверить файл целиком.

### Вопрос

Принимать имена файлов аргументами в дополнение к роли хука или завести отдельную команду сверки?

### Гипотеза

Любой файл с машинными строками сверяется одной командой из чекаута, и результат тот же, что у отбивки хука.
