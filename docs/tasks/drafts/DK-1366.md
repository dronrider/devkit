# DK-1366: гейт бюджета цели отказывает по бакетам чужого харнеса

записан 2026-10-12
приоритет: средний

## Черновик

### Ситуация

2026-10-12, гейт agentctl spend --goal docs/tasks/DK-1326.md --record на активном харнесе mimo: ошибка «бакет week_all харнесу mimo незнаком, известны month_plan». Бюджетные строки цели написаны бакетами week_all и week_max, они же названы в goal-start как имена из снимка.

### Осложнение

После переключения машины на mimo у цели с бюджетом в недельных бакетах гейт не считает расход вообще: ни gate: ok, ни gate: over, и запись «Журнала» идёт без парного снимка. Файл цели при этом описывает свёртку строк в одну границу на month_plan, пока снимок нёс один бакет, но сами строки к свёртке не вернулись.

### Вопрос

Кто правит строки бюджета при смене словаря бакетов: человек развилкой или свёртка утилитой по правилу из файла цели?

### Гипотеза

Гейт бюджета любой цели считает расход при любом активном харнесе, а смена словаря бакетов не оставляет цель без границы.
