# DK-1384: pre-commit хук бракует amend коммита с тестами

записан 2026-10-14
приоритет: низкий

## Черновик

### Ситуация

При отработке замечания ревью DK-1379 14.10 правка по замечанию легла
amend'ом в коммит, где стенды уже лежат. Pre-commit hook отказал словами
«правка кода без единого теста в коммите».

### Осложнение

Хук судит дифф по инкременту против HEAD, а amend приносит инкремент из
одного кода: тесты остаются в теле коммита и инкрементом не видны. Обход
штатный (DEVKIT_NO_TESTS=1 из подсказки хука), но каждый amend с замечания
рвью упирается в него.

### Вопрос

Хуку стоит смотреть итоговый коммит, когда инкремент против HEAD пуст или
коммит делается amend'ом?

### Гипотеза

При amend'е (HEAD равен коммитуемому) проверять состав итогового коммита, а
не инкремент рабочей копии.
