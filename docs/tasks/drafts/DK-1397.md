# DK-1397: Обкатка валит чужой стенд board-task нехваткой agentctl

записан 2026-10-17
приоритет: средний

## Черновик

### Ситуация

Обкатка сценария DK-1396 гоняла полную суиту в свежем дереве обкатки.
Компонента board-task упала на тесте test_wait_end_closes_the_stage. Проверка
условий «слита DK-2» и «закрыта DK-2» напечатала «проверить нечем» с ошибкой
«No such file or directory: 'agentctl'», отметка события не встала, и
утверждение получило пустую строку вместо «событие». Дерево обкатки собрало
11 утилит, но тест их в PATH не увидел.

### Осложнение

Та же суита в слияниях зелёная. DK-499 слилось утром с полным прогоном, и
стенд board-task там прошёл. Стенду нужен agentctl из окружения, у слияния
он есть, у обкатки нет. Об это место будет падать любая обкатка с шагом
полной суиты, а предмет задачи тут ни при чём.

### Вопрос

Кто должен класть утилиты дерева в PATH прогонов стенда: сам стенд,
обёртка parallel.py или песочница обкатки?

### Гипотеза

Песочница обкатки собирает утилиты, но не ставит их на PATH прогонов
компонент. Снять можно прокидыванием каталога утилит дерева в PATH шагов,
и тогда полная суита вернётся в сценарии DK-1396 отдельным шагом.
