# DK-1402: Круги ревью не различают источник возврата

записан 2026-10-17
приоритет: низкий

## Черновик

### Ситуация

Возвраты человека после выката гоняют круги ревью дольше потолка rounds из конфига ревью: DK-1388 идёт третьим кругом, каждый следующий открыл человек уже после выката, а не агентский пинг-понг. Потолок кругов задуман против спора агентов, источник круга правило не различает, и ревьюверу приходится оговаривать это словами в вердикте. Рядом та же история с планом: метка DK-1388-review занята планом прошлого круга, новый круг кладётся только перекладкой с --force.
