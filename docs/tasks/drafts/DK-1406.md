# DK-1406: devkitctl test с двумя путями склеивает их в одну команду прогона

записан 2026-10-18
приоритет: низкий

## Черновик

### Ситуация

Вызов devkitctl test с двумя путями собирает из них одну команду go test и
падает с «named files must be .go files» вместо внятного отказа. Нашёл
ревьювер круга 2 задачи DK-1403, обошёл одиночным путём.
