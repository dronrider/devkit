# DK-1412: Рубеж ревью судит пуш из дерева задачи по диапазону main

записан 2026-10-18
приоритет: средний

## Черновик

### Ситуация

пуш ветки задачи из чужого дерева (git -C ../devkit-dk-1001 push из основного чекаута) отбит хуком check-review по диапазону origin/main..main. Пока main держал незапушенные коммиты слияния DK-1399, ветка не уезжала, хотя у самой ветки замечаний нет. Хук берёт дерево из cwd сессии и не разбирает -C у git push, то есть судит чужой диапазон. Обошёл ожиданием, пока тик запушит main.

Вопрос: не должен ли рубеж судить именно пушимое дерево. Гипотеза: дереву брать цель -C из команды, а без -C оставлять cwd.
