# DK-1418: hook коммита не находит тип fix в истории, забитой коммитами доски

записан 2026-10-23
приоритет: низкий

## Черновик

### Ситуация

Hook проверки префикса коммита собирает набор типов по окну последних
коммитов истории. В main репозитория devkit из сотни недавних коммитов
подавляющая часть это docs(tasks) от движений доски, рабочие типы вроде
fix(taskctl) уходят глубже окна (например, af0e526ae). Ветке DK-1363 hook
отказал префиксу fix со словами «не встречается в истории».

### Осложнение

Исполнитель законного префикса получает отказ и обходит его через
--no-verify после ручного прогона check-symbols, рубеж превращается в
ручную работу.

### Вопрос

Откуда hook берёт набор префиксов и каким он должен быть: окно большего
размера, полный лог, фильтр коммитов доски при подсчёте или явный список
типов.

### Гипотеза

Окно в сотню коммитов не пережило частых коммитов доски; набор стоит
считать по полной истории либо исключая docs-коммиты доски из подсчёта.
