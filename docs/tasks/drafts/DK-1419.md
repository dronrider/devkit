# DK-1419: regcheck молча падает, когда команда после -- собрана одной строкой

записан 2026-10-23
приоритет: средний

## Черновик

### Ситуация

Вызов regcheck из README не работает как написано, нашлось по ходу DK-1337
дважды за день.

Исполнитель споткнулся первым: команда после «--», собранная одной строкой,
молча падает с пустым выводом. Помогла передача команды argv по частям:
«regcheck -- go test ...» вместо «regcheck -- 'go test ...'».

Ревьювер нашёл второе: в монорепозитории с go.work прогон из README
(`regcheck -C tools/taskctl -- go test ./...`) падает без GOWORK=off с
«directory tools/taskctl is contained in a module that is not one of the
workspace modules», а с GOWORK=off go test от cmdout-каталога не находит
go.mod. Рабочий вариант это обёртка «-- sh -c 'cd tools/taskctl && go test .'».
