# DK-1424: gitrun.Env перекрывает core.sshCommand репозитория

записан 2026-10-23
приоритет: высокий

## Черновик

### Ситуация

Переменная GIT_SSH_COMMAND=ssh -o BatchMode=yes, которую собирает internal/gitrun.Env, затирает конфиг репозитория с выделенным ключом и known_hosts, и внутренние вызовы shipctl и taskctl падают в publickey, хотя ручной git push тем же конфигом проходит.

Проявилось на слиянии DK-1333 2026-10-23: три отказа fetch origin подряд, обход это передача значения core.sshCommand через переменную GIT_SSH_COMMAND при запуске утилиты. gitrun должен читать core.sshCommand репозитория и сохранять его, добавляя BatchMode, а не подменять голым ssh.
