записан 2026-10-24
приоритет: высокий

## Черновик

### Ситуация

Приписка 2026-11-09, фактура из сдачи DK-1663: исполнительская связка
«git commit && git push && git show > <файл основного чекаута>» отбит
рубежом hooks/check-review.py на диапазон с чужим коммитом без ID задачи
(0534e3f4fa0a в main). Одиночный push того же коммита из отдельного вызова
прошёл. Обход на сдаче: разбиение связки на отдельные вызовы.
