# DK-1458: SubagentHandback недоступен исполнителю exec-high, ревьюверу доступен

записан 2026-10-25
приоритет: средний

## Черновик

### Ситуация

Ситуация: 25.10.2026 исполнитель задачи DK-1455 (определение exec-high,
glm-5.3) дважды заканчивал ход без отчёта. Стоп-хук требует отдать отчёт
инструментом SubagentHandback, исполнитель четыре раза искал инструмент в
своём наборе и не нашёл, отчёты дошли только репликами SendMessage.

Осложнение: ревьювер review-high той же подписки вернул отчёт
SubagentHandback-ом без затруднений. Инструмент есть в наборе не у всех
определений, и исполнитель молча теряет финальный текст.

Вопрос: почему у exec-high нет SubagentHandback и как финальный отчёт
доходит стабильно.

Гипотеза: определение exec-* режет набор инструментов, либо имя
инструмента в glm-обвязке отличается, и стоп-хук зовёт имя, которого
субагент не знает.
