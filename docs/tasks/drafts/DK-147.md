# DK-147: Чтение файла целиком вдвое дороже чтения куском, и зовётся оно чаще. Замер по транскриптам 972 сессий: из 7577 вызовов Read 4428 (58.4%) идут без limit и offset, дают 41.4M символов и в среднем 9.4K за вызов, а 3150 (41.6%) с limit или offset дают 12.2M и в среднем 3.9K. Чтение целиком набирает 38% всего вывода инструментов за выборку, больше любой другой практики: весь grep за тот же период 8.1M, впятеро меньше. Правило ядра «не тянуть файл целиком, когда нужен фрагмент» стоит, а рубежа под ним нет, и статистика показывает, что оно не держится. Кандидат: подсказка на PreToolUse при Read без limit, когда файл длиннее порога, сам порог подобрать по распределению длин. Смежно с DK-146 (повторные чтения), рубеж тот же самый.

## Черновик

Замер по транскриптам 972 сессий: из 7577 вызовов Read 4428 (58.4%) идут без limit и offset, дают 41.4M символов и в среднем 9.4K за вызов, а 3150 (41.6%) с limit или offset дают 12.2M и в среднем 3.9K. Правило ядра «не тянуть файл целиком, когда нужен фрагмент» стоит, а рубежа под ним нет, и статистика показывает, что оно не держится. Кандидат: подсказка на PreToolUse при Read без limit, когда файл длиннее порога, сам порог подобрать по распределению длин. Смежно с DK-146 (повторные чтения), рубеж тот же самый.
