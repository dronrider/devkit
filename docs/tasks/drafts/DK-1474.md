# DK-1474: Проход головы без отметок хода тик наблюдает, а не глушит

записан 2026-10-26
приоритет: высокий

## Черновик

### Ситуация

26.10.2026, голова DK-489. Проход 5 длился 4835 секунд. Полтора часа из них
не дали ни одной отметки хода. В 12:36 сесс разом закрыл больше двадцати
фоновых `sleep 600` с пустой сдачей. Тик записал молчание в журнал и
продолжил наблюдать. За три часа голова сняла около двух часов модельного
времени, строка не сдвинулась.

### Осложнение

Замок по признаку жизни (DK-1454) замерзший процесс не держит. Конвейер
поднимает нового исполнителя, а старая сессия продолжает тратить квоту.
Дашбордная «Стопа» агенту недоступна, вход в панель закрыт. Своего стопа у
тика нет.

### Вопрос

Должен ли тик гасить сессию сам, когда проход молчит дольше порога без
отметок хода?

### Гипотеза

Порог молчания тик уже считает для журнала. Тот же замер ставит заказ
стопа, проход паркуется с причиной «молчание». Потолок проходов держит
повтор от закольчивания.

## Развилки

- «автостоп тика»: Должен ли тик гасить сессию головы сам, когда проход молчит дольше порога без отметок хода?
  - решает: человек
  - рекомендация: гасить самому. Порог молчания тот же, что у журнала, заказ стопа паркует проход причиной «молчание», потолок проходов держит повтор от закольчивания. Довод: DK-1454 уже поставил правило, что диагноз тишины завершается исходом, а не наблюдением. Наблюдение без исхода возвращает затор, молчащая сессия при этом жжёт квоту. Подтверждённое ожидание, вопрос человеку, гасить нельзя. Источник: архив DK-1454 и черновик DK-1474
  - вариант: тик гасит молчащий проход сам
  - вариант: тик зовёт человека, без автостопа
  - вариант: оставить наблюдение как есть
