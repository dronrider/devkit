# DK-1477: Вложенный спавн отдаёт субагенту поток без инструментов

записан 2026-10-26
приоритет: высокий

## Черновик

### Ситуация

Субагент, поднятый другим субагентом (исполнитель DK-994 позвал вычитку),
получил поток с одним ToolSearch, который не находит ни одного инструмента
даже по маске .* при десяти отложенных. Прямые спавны диспетчера работают
с полным набором. Вычитка умерла вхолостую, повтор подъёма с верхнего
уровня. Замер 26.10, поток ae2c1a3e44ee8bb98.
