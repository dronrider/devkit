# DK-1479: Ворота этапа проверки плана читают DEVKIT_TASK вместо метки плана

записан 2026-10-26
приоритет: средний

## Черновик

### Ситуация

26.10.2026, субагент задачи DK-994 закрыл этап «проверка» по скиллу board-task.
Прогон сценария прошёл чужой моделью (glm-5.3-flash), отметка легла в файл
задачи DK-994 командой agentctl stage. Ворота закрытия пункта плана
(agentctl plan done --label DK-994 «проверка») отказали: они искали раздел
«Проверка» в docs/tasks/DK-1198.md, в файле цели из переменной DEVKIT_TASK
родительского окна. Ворота internal/trace/check.go берут задачу из
окружения сессии (c.ID из DEVKIT_TASK), метка плана в команде остаётся
без внимания.

### Осложнение

У файла цели раздела «Проверка» нет по форме TASKFORM, пункт плана не закрыть
ни флагом --force, ни фактом прогона. План задачи остаётся с открытым пунктом
после закрытия строки, это выглядит незакрытым заходом.

### Гипотеза

Ворота этапа проверки должны читать задачу из метки плана, когда она задана,
а DEVKIT_TASK оставлять запасом для сессии без метки.
