# DK-1482: Отставание main останавливает слияние, тянет ветку только человек

записан 2026-10-26
приоритет: средний

## Черновик

### Ситуация

2026-10-25 слияние DK-1457 отворотилось проверкой freshMain: локальный main отстал от origin/main, потому что досочный коммит ушёл в origin из другого окна, а отказ посоветовал «git pull --rebase». Сам конвейер ветку не тянет: freshMain только сверяет предка и отказывает, слой эскалации дежурного прав не имеет. 2026-10-26 в 18:36 ребейз выполнили вручную, пуш прошёл, к началу разбора отказ был уже снят.

Чего хотим: слияние и пуш наводят свежесть main сами, повторным заходом после подтягивания; эскалация дежурному остаётся на настоящий конфликт ребейза и недоступный origin. Как подтягивание уживается с грязью общего чекаута, решить в грумминге.
