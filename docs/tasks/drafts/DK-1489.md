# DK-1489: Хук спавна записывает proofread-субагента этапом разработки

записан 2026-10-27
приоритет: средний

## Черновик

### Ситуация

На сдаче DK-1465 вычитку вёл субагент скилла proofread, поднятый из захода исполнителя.

### Осложнение

Хук спавна положил его в запись этапом разработка/exec-high вместо этапа вычитки, ворота этапа записи не увидели вычитку, исполнителю пришлось закрывать этап авторской строкой.

### Вопрос

Читать ли хуку этап из определения субагента (proofread -> вычитка), а не из определения исполнителя поднявшего?

### Гипотеза

Этап в записи совпадает с определением субагента, ворота видят вычитку без авторских строк.
