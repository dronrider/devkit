# DK-1495: Определениям харнеса claude-glm не выданы инструменты Bash и Read

записан 2026-10-28
приоритет: средний

## Черновик

### Ситуация

Ситуация: ревью DK-1470 поднимали определением general-purpose, у него в харнесе claude-glm не оказалось Bash и Read; работа шла shell-командами через Monitor, а сдача через SubagentHandback вышла только после повторного требования диспетчера.

Осложнение: то же известно про типизированные review-* из памяти машины, но на доске этого нет; свежий подъём без инструментов тратит бюджет на обходы и рискует потерей отчёта.

Вопрос: кто и по какому списку выдаёт инструменты определениям харнеса, генератор тонкого файла или doctor, и должен ли doctor находить определения без Bash/Read?

Гипотеза: список инструментов принадлежит определению в харнесе, doctor сверяет его с минимальным набором Bash/Read и правит генерацией.
