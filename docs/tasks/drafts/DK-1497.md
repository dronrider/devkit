# DK-1497: Заголовок чата в списке дашборда становится «1» на реплике с нумерацией

записан 2026-10-28
приоритет: высокий

## Черновик

### Ситуация

Разговор по цели DK-1198 открыт репликой из шести нумерованных пунктов. Первый
пункт начинался словами «1. Нашёл баг». В списке чатов дашборда разговор
получил заголовок «1». Харнес glm-code-2 записал в транскрипт осмысленный
заголовок «Баги главной страницы». Живой случай, сессия 9cf1c43a от 2026-10-28.

### Осложнение

Дашборд читает шапку транскрипта окном в 256 КБ (readSessionHead,
metaScanLimit, tools/dashboard/sessions.go). Харнес кладёт запись ai-title
после результатов инструментов первого хода. В живом случае запись легла на
смещении 415985, за окном. Список остался без ai-title и собрал заголовок
эвристикой первого предложения (titleTrim, tools/dashboard/chats.go). Эвристика
режет строку по первому знаку из «.?!». Реплика с нумерацией отдала заголовком
голую цифру.

### Вопрос

Расширять окно чтения или искать ai-title обратным чтением хвоста? Договариваться
о месте записи с харнесом? Отсеивать заголовок из одних цифр на месте эвристики?

### Гипотеза

Чинится парой правок. Список дочитывает ai-title хвостом файла. titleTrim не
возвращает заголовок из одних цифр, нумерация в начале реплики обрезается.
