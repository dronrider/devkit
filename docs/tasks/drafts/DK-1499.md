# DK-1499: Старым строкам этапа нет утилиты вписать хвост сессии

записан 2026-10-29
приоритет: средний

## Черновик

### Ситуация

Отказ закрытия по независимости прогона (DK-1360) называет дорогу
«вписать в строку этапа хвост сессии», хук машинных строк бьёт правку
из харнеса, а подкоманды с таким действием нет ни у taskctl, ни у
agentctl, ни у shipctl. Круг замыкает либо человек редактором вне
харнеса, либо отдельная подкоманда перехода старых записей.

### Осложнение

Тот же класс промаха у следа ревью: ворот пуша кода с main требует
git-заметку на ref review, а пишут её `taskctl review level` и
`review clean` только в репозитории без доски. Фикс закрытой задачи
на main остаётся без писателя следа, заметку приходится ставить
руками в формате утилиты.
