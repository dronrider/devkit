# DK-1505: regcheck в модуле tools/dashboard спотыкается о go.work корня

записан 2026-10-29
приоритет: средний

## Черновик

### Ситуация

У ревьювера прогон падал с сообщением «directory is contained in a module that is not one of the workspace modules», обход это env GOWORK=off перед командой теста. Прогон с -C на каталог модуля не спотыкается.
