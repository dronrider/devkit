# DK-1510: regcheck молча врёт про зелёный тест при абсолютном пути

записан 2026-10-30
приоритет: средний

## Черновик

### Ситуация
30.10.2026 ревьювер DK-1442 гнал regcheck с командой вида «regcheck -- env HOME=... devkitctl test /абс/путь/кода тест». Прогон на старом коде молча шёл по абсолютному пути рабочего дерева мимо временного worktree. Утилита печатала ложный вердикт «тест зелёный на старом коде» вместо ошибки про путь. С относительным путём в аргументе devkitctl test прогон корректен.
### Осложнение
Ложный зелёный вердикт снимает красноту регрессии на словах утилиты. Ревьюверы и ворота верят строке «успех» из журнала запусков. Обход известен, но требует помнить про него.
### Вопрос
Как regcheck должен ловить абсолютный путь рабочего дерева в команде теста и что при этом печатать.
### Гипотеза
Утилита сверяет аргументы команды с путём временного worktree и отказывает именем файла, когда аргумент указывает мимо worktree. Отказ с именем файла снимает ложный вердикт.
