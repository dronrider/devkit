# DK-1514: У подписки glm есть льготный период времени суток где стоимость

записан 2026-10-30
приоритет: средний

## Черновик

### Ситуация

запросов снижена. Хочется учитывать это и выполнять задачи именно в этот период, чтобы меньше сжигать подписку. В остальное время можно заниматься планированием задач, что хорошо ложится на такой процесс. Но пока непонятно как приостанавливать работу задач при завершении дешёвого периода времени. Возможно достаточно не запускать задачу в дорогой период времени, а предлагать запланировать запуск на начало льготного периода времени.
