# DK-1518: agentctl plan читает файл задачи основного чекаута при сбросе cwd

записан 2026-10-30
приоритет: средний

## Черновик

### Ситуация

Исполнитель в worktree задачи звал agentctl plan done по DK-1226 из Bash-вызовов. Харнес сбрасывает cwd между вызовами, команда читала docs/tasks/DK-1226.md основного чекаута, где раздела «Сценарий проверки» ещё нет, и отказывала воротами этапов. Обход: zsh -c 'cd <дерево>; agentctl plan done ...'. Случай в DK-1226 2026-10-30.
Ворота этапов читают чужой файл задачи и ложно краснеют, обход учит сбрасывать cwd руками, следующий исполнитель потеряет час.
Как команде plan находить файл задачи сессии: по замку или дереву задачи, а не по cwd?
Гипотеза: план сессии связан с задачей через замок или run-каталог, оттуда и дерево, где лежит живой файл задачи.
