# DK-1539: plan done читает файл задачи от cwd вызова

записан 2026-11-01

## Черновик

### Ситуация

Ворота этапов agentctl plan (step/done) ищут docs/tasks/<ID>.md от cwd
вызова. Из основного чекаута plan done отказывает с «нет записи этапа»,
хотя запись лежит в дереве задачи: ворота не находят файл в этом чекауте.
Обход это явный cd в дерево задачи перед каждой plan done.

Наблюдение: WB-004 watch-bot, исполнитель звал plan done из
/Users/rider/projects/watch-bot, дерево задачи /Users/rider/projects/watch-bot-wb-004.
