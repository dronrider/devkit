# DK-1540: Хук спавна proofread не пишет запись этапа вычитка

записан 2026-11-01

## Черновик

### Ситуация

Хук спавна субагента по определению proofread не положил запись этапа
«Вычитка» ни в «Ход работы» файла задачи, ни в пакет ~/.devkit/runs.
Из-за пустой записи ворота этапа «вычитка» в плане шаблона task
отказывали закрывать пункт, пока строку не дописали руками в файл задачи.

Наблюдение: WB-004 watch-bot, вычитка шла субагентом proofread из дерева
задачи /Users/rider/projects/watch-bot-wb-004.
