# DK-1541: plan done не берёт полный текст пункта с пометкой

записан 2026-11-01

## Черновик

### Ситуация

agentctl plan done отказывает «пункта нет», когда пункту передан полный
текст вместе с пометкой «(на слове агента)», короткий префикс текста
проходит. Рядом в том же заходе plan set не разобрал литеральный \n
в аргументе, перестановка на настоящие переводы строк помогла.

Наблюдение: WB-004 watch-bot, ревьювер звал plan по метке WB-004-review.
