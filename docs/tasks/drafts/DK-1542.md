# DK-1542: shipctl push нет, ворот на пуше не сработало

записан 2026-11-01

## Черновик

### Ситуация

shipctl push в этой сборке печатает общую справку: подкоманды нет. Пуш
ветки задачи прошёл гитом напрямую, и ворот предсказанного поведения
(например след ревью) на таком пуше не сработало. Либо вернуть подкоманду,
либо убрать её из подсказок утилиты.

Наблюдение: WB-004 watch-bot, ревьювер пушить ветку по правилу немедленного
пуша коммитов docs/tasks/.
