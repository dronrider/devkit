# DK-1543: Рубеж машинных строк не пускает правку вида приёмки

записан 2026-11-01

## Черновик

### Ситуация

hooks/check-machine-lines.py отбивает ручную правку строки «- вид:» в
файле задачи даже когда правка идёт в пользу замечания ревью: смена вида
доступна только утилите доски. Исполнитель не может закрыть замечание
полностью сам,Machine строка остаётся за taskctl set --accept из основного
чекаута. Подсказка «правь утилитой» в тексте отказа назвала бы утилиту
явно и сняла бы шаг тыканья.

Наблюдение: WB-004 watch-bot, исполнитель правил файл в дереве задачи.
