# DK-1544: merge убирает дерево задачи до записи clean круга 2

записан 2026-11-01

## Черновик

### Ситуация

shipctl merge сносит worktree задачи сразу по слиянию. Ревьювер круга 2,
работавший в этом дереве, получил отказ taskctl review clean «не нашёл
docs/TASKS.md» и записал вердикт в основной чекаут руками. Сопутствово:
само слияние прошло до конца круга 2, ворота слияния след уровня и
закрытые замечания пускают, ожидания круга ревью в предусловиях нет.

Наблюдение: WB-004 watch-bot, слияние и круг 2 разнесены на две сессии.
