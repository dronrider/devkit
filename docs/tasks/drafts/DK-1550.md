# DK-1550: окно проверяющего снимается замком при живом исполнителе

записан 2026-11-01
приоритет: высокий

## Черновик

### Ситуация

На DK-1545 окно независимого проверяющего дважды снималось на замке задачи. Сессия исполнителя при этом была жива. Обходили делегированием `agentctl run`. Отметка проверки легла независимой сессией 1d6390d9.

### Осложнение

Проверка не может подняться, пока жив исполнитель, даже когда она ему не мешает. Прогон откладывается, круг проверки затягивается на каждой задаче.

### Вопрос

Какое состояние замка считает исполнителя занявшим слот проверяющего?

### Гипотеза

Замок различает исполнителя и проверяющего. Окно проверяющего живёт при живом исполнителе.

## Контекст обсуждения

Нашёл исполнитель DK-1545 на круге проверки 2026-11-01. Похоже на DK-840, там сторож холостых проходов снимает ждущего чужой замок. Здесь снимает сам замок задачи, стык может быть один.
