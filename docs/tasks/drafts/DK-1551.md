# DK-1551: журнал этапов не знает тип субагента из харнеса

записан 2026-11-01
приоритет: высокий

## Черновик

### Ситуация

Спавн субагента по определению proofread на DK-993 записан хуком hooks/agent-watch.py в журнал этапов как «разработка» по определению exec-high. Тип субагента до хука в харнесе claude-glm не доходит. Обходом строку журнала правили под факты.

### Осложнение

Этапы задачи врут о составе работы. Вычитка считается разработкой, след ревью и ворота читают журнал дальше. Правка журнала руками это ручная правка файлов вместо автоматики.

### Вопрос

Как харнесу донести тип субагента до хука?

### Гипотеза

Хук пишет определение субагента, которое назвал спавн. Пробел харнеса закрывается его стороной.

## Контекст обсуждения

Нашёл исполнитель DK-993 2026-11-01. Обход применён, журнал свёрстан под факты. Работа субагента a736e76e167ae9e1d обозначена этапом «вычитка».

## Идеи

- 2026-11-09: повторилось на DK-1661 в харнесе claude-glm: хук hooks/stagerun.py записал спавн proofread этапом разработка, subagent_type до PostToolUse не доходит; обошли строкой этапа в Ходе работы по журналу agents.log
