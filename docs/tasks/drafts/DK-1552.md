# DK-1552: повторный подъём исполнителя не видит живой заход

записан 2026-11-01
приоритет: высокий

## Черновик

### Ситуация

На DK-993 диспетчер поднял второго исполнителя по повторному pick. В это время жил конвейерный заход, окно task-DK-993, голова b643591d. Заход ожил в 21:55 и ходил до 22:16. Строка до подъёма показывала «сессии нет, брошена». Обходом второй заход остановил свой прогон стенда без отметки и уступил круг.

### Осложнение

Один круг получает двух исполнителей. Их правки и отметки сталкиваются, живой заход наследует чужие строки в файле задачи. Диспетчер решает по виду строки, хотя замок задачи называет голову конвейера.

### Вопрос

Должен ли pick отказывать при живой голове конвейера и показывать ли живой заход в строке до подъёма?

### Гипотеза

Подъём исполнителя сверяется с замком задачи. Живая голова конвейера видна в строке до подъёма.

## Контекст обсуждения

Дубль поднял диспетчер сессии 2026-11-01 по виду «брошена», без сверки замка. Связь с DK-1475, там повтор подъёма без потолка, здесь подъём поверх живого захода. Семья DK-1548, DK-1549 и DK-1550 найдена на тех же кругах.
