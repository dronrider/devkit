# DK-1553: Стенд prompt-test не измеряет сценарий 27-work-plan

записан 2026-11-02
приоритет: средний

## Черновик

### Ситуация

Движок планов DK-972 пишет план объектом с template и items, а проверка сценария ждёт голый список пунктов, поэтому сценарий красный на любой раскладке, и со старыми правилами, и с новыми. Вердикт стенда сам признаёт «сценарий не измеряет этот текст».
Второй симптом того же инструмента: прогон, пропустивший все сценарии по концу, записывает отметку «зачтён» с пустым списком сценариев, утилиты снять её нет, обходил пометкой в «Ходе работы».
Замечено при сдаче DK-993 2026-11-01, следы в файле задачи docs/tasks/DK-993.md.
