# DK-1560: Храповик машинных строк замораживает промежуточный перенос

записан 2026-11-02

## Черновик

### Ситуация

hooks/check-machine-lines.py не даёт менять soft-wrap одной и той же
машинной строки внутри одного захода: смена переноса блокируется, даже
если она возвращает строку к прежней форме. Найдено на DK-1546 при
переносе строки «Вычитка: ...», обошёл итоговой однострочной формой.
