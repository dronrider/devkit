# DK-1561: Правки вычитки не ложатся в хвосты машинных строк обходов

записан 2026-11-02

## Черновик

### Ситуация

Строки обходов «Приёмки» целиком машинные и заморожены рубежом, утилиты
доски для правки хвоста нет. Правки вычитки (два «держит» и усилитель
«уже» на DK-1546) применить нельзя. Стилистика, не блокер.
