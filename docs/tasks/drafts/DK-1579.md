# DK-1579: Отравление базы машинных строк заблокированной правкой

записан 2026-11-03
приоритет: средний

## Черновик

### Ситуация

Ревьювер DK-1570 поймал: хук check-machine-lines держит базу машинных строк, правка строки заблокировалась на PostToolUse, но база обновилась этой правкой и стала требовать несуществующую версию строки замечания. Выравнивание файла на HEAD вернуло проход. Похоже, база пишется до вердикта хука. Разобрать на груминге: где база должна стоять по порядку событий хука и нужен ли откат при отказе.
