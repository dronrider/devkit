# DK-1583: привязка дерева задачи переживает снос worktree

записан 2026-11-03
приоритет: средний

## Черновик

### Ситуация

Круг DK-919 2026-11-03. После слияния ворктри /Users/rider/projects/devkit-dk-919
снесён вместе с веткой. Субагент вычитки правит tools/dashboard/README.md в
основном чекауте, а хук hooks/check-tree-write.py запись отбивает, потому что
привязка сессии по метке DK-919 в ~/.devkit/trees всё ещё указывает на
удалённое дерево задачи.

### Осложнение

Правку пришлось применять точной заменой через Bash, то есть рубеж обойдён
руками. Всякий круг, сносящий ворктри до конца правок (вычитка, след в файле
задачи), упирается в тот же отказ, и обход становится привычкой.

### Вопрос

Кто чистит привязку при сносе ворктри, слияние или сама утилита сноса? Либо
хуку дать мягкое поведение, писать в основное дерево, когда дерево задачи на
диске уже нет.

### Гипотеза

Пользователь ждёт, что после слияния правки в основном чекауте проходят
штатной записью, без обходов.
