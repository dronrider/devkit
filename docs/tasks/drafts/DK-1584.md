# DK-1584: Бесплатные модели OpenCode доезжают до задач и чата дашборда

записан 2026-11-04
приоритет: средний

## Черновик

### Ситуация

2026-11-04 сессия идёт в OpenCode. Детект виден живьём: `OPENCODE=1` и `OPENCODE_SESSION_ID`. Пользователь спросил, можно ли добавить в дашборд OpenCode, чтобы гонять бесплатные модели. Проверено на машине несколько вещей. CLI v2.2.5 лежит в `/Applications/OpenCode.app/Contents/Resources/opencode-cli`, в PATH его нет. `opencode run --model opencode/deepseek-v4.1-flash-free --format json "..."` отвечает, `cost: 0`. `opencode models` показывает free-лестницу: `deepseek-v4.1-flash-free`, `glm-5.3-flash-free`, `mimo-v2.6-flash-free` и соседи. `opencode session export <ID>` отдаёт разговор JSON-ом. Дашборд берёт подписки и лестницу моделей у `agentctl harness --json` (`tools/dashboard/harnesses.go`). Голову задачи он поднимает по `[head]` профиля (`internal/taskhead`). Команды чата и груминга собираются claude-флагами: `--permission-mode`, `--resume`, `--name` в `tools/dashboard/chats.go` и `drafts.go`.

### Осложнение

Бесплатные модели OpenCode отдаются только клиенту OpenCode. Дока Inference API говорит, что другие клиенты получают `403` даже с ключом. Поэтому профиль `opencode-go` их не достаёт: это Claude Code на Anthropic-совместимом API подписки Go. Прокси тоже не поможет. Сейчас бесплатных моделей в дашборде нет вовсе. Даже ручной разговор оплачивается подпиской. Черновик DK-458 ждал первого повода завести профиль чужого харнеса. Повод наступил. Риск в том, что free-модели промо и недолговечны. `deepseek-v4-flash-free` уже убрали. Лимиты порядка сотни запросов в день. На таких моделях нельзя строить автоматические назначения и бюджет.

### Вопрос

Делать сразу полную поддержку или начать с запуска задач? Полная это профиль `opencode.toml` с detect, `home` через `OPENCODE_CONFIG_DIR`, правилами `embed` либо `instructions`, скиллами, `delegate` и `[head]` с `turn_end = "exit"`. Рядом общий сборщик флагов чата и груминга из профиля. Дальше читатель транскрипта через `opencode session export` или server API вместо `~/.claude/projects`. И плагин-мост OpenCode (JS/TS) к `hooks/*.py`: session-task, turn-mark, chat-in, notify, plan-watch. Протокол хуков devkit знает только `claude-code`. Профиль с headless-запуском задач это M. Чат панели это L и несколько строк.

### Гипотеза

На доске появляется подписка `opencode`. В выборе модели дашборда стоят free-модели. Задача, запущенная кнопкой, идёт headless-чередой `opencode run` без подписки. Чат панели и груминг на free-моделях приходят следом отдельными строками.
