# DK-159: taskctl add --id падает на коммите, когда черновик не был закоммичен. Оформление DK-158: файл черновика завели командой draft (она его не коммитит), потом переписали разбором, потом позвали add --id ... -m ... --push. Строка на доске завелась, файл переехал в docs/tasks/DK-158.md и попал в индекс, а команда упала: error: pathspec 'docs/tasks/drafts/DK-158.md' did not match any file(s) known to git, exit status 1. Коммита и пуша не случилось, работа осталась в индексе, доводить пришлось руками. Кандидат: в pathspec коммита класть путь черновика только тогда, когда git про него знает (git ls-files --error-unmatch либо проверка перед сборкой списка). Смежно с DK-116 (файл черновика всплыл в рабочем дереве после оформления) и DK-119 (коммит доски, собранный руками, отбивает pre-push): у всех трёх предмет один, стык оформления черновика с гитом.

## Черновик

taskctl add --id падает на коммите, когда черновик не был закоммичен. Оформление DK-158: файл черновика завели командой draft (она его не коммитит), потом переписали разбором, потом позвали add --id ... -m ... --push. Строка на доске завелась, файл переехал в docs/tasks/DK-158.md и попал в индекс, а команда упала: error: pathspec 'docs/tasks/drafts/DK-158.md' did not match any file(s) known to git, exit status 1. Коммита и пуша не случилось, работа осталась в индексе, доводить пришлось руками. Кандидат: в pathspec коммита класть путь черновика только тогда, когда git про него знает (git ls-files --error-unmatch либо проверка перед сборкой списка). Смежно с DK-116 (файл черновика всплыл в рабочем дереве после оформления) и DK-119 (коммит доски, собранный руками, отбивает pre-push): у всех трёх предмет один, стык оформления черновика с гитом.
