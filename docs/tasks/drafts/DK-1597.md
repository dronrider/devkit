# DK-1597: Калитка пуша судит чужие коммиты в диапазоне перебазированной ветки

записан 2026-11-05
приоритет: средний

## Черновик

### Ситуация

Ветка dk-1319 перебазирована на свежий main после снятия с очереди слияний. Пуш ветки в origin калитка DK-602 отбила. В диапазоне origin/dk-1319..dk-1319 лежала неделя коммитов main, среди них чужой код-коммит a8db9f9616bc. Его ID DK-1554 живёт только черновиком.

### Осложнение

rangeVerdict судит каждый коммит диапазона и не сверяется с тем, что сервер уже держит в других ссылках. ID черновика при этом не находит ни доска, ни архив. Пуш своей ветки заблокирован чужим уже опубликованным коммитом. Отказ не называет действия, которое агент может сделать сам.

### Вопрос

Сверять ли диапазон пуша с уже опубликованными коммитами и признавать ли ID черновика?

### Гипотеза

Коммиты, достижимые из origin/main, выпадают из суда калитки, а поиск ID идёт вдобавок по docs/tasks/drafts. Пуш перебазированной ветки проходит, черновиковые ссылки не ловят ложного отказа.
