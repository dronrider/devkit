# DK-1636: Запросы дашборда обрываются при смене проверки сертификатов

записан 2026-11-06
приоритет: средний

## Черновик

### Ситуация

В HAR Chrome от 2026-11-06 обнаружено 190 запросов со статусом 0 и net::ERR_CERT_VERIFIER_CHANGED. Эти запросы начались между 17:55:27,833 и 17:55:29,064. Длительность до ошибки 6,31-7,54 с. В это время шла вторая волна prepared.

### Осложнение

Запросы не доходят до успешного ответа. Это ошибка браузера, её нельзя считать обычной отменой при уходе с экрана или ответом сервера 502.

### Вопрос

Что изменило состояние проверки сертификатов в браузере? Нужны данные окружения и отдельное воспроизведение. По HAR причина не установлена.

### Гипотеза

Пользователь открывает дашборд без массовых ошибок проверки сертификатов. Сначала требуется установить воспроизводимое условие.

## Контекст обсуждения

Состояние браузера и доверенных сертификатов не менять без отдельного основания. Не предлагать отключение проверки TLS. Связь этой ошибки с нагрузкой dashboard пока не доказана. Пользователь поручил сохранить все находки, поэтому неопределённый случай записан отдельно.
