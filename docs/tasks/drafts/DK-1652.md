# DK-1652: «Чат разбора» записи открывает пустой разговор старше хвоста реестра

записан 2026-11-08
приоритет: высокий

## Черновик

### Ситуация

Кнопка «Чат разбора» ведёт на постоянный адрес записи (поправка DK-1564).
Адрес разрешается строкой журнала ~/.devkit/main-chat.log. Без строки в дело
входит миграция DK-1432, она собирает разговоры из заходов реестра
~/.devkit/sessions.log. Замечено на DK-1105. Разбор шёл 2026-10-02 в сессии
817298c9 (дом claude-glm, обход накопителя), назначение не встало, и кнопка
открывает пустую панель. Транскрипт разговора на месте.

### Осложнение

Реестр обрезается до хвоста около 500 строк, сейчас он начинается 1 ноября,
и октябрьские заходы вытеснены. Миграция берёт заходы только из реестра
(migrate.go, migSnapshot), о вытесненных она не знает. Журнал назначений
завёлся 24 октября, запись DK-1105 в него не попала. Любая запись с разговором
старше пары недель активности машины повторяет судьбу DK-1105. Поверхности
ручной привязки без кандидатов миграции у панели нет. Кнопка «Сделать
основным» живёт только на экране выбора, и для такой записи экран пуст.

### Вопрос

Как миграции видеть разговоры записей, чьи заходы ушли за хвост реестра,
и как человеку вернуть назначение, когда кандидатов у миграции нет?

### Гипотеза

Разговоры собирать и из транскриптов, список разговоров уже читает каталоги
проектов мимо реестра. Признак касания записи брать по тексту ленты. Для
пустого выбора завести ручную привязку списком разговоров проекта. Проверка
на DK-1105. После правки кнопка ведёт в разговор сессии 817298c9.
