# DK-1669: task-run валится на контракте идентичности команды головы

записан 2026-11-09
приоритет: высокий

## Черновик

### Ситуация

Цифра: 287 поломок taskctl run за неделю 2026-11-02..08 (12% вызовов), в базе за три недели до окна ноль; 11 инцидентов «ошибка конвейера» по строке DK-1 с 5 по 9 ноября.
Пример: INC-20261109-1, запуск task-DK-1655, «контракт идентичности не совпал с командой головы», диагностика осталась в снесённом временном каталоге task-run-handoff.
Мера: задача на совпадение контракта идентичности в task-run; диагностику инцидента писать в живой журнал, а не во временный дом.
