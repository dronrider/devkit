# DK-167: Скрипты сценариев проверки закрытых задач валяются в docs/tasks/. taskctl close увозит в архив только <ID>.md (ops.go, closeTask), файлы-спутники вида <ID>-check.sh остаются среди живых задач: сейчас так лежат DK-065, 066, 067, 068, 070, 093, 097. lintOrphanTaskFiles (lint.go) первым фильтром пропускает всё, что не .md, поэтому сироты копятся молча. Третья мелочь: архивные файлы зовут скрипт командой в код-блоке (sh docs/tasks/DK-065-check.sh), rewriteLinksInFile правит только markdown-ссылки, при переносе команда протухнет молча. Развилка решения: либо close увозит спутников <ID>-* вместе с файлом (и что-то делает с командой запуска в тексте), либо скрипты с постоянной ценностью (они самодостаточны, синтетическая доска) переезжают в тесты, разовые в архив. В любом варианте lintOrphanTaskFiles научить видеть не только .md.

## Черновик

Скрипты сценариев проверки закрытых задач валяются в docs/tasks/. taskctl close увозит в архив только <ID>.md (ops.go, closeTask), файлы-спутники вида <ID>-check.sh остаются среди живых задач: сейчас так лежат DK-065, 066, 067, 068, 070, 093, 097. lintOrphanTaskFiles (lint.go) первым фильтром пропускает всё, что не .md, поэтому сироты копятся молча. Третья мелочь: архивные файлы зовут скрипт командой в код-блоке (sh docs/tasks/DK-065-check.sh), rewriteLinksInFile правит только markdown-ссылки, при переносе команда протухнет молча. Развилка решения: либо close увозит спутников <ID>-* вместе с файлом (и что-то делает с командой запуска в тексте), либо скрипты с постоянной ценностью (они самодостаточны, синтетическая доска) переезжают в тесты, разовые в архив. В любом варианте lintOrphanTaskFiles научить видеть не только .md.
