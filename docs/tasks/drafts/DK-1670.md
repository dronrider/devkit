# DK-1670: Корректор квоты claude-code протух, расход подписки не виден

записан 2026-11-09
приоритет: высокий

## Черновик

### Ситуация

Цифра: снимок квоты старше 39 дней (снят 2026-09-30), при этом за неделю 2026-11-02..08 дом claude-code обслужил 26317 запросов: opus-5 12884, sonnet-5 9353, fable-5-1 4030.
Пример: DEVKIT_HARNESS=claude-code agentctl quota печатает «протух, вверх корректор не двинет» при живом расходе самого дорогого дома.
Мера: задача на возврат корректора квоты claude-code, иначе недельный разбор не видит главную статью расхода.
