# DK-1671: Простой голов переписывает кэш claude-code на 62M токенов

записан 2026-11-09
приоритет: высокий

## Черновик

### Ситуация

Цифра: 338 перезаписей префикса за неделю 2026-11-02..08, записано 62.5M токенов, из них 60.7M по причине «простой»; у glm-code за ту же неделю 2.1M, у glm-code-2 ноль.
Пример: поток a2f87aec, запрос 358 из 378: записано 524 222, чтение просело 548 716 -> 28 149, причина «простой»; рядом марафонные потоки на 600-800 запросов.
Мера: ротация голов до остывания кэша порогом agentctl rotate, гигантские головы не держать в простое.
