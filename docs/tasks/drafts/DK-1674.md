записан 2026-11-09
приоритет: высокий

## Черновик

### Ситуация

Цифра: за неделю 2026-11-02..08 без данных 1292 из 1477 этапов (87%) при пороге разбора 46%, 57 головных сессий без транскрипта в журналах харнеса claude, статья «этапы» пуста всю неделю.
Пример: spend по DK-993 печатает «нет данных, второй харнес либо журнал стёрт» на каждом этапе разработки, при этом стенд посчитал себя сам отметками раздела «Проверка».
Мера: поднять DK-1114 и DK-1112 из брошенной постановки (33 и 49 дней соответственно), дублей не заводить; до покрытия разбор расхода по правилам откладывается.
