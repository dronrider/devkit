# DK-1675: Ворота плана закрывают этапы по задаче сессии, а не по задаче работы

записан 2026-11-09

## Черновик

### Ситуация

Ворота agentctl plan done сверяют запись этапа с задачей сессии (у окна
задачи DK-1650), а работа шла по другой строке доски (DK-1664): запись
этапа разработки лежит в файле DK-1664 и в пакете runs, но plan done
отвечает «нет записи этапа» и ищет её в DK-1650. Сессия головой подняла
вторую задачу по поручению человека, план лёг на неё. Из worktree ворота
тоже не видят файл задачи: читают только главный чекаут, поэтому пункты
вычитки, сценария и обкатки не закрыть из дерева задачи ни plan done, ни
--force. Хук спавна вдобавок кладёт субагента-вычитчика этапом
«разработка». Наблюдал 2026-11-09 в сессии DK-1650 при исполнении DK-1664.
