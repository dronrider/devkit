# DK-1686: DEVKIT_EFFORT из окружения сессии краснит pick-тесты гейта

записан 2026-11-10
приоритет: средний

## Черновик

### Ситуация

Панель запускает сессию с парой DEVKIT_EFFORT (DK-1570). Переменная едет во
все подпроцессы сессии. Гейт слияния гоняет go-тесты agentctl из такой
сессии, и все pick-вердикты в тестах выходят с пометкой ручного effort и его
значением вместо дефолта. 19 тестов краснеют, main при этом зелёный.

Случай 10.11: merge DK-1679 из панельной сессии упал на go:agentctl, второй
прогон с env -u DEVKIT_EFFORT зелёный.

Хочется: пакет agentctl отвязывает пару перед прогонами (t.Setenv в тестах
или unset в обёртке CLI), и гейт из панельной сессии красным не встаёт.
Находка для приёмки DK-1570.
