# DK-1687: review audit не собирается на ветке со старыми правилами

записан 2026-11-10
приоритет: средний

## Черновик

### Ситуация

taskctl review audit берёт эталон разбора из дерева самой ветки. Ветка,
отошедшая до появления ID ARCH-NNN в общих правилах, даёт отказ «правило без
устойчивого ID: common-architecture», и отчёт не собирается. Случай 10.11:
ревью DK-1683 в worktree dk-1683, симлинка .devkit/devkit там нет.

Обход найден: DEVKIT_HOME=<основной чекаут> перед запуском.

Хочется: резолв эталона падает обратно на активный devkit, когда правила
ветки старее, и отказ называет оба дерева.
