# DK-1688: Ворота плана требуют этап разработки у ревью и вычитки

записан 2026-11-10
приоритет: средний

## Черновик

### Ситуация

agentctl plan done у ревьювера и субагента вычитки отказывает: ворота пунктов
«вычитка» и «разработка» требуют запись этапа из ~/.devkit/runs или «Хода
работы». Хук спавна вычитки запись не положил, у пункта «вычитка при правке
**/*.md» в шаблоне нет пометки «на слове агента», а сводный пункт ревью
движок классифицировал как этап «разработка», которого у ревью не бывает.
Пункты остались открытыми при сделанной работе. Случаи 10.11: планы
DK-1683-review и DK-1683-proofread. Вторая мелочь: plan done без -C читает
файл задачи из текущего чекаута и не видит строку исключения ветки.

Хочется: у ревью и вычитки свои следы этапов, сводный пункт не классифицируется
разработкой, ворота видят дерево задачи по -C.
