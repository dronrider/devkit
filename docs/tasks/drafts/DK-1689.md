# DK-1689: gofmt дрейф в tools/dashboard: семь файлов вне формата на main

записан 2026-11-10

## Черновик

### Ситуация

Ревью DK-1683 заметило: gofmt -l на main называет семь файлов пакета
dashboard (chatclip_test.go, chathold_test.go, handover.go, harnesses.go,
mainchat_test.go, quietsmoke_test.go, ring_middle_test.go). Формат копился
мимо стилевых ворот, правки самих файлов дифф DK-1683 не трогает. Хотим
одну правку gofmt -w по пакету отдельной задачей без кодовых изменений,
чтобы диффы перестали нести чужой форматный шум.
