# DK-1698: У сторожа машинных строк нет автономного режима

записан 2026-11-12

## Черновик

### Ситуация

hooks/check-machine-lines.py умеет только хук-режим: вызов с путём файла как отдельной проверкой выходит кодом 2 с руководством. Соседний check-symbols.py путь аргументом принимает, и вычитка ожидает от него того же интерфейса. Из-за расхождения сверку машинных строк вычитка делает вручную диффом git.

Найти: дать сторожу режим проверки файла аргументом, как у соседнего. Случай: DK-1695, вычитка 2026-11-12.
