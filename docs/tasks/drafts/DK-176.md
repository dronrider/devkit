# DK-176: taskctl add --link принимает путь, который потом ловит lint: ссылка в строке доски относительна docs/, поэтому естественное --link docs/tasks/DK-171.md кладёт в строку битую ссылку на docs/docs/tasks/DK-171.md. Утилита при этом молчит, находка вылезает только на taskctl lint, и чинится вторым вызовом set. Кандидат: add и set нормализуют путь от корня репозитория к docs-относительному либо отказывают с человеческой строкой. Поймано на нарезке цели DK-171 (2026-08-07), там же на --link со ссылкой на файл цели наступает каждый виток нарезки.

записан 2026-08-07
приоритет: высокий

## Черновик

taskctl add --link принимает путь, который потом ловит lint: ссылка в строке доски относительна docs/, поэтому естественное --link docs/tasks/DK-171.md кладёт в строку битую ссылку на docs/docs/tasks/DK-171.md. Утилита при этом молчит, находка вылезает только на taskctl lint, и чинится вторым вызовом set. Кандидат: add и set нормализуют путь от корня репозитория к docs-относительному либо отказывают с человеческой строкой. Поймано на нарезке цели DK-171 (2026-08-07), там же на --link со ссылкой на файл цели наступает каждый виток нарезки.
