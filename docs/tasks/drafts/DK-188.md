# DK-188: Пустой элемент в PATH машины: текущая директория попадает в поиск команд, и в общем рабочем каталоге вместо машинного бинаря зовётся оставленная копия (agentctl из прогона DK-180 молча увёл живой прогон на первую подписку). Убрать пустой элемент из профиля оболочки, а doctor мог бы ловить такое находкой.

записан 2026-08-08

## Черновик

Пустой элемент в PATH машины: текущая директория попадает в поиск команд, и в общем рабочем каталоге вместо машинного бинаря зовётся оставленная копия (agentctl из прогона DK-180 молча увёл живой прогон на первую подписку). Убрать пустой элемент из профиля оболочки, а doctor мог бы ловить такое находкой.
