# DK-189: Окно запускатора (сессия с DEVKIT_HARNESS=glm-code) получало от pick вердикт с model: - и via: -: машинная секция [glm-code] с одной обвязкой (home/env, ярусов нет, что законно по DK-177) глушит предложение маппинга map_* из профиля glm-code, и активный харнес остаётся без лестницы. Хинт при этом обманчив: советует вписать секцию [glm-code], хотя секция есть, не хватает ярусов. Ожидаемое поведение: секция без ярусов не должна выключать предложение профиля для активного харнеса, либо хинт должен называть недостающие ключи. На машине обойдено явными ярусами в [glm-code] по предложению профиля. Найдено в первом живом окне shipctl code (IRC-097).

## Черновик

Окно запускатора (сессия с DEVKIT_HARNESS=glm-code) получало от pick вердикт с model: - и via: -: машинная секция [glm-code] с одной обвязкой (home/env, ярусов нет, что законно по DK-177) глушит предложение маппинга map_* из профиля glm-code, и активный харнес остаётся без лестницы. Хинт при этом обманчив: советует вписать секцию [glm-code], хотя секция есть, не хватает ярусов. Ожидаемое поведение: секция без ярусов не должна выключать предложение профиля для активного харнеса, либо хинт должен называть недостающие ключи. На машине обойдено явными ярусами в [glm-code] по предложению профиля. Найдено в первом живом окне shipctl code (IRC-097).
