Итог: рабочий каталог исчезает из-под живого окна, расширение claude падает (ReferenceError про native binary, настоящая причина это удалённый cwd), окно дохлое, в джамплисте vscode остаётся мёртвый путь. Дизайн DK-175/DK-090 не учёл, что merge может зваться из удаляемого дерева живой интерактивной сессией. Ходы на выбор задаче: merge при cwd внутри удаляемого дерева предупреждает и советует основной чекаут, либо ключ --keep-tree с уборкой позже, либо правило в скилл/README запускатора: слияние из окна не звать, звать из основного чекаута и окно закрывать. Наблюдение с живого случая IRC-097.

## Черновик

Слияние из окна запускатора убивает окно: shipctl merge по дизайну убирает worktree и ветку, а сессия окна vscode живёт ровно в этом дереве. Итог: рабочий каталог исчезает из-под живого окна, расширение claude падает (ReferenceError про native binary, настоящая причина это удалённый cwd), окно дохлое, в джамплисте vscode остаётся мёртвый путь. Дизайн DK-175/DK-090 не учёл, что merge может зваться из удаляемого дерева живой интерактивной сессией. Ходы на выбор задаче: merge при cwd внутри удаляемого дерева предупреждает и советует основной чекаут, либо ключ --keep-tree с уборкой позже, либо правило в скилл/README запускатора: слияние из окна не звать, звать из основного чекаута и окно закрывать. Наблюдение с живого случая IRC-097.
