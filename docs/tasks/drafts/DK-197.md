## Черновик

Песочница автономного витка: команды без человека идут на живой машине

Worktree разводит рабочие деревья, но команды исполнитель автономного
витка гоняет с полными правами пользователя: permissions.allow это
список разрешений харнеса, а не изоляция, и любая команда из allow
достаёт до всего HOME. Пока цикл катает только сам devkit, риск
терпимый; при выходе на чужие проекты нужен слой изоляции на виток:
доступ только к чекауту и рабочим каталогам, сеть по списку.

Открытые вопросы к груммингу:
- чем изолировать на macOS: sandbox-exec объявлен устаревшим, контейнер
  тянет Docker или Apple container, у обоих цена в раскладке машины;
- граница песочницы: весь виток целиком или только исполнителей, а
  слияние и выкат оставить снаружи (выкату часто нужна сеть и доступы);
- как в песочницу попадают доступы, которые нужны легально (git origin,
  команда выката из .devkit/deploy.local);
- что из этого умеет сам харнес: у Claude Code есть свой sandbox для
  Bash, может хватить его включения в профиль автономного режима.
