# DK-202: devkitctl new кладёт болванку AGENTS.md, не заметив рукописного CLAUDE.md

записан 2026-08-09

## Черновик

devkitctl new кладёт болванку AGENTS.md, не заметив рукописного CLAUDE.md

Подключение готового проекта с прожитым рукописным CLAUDE.md (обычный случай,
все подключённые проекты такие) задумано двухходовкой git mv CLAUDE.md
AGENTS.md плюс doctor --fix: автоматике не разобрать локальное содержимое,
находка-подсказка вместо автопереписи это сознательное решение (LLD DK-033,
шаг 4 миграции). Обе находки doctor на месте и проверены живым прогоном
2026-08-09: без AGENTS.md печатается двухходовка, с ним «проектное перенести,
файл удалить». Но сама установка момент теряет: new проверяет только
существование AGENTS.md, рукописный CLAUDE.md не смотрит, молча кладёт
шаблонную болванку рядом и делает первый коммит. С этой секунды git mv уже не
ход: пользователю остаётся ручное слияние прозы в болванку, и подсказка
doctor меняется с переименования на перенос руками. Кандидат: new при
рукописном файле правил харнеса (CLAUDE.md без маркера devkit:generated)
не кладёт шаблон, а отказывается с подсказкой про git mv, как отказывается
при существующем AGENTS.md; либо предлагает сделать git mv сам. Смежно с
DK-193 (дорога доставки правил) и IRC-103 (живой проект на этой развилке).
