## Черновик

doctor --fix сам переносит рукописный CLAUDE.md в AGENTS.md, когда файл разбирается без остатка: каждая строка либо известный импорт devkit (генератор выпишет её заново через ссылку), либо проза, едущая в AGENTS.md как есть. Неопознанная строка (чужой импорт, корп-специфика) это отказ с сегодняшней подсказкой про git mv. Повод: раскатка DK-204 потребовала трёх ручных шагов на каждый из трёх проектов, а разбирались все три без остатка.
