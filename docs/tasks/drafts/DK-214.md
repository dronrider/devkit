# DK-214: Доска видна из любого дерева без рук. Параллельные worktree рядом с проектом

записан 2026-08-09

## Черновик

Доска видна из любого дерева без рук. Параллельные worktree рядом с проектом
(devkit-glm и подобные) стоят на detached-срезе main и отстают, когда main
уезжает: окно второй подписки открывает docs/TASKS.md и показывает старую
доску. Нужна автоматика подтяжки: коммит доски через taskctl (он и так
пушится сразу) заодно двигает чистые detached-деревья соседних worktree на
свежий main; грязные и стоящие на ветке деревья не трогаются. Ручной команды
в флоу нет, повод сегодняшний: devkit-glm отстал на четыре коммита доски.
