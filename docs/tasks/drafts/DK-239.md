# DK-239: secretctl set <имя> со скрытым интерактивным вводом значения: сейчас секрет кладётся голыми средствами бэкенда (security add-generic-password плюс файл-маркер в индексе хранилища), значение в аргументах утекает в историю консоли, а про обязательный маркер для Keychain легко забыть. Команда записи принципу цели DK-207 не противоречит: значение вводится скрытно и в контекст модели не попадает. Попутно: хук check-read-secret ложно рубит команды, где путь хранилища стоит строкой-аргументом, а не читается

записан 2026-08-10

## Черновик

secretctl set <имя> со скрытым интерактивным вводом значения: сейчас секрет кладётся голыми средствами бэкенда (security add-generic-password плюс файл-маркер в индексе хранилища), значение в аргументах утекает в историю консоли, а про обязательный маркер для Keychain легко забыть. Команда записи принципу цели DK-207 не противоречит: значение вводится скрытно и в контекст модели не попадает. Попутно: хук check-read-secret ложно рубит команды, где путь хранилища стоит строкой-аргументом, а не читается
