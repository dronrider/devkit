# DK-240: Первый прогон devkitctl corp одной командой: сейчас после подключения корп-клона остаются ручные шаги, base_url и user контура вписываются редактором в болванку ~/.devkit/tracker/<имя>.local, а префикс доски пользователь выдумывает сам. Команде стоит спрашивать base_url и user интерактивно прямо на первом прогоне (по образцу скрытого ввода токена не нужно, это не секреты) и предлагать --prefix из имени клона, чтобы подключение новой компании сводилось к одной команде и одному export токена. Повод: коллега на gateway (UCS-PLATFORM) застряла на голом клоне без обвязки, сессия без корп-правил не знала про devkitctl corp и пошла сканировать соседние репозитории в поисках доски

записан 2026-08-10

## Черновик

Первый прогон devkitctl corp одной командой: сейчас после подключения корп-клона остаются ручные шаги, base_url и user контура вписываются редактором в болванку ~/.devkit/tracker/<имя>.local, а префикс доски пользователь выдумывает сам. Команде стоит спрашивать base_url и user интерактивно прямо на первом прогоне (по образцу скрытого ввода токена не нужно, это не секреты) и предлагать --prefix из имени клона, чтобы подключение новой компании сводилось к одной команде и одному export токена. Повод: коллега на gateway (UCS-PLATFORM) застряла на голом клоне без обвязки, сессия без корп-правил не знала про devkitctl corp и пошла сканировать соседние репозитории в поисках доски
