# DK-259: Склейка рабочего флоу корп-контура: доступ к боковой директории из клона. Обратная связь коллеги: код в клоне, доска в ../<проект>-local, и флоу рвётся, окно IDE с корнем в клоне доски не видит, сессия харнеса упирается в разрешения на соседнюю директорию. Утилиты не разорваны, редирект devkit.local их уводит куда надо, чинить нужно файловый доступ. Решение: devkitctl corp кладёт симлинк .devkit/local -> ../<проект>-local (каталог .devkit уже спрятан строкой .git/info/exclude, в чужой индекс и status ничего не добавляется, git clean -xdf сносит только ссылку, а не доску), восстанавливают его повторный corp и doctor --fix, потерянный симлинк это находка doctor. Вдобавок corp дописывает боковую директорию в разрешённые рабочие директории сессии харнеса для этого проекта, чтобы агент не собирал запросы разрешений на каждое чтение доски. Отвергнутая в LLD DK-074 альтернатива «всё в дереве под exclude» не повторяется: файлы физически остаются в боковой директории со своим git, в дереве одна ссылка под уже существующей строкой exclude.

## Черновик

Склейка рабочего флоу корп-контура: доступ к боковой директории из клона. Обратная связь коллеги: код в клоне, доска в ../<проект>-local, и флоу рвётся, окно IDE с корнем в клоне доски не видит, сессия харнеса упирается в разрешения на соседнюю директорию. Утилиты не разорваны, редирект devkit.local их уводит куда надо, чинить нужно файловый доступ. Решение: devkitctl corp кладёт симлинк .devkit/local -> ../<проект>-local (каталог .devkit уже спрятан строкой .git/info/exclude, в чужой индекс и status ничего не добавляется, git clean -xdf сносит только ссылку, а не доску), восстанавливают его повторный corp и doctor --fix, потерянный симлинк это находка doctor. Вдобавок corp дописывает боковую директорию в разрешённые рабочие директории сессии харнеса для этого проекта, чтобы агент не собирал запросы разрешений на каждое чтение доски. Отвергнутая в LLD DK-074 альтернатива «всё в дереве под exclude» не повторяется: файлы физически остаются в боковой директории со своим git, в дереве одна ссылка под уже существующей строкой exclude.
