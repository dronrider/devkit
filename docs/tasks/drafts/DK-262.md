# DK-262: Приёмочный тест из сценария проверки задачи

записан 2026-08-11

## Черновик

Приёмочный тест из сценария проверки задачи

У задачи доски уже есть сценарий проверки. Естественное продолжение TDD-порядка
(виден из DK-261): исполнитель начинает с того, что переводит сценарий в
исполняемый приёмочный тест и убеждается в его красноте до реализации.
Исполнитель получает спецификацию до кода, ревьювер получает готовый критерий
«тест соответствует сценарию» вместо чтения диффа с нуля.

Развилка, которую снять до оформления: всегда ли сценарий переводим в тест.
Пользовательские сценарии (посмотреть глазами, живой прод, чужой сервис) в
автотест не едут; надо решить, где граница и что пишется в файл задачи, когда
приёмочного теста не будет.

Трогает процедуру исполнителя и board-task, поэтому отдельно от правки
test-standard.
