## Черновик

shipctl revert при непустом поезде: cmdRevert не переводит задачи поезда в Check (в cmdShip такой цикл есть), после revert-починки провала очередь освобождается, а на проде висит непроверенный поезд, по доске не видно. Либо переводить поезд в Check самому, либо отказывать с внятным разбором. Находка ревью DK-274
