# DK-277: openReviewNotes (board.go) не отличает запись «без замечаний» от открытого замечания: ревьюверская выжимка с маркером «- » без слов «исправлено»/«отклонено» ломает shipctl merge. Лечить либо форматом (без замечаний держать абзацем без маркера), либо парсер должен учитывать «без замечаний» как чистый итог.

записан 2026-08-12

## Черновик

openReviewNotes (board.go) не отличает запись «без замечаний» от открытого замечания: ревьюверская выжимка с маркером «- » без слов «исправлено»/«отклонено» ломает shipctl merge. Лечить либо форматом (без замечаний держать абзацем без маркера), либо парсер должен учитывать «без замечаний» как чистый итог.
