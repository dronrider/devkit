# DK-291: Карточка нераспознанной сессии на дашборде бесполезна: подпись «интерактивная сессия, задача не распознана» не говорит ни чьё это окно, ни чем оно занято, а зайти внутрь нельзя, потому что экран агента открывается по ID задачи, которого у такой работы нет. Место на экране она занимает (на телефоне заметно), пользы не даёт. Показ таких сессий завела DK-263 сознательно («пропавшая работа неотличима от несделанной»), и решение это верное, вопрос в том, что карточка молчит. На груминге сначала посмотреть живьём, что это за сессии вообще: узнать задачу пытаются тремя способами (каталог бокового дерева, упоминание ID в первой реплике, имя ветки, sessionTask в tools/dashboard/sessions.go), и мимо всех трёх идут как минимум диспетчерские сессии, которые ведут несколько задач сразу и ни к одной не привязаны, живой чат про devkit без ID в первой реплике и окна, начатые с произвольного разговора. По итогам решить, что с ними делать: показывать признак (первая реплика, каталог, время начала), открывать транскрипт по ID сессии, а не по ID задачи, сворачивать несколько нераспознанных в одну строку либо не считать работой ту, что задачу не назвала.
