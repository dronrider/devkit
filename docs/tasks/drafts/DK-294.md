# DK-294: dashboard: разговор живой сессии без узнанной задачи не открыть

записан 2026-08-13

## Черновик

dashboard: разговор живой сессии без узнанной задачи не открыть

В полосе живых работ вверху экрана сессия, чью задачу узнать не удалось,
стоит карточкой с подписью «задача не распознана», и карточка эта мёртвая:
экран агента открывается по ID задачи, а его-то и нет. Поймано на приёмке
DK-280: два окна начаты вольным вопросом без номера задачи, и посмотреть,
чем они заняты, неоткуда, при том что транскрипт лежит на диске и сервер про
него знает (в ответе `/api/projects` у такой работы заполнено поле `session`).

После DK-280 разговор ищется по ID задачи, и напрашивается второй вход, по id
сессии: полоса живых работ ведёт на экран агента прямо по `session`, а экран,
открытый так, шапку берёт из первой реплики вместо строки доски. Заодно
закрывается тот же случай для тех, кто вообще работает без доски.

Развилка, которую надо снять: экран агента сейчас завязан на ID задачи и
маршрутом (`#project/agent/<id>`), и журнал с tmux он ищет по нему же. Либо
маршрут учится принимать id сессии, либо заводится отдельный экран разговора.
