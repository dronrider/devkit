# DK-295: Имя LLD дашборда не сходится с ID его задачи

записан 2026-08-13
приоритет: низкий

## Черновик

Имя LLD дашборда не сходится с ID его задачи

LLD дашборда лежит в docs/lld/DK-112-dashboard.md: имя файлу дано по цели DK-112, а писала его LLD-задача DK-215. Остальные четырнадцать файлов каталога названы по ID своей LLD-задачи, а по DK-215 документ не находится. Навигация «строка -> файл» держится только ссылкой в архиве. Решить одно из двух: переименовать файл с правкой четырёх ссылок (tools/dashboard/README.md, docs/tasks/DK-112.md, архивные DK-215 и DK-244) либо записать рядом с правилом раскладки, что LLD, привязанный к цели, зовётся её ID.
