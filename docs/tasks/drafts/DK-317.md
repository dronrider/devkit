# DK-317: dashboard: нажатое действие не меняет строку задачи без обновления страницы

записан 2026-08-13

## Черновик

dashboard: нажатое действие не меняет строку задачи без обновления страницы

Кнопка «Продолжить» поднимает работу, а строка остаётся прежней: та же кнопка
на том же месте, и человек, не увидев отклика, жмёт ещё раз и получает отказ.
Смена статуса до строки тоже не доезжает без обновления страницы. По коду
startRun после ответа сервера зовёт refresh() (static/app.js:120-134), но
статус строки в этот момент ещё не изменился: агент двигает его позже, внутри
поднятой сессии. Ручки смены статуса в API дашборда нет вовсе (LLD
предусматривал POST tasks/{id}/move, в server.go она не зарегистрирована).

Хочется: сразу после удачного запуска строка показывает работу (признак
«выполняется», кнопка действия сменяется стопом), повторное нажатие
невозможно, а когда агент двигает статус, строка обновляется сама, без
обновления страницы. Проверить каждую кнопку действия: «Выполнить»,
«Продолжить», «Закрыть», «Стоп», «Оформить». Поймано пользователем
2026-08-13. Смежно DK-289 (отклик закрытия), DK-309 (молчаливые отказы
ручки).
