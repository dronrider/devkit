записан 2026-08-13

## Черновик

Событие уведомителя несёт задачу и проект полем, а не догадкой ленты

Лента дашборда привязывает событие к задаче регуляркой по тексту баннера
(notifyIDRe, tools/dashboard/notifications.go:63 и 131): событие, в чьём
тексте ID не написан, остаётся без перехода к задаче (static/app.js:2433),
хотя повод почти всегда рождается внутри работы над конкретной строкой.
Проекта в событии нет вовсе, журнал ~/.devkit/notify.log один на все доски,
и «Поднять виток» бьёт в открытый проект наугад (app.js:2667-2669).

Хочется: notify.py и его потребители пишут ID задачи и проект отдельными
полями события, лента ведёт к задаче и журналу агента с любого события, а
событие, у которого задачи правда нет (авария контура, протухшая квота),
помечено честно, а не выглядит оторванным. Поймано пользователем 2026-08-13:
не все события ленты привязаны к задаче, хотя по смыслу привязка есть у
каждого.
