# DK-330: Подсказка taskctl add не называет --accept и --barrier. После DK-298 у add появились обязательные по смыслу флаги вида приёмки, но шапка вывода без аргументов (tools/taskctl/main.go, строка 47) перечисляет прежний набор: --cost, --link, --status, --id, --reason. Про --accept и --barrier там ни слова, и узнаются они только из отказа команды («для --accept mixed нужен --barrier <ключ> из шести барьеров») либо из -h подкоманды. То же у set. Поймано на нарезке цели DK-327 (2026-08-14). Кандидат: дописать оба флага в шапку add и set вместе с закрытым списком барьеров, а тест на подсказку сверить с набором флагов, чтобы расхождение ловилось само.

## Черновик

Подсказка taskctl add не называет --accept и --barrier. После DK-298 у add появились обязательные по смыслу флаги вида приёмки, но шапка вывода без аргументов (tools/taskctl/main.go, строка 47) перечисляет прежний набор: --cost, --link, --status, --id, --reason. Про --accept и --barrier там ни слова, и узнаются они только из отказа команды («для --accept mixed нужен --barrier <ключ> из шести барьеров») либо из -h подкоманды. То же у set. Поймано на нарезке цели DK-327 (2026-08-14). Кандидат: дописать оба флага в шапку add и set вместе с закрытым списком барьеров, а тест на подсказку сверить с набором флагов, чтобы расхождение ловилось само.
