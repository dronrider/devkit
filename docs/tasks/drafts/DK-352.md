## Черновик

Дашборд. После записи черновика появляется промежуточная форма с кнопками "Добавить ещё" и "На доску". Нужно убрать эту форму, а после записи черновика пользователя должно возвращать в список черновиков, аналогично в случае создания задачи возврат идёт в список задач. Также должна быть возможность помимо просто записи черновика запустить его груминг. То есть по сути две кнопки "Сохранить" и "Сохранить и грумить".
