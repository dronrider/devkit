# DK-364: Назначение исполнителя с учётом остатков подписок

записан 2026-08-15

## Черновик

Назначение исполнителя с учётом остатков подписок

Вердикт agentctl pick разворачивает ярус в харнес статически по маппингу
машинного слоя, остаток подписки назначения в решении не участвует: 15 августа
конвейер цели DK-327 продолжал назначать исполнителей на glm-code при пустом
пятичасовом окне и падал в отказы посреди работы.

Нужен гейт перед назначением: сверять снимок квоты харнеса назначения, при
пустом окне уводить ступень на другой харнес либо ставить задачу в очередь до
сброса окна (время сброса берётся из снимка). Вторая подписка должна встать в
тот же гейт бюджета, которым agentctl budget уже держит витки цели по бакетам
claude-code.

Следующий слой, при грумминге отрезать отдельной строкой: учитывать пиковые
часы z.ai (09:00-13:00 МСК, кредиты дороже) и курс кредитов при выборе стороны.

Делается после DK-363 (съём квоты), без снимка гейту не на что опираться.
