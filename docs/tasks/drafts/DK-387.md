# DK-387: README отвечает «что это» раньше, чем «как поставить»

записан 2026-08-16

## Черновик

README отвечает «что это» раньше, чем «как поставить»

Файл открывается строкой клона, а вводного абзаца про то, что тут вообще
происходит, нет вовсе. Человеку снаружи первые пять минут решают, читать ли
дальше, и сейчас он получает команду установки раньше ответа на вопрос, зачем её
вводить. Заметно это в сравнении с плагинами вроде claude superpowers, где
линейная цепочка скиллов видна с первого экрана и понятна без чтения.

Чего хотим: короткий вводный раздел про то, чем devkit отличается от линейной
цепочки скиллов. Связь между шагами держит состояние доски, а не текст промпта,
поэтому путь переживает конец сессии, ветвится и работает при нескольких руках
сразу. Раздел ссылается на карту переходов и не пересказывает её.

Идёт после карты DK-384: вводный текст пишется проще, когда путь уже нарисован,
и ссылаться тогда есть на что.
