# DK-441: Правило языка DK-139 выбирает python по признаку «зовут путём из чекаута», а смысл у него другой: «инструмент обязан работать, когда собранных утилит devkit нет». Оси совпадали в день написания правила (05.08), а дальше разошлись: место в hooks/ само делает вызов «путём», сторож layout.py считает python в hooks/ чистым (PY_PLACES), смысловую сверку правило оставило ревью, и ревью дважды прочитало букву: hooks/inbox.py (DK-341, 651 строка, письма кладут собранные дашборд и taskctl) и hooks/notify.py (825 строк, аргументный режим зовут taskctl, shipctl и дашборд по пути с тремя копиями искателя hooks/notify.py, лента дашборда парсит его журнал по словарю полей из python). Само правило узаконило сложившееся: в LLD DK-139 notify.py назван примером «зовут путём», хотя его уже тогда звали go-утилиты, и направление зависимости go -> python по пути принято за факт природы. Замечено пользователем 2026-08-18 при разборе почтальона в LLD DK-430 (решение 3 переписано тем же днём). Что сделать: (1) переформулировать решение 1 DK-139 и раздел «Раскладка» README: язык выбирается по вопросу «обязан ли инструмент работать без собранных утилит devkit», способ вызова это следствие, хук харнеса в settings.json вправе звать go-бинарь по имени; (2) явный запрет обратной зависимости: go-утилита из tools/ не зовёт файл чекаута по пути, кроме материала kit/; (3) машинная опора в tools/devkitctl/layout.py, раз ревью не сработало дважды: находка на subprocess с именами утилит devkit из hooks/*.py, находка на строку hooks/*.py в go-коде tools/, порог длины python в hooks/ по образцу SH_LIMIT с закрытым списком исключений; сторож readme_gaps сверяет новый текст правила с проверкой. Законные обитатели hooks/ по новому признаку: git-хуки, check-*.py, corp.py, hookio.py (оговорка: тянет tools/devkitctl/harness через sys.path, оба python до сборки), quota-refresh.sh пограничен (обёртка над agentctl, без бинаря молчит с отсылкой к доктору). Переезд самих inbox.py и notify.py в go идёт своими строками: почтальон в составе DK-432, уведомитель отдельным черновиком того же дня.
