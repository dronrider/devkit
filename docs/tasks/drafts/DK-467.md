# DK-467: Маскировка токенов доктором рвёт экранирование и ломает settings.json

записан 2026-08-21

## Черновик

### Ситуация

Ситуация. doctor --fix заменяет литеральные токены в allow-правилах маской __TRACKED_VAR__. В правилах вида Bash(curl -H \"Authorization: Bearer <токен>\" ...) токен стоит перед экранированной кавычкой, и замена съедает обратную косую: остаётся __TRACKED_VAR__" без экранирования. Замечено 2026-08-21: после doctor --fix файл ~/.claude/settings.json перестал быть валидным JSON (семь таких мест), парс падал на char 4239.

Осложнение. Битый settings.json молча выключает настройки харнеса у новых сессий: хуки, разрешения, crossSessionInbound. Починено руками возвратом косой во все семь мест; окно поломки было около часа.

Вопрос. Чинить регулярку маски (не захватывать хвостовую косую) или маскировать через разбор JSON, а не текстом?

Гипотеза. Маска ставится через json-разбор строки правила, тест кормит доктору правило с экранированной кавычкой и сверяет валидность файла после --fix.
