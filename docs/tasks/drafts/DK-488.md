# DK-488: Скилл proofread разложен без pairs.md, dictionary.md и corpus.md

записан 2026-08-23

## Черновик

### Ситуация

В kit/skills/proofread четыре файла (SKILL.md, pairs.md, dictionary.md,
corpus.md), а в раскладке ~/.claude/skills/proofread лежит один SKILL.md.

### Осложнение

Вычитка идёт без пар «плохо/хорошо» и словаря, хотя SKILL.md велит их читать:
живой случай это вычитка IRC-111 в it-road-course, где субагент назвал
нехватку препятствием. devkitctl doctor --fix раскладку не дочинивает и находки про
расхождение не даёт, то есть молчит там, где молчание неотличимо от штатной
работы.

### Вопрос

Кто раскладывает спутники скилла и почему доктор не видит расхождения состава?

### Гипотеза

Раскладчик копирует только SKILL.md. Доразложить остальные файлы каталога
скилла и завести находку доктора на расхождение состава раскладки с kit/skills.
