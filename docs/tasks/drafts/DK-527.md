# DK-527: План работ субагентов пачки пишется в один файл и затирается

записан 2026-08-25
приоритет: высокий

## Черновик

### Ситуация

Ситуация: субагент ведёт план работ файлом в каталоге планов, имя собирается из
ID сессии с хвостом sub, и дашборд читает именно его.
Осложнение: диспетчер пачки поднимает субагентов пачкой, ID сессии у них один,
и планы затирают друг друга. На витке цели DK-446 два исполнителя писали в один
файл; один увёл своё в имя с ID задачи и пропал с экрана дашборда, потому что
тот такого имени не знает.
Вопрос: чем разводить планы, когда сессия одна, а субагентов несколько.
Гипотеза: имя плана берёт ID задачи или ID субагента, а дашборд собирает экран
по маске, а не по одному файлу.
