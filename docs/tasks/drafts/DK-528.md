# DK-528: Сторож тестов отбивает правку комментария, а обход режут права

записан 2026-08-25
приоритет: средний

## Черновик

### Ситуация

Ситуация: hooks/check-tests.py не пускает коммит кода без теста и сам предлагает
обход через переменную окружения перед git commit.
Осложнение: правка комментария в хуке тестом не сопровождается по существу, а
предложенная форма обхода режется правами машинного контура: команда с
префиксом переменной окружения требует одобрения человека. На витке цели DK-446
два исполнителя из двух ушли в git commit --no-verify, то есть мимо всех
рубежей сразу, а не мимо одного.
Вопрос: как дать законный обход, который не снимает остальные рубежи.
Гипотеза: свой ключ у самого хука или отдельная команда, которую права машинного
контура пропускают.
