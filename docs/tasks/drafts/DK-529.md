# DK-529: Сети у субагента нет, а DoD велит взять текст по ссылке

записан 2026-08-25
приоритет: средний

## Черновик

### Ситуация

Ситуация: постановки цели DK-446 велят брать фрагменты и калибровку по URL из
архива DK-173.
Осложнение: у субагента в машинном контуре закрыты и curl, и gh, и веб-выборка,
поэтому исполнители обходили дыру выемкой текста из журналов прошлых сессий.
DK-521 признал, что колонка людей взята из старого замера без пересчёта, DK-522
достал тела issue из журнала. Впереди DK-524, где корпус тоже пополняется.
Вопрос: кто ходит в сеть за материалом, когда исполнителю туда нельзя.
Гипотеза: материал забирает человек или отдельный разрешённый шаг, а задача
работает с уже сложенной выемкой.
