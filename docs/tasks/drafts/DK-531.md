# DK-531: Линт не видит файл задачи, у которой строка уже в архиве

записан 2026-08-25
приоритет: средний

## Черновик

### Ситуация

Ситуация: закрытие переносит строку в архив доски, а файл задачи в
docs/tasks/archive/2026. taskctl lint сверяет доску с архивом и на такой паре
молчит.
Осложнение: 20 августа четыре задачи закрывались разом, архивные копии
завелись, а обрубки в docs/tasks остались, и линт полгода звал доску здоровой.
Нашлось это со стороны: git pull на второй машине отбился о неотслеживаемые
DK-043..DK-046, потому что там те же файлы лежали россыпью. Убрано вручную
коммитом 5bbf9c61.
Вопрос: чем ловить осиротевший файл задачи, пока он не разошёлся по машинам.
Гипотеза: линту добавить сверку каталога docs/tasks с архивом доски, находка на
каждый файл, чья строка уже закрыта.
