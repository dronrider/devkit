# DK-533: Пороги prose.toml стоят на отбракованном ориентире

записан 2026-08-25

## Черновик

### Ситуация

Три порога предупреждения в kit/prose.toml калибровались по двум человеческим колонкам замера DK-446: цитаты из трекеров и первый коммит RULES.md. Приёмка DK-522 первый коммит из корпуса эталонов отбраковала, и опора у порогов colon_mid 15, argued 35 и but_not_tail 3 осталась одна. Комментарий конфига при этом всё ещё ссылается на первый коммит.

По прогону check-prose.py девять отбракованных абзацев дают хвост «а не» 4,9 на 1000 слов, рядом с агентской колонкой 4,4. Похоже, пороги стоит пересчитать по колонке трекеров и по свежим репликам пользователя, а комментарий переписать. Сходится ли новый расчёт со старым, покажет прогон по corpus.md скилла proofread.
