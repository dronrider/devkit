# DK-534: Метрика обобщения в конце абзаца ловит манеру пользователя

записан 2026-08-25

## Черновик

### Ситуация

Сторож прозы даёт на новых фрагментах корпуса DK-522 «абзац кончается обобщением» 4,5 % при пороге предупреждения 2. Фрагменты эти реплики самого пользователя из журналов сессий, то есть метрика бьёт по его привычке закрывать реплику предложением обсудить.

Тот же счётчик поднял предупреждение на SKILL.md вычитки, 5,0 % на прогоне сценария DK-524. Два срабатывания подряд на текстах, которые метрика трогать не должна, похожи на слишком узкое определение обобщения либо на низкий порог. Проверить стоит прогоном по всему живому корпусу kit/skills/prose, ожидание это ноль находок на репликах пользователя.
