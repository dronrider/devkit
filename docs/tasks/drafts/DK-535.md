# DK-535: Хук check-reread отбивает первое чтение файла у субагента

записан 2026-08-25

## Черновик

### Ситуация

Субагент, поднятый из сессии с чужим ID, получает отказ «файл уже прочитан в этой сессии» на первом же Read. Кэш чтения общий с родителем, а субагент про родительские чтения не знает и видит отказ на пустом месте. Исполнитель DK-522 обошёл его явными offset и limit в каждом Read, то есть заплатил лишними ходами.

Похоже, кэшу нужен разряд по агенту, а не по сессии: родитель и субагент читают свои файлы независимо. Проверить можно прогоном стенда с субагентом, который читает файл, уже прочитанный диспетчером, ожидание это чтение без отказа.
