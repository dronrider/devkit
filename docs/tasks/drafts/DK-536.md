# DK-536: taskctl review add из чужого дерева молча пишет в свой чекаут

записан 2026-08-25

## Черновик

### Ситуация

Ревьювер DK-533 позвал review add из основного чекаута, а не из дерева задачи. Команда нашла файл задачи по своему пути, дописала замечание в копию из старого коммита main и вышла без единого слова. Заметил ревьювер только по git status в обоих деревьях, а замечание в дереве задачи так и не появилось бы.

Изменяющие доску команды taskctl из линкованного worktree отказывают сами, тут же вышло наоборот: команда, чьё место в дереве задачи, отработала в основном чекауте. Похоже, review add стоит сверять текущее дерево с веткой задачи и отказывать при расхождении так же, как отказывают команды доски.
