# DK-537: dashboard валится в parallel.py на полном параллелизме

записан 2026-08-26

## Черновик

### Ситуация

Полный прогон ключа test (parallel.py) с умолчальными восемью воркерами
валится на компоненте go:dashboard по 10-минутному go-таймауту: 602с под
нагрузкой против 228с в одиночном прогоне, паника-дамп, стоп по первому
провалу. С -j 5 полный прогон зелёный. Похоже на нагрузочный срыв тяжёлого
go-компонента, а не на регрессию: найдено в заходе DK-168 на загруженной
машине. Если повторяется на тихой машине, это задача про таймаут go test
в компоненте раннера.
