# DK-562: Подхват реплик остаётся на python, разбор формата живёт в двух языках

записан 2026-08-28

## Черновик

### Ситуация
Свод LLD DK-430 с кодом (задача DK-540, 2026-08-28) показал: решение 3 того
документа не сделано вовсе. `taskctl chat --hook` не написан, реплики из входов
разносит `hooks/chat-in.py`, доктор пишет в settings.json его же, входы с
питоновского читателя не сняты.
### Осложнение
Формат входа разбираютдва языка: go пишет строки, python их читает и удаляет.
Правка формата требует двух согласованных правок, и разъезд ловится только
живым прогоном. Решение 3 заводилось ровно ради снятия этой цены, и цена
осталась.
### Вопрос
Переносить подхват целиком на go, как задумано решением 3, или признать
питоновский читатель постоянным и записать это отдельным решением документа.
### Гипотеза
Реплики разносит одна утилита, формат входа разбирается одним кодом, доктор
раскладывает её же, а питоновский читатель снят вместе со своими тестами.
