# DK-563: Ручки экрана документов не покрыты тестами вовсе

записан 2026-08-28

## Черновик

### Ситуация
Свод LLD DK-430 (задача DK-540, 2026-08-28) нашёл: у ручек экрана документов
(handleLldList, handleDoc, handleDocPut в tools/dashboard) своих тестов нет,
покрыт только блок «Связи» в lld_test.go. Экран LLD появился в POC цели DK-397
и описан в README дашборда той же задачей.
### Осложнение
Правка документа идёт ручкой PUT, то есть запись на диск без единой проверки
поведения. Поломка вылезет правкой живого документа, а не прогоном.
### Вопрос
### Гипотеза
Три ручки экрана документов покрыты тестами наравне с прочими ручками
дашборда: список, чтение, запись, отказы на чужой путь и на кривой запрос.
