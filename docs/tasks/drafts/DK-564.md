# DK-564: Стенд послушания не раскладывает скиллы во временный дом

записан 2026-08-28

## Черновик

### Ситуация
Заход по DK-373 (2026-08-28) завёл сценарий стенда послушания про живой вопрос
грумера и увидел: obeycheck кладёт во временный дом только kit/agents, а
kit/skills не раскладывает. Сценарий скилла проверяет текст через указатель
раскладки правил, а не через подхват скилла харнесом.
### Осложнение
Сценарии про поведение скиллов проверяют не то, что видит агент. Правка скилла
может разъехаться с проверкой, и стенд этого не заметит.
### Вопрос
### Гипотеза
Стенд раскладывает скиллы во временный дом наравне с определениями агентов, и
сценарий видит скилл тем же путём, каким его видит живая сессия.
