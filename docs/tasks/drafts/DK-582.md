# DK-582: Хуки на машине зовутся из дерева ветки, а не из main

записан 2026-08-29
приоритет: высокий

## Черновик

### Ситуация

В `~/.claude/settings.json` и в `~/.devkit/claude-glm/settings.json` команды
хуков прописаны путём `~/projects/devkit-poc-chat/hooks/...`, то есть из дерева
POC-ветки. Копия хуков в main на машине не работает вовсе.

Значит правка хука в main до пользователя не доезжает, пока ветка её не возьмёт
ребейзом либо пока доктор не перенацелит команду. Нашлось разбором DK-581,
2026-08-29, где поле реестра ожило только после коммита в ветку.

Это родня закрытой DK-549, где каталог экземпляра POC стоял в PATH демона
первым и вердикты неделю считала сборка ветки. Тот же разряд беды с другой
стороны: рабочий контур машины смотрит в дерево ветки, а не в выкаченное.

Что проверить разбором: кто и когда прописал этот путь (похоже, доктор из
дерева ветки), не осталось ли других таких же путей, и чем контур защитить от
повторения после слияния POC.
