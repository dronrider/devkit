# DK-587: devkitctl из PATH в дереве ветки молча исполняет код main

записан 2026-08-29
приоритет: средний

## Черновик

### Ситуация

Ревью DK-583, 2026-08-29. Обёртка `~/go/bin/devkitctl` это шелл-скрипт с
зашитым абсолютным путём на `~/projects/devkit/tools/devkitctl/devkitctl.py`.
`devkitctl build`, запущенный из дерева ветки `devkit-dk-583`, пересобирает
только go-бинари, обёртку не переписывает.

### Осложнение

`devkitctl corp ...` из PATH в дереве задачи исполняет код main, а не ветки.
Ревьювер поймал это только по расхождению поведения с DoD и обошёл прямым
`python3 <ветка>/tools/devkitctl/devkitctl.py`. Любое ревью или сценарий
проверки, что зовёт `devkitctl` из PATH, проверяет не тот код и молчит об этом.

### Вопрос

Обёртке идти по `git rev-parse` от cwd (в дереве devkit брать devkitctl.py
дерева), или `build` в дереве ветки должен печатать предупреждение и путь
прямого вызова?

### Гипотеза

Вызов `devkitctl` из дерева ветки devkit исполняет код этого дерева, а не
main, либо громко говорит, что исполняет чужой.
