# DK-589: Поиск из корп-клона уходит в дерево devkit через ссылку .devkit/devkit

записан 2026-08-29
приоритет: средний

## Черновик

### Ситуация

Прогон сценария DK-583, 2026-08-29. `rg --hidden --follow` из клона нашёл не
только `.devkit/docs/TASKS.md`, но и `.devkit/.devkit/devkit/docs/tasks/...`:
в боковой директории лежит ссылка `.devkit/devkit -> ~/projects/devkit` для
импортов тонкого файла, и поиск идёт по ней в весь чекаут devkit.

### Осложнение

Поиск VS Code по корп-проекту при `search.followSymlinks` выдаёт файлы devkit
(доску DK, LLD, скиллы) на каждый запрос, и чем больше devkit, тем больше
шума. Сессия Claude тем же путём видит чужие задачи как часть проекта.

### Вопрос

Класть в боковую директорию `.devkit/.gitignore` со строкой `devkit` (ripgrep
его прочтёт, а git боковой директории и так не коммитит ссылку), или увести
ссылку на devkit из `.devkit` в другое место, куда поиск не заходит?

### Гипотеза

Поиск из клона находит доску и файлы задач проекта и не находит файлы devkit.
