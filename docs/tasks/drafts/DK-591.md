# DK-591: regcheck выдаёт «тест не проходит» при ненайденной команде

записан 2026-08-29
приоритет: средний

## Черновик

### Ситуация

Если команды тестов нет в PATH субагента (cargo без ~/.cargo/bin), regcheck глотает command-not-found с пустым выводом (0 байт в cmdout) и ставит диагноз «тест не проходит на текущем коде». Должен различать «красный тест» и «не смог запустить».
