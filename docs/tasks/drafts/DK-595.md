# DK-595: Игнор cmdout не матчится из корня проекта

записан 2026-08-29
приоритет: средний

## Черновик

### Ситуация

Путь .devkit/cmdout/ в gitignore вложенного каталога .devkit/devkit описывает каталог внутри него, а не корень репозитория. Мусор обёртки болтается untracked, worktree задачи не убирается автоматически.
