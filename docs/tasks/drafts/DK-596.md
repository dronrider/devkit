# DK-596: regcheck --inline роняет разбор файла с mod tests: не находит скобку

записан 2026-08-29

## Черновик

### Ситуация

Разбор inline-региона падает синтаксической ошибкой на файле, где тесты
лежат вложенным модулем: regcheck сообщает, что не нашёл закрывающую скобку
mod tests. Воспроизводится на чистом main без правок, например на
xr-core/src/sync.rs. Ручной эквивалент (перенос теста на main, краснота
компиляцией) работает, то есть дефект именно в парсере границ региона.
