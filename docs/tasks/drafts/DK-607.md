# DK-607: regcheck молча валит команду с присваиванием среды после -- и выдаёт ложную красноту

## Что происходит

Команда тестов с префиксом среды, например `PATH=$HOME/.cargo/bin:$PATH
cargo test --workspace`, после `--` в regcheck падает с пустым выводом,
и утилита отчитывается «тест не проходит на текущем коде». Причина в способе
запуска: argv уходит в exec целиком, а присваивание среды это синтаксис
оболочки, исполняемого файла с таким именем нет. Пустой вывод при этом
не отличен от честного падения тестов, и читатель верит красноте.

## Чего хотим

Regcheck либо запускает команду через оболочку, либо называет причину
пустого вывода («команда не нашлась») и не считает её краснотой тестов.
Шаблон команды из .devkit/deploy.local с PATH= заработал бы без правки
на вызывающей стороне.
