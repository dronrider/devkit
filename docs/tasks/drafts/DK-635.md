# DK-635: devkitctl parallel: потолок теста убийства компонента валит merge

записан 2026-08-31
приоритет: высокий

## Черновик

### Ситуация

Тест test_term_proof_component_is_killed_harder (tools/devkitctl/parallel_test.py) меряет стенные секунды с потолком 10, а подопытный подпроцесс спит 30. На машине с load average под 70 (полный параллельный прогон плюс соседние деревья) выходит 11-13 секунд, и любой shipctl merge падает, хотя настоящий инвариант «компонент умер по KILL, до метки не дожил» держится. Поодиночке тест проходит за 4-5 секунд. Лечить поднятием потолка до 20 или замером не стенными секундами. Всплыло на слиянии DK-428, три захода подряд.
