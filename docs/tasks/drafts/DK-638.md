# DK-638: devkitctl parallel: компонент go:dashboard упирается в потолок go test

записан 2026-08-31
приоритет: средний

## Черновик

### Ситуация

Пакет tools/dashboard идёт 1060 секунд в одиночку и зелен, а parallel.py гоняет его с умолчательным потолком go test 600 секунд, и компонент падает по таймауту на любом полном прогоне. Обход: одиночный прогон с -timeout 25m. Чинить потолком в команде компонента или дроблением пакета. Всплыло на DK-582.
