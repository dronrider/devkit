# DK-639: План субагента: имя файла общее у параллельных исполнителей

записан 2026-08-31
приоритет: средний

## Черновик

### Ситуация

План субагента пишется в ~/.devkit/plans/<ID сессии>-sub.json, и у двух параллельных субагентов одной сессии имя совпадает: чужой исполнитель перезаписал план соседа по ходу работы. Обход: субагент уводит план в файл с суффиксом задачи. Чинить именованием по ID субагента или задаче. Всплыло на DK-452.
