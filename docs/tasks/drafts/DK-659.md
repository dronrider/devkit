# DK-659: сторож прозы находит обобщение внутри слова

записан 2026-08-31
приоритет: средний

## Черновик

### Ситуация

При записи черновика DK-658 сторож check-prose.py посчитал фразу «про
комментарии есть строка» концовкой-обобщением и перевёл файл за порог
блокировки. Шаблон FINAL_RE в hooks/check-prose.py:78 ищет «и есть» без
границ слова, и хвост «комментарии» дал совпадение.

### Что показал разбор

Прогон FINAL_RE (hooks/check-prose.py:78) по пробным фразам 2026-08-31: границ
слова нет ни у одной из восьми примет, и ложное совпадение дают ещё четыре.
«то есть» ловится в «что есть», «значит» в «значительно» и в «обозначит»,
«вот и» в «вот их», «именно» в «именной». Фраза «у ссылки есть цель» ловится
на «и есть» тем же манером, что и «про комментарии есть строка».

Дубля по доске нет. DK-622 правит текст находки того же сторожа, DK-541 считает
двоеточия строк ранга, DK-592 судит контекст диффа, предмет у всех трёх свой.
Задача DK-550 закрыта на том же файле и служит якорем ранга.

Соседним боком лежит доля: метрика считает абзацы текста, и на трёх абзацах
одно попадание даёт 33% при пороге блокировки 6%. Тест калибровки
(hooks/check_prose_test.py:446) метрику aphorism из проверки уже вынул, шаг на
корпусе 4,8% против порога 2%. Границы слова этой половины не снимают.

### Осложнение

Примета блокирующая, и одного ложного совпадения на три абзаца хватило для
порога. Автор перестраивает невинную фразу под сторож, правка 905c71ee ушла
отдельным коммитом.

### Гипотеза

Приметы сторожа совпадают только по целым словам, фраза «про комментарии есть
строка» проходит без находки.
