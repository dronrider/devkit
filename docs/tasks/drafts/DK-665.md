# DK-665: сторожевой тик проверяет условие скриптом, модель зовётся по делу

записан 2026-08-31
приоритет: низкий

## Черновик

### Ситуация

Сторожа и циклы (надзор цели, тики парковки) будят модель по расписанию
проверить, не изменилось ли что. Замечено на разборе трат 2026-08-31.

### Осложнение

Тик «ничего не изменилось» стоит полного входа модели с резидентным ядром, а
срабатывания в большинстве тиков нет. Фон капает в ту же недельную квоту, что
и рабочие задачи.

### Вопрос

Какие проверки сводимы к скрипту без модели (статусы доски, наличие файла,
git log), а каким нужно суждение.

### Гипотеза

Условие проверяет скрипт, модель поднимается только на срабатывание, холостые
тики квоты не тратят.
