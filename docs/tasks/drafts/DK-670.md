# DK-670: Тест порога свежести снимка флачит на секундах :58-:59 из-за усечения

записан 2026-08-31
приоритет: низкий

## Черновик

### Ситуация

TestQuotaStaleConfigured (DK-633) пишет taken с усечением до минуты, и при
запуске на последних секундах минуты возраст пятиминутного снимка успевает
перевалить за шесть минут даже с тёплым кэшем сборки, вероятность порядка
трёх процентов. Нашлось при починке красноты в DK-642 (там же добавлен
прогрев сборки перед замером). Хочется либо секунды в taken тестового
снимка, либо запас порога в тесте.
