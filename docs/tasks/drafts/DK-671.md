# DK-671: Ворот «Сценарий проверки» читает файл задачи из ветки до ребейза

записан 2026-08-31
приоритет: средний

## Черновик

### Ситуация

Прогон DK-641 показал: раздел дописан и закоммичен в main, а shipctl merge
всё равно отказывает «нет раздела», потому что ворот читает файл задачи из
дерева ветки до ребейза. После git rebase main в worktree ворот пропускает.
Поведение объяснимо, но снаружи читается ложным отказом. Хочется, чтобы
ворот смотрел и в main, либо отказ называл, где искал и что ребейз может
снять находку.
