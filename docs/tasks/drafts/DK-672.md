# DK-672: Разлив внутри close спотыкается на доске вне гита

записан 2026-08-31
приоритет: низкий

## Черновик

### Ситуация

На синтетической доске без git init каждый taskctl close печатает
«предупреждение: разлив упал: fatal: not a git repository». Воротам закрытия
это не мешает, но строка пугает и в стендах будет всегда. Хочется молчания
разлива на негитовой доске.
