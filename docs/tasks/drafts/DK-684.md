# DK-684: Шаг сценария с бинарём devkit падает в чистом PATH обкатки

записан 2026-09-01
приоритет: высокий

## Черновик

### Ситуация

Обкатка DK-682 упала с command not found: шаг зовёт agentctl, а чистый PATH
прогона каталоги релиза не несёт. Сценарии задач devkit почти все зовут его
утилиты, и обкатка таким шагам недоступна. Хочется, чтобы прогон обкатки
собирал утилиты из дерева либо добавлял в PATH каталог релизных бинарей, а
отказ называл, чего не хватило.
