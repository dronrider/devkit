# DK-717: regcheck: пути --tests считаются от корня репозитория, README молчит

записан 2026-09-02
приоритет: низкий

## Черновик

### Ситуация

Вызов regcheck -C tools/dashboard --tests testdata/poc_ringwake.mjs отвечает
«тестовый файл не найден в рабочем дереве»: в tools/regcheck/check.go:328 путь
склеивается с корнем репозитория (filepath.Join(root, t)), а -C задаёт только
каталог команды. До цели доводит автопоиск тестов. Либо считать --tests от
каталога -C, либо назвать единицу пути в README regcheck. Нашёл ревьювер DK-711.
