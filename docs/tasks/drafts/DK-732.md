# DK-732: Стенд poc_chatarch.mjs не подключён к прогону, а README говорит обратное

записан 2026-09-03
приоритет: средний

## Черновик

### Ситуация

Стенд tools/dashboard/testdata/poc_chatarch.mjs не зовётся ни из одного go test, хотя README дашборда уверяет, что его держит chatarch_test.go. Мёртвый стенд никого не сторожит, а читатель считает область покрытой.

Хуже, что первый блок стенда падает уже на текущем коде, до всякой правки: chatState пришпиливает к списку первую строку набора как текущий разговор, когда адрес панели ни с чем не совпал, и ожидание «ровно два неубранных чата» ломается.

Всплыло на DK-726, исполнитель обошёл находку, не трогая чужой блок. Разобрать надо оба конца: подключить стенд к прогону либо убрать вместе со строкой README, и решить, права ли пришпиленная строка.
