# DK-735: Шаблон CLAUDE.md в info/exclude корп-клона прячет doc/claude.md на macOS

записан 2026-09-03
приоритет: средний

## Черновик

### Ситуация

devkitctl corp пишет в .git/info/exclude клона строку CLAUDE.md без ведущего
слэша. На задаче CP-001 2026-09-03 в клоне cozyphi исполнитель добавил
doc/claude.md, и на регистронезависимой ФС macOS git счёл файл исключённым:
git add промолчал, файл добавился только через git add -f.

### Осложнение

Легальный файл проекта пропадает из индекса молча, коммит с докой выходит
неполным, а причина видна только по git check-ignore. На любом корп-клоне с
файлом claude.md в любом каталоге это повторится.

### Вопрос

### Гипотеза

Шаблон в exclude стоит с ведущим слэшем (/CLAUDE.md) и прячет только корневой
файл обвязки, а doctor находит старый шаблон без слэша и чинит его.
