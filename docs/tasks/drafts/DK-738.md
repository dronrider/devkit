# DK-738: Обкатка рвёт ограждённый блок сценария построчно

записан 2026-09-03
приоритет: низкий

## Черновик

### Ситуация

taskctl rehearse читает блок ```sh``` из «Сценария проверки» и гонит каждую физическую строку своим sh -c, без общего состояния. Многострочный скрипт разваливается: переменные не переживают строку, heredoc рвётся посередине, и строка вроде «const RealDate = Date» уходит отдельной командой с ответом «command not found».

Автору шага остаётся укладывать всё в одну физическую строку, например через node -e с длинной строкой, и это ухудшает читаемость сценария ради обхода парсера.

Всплыло на DK-733. Разобрать надо, чем считать шаг: блоком целиком или строкой, и как тогда быть с многошаговыми блоками, где строки сейчас честно идут отдельными шагами.
