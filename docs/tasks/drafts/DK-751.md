# DK-751: ревью, заказанное на fable, молча исполняется flash

записан 2026-09-03
приоритет: высокий

## Черновик

### Ситуация

agentctl pick в сессии glm-code выдаёт модели glm-именами. Это glm-5.3 и
glm-5.3-flash. Параметр model инструмента Agent принимает только алиасы первой
лестницы, sonnet, opus, haiku, fable. glm-имена в этот перечень не входят.

Диспетчер переводил glm-5.3 в fable, набралось 8 вызовов. Транскрипты xr-proxy
лежат в сессиях 241619c6, 2304fe5d, 405d126a. Переменной
ANTHROPIC_DEFAULT_FABLE_MODEL у клиента glm-профиля нет. Алиас уходил на провод
как claude-fable-5(-1). Сервер z.ai обслуживал его glm-5.3-flash. Это видно по
полю model в subagents/agent-*.jsonl.

Проба 2026-09-03 подтверждает лекарство. С переменной
ANTHROPIC_DEFAULT_FABLE_MODEL=glm-5.3 клиент разворачивает fable в glm-5.3.
Подмена sonnet через ANTHROPIC_DEFAULT_SONNET_MODEL работает, в транскриптах
стоит resolvedModel glm-5.3.

### Осложнение

Ревью заказывали на самой сильной модели. Исполняла их лёгкая, молча. Качество
каждого ревью вышло ниже оплаченного яруса.

### Вопрос

Чинить инструкции диспетчерских скиллов, переменную ANTHROPIC_DEFAULT_FABLE_MODEL
в env профиля или обе меры разом. Правило для инструкций расшифровывается легко.
glm-5.3 значит вызов без параметра модели. glm-5.3-flash значит haiku. Чужой via
значит agentctl run. Отдельный вопрос, как разносятся установленные копии
скиллов.

### Гипотеза

Модель из первой строки вердикта pick доезжает до исполнителя на любой ступени.
В транскрипте субагента стоит именно она.
