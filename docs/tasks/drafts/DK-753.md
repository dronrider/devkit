# DK-753: Строка уровня ревью несёт sha доски, когда код в другом репозитории

записан 2026-09-03
приоритет: средний

## Черновик

### Ситуация

`taskctl review level` записал в файл задачи строку «Уровень 3 до a343fb4», и
a343fb4 это вершина репозитория доски. Дерево ревью при этом было клоном кода
с совсем другой вершиной. Поймано 2026-09-03 на задаче проекта cap_autotests,
где доска лежит боковой директорией корп-контура.

### Осложнение

Sha в этой строке нужен второму кругу ревью, он строит от него дифф до текущего
HEAD кода. От вершины доски такой дифф не строится. Ревьювер второго круга тогда
либо перечитывает весь дифф ветки, либо берёт границу на глаз. В корп-контуре
доска отделена от кода всегда, и строка бесполезна на каждой задаче.

### Вопрос

Откуда брать вершину кода, из привязки `tracker.local` по ключу repo, из
рабочей директории вызова или новым ключом команды?

### Гипотеза

Строка уровня несёт вершину дерева, по которому шло ревью, и второй круг строит
от неё дифф.
