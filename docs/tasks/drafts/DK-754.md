# DK-754: Сторож прозы считает раздел «Ревью» файла задачи прозой автора

записан 2026-09-03
приоритет: низкий

## Черновик

### Ситуация

Файл задачи с одиннадцатью замечаниями ревью даёт среднюю длину предложения
146 слов и обобщение в каждом пятом абзаце. Замечания туда пишет
`taskctl review add` одной строкой на замечание, форма их машинная. Поймано
2026-09-03 на задаче проекта cap_autotests.

### Осложнение

DK-550 вывела из счёта «Ход работы», «Ранг» и «Выкат», а «Ревью» осталось.
Отработавший замечания автор получает на коммите разбор о том, что его проза
сбилась на шаблон, хотя ни одной своей фразы в этих строках нет. Совет «резать
надвое» применить не к чему, и разбор приучает пропускать вывод сторожа мимо
глаз.

### Вопрос

Выводить из счёта весь раздел «Ревью» или только строки, начинающиеся ярусом
(`блокирует:`, `не блокирует:`) и строку уровня?

### Гипотеза

Файл задачи с машинными замечаниями проходит сторожа прозы, а разбор считает
только то, что писал человек.
