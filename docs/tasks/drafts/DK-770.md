# DK-770: Команды с cd не проходят классификатор и требуют человека

записан 2026-09-03
приоритет: низкий

## Черновик

### Ситуация

Автономная сессия встаёт на обычном поиске по коду, если команда начинается с cd: путь после него классификатор не определяет, поверх стоит запрет на чтение, и решение остаётся за человеком. Права машинного контура тут ни при чём, они разложены.

Всплыло на DK-724, где конвейер простоял двенадцать минут на «cd ~/projects/devkit && grep -rn ...». Видимость такого стопа чинит DK-765, а сам стоп остаётся: агент, пишущий команды привычным образом, будет упираться в него снова.

Разобрать надо, как готовить команды, чтобы классификатор их понимал. Похоже, дорог две: звать из корня без cd, ключами самих утилит вроде git -C и go test с путём, либо научить раскладку понимать связку cd с последующей командой. Первая дешевле и лечится словами в правилах, вторая надёжнее.
