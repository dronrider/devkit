# DK-777: Разлив поезда отказывает только на своих незакоммиченных файлах

записан 2026-09-03
приоритет: средний

## Черновик

### Ситуация

`shipctl ship` перед работой требует чистого рабочего дерева целиком. 2026-09-03 в 18:50 отказ пришёл на незакоммиченном DK-724.md сессии проверки, с 20:23 до 20:43 на DK-771.md сессии мелкого фикса. Обе сессии по правилам работают в основном чекауте, файл задачи у них лежит правленым весь ход.

### Осложнение

Поезд с DK-758 не разливался всё время, пока соседняя сессия держала свой файл задачи незакоммиченным. Ship сам пишет только доску и файлы задач своего состава, чужой файл ему ни к чему.

### Вопрос

Считать конфликтом только доску и файлы задач из состава поезда или ещё и код вне docs/. Код вне docs/ в дереве при ship значит, что кто-то правит main мимо ветки, и это отдельный сигнал.

### Гипотеза

Разлив идёт при чужих незакоммиченных файлах задач в основном чекауте и отказывает, когда незакоммичен файл из его собственного состава или доска.
