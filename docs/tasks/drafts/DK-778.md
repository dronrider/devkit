# DK-778: Задача после «выкат прошёл, доска не переведена» чинится одной командой

записан 2026-09-03
приоритет: низкий

## Черновик

### Ситуация

2026-09-03 DK-758 осталась в In progress после успешного деплоя поезда. Тег deployed сдвинут, запись о выкате в файле задачи не сделана. Способа довести строку до Check штатной командой нет, `shipctl status` показывает её как «выкат на проде за ушедшими из Check».

### Осложнение

Строку чинят руками в файле задачи и на доске, запись о выкате дописывают по памяти. При повторе случая каждый чинит по-своему.

### Вопрос

Отдельная команда `shipctl` или повторный `ship`, который видит задачу в окне выката за тегом без записи и дописывает её. Зависит от того, как ляжет проверка ворот до деплоя.

### Гипотеза

Задача, чей код уехал с поездом без перевода доски, доводится до Check одной командой с записью о выкате в файле.
