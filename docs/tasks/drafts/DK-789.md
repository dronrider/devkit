# DK-789: Обкатка сценария не видит файл задачи из дерева ветки

записан 2026-09-04
приоритет: средний

## Черновик

### Ситуация

taskctl rehearse гоняет шаги от основного чекаута и его HEAD, а файл задачи
по ходу работы живёт в дереве ветки. Обкатка оттуда отвечает «нет раздела
Сценарий проверки», хотя раздел написан.

Обойти можно двумя дорогами, и обе кривые. Копия файла задачи в основном
чекауте разводит две копии одного текста. В DK-784 это кончилось конфликтом
ребейза на ровном месте. Пометка исключения гасит ворот и отменяет обкатку
целиком.

Отдельно стоит случай, когда шаги судят выкаченное. До слияния они красные
по определению. Обкатка на HEAD таким шагам не подходит.

Вопрос: должна ли обкатка уметь дерево задачи, и что делать со сценарием,
который судит выкаченное.

Гипотеза. Дать rehearse ключ дерева, как он есть у regcheck. Сценарию,
который судит выкаченное, завести признак вместо исключения. Такой
прогоняется после выката и в обкатке не участвует.
