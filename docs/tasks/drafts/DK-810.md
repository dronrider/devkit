# DK-810: Замена, которую предлагает рубеж cd-связки, местами ломает команду

записан 2026-09-05
приоритет: средний

## Черновик

### Ситуация

Рубеж отбивает связку cd со второй командой и предлагает готовую замену. Замена не всегда рабочая: глобы она берёт в кавычки, и получается wc -l '*.go', а heredoc рвёт, оставляя cat >> файл << EOF без тела. Исполнитель на DK-696 обошёл это, переписывая команды руками с абсолютными путями.

Сам рубеж верный, ловит настоящую беду: связка с cd подвешивала автономные сессии на вопросе разрешения. Но подсказка, которой нельзя воспользоваться дословно, учит не читать подсказку, а отмахиваться от неё.

Разобрать надо, что подсказке делать в этих случаях. Похоже, честнее не предлагать готовую строку там, где перенос неоднозначен, а называть приём словами: абсолютный путь в аргументе, ключ утилиты вроде git -C, одинокий cd отдельным вызовом.
