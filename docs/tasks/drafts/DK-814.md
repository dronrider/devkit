# DK-814: check-symbols отбивает коммит образца в testdata с эмодзи

записан 2026-09-05
приоритет: средний

## Черновик

### Ситуация
Хук pre-commit не пропустил `hooks/testdata/claude-code/transcript-usage.jsonl`
за эмодзи внутри реплики пользователя, хотя `hooks/README.md` обещает пропуск
каталогов `testdata`. Поймано 2026-09-05 на разработке DK-803, обход был в том,
что образец урезали до ходов ассистента.
### Осложнение
Живой транскрипт как образец теста завести нельзя: любой хук, который читает
чужой формат, тащит в тесты выдуманные данные вместо снятых с прогона. Автор
правки либо режет образец до неузнаваемости, либо гасит сторожа целиком.
### Вопрос
Правило пропуска сломано у самого хука или обещание README расходится с
раскладкой путей?
### Гипотеза
Образец под `testdata` коммитится как снят, а сторож символов смотрит только на
текст, который писали руками.
