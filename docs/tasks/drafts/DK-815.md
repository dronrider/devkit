# DK-815: doctor из дерева задачи меряет карман ядра чужим файлом правил

записан 2026-09-05
приоритет: средний

## Черновик

### Ситуация
`devkitctl doctor -C <дерево задачи>` считает вес резидентной части по импорту
глобальной точки, то есть по `~/projects/devkit/RULES.core.md`, а не по
`RULES.core.md` того дерева, откуда позван. Поймано 2026-09-05 на DK-803, где
ядро правилось в ветке: исполнитель считал длину отдельной командой.
### Осложнение
Правка ядра идёт веткой, а сторож порога кармана в этой ветке слеп. Перебор
всплывает уже на слиянии красным `rules_test`, когда правка вычитана и прогнана
стендом, и переписывать приходится всё вместе с повторным прогоном.
### Вопрос
Доктор берёт файл из дерева всегда или только при явном ключе?
### Гипотеза
Карман ядра считается по тому файлу правил, который лежит в дереве вызова, и
перебор виден до коммита.
