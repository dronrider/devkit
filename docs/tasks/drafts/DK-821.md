# DK-821: Ворот тестов shipctl merge узнаёт стенды testdata/*.mjs дашборда

записан 2026-09-05
приоритет: средний

## Черновик

### Ситуация

Слияние DK-817 2026-09-05. shipctl merge отбил ветку словами «в диффе ветки против main нет тестовых файлов». Правка дашборда шла вместе с переведённым стендом tools/dashboard/testdata/poc_draftlock.mjs, и regcheck подтвердил его красноту на main. Предикат isTestFile в tools/shipctl/advice.go знает суффиксы _test.go, _test.py, _test.sh, _test.rs, префикс test_ и каталоги tests/ и src/test. Каталог testdata со стендами .mjs под go-обёртками он не знает.

### Осложнение

У дашборда экранная часть проверяется стендами testdata/poc_*.mjs, go-обёртка при этом не меняется. Пометка «Исключение: тесты» тут врёт по смыслу, тест у правки есть. Каждая такая правка отбивается воротом, и исполнитель либо ставит эту пометку, либо правит обёртку ради ворот. На DK-817 ушёл лишний коммит с пометкой.

### Вопрос

Считать тестом любой файл в testdata, или только стенды .mjs, у которых есть go-обёртка в том же пакете?

### Гипотеза

Правка с изменённым стендом testdata/*.mjs проходит ворот тестов без пометки-исключения.
