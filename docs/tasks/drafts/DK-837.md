# DK-837: Слитая задача не пушится: рубеж ревью ищет след не там

записан 2026-09-06
приоритет: высокий

## Черновик

### Ситуация

После слияния ветка задачи удаляется, и рубеж пуша перестаёт видеть след ревью. Строку уровня он ищет в файле задачи только пока стоит на ветке задачи, а на main переходит к заметке git. Заметку же в проекте с доской поставить нечем: ярлык обязан быть ID с доски, а для ID с доски команда пишет в файл задачи, не в заметку.

Выходит замкнутый круг. Код DK-716 слит в main, ревью прошло восемью кругами, вердикт «принято» записан в разделе «Ревью», а git push отбит словами «нет следа ревью у кода в диапазоне». Обхода изнутри нет, остаётся прямая команда человека с переменной.

Всплыло на DK-716, когда слияние прошло, а пуш не успел: сеть пропала между ними, и push поехал отдельным ходом уже с main.

Разобрать надо, где рубежу искать след слитой задачи. Похоже, по ID в subject коммитов диапазона: они там есть у каждого, и по ним же рубеж уже проверяет, что код не безымянный.
