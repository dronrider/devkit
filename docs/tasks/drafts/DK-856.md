# DK-856: Обкатка сценария рвёт шаг с переносом строки на обрывки

записан 2026-09-07
приоритет: средний

## Черновик

### Ситуация
`taskctl rehearse` берёт из блока `sh` каждую строку отдельным шагом. Шаг DK-851, записанный в три строки с обратным слэшем на конце, поехал тремя прогонами: первая строка прошла, две следующие упали с `syntax error near unexpected token &&`. Поймано 2026-09-07 на обкатке DK-851, сценарий пришлось переписать по строке на шаг.
### Осложнение
Ворота `move check` красные без вины сценария, а вывод обкатки в «Проверке» показывает обрывки команд. Автор сценария правило «одна строка на шаг» узнаёт только по провалу, README обкатки его не называет.
### Вопрос
Склеивать продолжения с обратным слэшем в один шаг или отбивать такой блок отказом с подсказкой до прогона?
### Гипотеза
Обкатка склеивает продолжения сама, как это делает shell, а README называет границу шага. Красный прогон тогда значит красный сценарий.
