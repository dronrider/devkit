# DK-857: Рубеж cd-связки предлагает замену с потерянными кавычками

записан 2026-09-07
приоритет: средний

## Черновик

### Ситуация
Хук `hooks/check-cd-compound.py` отбивает `cd tools/dashboard && fix=$(git log ... --grep='DK-851' ...)` и печатает замену. В замене кавычки и подстановка пропали: `fix=$git -C ... --grep=DK-851`, `$fix^:...` без экранирования. Поймано 2026-09-07 проверяющим DK-851, шаг он гонял руками через `git -C`.
### Осложнение
Замена несёт вид готовой команды, а в таком виде не запускается. Агент либо верит ей и получает ошибку shell, либо чинит руками, и рубеж вместо экономии хода добавляет заход. Сценарий проверки в файле задачи при этом стоит в виде, который рубеж не пропускает, хотя обкатка его гоняет зелёным.
### Вопрос
Чинить сборку замены (кавычки, подстановки) или отдавать замену только простым связкам, а сложные отбивать без подсказки?
### Гипотеза
Замена собирается через shlex с сохранением кавычек, а связка с подстановкой команд остаётся без подсказки: честное «переписать руками» лучше ложной готовой команды.
