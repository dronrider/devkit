# DK-873: agentctl plan set кладёт весь план одним пунктом

записан 2026-09-08
приоритет: средний

## Черновик

### Ситуация

Замечено 2026-09-08 исполнителем DK-571. Многострочный план кладётся командой
`agentctl plan set "первый\nвторой"`, и литерал `\n` в аргументе командой не
разворачивается: все строки склеиваются в один пункт. Исполнитель обошёл
подстановкой перевода строки через `printf`.

### Осложнение

Снаружи такая сессия выглядит работой без плана: кольцо в шапке разговора
рисуется одним делением, блок «План агента» показывает простыню, и человек не
видит, на каком шаге заход. Наступает на это всякий, кто собирает план в одну
строку, а не heredoc.

### Вопрос

Разворачивать ли `\n` в аргументе самой командой или отбивать такой аргумент
подсказкой про heredoc.

### Гипотеза

План, собранный любым из двух способов, ложится одинаково пунктами.
