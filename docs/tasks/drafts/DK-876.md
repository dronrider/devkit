# DK-876: Песочница стенда зовёт утилиту с машины, а не из проверяемого дерева

записан 2026-09-08
приоритет: средний

## Черновик

### Ситуация

Стенд obeycheck поднимает сессию в песочнице и меряет, как агент себя ведёт по
правленому тексту. Утилиты агент зовёт из PATH машины.

### Осложнение

Правка задачи заводит у утилиты новый ключ, и в песочнице его нет. Бинарь там
старый, из установленной раскладки. Кандидат краснеет на строке «flag provided
but not defined», а промпт тут ни при чём. По ходу DK-864 это вылезло дважды,
и обходили руками, сборкой taskctl ветки во временный каталог и подстановкой
его первым в PATH прогона.

### Вопрос

Кто собирает бинари проверяемого дерева для песочницы, сам стенд или тот, кто
его зовёт?

### Гипотеза

Стенд собирает утилиты из чекаута --devkit во временный каталог и кладёт его в
PATH песочницы сам. Тогда прогон меряет промпт, и разница версий бинаря на
вердикт не влияет.
