# DK-889: Полка «ждут ответа» держит архивные и уже отвеченные чаты

записан 2026-09-09
приоритет: высокий

## Черновик

### Ситуация

Кнопка «ждут ответа» в шапке дашборда, полка DK-696. Обработчик
`handleWaitShelf` лежит в `tools/dashboard/waitshelf.go`. Замечено 2026-09-09
на живом дашборде машины. В списке стоят разговоры, уже убранные в архив.
Там же стоят разговоры с давно закрытым вопросом, отвечать по ним нечего.
Полка собирает записи из строк доски через `waitLookup` и из обхода файлов
`.ask` в корне чатов проекта через `askScan`. Ни один источник не сверяется с
признаком `Archived` в хранилище чата.

### Осложнение

Список перестаёт отвечать на свой вопрос «кому отвечать сейчас». Человек
открывает запись, видит закрытый разговор и идёт к следующей. За один заход
так случается по нескольку раз. Счётчик на кнопке врёт, и по нему нельзя
понять, есть ли живое ожидание вообще.

### Вопрос

Случая два, и причины у них, скорее всего, разные. Архивный чат надо выкидывать
из полки по признаку архива либо снимать его `.ask` при архивации. Отвеченный
чат остаётся в полке, потому что признак ожидания не гасится ответом человека
или концом хода. Разобрать по одному живому примеру на каждый случай и найти,
какой источник держит запись.

### Гипотеза

В полке стоят только разговоры с открытым вопросом человеку, и все они не
архивные. Архивация чата и ответ человека убирают запись из полки тем же кругом
обновления.
