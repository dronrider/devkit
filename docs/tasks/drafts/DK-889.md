# DK-889: Полка «ждут ответа» держит архивные и уже отвеченные чаты

записан 2026-09-09
приоритет: высокий

## Черновик

### Ситуация

Кнопка «ждут ответа» в шапке дашборда (полка DK-696, обработчик `handleWaitShelf`
в `tools/dashboard/waitshelf.go`). Замечено 2026-09-09 на живом дашборде
машины: в списке стоят разговоры, которые уже убраны в архив, и разговоры, по
которым вопрос давно закрыт, отвечать там нечего. Полка собирает записи из
строк доски (`waitLookup`) и из обхода файлов `.ask` в корне чатов проекта
(`askScan`), и ни один из источников не сверяется с признаком `Archived`
в хранилище чата.

### Осложнение

Список перестаёт отвечать на свой вопрос «кому отвечать сейчас»: человек
открывает запись, видит закрытый разговор, закрывает и идёт к следующей, и так
по нескольку раз за заход. Счётчик на кнопке врёт, и по нему уже нельзя понять,
есть ли живое ожидание вообще.

### Вопрос

Два случая, и причины у них, скорее всего, разные: архивный чат надо выкидывать
из полки по признаку архива (или снимать его `.ask` при архивации), а
отвеченный чат остаётся в полке, потому что признак ожидания не гасится ответом
человека или концом хода. Разобрать по одному живому примеру каждого случая,
какой источник держит запись.

### Гипотеза

В полке стоят только разговоры, где вопрос человеку открыт и разговор не
архивный. Архивация чата и ответ человека убирают запись из полки тем же
кругом обновления.
