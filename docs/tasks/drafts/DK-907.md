# DK-907: стенд obeycheck зовёт утилиты из PATH, а не из проверяемого дерева

записан 2026-09-10
приоритет: средний

## Черновик

### Ситуация

2026-09-10, прогон стенда по DK-899. Новая команда `agentctl wait` лежала в
ветке задачи, а живые сессии стенда звали `agentctl` из PATH, где стоит
релизный бинарь без неё. Сценарий краснел на обеих раскладках, пока прогон не
позвали с временным каталогом бинарей: `go build -o <скратч>/bin/agentctl` и
этот каталог в начале PATH.

### Осложнение

Правку утилиты стендом до выката не проверить. Обход собирается руками на
каждом прогоне, в следе прогона его не видно, и сценарий про новую команду
краснеет по причине, к промпту отношения не имеющей.

### Вопрос

Собирать утилиты проверяемого дерева самим стендом или дать ему ключ на
готовый каталог с бинарями?

### Гипотеза

Прогон стенда видит утилиты того дерева, где идёт правка, и ручной сборки для
этого не нужно.
