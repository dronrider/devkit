# DK-944: Браузерные тесты дашборда роняют слияние на загруженной машине

записан 2026-09-11
приоритет: средний

## Черновик

### Ситуация

2026-09-11 слияние DK-933 дважды отбито компонентом go:dashboard, хотя правка
дашборда не касалась. Упали TestBoardRowActionsAligned и TestBoardTabsSameLook.
Chrome на окне 1400,900 убит пределом 90 с при load average около 20. Нагрузку
создаёт сам полный прогон, 17 компонентов параллельно. Те же тесты отдельно
проходят за 4 с. Родня DK-746, там рубеж замера ленты, здесь предел окна
браузера.
