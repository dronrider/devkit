# DK-946: TestQuotaNoHarnessNamesInCode падает на собранном бинаре дашборда

записан 2026-09-11
приоритет: средний

## Черновик

### Ситуация

Прогон DK-935, 2026-09-11. После go build ./... в каталоге tools/dashboard остаётся гитигнорнутый бинарь dashboard. Тест в quota_test.go:217 читает все файлы каталога, кроме подкаталогов и _test.go, и находит в бинаре имя харнеса. go clean бинарь не снял. Исполнитель и ревьювер DK-935 оба переносили бинарь в каталог вне дерева.

### Осложнение

Пакет дашборда красный в любом дереве, где собирали дашборд, хотя код цел. Исполнитель тратит заход на разбор красноты, которой слияние в свежем дереве не видит. На DK-935 так ушло два захода.

### Вопрос

### Гипотеза

Тест смотрит только исходники и статику дашборда, собранный бинарь в каталоге его не роняет.
