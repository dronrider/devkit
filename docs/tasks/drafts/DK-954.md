# DK-954: Кнопки «повторить» и «отменить» уходят с недоставленной реплики

записан 2026-09-12
приоритет: средний

## Черновик

### Ситуация

2026-09-12 в 09:54 реплика в панель задачи DK-947 легла во вход без ведущей сессии. Сервер ответил панели признаком undelivered с причиной «работа по задаче не идёт, отвечать некому», и панель нарисовала пузырь «не доставлено» с кнопками «повторить» и «отменить» (tools/dashboard/static/app.js, draw в очереди отправок, состояния bad и held). Через несколько секунд дашборд записал реплику в журнал сказанного, лента показала её копию, и сверка reconcile сняла пузырь вместе с причиной и кнопками. В ленте осталась обычная строка без состояния. Кнопки пришли с POC DK-397 по живому случаю DK-466 и держатся стендом testdata/poc_taskretry.mjs. README дашборда (раздел про панель чата) говорит обратное: нажимать на реплике нечего, кнопки «Повторить» нет, неушедшее дожимает сам дашборд.

### Осложнение

Кнопки мелькают и пропадают, человек не понимает, что это было и надо ли что-то нажимать. Дока и экран расходятся. Повтор при живом входе кладёт ту же строку, которую сервер и так узнаёт как повтор, то есть кнопка ничего не делает.

### Вопрос

Остаётся ли у пузыря состояние «не доставлено» с причиной после того, как лента показала копию реплики, или причину несёт сама строка ленты.

### Гипотеза

На реплике в панели чата кнопок нет ни в одном состоянии, неушедшее дожимает дашборд, а недоставленное стоит с причиной. README про панель чата остаётся верным без правки. Стенд poc_taskretry.mjs переписан под отсутствие кнопок.
