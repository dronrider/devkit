# DK-988: Пометка исключения гасит ворот стенда на всю ветку, а не на свой файл

записан 2026-09-14
приоритет: средний

## Черновик

### Ситуация

Нашлось при слиянии DK-971 14 сентября. Ворот стенда (standGate в tools/shipctl/advice.go) считает агентским текстом всё под kit/skills/, включая код оболочки goal-run.py и её тест. Прогоном стенда такой файл мерить нечем: стенд поднимает сессию, а оболочку не запускает.

Гасится ворот пометкой «- Исключение: стенд (причина)» в файле задачи, и вызов hasException смотрит только на её наличие. Пометка, поставленная ради одного файла, снимает проверку со всей ветки, включая настоящий текст скиллов. В DK-971 это разошлось: сценарий на SKILL.md там есть и прогнан, но формально после пометки ворот уже ничего не проверял.

Хочется, чтобы пометка называла файл и гасила ворот только на него, а код под kit/skills ворот не считал текстом для агентов вовсе.
