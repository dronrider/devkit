# internal: общий go-модуль каркаса утилит

Библиотека, а не команда: пакеты отсюда импортируют утилиты из `tools/`
через relative replace в своих go.mod, и ни один из них не зовётся по имени.
Заведён DK-237, когда замер показал, что копии каркасных функций уже
разошлись; разбор и граница модуля в
[LLD DK-237](../docs/lld/DK-237-shared-go-module.md).

- `frame` - выжимка вывода команды по формату LLD DK-137: `Capture` пишет
  полный вывод файлом в `.devkit/cmdout/`, `Summarize` собирает сводку,
  `Clean` чистит устаревшее. Порог выжимки живёт тут же.
- `accept` - разбор вида приёмки задачи по суффиксу заголовка строки доски
  (LLD DK-292), общий для taskctl и процедур ревью.
- `stage` - живое состояние этапа работы над задачей (DK-338): словарь видов
  деятельности, запись `~/.devkit/runs/<ID>-<slug>.run` за пределами
  репозитория, разбор её и сборка пакета строк для раздела «Ход работы».
  `agentctl` и `taskctl` пишут запись, `dashboard` читает её.
