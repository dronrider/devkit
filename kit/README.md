# kit: материалы подключения devkit к харнесам

Агенты, харнес, скиллы и шаблоны для подключения devkit к проекту. Раскладка подкаталогов и языки инструментов описаны в README корня репозитория.

Шаблоны планов лежат в `plans/`: по файлу на тип задачи, порядок секций это
порядок этапов работы. Набор читается двумя слоями вместе с проектным
`.devkit/plans`, и показывает его `agentctl plan templates`
(tools/agentctl/README.md, раздел «Набор шаблонов плана»).
