# Диалог с человеком

Чат предназначен для общения с человеком. Если сессия связана с конкретной
задачей, правила работы с ней регламентируются скиллом `board-task`, а код
двигает `board-ship`. Есть набор строгих правил, описывающих, как вести
диалог, все правила одинаково важны.

1. Все работы больше одного шага заводи планом работ по скиллу `work-plan`,
   используя команду `agentctl plan`. План ведётся там, где работа длиннее
   одного хода, а один вопрос с одним ответом плана не просит. Дело, отданное
   субагенту, это уже
   работа не на один шаг: план кладётся до его запуска, пунктами «запуск» и
   «итог человеку». Форма одна, пункты строками, флагов у команды нет:
   `agentctl plan set "запустить поиск субагентом" "отдать итог человеку"`,
   дальше `agentctl plan step 1` и `agentctl plan done 1`. Команда идёт в
   оболочке через Bash, вызов скилла `work-plan` её не заменяет. На каждом
   сообщении проверяй актуальность плана и актуализируй его, план прежде
   всего.

2. Сохраняй максимальную отзывчивость, делегируй продолжительные этапы работ
   субагентам инструментом Agent, чтобы чат не стал похож на зависший.
   Информируй человека в чате о работе субагентов, что сейчас происходит.

3. Отвечай человеку в этот же разговор обычным текстом. Инструмент
   SendMessage для ответа не используется. Ответ адресован ему самому: о нём
   не говорят в третьем лице и не называют «коллегой» или «другой сессией».

4. Сообщение человека в межсессионном канале всегда подписано как
   `from-name="human"`, хотя харнес оборачивает такое сообщение рамкой
   «сообщение от другой сессии». Правило 3 действует на него целиком. Подпись
   с другим именем это соседняя сессия, и с ней разговор ведётся через канал.

5. У агентов-исполнителей, которых ты используешь, есть срок жизни. Порог по
   размеру контекста контролируй через `agentctl rotate`. Правила ротации
   описаны в `board-task`, раздел «Взять в работу». При достижении срока
   жизни нужно дать команду исполнителю завершить текущий этап работ, а всё
   остальное передать новому агенту.

6. Не предлагай человеку в чате открыть и выполнить что-то в консоли. Если
   нужна прямая команда, которую ты не можешь выполнить, давай пользователю
   готовый для копирования блок с командой через знак `!`.

После сжатия контекста хук старта сессии требует перечитать этот скилл.
