# Обход перед вопросом

Передай субагенту запись, предмет поиска, известные продуктовые показатели,
нужные уровни и условия оценки. Поручи проверить код, документацию и доску
на готовые возможности, принятые решения, доступные обходы, риски на стыках
и основания для возражений. Находки подкрепи путями файлов, ID задач либо
цитатами решений или правил. Не требуй минимального числа находок.
Поручи проверить риски для функциональных и нефункциональных
ограничений, включая совместную работу сценариев. Для выводов нужны
основания достижимости показателей: факты, расчёты или результаты проб.
Отдели подтверждённое от предположений и недостающих данных.
Если новых фактов нет, перечисли проверенные места и пределы проверки.
Отсутствие находок не подтверждает готовность постановки.

## Выбор субагента и доступ к материалам

Субагент работает со свежим контекстом. Для записи на доске возьми ярус из
`agentctl pick <ID> --role review`. Для черновика без строки доски используй
ярус `base`: у него ещё нет метаданных для `pick`.

При `board-groom` передай субагенту `taskctl list --safe` для доски и архива,
`taskctl draft list --safe` для накопителя. Тело найденной записи он читает
только после `taskctl guard <ID>`. Скрытый ID передай человеку для локальной
проверки. Прямой поиск по файлам доски, задач и архива не заменяет безопасный
список. Код ищи по явно выбранным файлам или каталогам кода, чтобы поиск
не захватил файлы задач и архив.

## Сохранение находок

Ответ, найденный в материалах, используй с указанием источника и проверь
его применимость к текущим условиям и нужным продуктовым показателям.
Нерешённый вопрос обработай по шагу 4 `SKILL.md` и сохрани через `taskctl decide --ask`.
Передай рекомендацию с доводом ключом `--hint`, а при равно обоснованных
вариантах используй `--tie "<довод равенства>"`.

Под развилкой допиши отдельную строку `источник:` с видом источника и путём
или ID. Допустимые виды: `код`, `дока`, `доска`, `архитектура`, `возражение`.
Для архитектуры укажи соответствующий раздел документа о затронутом слое.
Сохрани отступ, как у `решает` и `рекомендация`. У `decide` нет флага для этой
строки, её добавляет агент правкой файла. Источник внутри вопроса или
`--hint` отдельную строку не заменяет. Формат описан в `TASKFORM.md`.

Если открытый вопрос родительской цели относится к новой задаче, перенеси
его в перечень задачи через `decide --ask` с тем же именем, значением
`решает` и рекомендацией. Решённый вопрос оставь в родителе и сошлись на
него из задачи. Проверь, сохраняются ли основания родительского решения
при нагрузке, ограничениях и целевых показателях новой задачи. При изменении
условий отметь зависимые решения для сверки и продолжи исследование.
Перенесённые вопросы закрываются в каждой записи отдельно;
ответ задачи автоматически не переносится в цель.
