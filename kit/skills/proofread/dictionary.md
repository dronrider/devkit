# Словарь devkit

Термины проекта, которые вычитка принимает как свои и не пытается заменить
на «более литературный» вариант. Слово, которого нет ни в этом словаре, ни в
общем техническом русском, помечается как кандидат в словарь: пополняет
словарь пользователь, у одного слова в проекте бывает ровно одно значение.

| Термин | Значение в проекте |
|---|---|
| поезд | связка задач, идущих в одном конвейере с общим ревью и выкатом |
| виток | один проход цикла цели в goal-loop |
| лестница | набор уровней выбора модели (haiku, sonnet, opus) в agentctl |
| накопитель | очередь черновиков `taskctl draft`, из которой черновик становится строкой доски |
| сторожок | фоновое наблюдение за событием, будящее сессию при его наступлении |
| заход | один запуск процедуры скилла или проход по списку (например, «заход груминга») |
| ворота | шаг проверки готовности черновика или задачи перед следующим состоянием |
| рубеж | граница, на которой держится поведение: правило, хук или проверка |
| лента | список реплик разговора на экране чата дашборда |
| хвост | недоделанная работа, которую исполнитель сдаёт при смене строкой «Лимит жизненного цикла» в «Ход работы» (DK-503) |
| дорезка | разбивка одной задачи на несколько при груминге или нарезке цели |
