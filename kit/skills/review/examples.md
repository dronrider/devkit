# Образцы к скиллу review

Открой нужный пример для записи результата или настройки проекта.

## Раздел «Ревью» целиком

```text
## Ревью

Уровень 2 до a1b2c3d: риск пропуска ворот слияния, проверка разбора раздела и живого пути.

- блокирует: shipctl merge пропускает раздел «Ревью» за ограждённым блоком.
  Исправлено.
- не блокирует: имя флага --at читается как время. Отклонено:
  флаг назван по образцу taskctl stage --at.
- Вердикт: без замечаний до e4f5a6b. fixed 1 сверено тестом разбора раздела,
  rejected 2 принято. Прогнано: shipctl ready на задаче и на файле без раздела.
```

Строку уровня пишет `review level`, замечания `review add`, исходы
`review resolve`, вердикт `review clean` по завершённому аудиту.

## Файл замечаний чужого ревью

`review draft` заполняет шапку и добавляет блоки в
`docs/tasks/<ID>.review.md`. Номера блоков сохраняются при ручной правке.

```text
# Замечания ревью DK-1

- MR: https://gitlab.example.com/group/proj/-/merge_requests/42
- ревью до: a1b2c3d
- уровень: 2
- пометка: автор ответил

## Замечание 1

- файл: tools/shipctl/ops.go
- строка: 214
- метка: issue
- состояние: опубликовано, тред 7f21c8a

Ворота пропускают раздел «Ревью» за ограждённым блоком.
Проверь merge с таким разделом и отказ при отсутствии отчёта.

## Замечание 2

- метка: итог
- состояние: снято, не публикуется

Тесты разбора прошли. Нужен доступ к стенду для проверки выпуска.
```

Пометку «автор ответил», «автор молчит с ...», «апрув поставлен» или судьбу
MR обновляет опрос тредов. Публикацию ведёт [foreign.md](foreign.md).

## Замечание человеку

```text
issue: В обработчиках берётся пакетный логгер. В логах нет request_id,
поэтому записи одного запроса нельзя связать. Передай логгер из middleware
через контекст и проверь, что две записи одного запроса имеют один request_id.
```

## Конфиг ревью целиком

```ini
critical_paths = tools/shipctl tools/taskctl hooks
labels = issue, suggestion (non-blocking)
checks = новых пакетов npm без согласования не берём
# Укажи существующий файл, если он нужен в обязательном перечне.
# rule_sources = docs/SECURITY.md
publish = confirm
pause = 20-60
poll = 5m
silence = 1d
worklog = off
```
