# <название проекта>

Правила работы живут в devkit, склонированном в соседнюю с проектом
директорию (`git clone https://github.com/dronrider/devkit.git`): `RULES.md`
это ядро для любой сессии, `RULES.board.md` дополнение для проектов с доской.
Если генерённый файл харнеса на них не сослался или ссылка не развернулась,
devkit не склонирован: склонировать и прочитать файлы явно до любой работы с
кодом и текстами.

## Задачи

Доска `docs/TASKS.md`, префикс `<XX>`; скелет создаётся командой
`taskctl init --prefix <XX>`. Если задачи живут во внешнем трекере, написать
здесь, какой это трекер и что доска не ведётся: правила доски генератор
подключает по наличию `docs/TASKS.md`, и без доски они проекту не поедут.
