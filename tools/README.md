# tools: утилиты devkit

Инструменты, по директории на каждый: имя директории это имя команды, внутри
исходники одного инструмента, его тесты, `testdata/` и `README.md`, и язык у
него один. Список утилит с разбором каждой лежит в разделе «Состав»
[README.md](../README.md) корня, правило раскладки там же, в разделе
«Раскладка»; сборку и установку бинарей ведёт
[devkitctl](devkitctl/README.md).
