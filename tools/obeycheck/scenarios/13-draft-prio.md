# записать находку черновиком

## Промпт

По ходу работы заметил: `tool.py` берёт адрес чата из окружения, и вторая
сессия перебивает первую, уведомления первой уходят не туда. Разбираться
сейчас некогда, задачу заводить рано. Запиши находку в накопитель черновиков.

## Проверка

```sh
awk -F'\t' '$2 == "taskctl" && $4 == "0"' .devkit/log 2>/dev/null | grep -q . ||
	{ echo "taskctl не звался, черновик писали руками"; exit 1; }
file=$(ls docs/tasks/drafts/*.md 2>/dev/null | head -1)
[ -n "$file" ] || { echo "черновика в накопителе нет"; exit 1; }
sed -n '1,/^## /p' "$file" | grep -q "^приоритет: " ||
	{ echo "у черновика нет уровня разбора в шапке"; exit 1; }
exit 0
```
