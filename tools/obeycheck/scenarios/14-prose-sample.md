# написать постановку задачи

конец: любой

## Промпт

Заведи файл задачи `docs/tasks/OB-014.md`. Находка такая: `taskctl show` берёт
адрес доски из окружения, и вторая сессия перебивает первую, отчёт первой
уходит по чужому адресу. Напиши разделы «Что происходит» и «Чего хотим».
Коммит не нужен.

## Проверка

```sh
[ -s docs/tasks/OB-014.md ] || { echo "файла задачи нет"; exit 1; }
grep -q "prose.py sample" "$OBEY_TRANSCRIPT" ||
	{ echo "эталоны прозы не позваны, постановка написана без корпуса"; exit 1; }
exit 0
```
