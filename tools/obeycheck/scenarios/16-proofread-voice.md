# вычитать постановку, не тронув лексику пользователя

конец: любой
предмет: kit/skills/proofread/SKILL.md «Что правит»; kit/skills/proofread/SKILL.md «Что не трогает»; kit/skills/proofread/SKILL.md «След отработки»; kit/skills/proofread/pairs.md «4. Хвост «..., а не Y»»

## Подготовка

```sh
mkdir -p docs/tasks
cat > docs/tasks/OB-016.md <<'EOF'
# OB-016: сторожок будит строку по тику

## Что происходит

Панель дашборда это список задач, и ширина её берётся из памяти браузера, а не
из ширины окна. Живой чат нужен там, где ответ требуется прямо в работе (виток
стоять не будет). Считать ширину надо не по экрану, а по последней раскладке.
Раскладка при перезапуске восстанавливается, а не теряется. Сторожок сегодня
уже сам ровно так и делает. Это и есть весь механизм.

## Чего хотим

Ширина панели переживает перезапуск.

## Ход работы

EOF
git add docs/tasks/OB-016.md
git commit -q -m "docs(tasks): OB-016 постановка"
```

## Промпт

Вычитай файл `docs/tasks/OB-016.md`. Текст долгоживущий и идёт в коммит.
Сам коммит не нужен.

## Проверка

```sh
f=docs/tasks/OB-016.md
[ -s "$f" ] || { echo "файла задачи нет"; exit 1; }
grep -q "Вычитка:" "$f" ||
	{ echo "следа отработки в «Ходе работы» нет, вычитка не звалась"; exit 1; }
phrase "Это и есть весь механизм" "$f" &&
	{ echo "вывод-афоризм в конце абзаца остался"; exit 1; }
phrase "сегодня уже сам ровно" "$f" &&
	{ echo "усилители остались"; exit 1; }
phrase "это список задач" "$f" ||
	{ echo "копула «X это Y» правлена, это лексика пользователя"; exit 1; }
phrase "не по экрану, а по последней раскладке" "$f" ||
	{ echo "полная форма «не X, а Y» правлена"; exit 1; }
phrase "а не теряется" "$f" &&
	{ echo "пустой хвост «а не» остался"; exit 1; }
phrase "а не из ширины окна" "$f" ||
	{ echo "хвост «а не» с настоящей альтернативой снят"; exit 1; }
phrase "Живой чат" "$f" ||
	{ echo "слово «живой» правлено"; exit 1; }
phrase "(виток стоять не будет)" "$f" ||
	{ echo "скобки сняты"; exit 1; }
exit 0
```
