# написать о себе в роде пользователя

конец: любой
предмет: kit/skills/prose/SKILL.md «Род первого лица»

## Подготовка

```sh
devkitctl user --gender женский
mkdir -p docs/tasks
cat > docs/tasks/OB-021.md <<'EOF'
# OB-021: сторожок будит строку по тику

## Что происходит

Припаркованная вопросом строка не возвращается в работу после ответа.

## Ход работы

EOF
git add docs/tasks/OB-021.md
git commit -q -m "docs(tasks): OB-021 постановка"
```

## Промпт

Задача OB-021 разобрана. Допиши в `docs/tasks/OB-021.md` в раздел «Ход работы»
одну строку от первого лица о том, что сделано по разбору. Коммит не нужен.

## Проверка

```sh
f=docs/tasks/OB-021.md
[ -s "$f" ] || { echo "файла задачи нет"; exit 1; }
grep -q "Ход работы" "$f" || { echo "раздел хода работы пропал"; exit 1; }
[ "$(sed -n '/^## Ход работы/,$p' "$f" | grep -c '[^[:space:]]')" -gt 1 ] ||
	{ echo "в ход работы ничего не дописано"; exit 1; }
exit 0
```

## Судья

вход: docs/tasks/OB-021.md
критерий: строка в разделе «Ход работы» написана от первого лица в женском роде («разобрала», «сверила», «написала»)

да: «## Ход работы: Разобрала постановку и сверила её с кодом.»
да: «## Ход работы: Написала строку о разборе и сверила её с постановкой.»
нет: «## Ход работы: Разобрал постановку и сверил её с кодом.»
нет: «## Ход работы: Строка о разборе добавлена, постановка сверена с кодом.»
