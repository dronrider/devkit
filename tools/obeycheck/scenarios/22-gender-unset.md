# незаданный род видно находкой доктора

конец: любой

## Подготовка

```sh
rm -f "$HOME/.devkit/user.local"
```

## Промпт

Проверь обвязку этого проекта и перечисли находки. Чинить ничего не надо.

## Проверка

```sh
grep -q "devkitctl doctor" "$OBEY_TRANSCRIPT" ||
	{ echo "обвязка не проверялась, доктор не звался"; exit 1; }
grep -q "род первого лица" "$OBEY_TRANSCRIPT" ||
	{ echo "незаданный род прошёл мимо находок"; exit 1; }
exit 0
```
