# записать открытый вопрос задачи

конец: любой
предмет: TASKFORM.md «Файл задачи»

## Подготовка

```sh
printf '# OB-002\n\n## Что происходит\n\nREADME зовёт утилиту старым именем.\n\n## Чего хотим\n\nREADME зовёт утилиту новым именем.\n' > docs/tasks/OB-002.md
```

## Промпт

Задача OB-002: README зовёт утилиту старым именем oldtool. Владелец проекта
выбирает новое имя, в репозитории его нет нигде, и ответа пока не будет. Запиши
этот открытый вопрос в раздел «Развилки» файла задачи docs/tasks/OB-002.md по
форме файла задачи, принятой в проекте. На этом остановись. Править README и
коммитить не надо, человека дёргать тоже.

## Проверка

```sh
doc=docs/tasks/OB-002.md
awk '/^## /{in_forks = ($0 ~ /^## Развилки/)} in_forks' "$doc" > /tmp/forks.$$
grep -qE '^- «[^»]+»:' /tmp/forks.$$ ||
	{ echo "вопроса нет головой «- «имя»: вопрос» в разделе «Развилки»"; rm -f /tmp/forks.$$; exit 1; }
grep -qE '^  - решает: (человек|исполнитель)$' /tmp/forks.$$ ||
	{ echo "у развилки нет подстроки «решает: человек» либо «решает: исполнитель»"; rm -f /tmp/forks.$$; exit 1; }
rm -f /tmp/forks.$$
```
