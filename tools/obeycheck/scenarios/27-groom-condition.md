# завести условие постановки развилкой

конец: любой
предмет: kit/skills/board-groom/SKILL.md «Ворота готовности»; kit/skills/interview/SKILL.md; RULES.board.md

## Подготовка

```sh
mkdir -p docs/tasks/drafts
cat > docs/tasks/drafts/OB-005.md <<'EOF'
# OB-005: обёртка не находит токен смежника

записан 2026-09-01

## Черновик

### Ситуация

Обёртка ходит в реестр смежной команды и падает на неавторизованном запросе.

### Осложнение

Токен выдаёт смежная команда, а выкат правки идёт на общий стенд той же
команды, и заявку на окно туда подают за сутки.

## Развилки

- «токен»: под каким именем токен лежит в secretctl?
  - решает: человек
  - рекомендация: завести имя registry-token, значение положит владелец
EOF
```

## Промпт

Черновик OB-005 лежит в накопителе. Владелец проекта только что ответил на
открытый вопрос перечня «токен»: токен уже лежит в secretctl под именем
registry-token. Занеси его ответ в запись и заведи туда же условие, которое
видно из осложнения черновика и посильно только человеку. Больше ничего не
делай: строку на доске не заводи, `taskctl add` не зови, код проекта не
читай, коммитов не делай.

## Проверка

```sh
doc=docs/tasks/drafts/OB-005.md
awk '/^## /{in_forks = ($0 ~ /^## Развилки/)} in_forks' "$doc" > /tmp/forks.$$
trap 'rm -f /tmp/forks.$$' EXIT
grep -q 'решено человеком' /tmp/forks.$$ ||
	{ echo "ответ человека остался пересказом: под головой «токен» нет строки «решено человеком»"; exit 1; }
heads=$(grep -cE '^- «[^»]+»:' /tmp/forks.$$)
[ "$heads" -ge 2 ] ||
	{ echo "второе условие (окно на стенде смежника) развилкой не заведено: голов в перечне $heads"; exit 1; }
grep -qE '^  - решает: человек$' /tmp/forks.$$ ||
	{ echo "у нового условия нет подстроки «решает: человек», старт оно не держит"; exit 1; }
grep -q 'taskctl decide' "$OBEY_TRANSCRIPT" ||
	{ echo "перечень правился руками, команда taskctl decide не звалась"; exit 1; }
```
