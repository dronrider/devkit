# отдать хвост при контексте исполнителя за порогом

конец: сессия
предмет: kit/skills/board-task/SKILL.md; kit/skills/board-batch/SKILL.md

## Подготовка

```sh
mkdir -p docs/tasks
cat > docs/tasks/OB-028.md <<'INNER'
# OB-028: сторожок расписания не будит припаркованную строку

## Что происходит

Строка, припаркованная вопросом, после ответа человека остаётся в blocked.

## Ход работы

INNER
git add docs/tasks/OB-028.md >/dev/null 2>&1
git commit -qm "docs(tasks): OB-028 постановка" >/dev/null 2>&1
```

## Промпт

Ты диспетчер доски. Порядок работы возьми из скилла board-task, позови его
первым делом. Задача OB-028 в работе. Исполнителя ты держишь репликами в этом
разговоре. Он работает в дереве ../ob-028, прислал два куска работы и ждёт
следующего. Последнее уведомление от него такое.

```
subagent_tokens 720000, tool_uses 214, ход закончен
```

Работы осталось на два шага. Дописать тест сторожка и обновить README.

Реши, как отдать эти два шага. Запиши решение строкой в раздел «Ход работы»
файла docs/tasks/OB-028.md. В строке скажи, что отправишь текущему исполнителю
и кто получит оставшиеся два шага. Субагентов не спавни, коммит не нужен.

## Проверка

```sh
f=docs/tasks/OB-028.md
[ -s "$f" ] || { echo "файла задачи нет"; exit 1; }
grep -q "Ход работы" "$f" || { echo "раздел хода работы пропал"; exit 1; }
[ "$(sed -n '/^## Ход работы/,$p' "$f" | grep -c '[^[:space:]]')" -gt 1 ] ||
	{ echo "в ход работы ничего не дописано"; exit 1; }
exit 0
```

## Судья

вход: docs/tasks/OB-028.md
критерий: в записи сказано, что текущему исполнителю уходит просьба сдать хвост работы, а оставшиеся шаги получит новый субагент

да: «Контекст исполнителя за порогом ротации. Прошу его короткой репликой сдать хвост и закончить заход. Оба оставшихся шага отдаю свежему субагенту повторным agentctl pick OB-028 --record.»
да: «Реплика исполнителю: сдай хвост и закончи ход. Тест и README уйдут новому исполнителю следующим спавном.»
нет: «Дошлю оба шага той же репликой текущему исполнителю. Он уже в контексте задачи.»
нет: «Часы этапа в пределах лимита 120 минут. Работу продолжает тот же исполнитель.»
