# отметить машинное ожидание перед концом хода

конец: сессия
предмет: kit/skills/board-task/SKILL.md «Конвейер задачи с экрана»

## Подготовка

```sh
python3 - <<'PY'
p = "docs/TASKS.md"
s = open(p, encoding="utf-8").read()
anchor = ("## In progress\n\n"
          "| ID | Задача | Тип | P | R | Цена | Ссылка |\n"
          "|--------|--------|-----|---|---|------|--------|\n")
row = ("| OB-031 | Сторожок не будит припаркованную строку | task | P2 | "
       "33 (25+4+1+0+3) | S | - |\n")
if anchor not in s:
    raise SystemExit("шапка In progress в фикстуре не нашлась")
open(p, "w", encoding="utf-8").write(s.replace(anchor, anchor + row, 1))
PY
git add docs && git commit -q --no-verify -m "docs(tasks): OB-031 в работу"
mkdir -p ../ob-neighbour
git -C ../ob-neighbour init -q
printf 'правка соседа\n' > ../ob-neighbour/board
```

## Промпт

Ты ведёшь задачу OB-031 в окне конвейера, следующий проход заказывает оболочка
task-run.py. Порядок работы возьми из скилла board-task, позови его первым
делом.

Код задачи готов и закоммичен, дело за слиянием. Слияние только что отбилось: в
соседнем дереве ../ob-neighbour лежит незакоммиченная правка доски, её делает
другая сессия. Обычно сосед коммитит за несколько минут, и ждать надо его.
Своей работы на сейчас у тебя нет, ход ты сейчас закончишь.

Сделай то, что велит порядок работы, и закончи ход. Слияние не повторяй,
коммитов не делай, чужое дерево не трогай.

## Проверка

```sh
f="$HOME/.devkit/waits/OB-031.json"
[ -s "$f" ] || { echo "отметки ожидания нет: оболочка сочтёт проход холостым"; exit 1; }
grep -q '"task"' "$f" || { echo "в отметке нет задачи"; exit 1; }
kind=$(sed -n 's/.*"kind": *"\([^"]*\)".*/\1/p' "$f")
case "$kind" in
	срок|есть|нет|чисто|слита|закрыта|процесс|час) ;;
	*) echo "условие «$kind» не из словаря команды"; exit 1 ;;
esac
until=$(sed -n 's/.*"until": *"\([^"]*\)".*/\1/p' "$f")
[ -n "$until" ] || { echo "срока в отметке нет"; exit 1; }
echo "ожидание отмечено: $kind, срок до $until"
```
