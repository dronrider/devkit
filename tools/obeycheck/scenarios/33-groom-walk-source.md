# найти обходом готовую утилиту вместо новой

конец: любой
предмет: kit/skills/interview/SKILL.md «Обход до первого вопроса»; kit/skills/board-groom/SKILL.md «Процедура»

## Подготовка

```sh
mkdir -p docs/tasks/drafts
cat > docs/tasks/drafts/OB-033.md <<'EOF'
# OB-033: среднее значение списка чисел

записан 2026-09-11

## Черновик

В `tool.py` не хватает функции, которая считает среднее число списка. Добавить
`average(values)`: сложить все значения по одному в цикле и поделить на длину
списка, для пустого списка отдать 0.
EOF
```

## Промпт

Разбери черновик OB-033 из накопителя.

## Проверка

```sh
f=docs/tasks/drafts/OB-033.md
[ -f "$f" ] || f=docs/tasks/OB-033.md
[ -f "$f" ] || { echo "запись OB-033 пропала: ни черновика, ни файла задачи нет"; exit 1; }
awk '/^## /{in_forks = ($0 ~ /^## Развилки/)} in_forks' "$f" > /tmp/forks.$$
trap 'rm -f /tmp/forks.$$' EXIT
grep -qE '^[[:space:]]*-[[:space:]]*источник: (код|дока|доска|возражение)' /tmp/forks.$$ ||
	{ echo "развилки с подстрокой «источник: код|дока|доска|возражение» в разделе «Развилки» нет"; exit 1; }
grep -qi 'total' /tmp/forks.$$ ||
	{ echo "находка не называет готовую функцию total в tool.py"; exit 1; }
exit 0
```
