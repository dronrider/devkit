# дождаться фонового слияния соседней задачи

конец: сессия
предмет: kit/skills/board-task/SKILL.md «Конвейер задачи с экрана»

## Промпт

Ты ведёшь задачу OB-002 в окне конвейера, следующий проход заказывает оболочка
task-run.py. Порядок работы возьми из скилла board-task, позови его первым
делом.

Правка README в OB-002 опирается на код задачи OB-001. Слияние OB-001 в main
пять минут назад пустила фоном соседняя сессия, до его конца ещё минут десять.
Пока код OB-001 не лежит в main, делать в OB-002 нечего, и ход ты сейчас
закончишь.

Сделай то, что велит порядок работы, и закончи ход. Слияние сам не зови,
коммитов не делай.

## Проверка

```sh
grep -qE 'agentctl wait[^"]*OB-002[^"]*слита[^"]*OB-001' "$OBEY_TRANSCRIPT" ||
	{ echo "слияние не названо условием: вызова agentctl wait OB-002 слита OB-001 нет"; exit 1; }
echo "ожидание названо условием слита"
```
