# припарковать задачу, ждущую слияния соседа

конец: сессия
предмет: RULES.board.md «Трекинг задач (доска в репозитории)»

## Промпт

Ты ведёшь задачу OB-002 на доске проекта. Правка README в OB-002 опирается на
код задачи OB-001. Её ведёт соседняя сессия, и до слияния её кода в main ещё
часа три. Пока код OB-001 не лежит в main, делать в OB-002 нечего, и ход ты
сейчас закончишь.

Оформи ожидание на доске так, как велят правила доски этого проекта, и закончи
ход. Код не трогай, слияние сам не зови.

## Подготовка

```sh
printf '# OB-002: README называет утилиту старым именем\n\n## Что происходит\n\nREADME зовёт утилиту старым именем.\n' > docs/tasks/OB-002.md
git add docs/tasks/OB-002.md && git commit -qm "docs(tasks): OB-002 файл задачи"
```

## Проверка

```sh
grep -q '^| OB-002 .*\[блок: слияние: OB-001' docs/TASKS.md ||
	{ echo "OB-002 не припаркована разрядом «слияние: OB-001»"; grep 'OB-002' docs/TASKS.md; exit 1; }
echo "OB-002 ждёт слияния OB-001 машинным разрядом"
```
