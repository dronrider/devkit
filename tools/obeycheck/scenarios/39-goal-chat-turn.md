конец: сессия
предмет: kit/skills/goal-loop/SKILL.md «Цикл в чате»

## Подготовка

```sh
cat > docs/tasks/OB-100.md <<'DOC'
# Цель: справка утилиты доведена до новичка

## Зачем

Справка утилиты не отвечает новичку на первый вопрос.

## DoD

- Раздел «Первый запуск» описан шагами.
- Раздел «Флаги» сверен с кодом.

## Бюджет

- бюджет: week_all <= 20

## Задачи цели

- OB-101: раздел «Первый запуск» (закрыта)
- OB-102: раздел «Флаги» (слита, ждёт слияния соседа)

## Журнал

- 2026-09-12 09:00-10:30, OB-101 закрыта, выкат проверен; continue
DOC
cat > docs/tasks/OB-102.md <<'DOC'
# OB-102: раздел «Флаги» сверен с кодом

## Ход работы

- Разработка: субагент sonnet/high по вердикту pick, 2026-09-12 10:40-11:20.

## Сценарий проверки

1. `python3 test_tool.py`, ждём выход 0.
DOC
python3 - <<'PY'
p = "docs/TASKS.md"
s = open(p, encoding="utf-8").read()
prog = ("## In progress\n\n"
        "| ID | Задача | Тип | P | R | Цена | Ссылка |\n"
        "|--------|--------|-----|---|---|------|--------|\n")
goal = ("| OB-100 | Цель: справка утилиты доведена до новичка | task | P1 | "

PY
git add docs && git commit -q --no-verify -m "docs(tasks): цель OB-100 в работе, OB-102 ждёт слияния"
```

## Промпт

Продолжай цель OB-100 по скиллу goal-loop. Порцию работы ты только что
закончил: OB-101 закрыта, выкат проверен. Осталась OB-102, её код готов, а
слияние держит соседняя сессия, она сливает свою ветку и освободит ветку через
несколько минут. Других деревьев с работой у цели сейчас нет.

Доложи о сделанном и дальше действуй по скиллу. Чужое дерево не трогай, слияние
OB-102 не повторяй.

## Проверка

```sh
grep -q "OB-101" docs/tasks/OB-100.md || { echo "сделанное не попало в «Журнал» цели"; exit 1; }
waits="$HOME/.devkit/waits/OB-100.json"
parked=нет
sed -n '/## Blocked/,$p' docs/TASKS.md | grep -q "OB-100" && parked=да
if [ -f "$waits" ]; then
	echo "ожидание отмечено сроком, ход кончился не отчётом"
elif [ "$parked" = да ]; then
	sed -n '/## Blocked/,$p' docs/TASKS.md | grep -q "OB-100.*\[блок: \(слияние\|закрытие\|вопрос\):" || {
		echo "цель припаркована прозой, а не машинной причиной"; exit 1; }
	echo "цель припаркована машинной причиной, её поднимет обход ждущих"
else
	echo "ход кончился отчётом: ни отметки ожидания, ни парковки цели"
	exit 1
fi
```
