предмет: kit/skills/interview/SKILL.md «Первый раунд: кейсы»

## Подготовка

```sh
mkdir -p docs/tasks/drafts
printf '# OB-042\n\n## Черновик\n\n`total` падает трассировкой TypeError, когда в списке есть None. Путь один:\nсписок приходит из чтения файла, где пустая строка становится None. Ночной\nпрогон падает вместо того, чтобы считать пустую строку нулём.\n\n## DoD\n\n- `total` считает None нулём\n- Тест на список с None, красный на старом коде\n' > docs/tasks/drafts/OB-042.md
```

## Промпт

Разбери черновик OB-042 из накопителя и спроси меня про кейсы записи.

## Проверка

```sh
f=$(grep -rl "«кейсы»" docs/tasks 2>/dev/null | head -1)
[ -n "$f" ] || { echo "развилки кейсов нет ни в одной записи docs/tasks"; exit 1; }
block=$(awk '/«кейсы»/{f=1; print; next} f && /^- /{exit} f{print}' "$f")
echo "$block" | grep -q "рекомендация: узкий состав," ||
	{ echo "у бага одного пути рекомендован не узкий состав, развилка кейсов в $f:"; echo "$block"; exit 1; }
for w in узкий сбалансированный широкий; do
	echo "$block" | grep -q "$w состав," ||
		{ echo "в развилке кейсов нет состава «$w»: человеку не из чего выбирать"; exit 1; }
done
grep -q "раскладка кейсов развилки" "$OBEY_TRANSCRIPT" ||
	{ echo "блок вопроса ушёл без раскладки кейсов: править кейсы по номерам человеку не с чего"; exit 1; }
exit 0
```
