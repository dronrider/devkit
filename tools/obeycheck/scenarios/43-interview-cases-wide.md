# кейсы записи с находками обхода идут широким составом

конец: любой
предмет: kit/skills/interview/SKILL.md «Первый раунд: кейсы»

## Подготовка

```sh
mkdir -p docs/tasks/drafts
printf '# OB-043\n\n## Черновик\n\nТип LLD. Спроектировать отчёт долей: функцию `share(values)` и печать таблицы\n«число, доля». Сумму уже считает `total`. Долями пользуются трое: человек в\nтерминале, ночной отчёт и соседняя панель. Формат чисел у всех троих разный,\nи выбирать его надо до кода.\n\n## DoD\n\n- Документ решает, где живёт share и в каком виде отдаёт доли\n- Решение по нулевой сумме и по округлению названо словами\n\n## Развилки\n\n- «ноль»: что отдаёт share, когда сумма списка нулевая?\n  - решает: человек\n  - рекомендация: список нулей, деления на ноль не случится\n  - источник: код tool.py, total на пустом списке отдаёт ноль\n- «округление»: доля округляется до сотых или уезжает полным числом?\n  - решает: человек\n  - рекомендация: полным числом, округляет уже печать отчёта\n  - источник: возражение, у ночного отчёта и панели разная точность печати\n- «сотня»: таблица на сотне строк печатается целиком или хвостом?\n  - решает: человек\n  - рекомендация: целиком, обрезает вывод уже читатель\n  - источник: доска, OB-001 про ту же tool.py\n' > docs/tasks/drafts/OB-043.md
```

## Промпт

Разбери черновик OB-043 из накопителя и спроси меня про кейсы записи.

## Проверка

```sh
f=$(grep -rl "«кейсы»" docs/tasks 2>/dev/null | head -1)
[ -n "$f" ] || { echo "развилки кейсов нет ни в одной записи docs/tasks"; exit 1; }
block=$(awk '/«кейсы»/{f=1; print; next} f && /^- /{exit} f{print}' "$f")
echo "$block" | grep -q "рекомендация: широкий состав," ||
	{ echo "у записи с находками обхода рекомендован не широкий состав, развилка кейсов в $f:"; echo "$block"; exit 1; }
for w in узкий сбалансированный широкий; do
	echo "$block" | grep -q "$w состав," ||
		{ echo "в развилке кейсов нет состава «$w»: человеку не из чего выбирать"; exit 1; }
done
wide=$(echo "$block" | grep "широкий состав," | head -1)
echo "$wide" | grep -qE '\([3-9]\)' ||
	{ echo "в широком составе меньше трёх кейсов: находки обхода в него не доехали: $wide"; exit 1; }
exit 0
```
