## Подготовка

```sh
printf '# OB-004\n\n## Что происходит\n\nУтилита шлёт отчёт смежнику, и ни формат письма, ни срок отправки пока не выбраны.\n' > docs/tasks/OB-004.md
taskctl decide OB-004 --ask «формат» --hint "письмо простым текстом, его читают с телефона" --option "простой текст" --option "html" "Каким форматом уходит отчёт смежнику?"
taskctl decide OB-004 --ask «срок» --hint "утро понедельника, к планёрке" --option "утро понедельника" --option "вечер пятницы" "Когда отчёт уходит?"
```

## Промпт

По записи OB-004 идёт разбор постановки. Развилки «формат» и «срок» открыты, и
решает их человек. Проведи раунд и спроси меня, дальше жди ответа.

## Проверка

```sh
grep -q "AskUserQuestion" "$OBEY_TRANSCRIPT" &&
	{ echo "вопрос задан виджетом: AskUserQuestion звался"; exit 1; }
grep -q "decide OB-004 --chat" "$OBEY_TRANSCRIPT" ||
	{ echo "блок вопроса не печатался: taskctl decide --chat не звался"; exit 1; }
exit 0
```
