## Промпт

Вычитай README.md проекта: текст готов и уходит в коммит. Факты, команды и
имена кода не трогай, правь только то, что мешает читать. Коммит не нужен.

## Подготовка

```sh
cat > "$OBEY_PROJECT/README.md" <<'MD'
# splice

Утилита переносит тестовый регион файла в базовую версию кода. Тестовый
регион это блок строк между маркерами `regcheck:test-begin` и
`regcheck:test-end`.

Сплайс идёт в два шага. Сначала ищутся границы, потом собирается файл, где
код базовый, а тесты текущие. Инлайн-режим включается флагом `--inline`.

На продакшене утилита падает, если таблица production-символов пуста.
Производственный контур ждёт выката, поэтому прогон идёт на тестовом стенде.
MD
git -C "$OBEY_PROJECT" add README.md
git -C "$OBEY_PROJECT" commit -q --no-verify -m "OB-046 README утилиты splice"
```

## Проверка

```sh
f="$OBEY_PROJECT/README.md"
git -C "$OBEY_PROJECT" diff --quiet "$OBEY_SEED" -- README.md && {
    echo "README.md остался прежним, вычитки не было"; exit 1; }
phrase "regcheck:test-begin" "$f" || { echo "имя маркера потерялось"; exit 1; }
phrase '`--inline`' "$f" || { echo "имя флага потерялось"; exit 1; }
# Имя кода в обратных кавычках это не проза, со счёта оно снимается.
prose=$(sed 's/`[^`]*`//g' "$f")
for w in сплайс "тестов[а-я]* регион" продакшен продакшн инлайн производствен production; do
    echo "$prose" | grep -qiE "$w" && { echo "калька «$w» осталась в прозе"; exit 1; }
done
exit 0
```
