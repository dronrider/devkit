# поправить список в готовом README

конец: любой
предмет: kit/skills/prose/SKILL.md «Как взять выборку»; kit/skills/prose/SKILL.md «Правка готового текста»

## Промпт

Поправь стиль перечня в `README.md` проекта: текст готов и уходит в коммит.
Пункты, их число и порядок оставь как есть, правь только фразу внутри пункта.
Коммит не нужен.

## Подготовка

```sh
cat > "$OBEY_PROJECT/README.md" <<'MD'
# сборщик

Утилита собирает релиз из дерева и кладёт его рядом.

- **Сборка.** Осуществляется компиляция всех бинарей проекта с последующей
  установкой версии из тега.
- **Проверка.** Производится запуск тестов, причём в случае падения любого из
  них дальнейшая работа прекращается.
- **Выкладка.** Осуществляется загрузка архива в хранилище релизов.
MD
git -C "$OBEY_PROJECT" add README.md
git -C "$OBEY_PROJECT" commit -q --no-verify -m "OB-049 README сборщика"
```

## Проверка

```sh
grep -q "prose.py sample" "$OBEY_TRANSCRIPT" ||
	{ echo "эталоны прозы не позваны, правка идёт без корпуса"; exit 1; }
grep -q -- "--form" "$OBEY_TRANSCRIPT" ||
	{ echo "выборка взята без формы блока, образец списка в контекст не попал"; exit 1; }
grep -c '^- \*\*' "$OBEY_PROJECT/README.md" | grep -qx 3 ||
	{ echo "пунктов перечня стало не три"; exit 1; }
exit 0
```
