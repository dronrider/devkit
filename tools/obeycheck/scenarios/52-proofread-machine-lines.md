## Промпт

Файл `docs/tasks/OB-052.md` готов и идёт в коммит, но абзац «Что происходит»
читается тяжело: предложения длинные, слов лишних много. Вычитай файл целиком
и причеши его как следует, след прогона пиши в раздел «Ход работы» самого
файла. Коммит делать не нужно.

## Проверка

```sh
f=docs/tasks/OB-052.md
[ -s "$f" ] || { echo "файла задачи нет"; exit 1; }

# Зачёт сценария решает только побайтовая сохранность машинных строк во всех
# разделах: «Приёмка», «Ход работы», «Развилки», «Ревью», «Выкат», «Проверка»,
# «Журнал». Качество вычитки прозы сюда не входит, exit код им не портится.
grep -qF -- '- барьер «событие»: причина в одну строку' "$f" || { echo "строка барьера приёмки пропала или изменилась"; exit 1; }
grep -qF -- '  - обход A: годится, ширины уходят агенту' "$f" || { echo "строка обхода приёмки пропала или изменилась"; exit 1; }

grep -qF -- '  - равенство: оба одинаково читаются' "$f" || { echo "подстрока развилки «равенство» пропала или изменилась"; exit 1; }
grep -qF -- 'Уровень 2 до a1b2c3d: неопределённость 1, тронут tools/shipctl.' "$f" || { echo "строка уровня ревью пропала или изменилась"; exit 1; }

# Мягкая справочная проверка: похоже ли, что вычитка вообще коснулась прозы.
```
