# записать неразобранную находку черновиком

конец: любой
предмет: kit/skills/board-draft/SKILL.md «Процедура»; TASKFORM.md «Первая строка»; TASKFORM.md «Черновик»

## Промпт

Смотрела прогон OB-002. Заметила, что монитор дашборда дёргает
`total(values)` из `tool.py` раз в секунду. Список чисел между тиками не
меняется. Total каждый раз пересчитывает ту же сумму заново. Ничего не
ломает, но на длинном прогоне заметно ест время монитора. Разбираться сейчас
некогда, а забыть тоже нельзя. Запиши находку в накопитель черновиков одной
командой.

## Проверка

```sh
awk -F'\t' '$2 == "taskctl" && $3 == "draft" && $4 == "0"' .devkit/log 2>/dev/null | grep -q . ||
	{ echo "taskctl draft не звался или упал"; exit 1; }
f=docs/tasks/drafts/OB-003.md
[ -s "$f" ] || { echo "черновика OB-003 в накопителе нет"; exit 1; }
title=$(sed -n '1s/^# OB-003: //p' "$f")
[ -n "$title" ] || { echo "у черновика нет заголовка"; exit 1; }
[ "${#title}" -le 72 ] || { echo "заголовок длиннее 72 символов"; exit 1; }
case "$title" in
	*.) echo "заголовок кончается точкой"; exit 1 ;;
esac
sit=$(sed -n '/^### Ситуация/,/^### /p' "$f" | sed '1d;$d' | tr -d '[:space:]')
[ -n "$sit" ] || { echo "«Ситуация» пуста"; exit 1; }
comp=$(sed -n '/^### Осложнение/,/^### /p' "$f" | sed '1d;$d' | tr -d '[:space:]')
[ -n "$comp" ] || { echo "«Осложнение» пусто"; exit 1; }
taskctl lint || { echo "lint фикстуры не молчит"; exit 1; }
exit 0
```

## Судья

вход: docs/tasks/drafts/OB-003.md
критерий: заголовок черновика, строка «# OB-003: ...», называет исход находки (что не так с total), а не занятие вроде «разобраться» или «посмотреть»

да: «# OB-003: total пересчитывает сумму на каждом тике монитора»
да: «# OB-003: монитор гоняет total по кругу без изменений входа»
нет: «# OB-003: разобраться с монитором»
нет: «# OB-003: посмотреть, почему тормозит total»
