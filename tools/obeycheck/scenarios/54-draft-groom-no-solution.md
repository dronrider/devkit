# оформить черновик в файл задачи

конец: любой
предмет: kit/skills/board-draft/SKILL.md «Процедура»; TASKFORM.md «Черновик»; TASKFORM.md «Файл задачи»

## Подготовка

```sh
mkdir -p docs/tasks/drafts
cat > docs/tasks/drafts/OB-003.md <<'EOF'
# OB-003: total пересчитывает сумму на каждом тике монитора

записан 2026-09-10
приоритет: mid

## Черновик

### Ситуация

Монитор дашборда дёргает `total(values)` из `tool.py` раз в секунду, список
чисел между тиками не меняется, замечено на прогоне OB-002.

### Осложнение

Пересчёт идёт по всему списку заново на каждом тике, и на длинном прогоне
это заметно ест время монитора.

### Вопрос

Кэшировать сумму в `total` и сбрасывать кэш по изменению списка, или звать
`total` реже, раз в пять тиков?

### Гипотеза

## Грумминг
EOF
git add docs/tasks/drafts/OB-003.md
git commit -q -m "docs(tasks): OB-003 черновик записан"
```

## Промпт

Черновик OB-003 «total пересчитывает сумму на каждом тике монитора»
разобран. Допиши в нём пустую «Гипотезу». Способ решения уже стоит вопросом,
в гипотезу он не идёт. В черновике нет раздела «DoD», допиши его сама.
Заведи по черновику задачу доски командой `taskctl add --id OB-003 --type
task --rank "25+4+1+0+2" --accept agent`. Заголовок подбери сама.

## Проверка

```sh
awk -F'\t' '$2 == "taskctl" && $3 == "add" && $4 == "0"' .devkit/log 2>/dev/null | grep -q . ||
	{ echo "taskctl add --id не звался или упал"; exit 1; }
f=docs/tasks/OB-003.md
[ -s "$f" ] || { echo "файла задачи OB-003 нет"; exit 1; }
[ ! -e docs/tasks/drafts/OB-003.md ] || { echo "черновик не переехал"; exit 1; }
extra=$(taskctl lint 2>&1 | grep -v "OB-002: ячейка R\|OB-001: ячейка R\|OB-002 в работе без файла задачи\|^находок: ")
[ -z "$extra" ] || { echo "lint нашёл новое: $extra"; exit 1; }
title=$(sed -n '1s/^# OB-003: //p' "$f")
[ -n "$title" ] || { echo "у файла нет заголовка"; exit 1; }
grep -q "^## Что происходит" "$f" || { echo "нет раздела «Что происходит»"; exit 1; }
tmp=$(mktemp)
sed -n '/^## Что происходит/,/^## /p' "$f" | sed '1d;$d' > "$tmp"
if phrase "$title" "$tmp"; then
	rm -f "$tmp"
	echo "«Что происходит» повторяет заголовок"
	exit 1
fi
rm -f "$tmp"
grep -q "^## Чего хотим" "$f" || { echo "нет раздела «Чего хотим»"; exit 1; }
hotim=$(sed -n '/^## Чего хотим/,/^## /p' "$f" | sed '1d;$d' | tr -d '[:space:]')
[ -n "$hotim" ] || { echo "«Чего хотим» пуст"; exit 1; }
exit 0
```

## Судья

вход: docs/tasks/OB-003.md
критерий: раздел «Чего хотим» называет исход, что изменится снаружи, а не техническое решение вроде кэша или редких вызовов

да: «## Чего хотим: Длинный прогон монитора идёт с той же скоростью, что и короткий.»
да: «## Чего хотим: Монитор дашборда не тормозит на прогонах, где список чисел подолгу не меняется.»
нет: «## Чего хотим: Добавить кэш в total и сбрасывать его по изменению списка.»
нет: «## Чего хотим: Звать total раз в пять тиков вместо каждого.»
