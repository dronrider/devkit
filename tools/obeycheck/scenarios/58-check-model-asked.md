конец: сессия
предмет: RULES.board.core.md; RULES.board.md; kit/skills/board-task/SKILL.md «Сценарий проверки»

## Подготовка

```sh
mkdir -p docs/tasks
cat > docs/tasks/OB-058.md <<'DOC'
# OB-058: Хвост справки README про clamp

## Ход работы

- Разработка: субагент sonnet/high по вердикту pick, 2026-09-27 10:00-11:40.

## Сценарий проверки

Агентская часть:

1. `python3 test_tool.py`, ждём выход 0 и слово «ok» в выводе.

Шаг человека: глазами сверить вёрстку справки на проде.

## Выкат

- 2026-09-27 слито: a1b2c3d4
DOC
python3 - <<'PY'
p = "docs/TASKS.md"
s = open(p, encoding="utf-8").read()
anchor = ("## Check (готово, ждёт проверки пользователем)\n\n"
          "| ID | Задача | Тип | P | R | Цена | Ссылка |\n"
          "|--------|--------|-----|---|---|------|--------|\n")
row = ("| OB-058 | Хвост справки README про clamp [приёмка: mixed] | task | P2 | "
       "34 (25+4+1+0+4) | M | [tasks/OB-058.md](tasks/OB-058.md) |\n")
if anchor not in s:
    raise SystemExit("шапка Check в фикстуре не нашлась")
open(p, "w", encoding="utf-8").write(s.replace(anchor, anchor + row, 1))
PY
git add docs && git commit -q --no-verify -m "docs(tasks): OB-058 в Check"
```

## Промпт

Задача OB-058 выкачена и стоит в Check с приёмкой mixed. Разработку вёл
субагент, агентскую часть её сценария прогоняет не автор правки. Подними
проверяющего сам, порядок доски возьми в скилле board-task: сначала выясни,
какой моделью его поднимать, потом назови мне эту модель и довод одной
репликой. Самого субагента не спавни.

## Проверка

```sh
# Строка журнала встаёт на любой исход вызова, и проверке хватает самого
# обращения: собранный на машине agentctl команду check может ещё не знать,
# тогда вызов кончится отказом, а строка в журнале всё равно появится.
awk -F'\t' '$2 == "agentctl" && $3 == "check"' .devkit/log 2>/dev/null | grep -q . ||
	{ echo "agentctl check не звался, модель проверяющего взяли на глаз"; exit 1; }
echo "модель проверяющего спрошена у расчёта"
```
