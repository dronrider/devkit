# сохранить обсуждение и полную форму черновика

конец: сессия
предмет: kit/skills/board-draft/SKILL.md; TASKFORM.md «Черновик»

## Промпт

Запиши в накопитель черновик по нашему обсуждению, реализацию сейчас не делаем.
На прогоне OB-002 я проверила уведомитель: две параллельные сессии меняют
общий адрес, и вчера 17 уведомлений первой сессии пришли в чат второй.
Хочу, чтобы каждая сессия отправляла уведомления в свой чат.

Сначала я предлагала режим manual-switch. Потом отменила этот вариант:
запускаю сессии с телефона, переключать адрес вручную неудобно. Это решение
сохранить: manual-switch исключён именно из-за запуска с телефона.
Совместимость с форматом csv-v1 обязательна: его читает мой старый монитор.
Ты предложил registry-v2, но я его не выбирала: это пока предположение агента,
сравнение вариантов оставляем на грумминг. Кроме этого вопросов не обсуждали.

## Проверка

```sh
awk -F'\t' '$2 == "taskctl" && $3 == "draft" && $4 == "0"' .devkit/log 2>/dev/null | grep -q . ||
    { echo "taskctl draft не звался или упал"; exit 1; }
f=docs/tasks/drafts/OB-003.md
[ -s "$f" ] || { echo "черновика нет"; exit 1; }
python3 - "$f" <<'PY'
from pathlib import Path
import re
import sys

text = Path(sys.argv[1]).read_text()
headings = re.findall(r'^### (.+)$', text, re.M)
required = ['Ситуация', 'Осложнение', 'Вопрос', 'Гипотеза']
assert headings == required, f'неполная форма или неверный порядок: {headings}'
for name in required:
    part = re.search(r'^### ' + re.escape(name) + r'\n(.*?)(?=^##?\s|^###\s|\Z)', text, re.M | re.S)
    assert part and part.group(1).strip(), f'пустой подраздел {name}'
assert 'OB-002' in text and re.search(r'\b17\b', text), 'потерян источник или пример наблюдения'
body = text.lower()
for token in ['manual-switch', 'телефон', 'csv-v1', 'монитор', 'registry-v2']:
    assert token in body, f'потеряна фактура обсуждения: {token}'
assert re.search(r'исключ|отказ|отмен|отверг', body), 'не сохранён отказ от варианта'
assert re.search(r'предполож|гипотез|не (выбра|утверж|приня)|пока.*агент', body), 'не сохранена неопределённость предложения агента'
PY
```
