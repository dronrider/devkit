# приписка снимает осиротевший ID из состава цели

конец: любой
предмет: kit/skills/board-groom/SKILL.md «Исходы разбора»

## Подготовка

```sh
mkdir -p docs/tasks/drafts
cat > docs/tasks/drafts/OB-005.md <<'DOC'
# OB-005: виджет состава пропадает при узкой панели

записан 2026-10-20

## Черновик

### Ситуация

Экран цели рисует состав списком, а на телефоне панель уже экрана и список
уезжает за край.

### Гипотеза

Состав сворачивается в кольцо с подписями, раскрытие по тапу.
DOC
cat > docs/tasks/OB-20.md <<'DOC'
# OB-20: Экран цели в панели

## Что происходит

Экран цели показывает состав задач и кольцо прогресса, панель уже рабочего
экрана.

## Задачи цели

Состав держит OB-20 (сама цель) и черновик OB-005 (виджет состава), он
приписывается к этой строке.

## Журнал
DOC
python3 - <<'PY'
p = "docs/TASKS.md"
s = open(p, encoding="utf-8").read()
old = "| OB-002 | README называет утилиту старым именем | task | P2 | 35 (25+4+1+0+3, S+2) | S | [tasks/OB-002.md](tasks/OB-002.md) |\n"
row = "| OB-20 | Экран цели в панели | task | P2 | 30 (20+4+2+0+4) | M | [tasks/OB-20.md](tasks/OB-20.md) |\n"
if old not in s:
    raise SystemExit("строка OB-002 в фикстуре не нашлась")
open(p, "w", encoding="utf-8").write(s.replace(old, old + row))
PY
```

## Промпт

Черновик OB-005 из накопителя решено не оформлять отдельной строкой. Его
предмет входит в задачу OB-20. Разбери его припиской и наведи порядок в
текстах, куда до этого ссылался его ID.

## Проверка

```sh
grep -q '^## Из черновика OB-005' docs/tasks/OB-20.md ||
	{ echo "приписки нет: раздел «Из черновика OB-005» не приехал в файл задачи"; exit 1; }
[ ! -f docs/tasks/drafts/OB-005.md ] ||
	{ echo "черновик остался в накопителе"; exit 1; }
grep -q 'taskctl' "$OBEY_TRANSCRIPT" ||
	{ echo "taskctl не звался, приписка делалась руками"; exit 1; }
section=$(awk '/^## Задачи цели/{f=1;next} f && /^## /{f=0} f' docs/tasks/OB-20.md)
echo "$section" | grep -q 'OB-005 (' &&
	{ echo "осиротевший ID со скобкой остался членом состава"; exit 1; }
exit 0
```
