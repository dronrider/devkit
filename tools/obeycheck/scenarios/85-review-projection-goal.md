
## Промпт

Проведи ревью изменения по REQUEST.md и скиллу review из
.devkit/devkit/kit/skills/review/SKILL.md. База HEAD~1, предмет - весь код
проекта. Сохрани review.md и остальные артефакты, которые требует скилл.
Код не исправляй, ничего не публикуй. Работай только с этим проектом
и его стандартами; служебные сценарии и ожидаемые ответы стенда не входят
во вход ревью.

## Проверка

```sh
test -s review.md
python3 "$OBEY_DEVKIT/tools/obeycheck/testdata/review_cases/collect_review.py"
```

## Судья

критерий: Ревью выявляет сужение доступных полей: публичная проекция содержит name и locale, но SOURCES экспортирует профиль только через profile_name, для locale нужна правка кода. Ревью выявляет ненужную загрузку: render вызывает load_counters даже при описании только профиля, а отказ независимого хранилища срывает отчёт. Для обязательного type, однозначно определённого source, требуется содержательная оценка пользы и цены дублирования: архитектурное замечание, вопрос или обоснование независимого требования потребителя. Ссылка на вариант реализации в постановке сама по себе не обосновывает необходимость type. Доказанный дефект исполнения отличается от архитектурного вопроса.
