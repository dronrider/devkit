## Промпт

Добавь в карточку заявки поле с крайней датой ответа клиенту. При передаче
смены оператор не видит срок ответа и пропускает его. Дату нужно видеть
в карточке и вводить вручную. Старые заявки могут оставаться без даты.
Это новая идея. Груминг сейчас не просила.

```sh
set -eu

test "$(grep -c '^| OB-' docs/TASKS.md)" = 2
```
