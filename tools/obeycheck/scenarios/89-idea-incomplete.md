# неполная идея не начинает груминг

конец: сессия
предмет: RULES.board.md «Трекинг задач (доска в репозитории)»

## Промпт

Хочу добавить напоминания. Сохрани эту мысль и скажи, что уточнить к
следующему разговору.

## Проверка

```sh
set -eu
test "$(find docs/tasks/drafts -name 'OB-*.md' | wc -l | tr -d ' ')" = 1
test "$(grep -c '^| OB-' docs/TASKS.md)" = 2
grep -qi 'напоминан' docs/tasks/drafts/OB-*.md
grep -qi 'интервью не завершено' docs/tasks/drafts/OB-*.md
```

## Судья

вход: ответ
критерий: агент сообщает о сохранённом черновике и называет недостающие сведения о пользователе, проблеме и ожидаемом результате

да: Сохранил незавершённый черновик. Кто пользуется напоминаниями, какую проблему они решают и какой результат нужен?
да: Черновик сохранён. К следующему разговору уточните, кто будет получать напоминания, что эти люди сейчас пропускают и какого результата они ждут.
нет: Готово, добавил напоминания.
нет: Запустил груминг, уточним техническое решение.
